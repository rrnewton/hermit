pub fn suite_tests(source: &str) -> Result<BTreeMap<String, bool>, String>
Expand description

The test functions a suite’s source declares, each with whether it is ignored.

A test is a top-level fn whose attributes include #[test]; it is ignored when they also include #[ignore] or #[ignore = "..."], before or after #[test]. Every other attribute on a test must be neutral: #[should_panic] in any form, lint and documentation attributes. Among the lines it reads, it REFUSES what it does not understand:

  • any attribute that names test, ignore, cfg or cfg_attr other than the forms above, anywhere in the file: #[cfg_attr(all(), test)], #[tokio::test], #[cfg(test)], a conditional #[cfg_attr(.., ignore)];
  • such an attribute on an indented line (a nested module’s test, or a macro’s);
  • any attribute it does not know on a function, which could be a test-generating macro;
  • #[ignore] without #[test], #[test] on anything but a top-level fn, a test declared twice, and an inner attribute other than a lint.

It is not a Rust parser: it skips an attribute that follows a block comment on the same line, takes a declaration inside a string or a block comment for a real one, and does not follow include!, #[path] and #[macro_use] modules, or macros. The node checks the result against Nextest’s own list of the built suite, which is authoritative, so the two together see every test added, removed or ignored; this is the check that needs no build, and the one history can make.
