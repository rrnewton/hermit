cohort_prepare_command
The exact payload a non-default cohort’s prepare node runs: prepare the cohort, then assert the published record, so every consumer’s ancestry contains the cohort check by construction. A cohort with a pinned build mode (PreparedCohort::pinned_build_mode) prepares in that literal mode in every run — its binaries never come from the Buck harvest, so forwarding the run’s mode would either refuse (buck) or mislabel the record; an unpinned cohort forwards the run’s mode. The cohort’s compile node built its test executables first (the prepare listings then compile only the test harnesses), mirroring the workspace compile/prepare split without the unified workspace build: a cohort selection must never widen to the workspace union.
