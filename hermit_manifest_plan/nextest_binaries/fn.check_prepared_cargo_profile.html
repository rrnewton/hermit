Expand description

Refuse a prepared record that assert must not accept for producer.

record is the raw prepared record (target/ci/nextest-binaries/current.json) and producer the graph profile whose prepare the asserting lane depends on. The record must name the Cargo profile prepare producer builds in. The shared record is rewritten by whichever producer ran last, so a focused lane’s prepare privileged (dev profile) can leave a dev record behind for a later full-lane consumer that expects validate-profile executables; every selection is still present, so only the profile tells them apart.

A record older than schema 6 names no profile and is refused rather than guessed from its executable paths: a path under target/<dir>/ names a Cargo output directory, not a profile (the default test profile writes target/debug, and a custom target directory moves the prefix), and the remedy, rerunning the producer, costs only that producer’s run.

selections is the asserted selection profile and producer_nodes the graph nodes that run prepare producer; both only shape the message.
