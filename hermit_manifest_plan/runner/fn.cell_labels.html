Expand description

The run types a cell belongs to: its test’s labels, plus its mode’s labels for its backend, or DEFAULT_RUN_TYPE alone when both are empty. A selection keeps a cell when the cell’s run types meet the selection’s --labels, and a selection without --label selects the default run type, so a cell labelled only with a focused run type (such as sabre-compat-only) is required there and nowhere else.
