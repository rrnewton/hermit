The Hermit an import run (E2E_IMPORT_RESULTS) compares logs with: HERMIT_BIN, else the Hermit ci/buck-e2e/stage staged for the imported Buck cells (ci/buck-e2e/staged/hermit, which -c hermit_e2e.hermit=staged cells run). An import runs no cell, but its parity post-pass runs hermit log-diff, and a Buck run builds no target/debug/hermit for it to fall back on.
