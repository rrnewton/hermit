pub fn interpreter_refusal_evidence(
    cell: &SelectedCell,
    history: &[CellResult],
) -> Option<InterpreterRefusalEvidence>
Expand description

The evidence that history, the finished attempts of cell after its retries, measured nothing about Hermit: this host’s own program interpreter refused the CPU Hermit presented, in every run of every attempt, and another host could have run it. None keeps the cell’s result. All of these must hold:

  • cell declares no image, so the interpreter is this host’s;
  • every attempt is a FAIL with runs, and no run ran inside an image (runs_inside_an_image): no v2 retry ran, because the cell was not eligible for it or the run had no rootfs. A v2 retry refused before launch (is_v2_retry_refusal) is an ERROR row with no runs, so it keeps the cell’s result too;
  • every run of every attempt is a loader rejection whose evidence names the level its interpreter needs and the CPU profile Hermit presented and why (attempt_interpreter_refusal), and every run names the same level, profile and reason;
  • that refusal is one another host could avoid (host_dependent_refusal_error): the level is above the presented profile’s and no higher than x86-64-v3, and the host chose the profile.

A level that is not above the presented one (glibc naming x86-64-v2 under x86-64-v2: Hermit presented a CPU short of its own profile), a profile the evidence does not name, a profile chosen for another reason than the host (an explicit x86-64-v2, say), any run whose guest started, or a v2 retry keeps the FAIL. Requiring this of every attempt, not only the last, keeps a failure an earlier attempt measured.
