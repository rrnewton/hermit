pub fn strict_run_arms_the_preemption_timer(backend: &str) -> bool
Expand description

Whether hermit run --strict on backend arms the PMU preemption timer, whose retired-conditional-branch counter is then the run’s virtual clock, so the hermit binary refuses the run where it reports no exact_branch_counter unless the run has no timeslice. It mirrors the CLI’s capability table: hermit-cli’s backend_delivers_preemption_timer, the backend’s delivers_preemption_timer_events capability (ptrace, e9patch preprocessing on it, and KVM since Reverie 9443a6b2), on which RunOpts::reads_the_branch_counter keys the --strict refusal.

Unlike backend_capability, this is decided on the machine that runs the cell and never enters a plan row: a plan row that names a host capability routes the cell off remote execution, and remote workers differ in CPU model, so the plan cannot say which of them count exactly.
