The fixture loadability verdict the v2 rootfs carries (fb-only/v2_rootfs/fixture_glibc_check.sh, issue 5476). It is tab-separated: schema 1, then status checked, or status unchecked REASON where the check could not run, then one missing PATH ITEM line per symbol version or library that a fixture file needs and the rootfs lacks, PATH relative to the prebuilt fixtures root (build_root).
