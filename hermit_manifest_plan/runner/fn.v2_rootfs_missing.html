pub fn v2_rootfs_missing(
    oci_dir: &Path,
    cell: &SelectedCell,
) -> Result<Vec<String>, String>
Expand description

What the v2 rootfs at oci_dir lacks for the files of cell’s prebuilt fixture directory, by its verdict (V2_ROOTFS_VERDICT_FILE): Ok with one “PATH needs ITEM” entry per lacking item, empty where the rootfs can load every file (and for a cell with no prebuilt fixture), or Err with why the verdict is unusable: absent, unreadable, malformed, or written by a check that did not run.
