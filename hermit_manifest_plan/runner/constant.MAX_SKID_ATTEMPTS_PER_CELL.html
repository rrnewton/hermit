Attempts a cell whose every attempt is a typed PMU skid overshoot and nothing else (skid_overshoot_only_reports) gets in all: the one shared skid budget (detcore_model::SKID_RETRY_MAX_ATTEMPTS), separate from the generic MAX_ATTEMPTS_PER_CELL bound. A history may run past the generic bound only while every attempt so far is skid-only; the first non-skid attempt returns the cell to the generic bound. Exhausting this budget selects the SKID_INFRA_VERDICT verdict, not a test failure.
