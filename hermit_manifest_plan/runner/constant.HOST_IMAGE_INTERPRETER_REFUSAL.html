The error kind of the one HOST-INAPPLICABLE row a run records, under RECORD_INTERPRETER_REFUSALS_ARG only, in place of a cell’s whole history when this host’s own program interpreter refused the CPU Hermit presented in every run of every attempt (interpreter_refusal_evidence).
