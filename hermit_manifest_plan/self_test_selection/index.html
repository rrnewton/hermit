Module self_test_selection 

Source
Expand description

Change-set selection for the tool self-tests (selftest.<name> nodes) that run only when a change touches their trigger paths.

A self-test with trigger paths (crate::validation_dag::ToolSelfTest’s run_when_changed) runs when any path changed since the merge base with origin/main, committed or not, lies under one of them (is_under). A self-test that does not run prints one line containing NOT_RUN_MARKER, so the node log and the scheduler’s one-line node summary both say it was not run.

Selection errs toward running. Main always runs, and so does any change set this module cannot resolve: a shallow clone, a missing origin/main, an empty change set, or any git failure.
