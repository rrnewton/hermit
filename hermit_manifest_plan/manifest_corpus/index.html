Module manifest_corpus 

Source
Expand description

Compatibility-corpus sections of E2E manifest documents.

A corpus is one lane’s settings written once and a list of (label, argv) rows written once. A manifest document may carry it as a corpus: section; expand_corpus turns every row into an ordinary test recipe before either validator or the runner sees the document, so a corpus row is validated, selected, executed and reported exactly like a hand-written test. The expansion adds no semantics of its own: everything it writes is an existing manifest key.

Constants§

ROOT_DIR_PLACEHOLDER
The repository root, in a direct argv element.
VALIDATE_RUN_STATE_PLACEHOLDER
The validation’s per-run state directory, in a direct argv element: the value of the harness’s VALIDATE_RUN_STATE. A cell that names it in a run without one is refused rather than run with the literal text.
XDG_CONFIG_HOME_PLACEHOLDER
The cell’s own copy of tests/e2e/xdg-config, in a direct argv element: the directory the guest’s XDG_CONFIG_HOME names. The harness prepares it in the cell directory before the run, and a verify guest on every backend sees it at /tmp/e2e/xdg-config, bound from there (the runner’s equalized inputs), so every directory on a path below it is one the cell’s own run owns: the guest’s private /tmp, the /tmp/e2e directory Hermit creates in it for the binds, and the bound copy. A program that stats every ancestor of its argument (readlink -f, realpath) therefore reads no directory another cell can change, which a path below {{VALIDATE_RUN_STATE}} cannot promise (https://github.com/rrnewton/hermit/issues/3975). Any other mode names the cell directory’s copy on the host.

Functions§

check_direct_placeholders
Refuse a direct argv that spells any {{...}} token other than the known placeholders, so a typo cannot reach a guest as literal text.
direct_shell_word
Render one direct argv element as a shell word for a command line run from the repository root, as the rerunnable command files do: literal text through quote, {{ROOT_DIR}} as "$PWD", and {{VALIDATE_RUN_STATE}} and {{XDG_CONFIG_HOME}} as expansions of their variables that refuse to run when the variable is unset, as the harness does.
expand_corpus
Expand a document’s corpus: section, if it has one, into ordinary test: recipes appended after any hand-written ones. A document without the section is returned unchanged.
resolve_direct_placeholders
Substitute the placeholders in a direct argv. run_state is the harness’s VALIDATE_RUN_STATE, when it has one, and xdg_config_home the cell’s XDG configuration directory, when the caller has a cell.
validate_run_state
The harness’s VALIDATE_RUN_STATE, for resolve_direct_placeholders.
