CoverageRow
Per-DAG-node test-coverage obligation outcome. Current producers compute this from dagrun’s structured per-step test-count files and terminal outcomes, crossed against the PLANNED set of test.* DAG nodes in the lane manifests. Historical rows were reconstructed from human-readable banners. The obligation is SATISFIED iff planned_test_nodes > 0 and both failure lists were reported and empty. This is the per-node replacement for the blunt aggregate filtered_tests == 0 predicate, which could not distinguish a full run’s legitimate cross-shard filtering (~693 tests) from a narrowed-subset masquerade.
