pub fn stale_lock_twin(
    argv: &[String],
    scratch: &Path,
) -> Result<StaleLockTwin, String>
Expand description

Run cargo with argv, a lock-resolving call’s exact arguments, in a fixture workspace under the empty directory scratch whose committed lock file is stale, then run its mutant without --locked and --frozen there.

The fixture has a member for each package argv selects, with the features, targets and custom profile it names, so that the call fails at the lock file rather than at a missing package. After its lock file is generated, each selected member gains a path dependency on one more member, the change a manifest edit without its lock update makes. Nothing is fetched: Cargo runs offline, with its target directory under scratch.
