pub fn script_cargo_calls(path: &str, text: &str) -> Vec<ScriptCargoCall>
Expand description

Every Cargo call in the script at path (for its language) with the contents text.

A shell script is scanned as cargo_calls scans a command. In a Rust script each Command::new("cargo") is a call, locked when a "--locked" or "--frozen" literal comes after it and before the next Command::new( or the end of its enclosing block, which the formatted source indents less.
