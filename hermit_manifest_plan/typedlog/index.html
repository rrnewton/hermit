One typed logging interface (design: dev-hermit ai_docs/2026-11-01-typed-logging-design.md).

Producers build a typed Record and call emit; they never open a sink directly. Each record carries the complete legacy payload verbatim alongside normalised query fields, so the git connector is byte-identical by construction. The git connector is authoritative (its failure fails emit); optional sinks are isolated. The internal Logger connector lives outside this OSS tree (dev-hermit ci-hub), shelling out to logger_cat; it is deliberately not implemented here.
