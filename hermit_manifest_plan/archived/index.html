The archived execution paths: the backend and the preprocessing step the owner stopped developing, whose tests left the per-commit validation for the nightly pressure run.

Owner direction, 2026-10-25: “mark our sabre and e9patch backends as archived for now and move their tests to nightly only and not actively develop them.” Archived code still builds in every validation (the third-party-backends workspace build, Clippy and the SaBRe smoke test test.sabre_examples), so it cannot rot silently, but no feature work lands on it.

A manifest cell on an archived backend that would belong to the full run type belongs to ARCHIVED_RUN_TYPE instead (crate::runner::cell_labels). Full validation, its portable and hosted subsets, and the Buck route (whose cells are ci/expected-e2e-plan.json’s) therefore do not select it, and the scorecard reports it as not selected by full: a red cell, which the nightly pressure sweep’s red part runs three times a night, and a verify cell, which its parity-all part measures beside ptrace. A cell that already names a focused run type, such as sabre-compat-only, keeps it.
