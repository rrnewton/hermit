The branch settings of ci/landing-branches.env.

The landing branch is the branch changes land on: the merge queue’s base, the branch validation measures a checkout against, and (for Reverie) the history a Hermit Reverie pin must be on. The upstream branch is the fast-forward-only inbox that mirrors facebookexperimental. They are separate settings, both main today.

A setting is the environment variable named after its key when that is set, and otherwise the key’s KEY=value line in the checkout’s SETTINGS_FILE. There is no built-in default: a setting that is missing, empty, repeated or not a plain branch name is an error, so no reader can quietly fall back to main. scripts/lib/landing_branch.sh and scripts/landing_branch.py implement the same rule.

Standard library only: scripts/check-reverie-pin.rs and scripts/check-record-version-floor.rs include this file with #[path] and are compiled by plain rustc --edition=2021, while Buck compiles this library as edition 2024.
