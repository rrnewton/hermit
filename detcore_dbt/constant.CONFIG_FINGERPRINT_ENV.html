The coordinator’s detcore::config_wire_fingerprint, which this runtime compares with its own before it decodes the coordinator’s first frame (initial_dbt_config). Detcore’s configuration and its global RPC travel as positional bincode, so a runtime built from another tree would decode either wrongly, or fail partway through a run, instead of being refused by name. Hermit sets it in every DBT launch; PRIVATE_ENV_PREFIX hides it from the guest and keeps it across instrumented execs.
