Expand description

Initializes native per-thread scratch state and registers the application thread with Detcore before it begins executing guest code.

Copied process runtimes retain scratch-only state until exec installs a new scheduler owned by that process.

Returns a positive retry status when a native child’s parent snapshot is not published yet, so the client can retry outside DynamoRIO’s thread-init path.

§Safety

The native client must pass a valid writable scratch pointer, a live DynamoRIO context, and callback pointers valid for this application.
