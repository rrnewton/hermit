9//! Rewriting aarch64 load/store-exclusive retry loops to FEAT_LSE atomics.
10//!
11//! On aarch64 an `LDXR`/`STXR` pair retries whenever the local exclusive
12//! monitor is cleared between the two, which any exception does: a timer tick,
13//! an IPI, a page fault, a PMU overflow, a ptrace stop. Each retry retires the
14//! loop's branches again, so the retired-branch count of identical guest work
15//! depends on host interrupt timing, and Hermit's branch-counted schedule
16//! cannot be replayed exactly. A single LSE atomic cannot retry, so a program
17//! whose exclusive loops have been rewritten retires a fixed number of
18//! branches for the same work.
19//!
20//! [`insn`] holds the decoder and the encoders; [`rewrite`] holds the idioms
21//! and the in-place replacement; [`elf`] applies them to the code of an ELF
22//! file's executable sections, which [`mapping`] tells from the data those
23//! sections can also hold. All four are pure functions of their input and
24//! compile on every architecture, so their tests run everywhere.
25//! `hermit-cli` writes rewritten files with them; Detcore applies the same
26//! rewrite to a guest's mapped pages.
27
28pub mod elf;
29pub mod insn;
30pub mod mapping;
31pub mod rewrite;
32
33/// Bumped whenever the rewrite's output for the same input can change. It is
34/// part of the overlay cache key, so a cached artifact from an older
35/// rewriter is never reused, and it is the algorithm identity a preemption
36/// record states for its run's rewrite (`crate::preemptions`), so a replay
37/// under another version is refused rather than retiring other
38/// instructions. 3: only code is rewritten, as [`mapping`] tells it from
39/// data; none of the changes since 2 had bumped it, though the canonical
40/// shapes the refusal census added, the conditional compare-and-swap
41/// refusal, the direct-entry decoding and the positive allow-list each
42/// changed what the rewrite writes. 4: a sequence a known entry (the
43/// loader's entry, a defined function symbol or an FDE start) points into
44/// is refused, as is a sub-word compare whose head is one. 5: literal loads
45/// of an FDE entry protect its instruction bytes from rewriting; only ADR
46/// address-taking can use the function-entry exemption. 6: literal readers
47/// in unknown executable ranges protect the bytes they reference, including
48/// bytes in other sections; only proven data is excluded from that scan.
49/// 7: so do the reads through an `ADRP`'s page or an `ADR`'s address: an
50/// access the instruction bounds protects those bytes, and any other use,
51/// or the address held where the scan stops, every executable byte.
52/// 8: a UDF #imm16 word, which traps and never branches, no longer refuses
53/// the image. 9: nor does a word of the SVE encodings, which hold no branch.
54/// 10: flag-setting read-modify-write loops retain the original ALU
55/// instruction after the LSE atomic so their outgoing flags are preserved.
56/// 11: literal and base readers in executable segment bytes no
57/// executable section covers protect the bytes they read, under
58/// their own refusal name, and direct branches out of those bytes
59/// count as branch targets.
60pub const REWRITE_FORMAT_VERSION: u32 = 11;

62/// Whether this host executes the FEAT_LSE atomics the rewrite emits.
63///
64/// The rewritten image is a program for the machine that is about to run
65/// it: without FEAT_LSE every rewritten site would raise SIGILL.
66pub fn host_has_lse_atomics() -> bool {
67    #[cfg(target_arch = "aarch64")]
68    {
69        // HWCAP_ATOMICS, Linux Documentation/arch/arm64/elf_hwcaps.rst.
70        const HWCAP_ATOMICS: libc::c_ulong = 1 << 8;
71        // SAFETY: getauxval reads the process's own auxiliary vector.
72        (unsafe { libc::getauxval(libc::AT_HWCAP) } & HWCAP_ATOMICS) != 0
73    }
74    #[cfg(not(target_arch = "aarch64"))]
75    {
76        false
77    }
78}
