9//! Descriptors a guest receives over `SCM_RIGHTS`.
10//!
11//! `recvmsg` and `recvmmsg` are the only calls that install descriptors
12//! another process sent: Linux's `scm_detach_fds` installs each descriptor
13//! that fits the receiver's control buffer, with `O_CLOEXEC` when the call
14//! passed `MSG_CMSG_CLOEXEC`, writes one `SCM_RIGHTS` message holding exactly
15//! the numbers it installed, releases the rest and sets `MSG_CTRUNC`; a
16//! `MSG_PEEK` receive installs them too. The control data the call leaves at
17//! the control buffer it was given, read up to the `msg_controllen` Linux
18//! writes back, therefore names exactly the descriptors that now exist
19//! ([`ReceiveGeometry::delivered`]).
20//!
21//! Where the tool shares the guest's descriptor table (the in-guest
22//! backends), Detcore discovers such a descriptor when a call first names it
23//! (`FileMetadata::discover_fd_from_current_process`). Elsewhere (ptrace,
24//! KVM) nothing would, and every later call through it that consults
25//! Detcore's table failed with `EBADF`
26//! (<https://github.com/rrnewton/hermit/issues/4547>). So there Detcore records
27//! each received descriptor as the receive returns
28//! ([`Detcore::record_received_descriptors`]), from the facts the in-guest
29//! discovery takes (`fcntl(F_GETFD)`, `fcntl(F_GETFL)` and `fstat`, here
30//! taken through the recording), through the same
31//! `FileMetadata::add_discovered_fd`, so the
32//! record is the description the in-guest discovery makes: a directory, for
33//! one, gets a sorted stream of its own. Unlike that discovery, a received
34//! descriptor is never given the container's stdio resource (it is not the
35//! container's stdio), nor rebuilt as a fixed procfs file or held for the
36//! session's `/proc/cpuinfo` decision (those are an exec image's own
37//! descriptors); a rendered procfs placeholder is adopted through the
38//! placeholder registry instead, as `Detcore::adopt_received_placeholders`
39//! adopts one when it is first named.
40//!
41//! An anonymous inode has no file type, so `fstat` does not tell its kind.
42//! Its descriptor link does: one that reads `anon_inode:inotify` (an injected
43//! `readlinkat` of `/proc/thread-self/fd/<fd>`) is recorded as an inotify
44//! instance, as the in-guest discovery records it, so its reads renumber
45//! rename cookies (`crate::syscalls::inotify`).
46//!
47//! Not recorded, as before, each named in a warning: any other anonymous
48//! inode (eventfd, signalfd, timerfd, epoll, pidfd, userfaultfd, ...), which
49//! an ordinary record would mishandle
50//! (<https://github.com/rrnewton/hermit/issues/4107>'s signalfd mode), and
51//! one whose link cannot be read; a receive whose buffers overlap so that the
52//! call may have overwritten its
53//! own inputs, whose vector cannot be read in full, or whose inputs changed
54//! before the attempt that succeeded; and every receive on the background
55//! path. Without sequentialized threads no receive is recorded, logged at
56//! debug level only (`ReceiptMode`).
57//!
58//! Under record and replay every fact is taken through the recording, so
59//! replay, which serves the receive from the log and holds a stand-in in each
60//! received slot, rebuilds the table the recording built. Where the recording
61//! joined a received descriptor to an open file the receiving table holds,
62//! replay also makes the received slot name the live open file
63//! (`Detcore::install_live_alias`), and a received socket whose peer is a
64//! guest is polled in the caller's turn (`Detcore::classify_socket_peer`).
65//!
66//! Linux installs the sender's `struct file` (`receive_fd`): the received
67//! descriptor shares its status flags, directory position and lock ownership
68//! with every descriptor of that open file, the sender's included, in
69//! whichever process holds them. Detcore names that open file without asking
70//! the kernel, as <https://github.com/rrnewton/hermit/issues/4670> proposes:
71//! at the send, it queues on the receiving socket the open file description
72//! its table modeled for each descriptor carried, with the file's
73//! `(st_dev, st_ino)` from an injected `fstat`
74//! ([`Detcore::queue_sent_rights`]); at the receipt, it takes the oldest
75//! queued message whose identities are the received descriptors', in order
76//! (all of them, or a prefix where Linux set `MSG_CTRUNC`; a `MSG_PEEK`
77//! receive leaves it queued), and each received descriptor joins the
78//! description its sender's table modeled, as `dup` would, before the
79//! anonymous-inode refusal, so a received eventfd is the sender's eventfd.
80//! The decision depends only on Detcore's own model and the facts its
81//! injected `fcntl` and `fstat` take, so it is the same on every backend that
82//! records received descriptors (ptrace, KVM); before, it asked the kernel
83//! through `kcmp(KCMP_FILE)`, which KVM's executor does not answer and which
84//! the host's kernel configuration and seccomp profile can refuse.
85//!
86//! The receiving socket is known only where Detcore knows a socket's peer,
87//! in any process that holds it and through any of its aliases: the two
88//! sockets of a `socketpair`, and an `AF_UNIX` stream or seqpacket connection
89//! and the socket whose `connect` made it. Linux queues each connection on
90//! the listener's receive queue at the tail (`unix_stream_connect`,
91//! `__skb_queue_tail(&other->sk_receive_queue, skb)`,
92//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.9#n1641>)
93//! and `accept` takes it from the head (`unix_accept`, `skb_recv_datagram`,
94//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.9#n1711>),
95//! so Detcore queues each guest's connection to a name a guest bound,
96//! abstract or an absolute path, where the `connect` completed in the
97//! caller's turn, and pairs the oldest with the socket an `accept` on that
98//! listener returns, also in its turn ([`Detcore::note_unix_accept`]).
99//!
100//! That needs every connection a listener gets. So a connect or accept on
101//! the name outside the turn leaves its order unknown until the name is
102//! bound again, and so does any `AF_UNIX` stream connect Detcore cannot
103//! attribute to one bound name, for every name: one through a relative path
104//! or another spelling of a path, to a name no guest bound here, or of a
105//! socket whose type Detcore did not see made ([`UnixConnections`]). A
106//! listener bound before its path was unlinked and bound again pairs
107//! nothing: the connections Detcore tracks for the name are the later
108//! listener's. A connection made from outside Hermit is not seen at all, and
109//! shifts the pairing of those queued after it.
110//!
111//! A `socketpair` datagram socket reaches its peer only while it stays
112//! connected to it and names no other destination. A `connect` gives it
113//! another peer, or none, and Linux then purges its receive queue
114//! (`unix_dgram_connect`, `unix_dgram_disconnected`,
115//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.9#n1414>),
116//! so Detcore unpairs the two and neither queue is in lockstep any more
117//! (`DetFd::unpair_rights_peer`). A send that names its destination
118//! (`msg_namelen`, `unix_dgram_sendmsg`,
119//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.9#n1980>)
120//! queues nothing, and its peer's queue is no longer in lockstep, since the
121//! named socket may be the peer itself. A seqpacket send ignores the name
122//! (`unix_seqpacket_sendmsg`) and a stream send with one fails
123//! (`unix_stream_sendmsg`).
124//!
125//! A descriptor received any other way is a description of its own in
126//! Detcore's model, as before: through any other socket (a datagram socket
127//! not made by `socketpair`, a connection Detcore did not pair), from a
128//! sender outside Hermit or whose send Detcore did not see complete in its
129//! turn, one whose sender's table modeled no description for it, or one
130//! whose every modeled descriptor was closed before the receipt (Linux's
131//! in-flight reference keeps that `struct file` alive; Detcore's queue keeps
132//! no model alive). The in-guest backends discover received descriptors
133//! lazily and keep the separate model they had.
134//!
135//! The identities confirm what order proposes, except for anonymous inodes:
136//! every eventfd, timerfd, signalfd and epoll set has one file identity. So
137//! once a socket's queue may no longer follow its messages one for one, no
138//! anonymous inode received through it joins anything
139//! (`DetFd::take_queued_rights`). That is from the first message sent to it
140//! that was not queued (unreadable control data, facts that could not be
141//! taken, a send outside the turn, a datagram send that named its
142//! destination, more than 4096 waiting), a `connect` of a datagram socket of
143//! the pair, or the first
144//! call that took a message from it Detcore could not match while some were
145//! queued: a `read`, `readv` or `recvfrom`, a receive that released
146//! descriptors (`MSG_CTRUNC` with none installed), one outside the turn or
147//! with an untrusted layout, one whose descriptors' facts could not be
148//! taken, or one that matched a later message than the oldest. Other files
149//! out of lockstep still join where their identities match, and two open
150//! files of one file are then told apart only by order.
151//!
152//! Under record and replay the send's `fstat` goes through the recording too,
153//! and a received descriptor joins its sender's description only where the
154//! receiving table holds a descriptor of it: replay holds a stand-in in the
155//! received slot and can put the live open file there only by duplicating a
156//! descriptor of the same table. One whose description only another
157//! process's table holds is recorded from the kernel's facts, in both runs
158//! alike.

200/// The descriptors carried by the `SCM_RIGHTS` messages in a sent or
201/// received control buffer.
202pub(crate) fn received_descriptors(control: &[u8]) -> Vec<RawFd> {
203    const HEADER: usize = size_of::<libc::cmsghdr>();
204    let align = |length: usize| length.next_multiple_of(size_of::<usize>());
205    let mut descriptors = Vec::new();
206    let mut offset = 0;
207    while let Some(header) = control.get(offset..offset + HEADER) {
208        let length = usize::from_ne_bytes(header[..8].try_into().unwrap());
209        let level = i32::from_ne_bytes(header[8..12].try_into().unwrap());
210        let kind = i32::from_ne_bytes(header[12..16].try_into().unwrap());
211        let Some(data) = control.get(offset + HEADER..offset.saturating_add(length)) else {
212            break;
213        };
214        if level == libc::SOL_SOCKET && kind == libc::SCM_RIGHTS {
215            descriptors.extend(
216                data.as_chunks::<{ size_of::<RawFd>() }>()
217                    .0
218                    .iter()
219                    .map(|fd| RawFd::from_ne_bytes(*fd)),
220            );
221        }
222        if length < HEADER {
223            break;
224        }
225        offset += align(length);
226    }
227    descriptors
228}

230/// The descriptors a `struct msghdr`, read after a receive, says Linux
231/// installed through `SCM_RIGHTS`: Linux updates `msg_controllen` to the
232/// control bytes it wrote, so bytes past it (a reused buffer's earlier
233/// messages) are not read.
234fn delivered_through<M: MemoryAccess>(memory: &M, header: &Msghdr) -> Vec<RawFd> {
235    if header.msg_control.is_null() || header.msg_controllen == 0 {
236        return Vec::new();
237    }
238    let Some(address) = Addr::<u8>::from_raw(header.msg_control as usize) else {
239        return Vec::new();
240    };
241    let mut control = vec![0; header.msg_controllen.min(MAX_CONTROL_BYTES)];
242    if memory.read_exact(address, &mut control).is_err() {
243        return Vec::new();
244    }
245    received_descriptors(&control)
246}

248/// The descriptors `call`, which returned `ret`, installed through
249/// `SCM_RIGHTS`, in the order Linux reports them: those of a `recvmsg`, or of
250/// the `ret` messages a `recvmmsg` received. `None` for any other call and
251/// for a failed one. Read from guest memory after the call; a header that
252/// cannot be read names none.
253pub(crate) fn delivered_descriptors<M: MemoryAccess>(
254    memory: &M,
255    call: &Syscall,
256    ret: i64,
257) -> Option<Vec<RawFd>> {
258    if ret < 0 {
259        return None;
260    }
261    match call {
262        Syscall::Recvmsg(call) => {
263            let header: Option<Msghdr> = call
264                .msg()
265                .and_then(|address| memory.read_value(address).ok());
266            Some(header.map_or_else(Vec::new, |header| delivered_through(memory, &header)))
267        }
268        Syscall::Recvmmsg(call) => {
269            let Some(address) = call.mmsg() else {
270                return Some(Vec::new());
271            };
272            let count = (ret as usize).min(libc::UIO_MAXIOV as usize);
273            // SAFETY: `mmsghdr` is a plain C record; all-zero values are
274            // valid staging values that `read_values` overwrites.
275            let mut messages: Vec<Mmsghdr> =
276                (0..count).map(|_| unsafe { std::mem::zeroed() }).collect();
277            if memory.read_values(address.into(), &mut messages).is_err() {
278                return Some(Vec::new());
279            }
280            Some(
281                messages
282                    .iter()
283                    .flat_map(|message| delivered_through(memory, &message.msg_hdr))
284                    .collect(),
285            )
286        }
287        _ => None,
288    }
289}

334/// Reads the input-only fields of `message`; `None` if its iovec array
335/// cannot be read (Linux then fails that message with EFAULT).
336fn message_fields<M: MemoryAccess>(memory: &M, message: &Msghdr) -> Option<MessageFields> {
337    let mut segments = Vec::new();
338    if !message.msg_iov.is_null() && message.msg_iovlen > 0 {
339        let count = message.msg_iovlen.min(libc::UIO_MAXIOV as usize);
340        // SAFETY: `iovec` is a plain C record; all-zero values are valid
341        // staging values that `read_values` overwrites.
342        let mut iovecs: Vec<libc::iovec> =
343            (0..count).map(|_| unsafe { std::mem::zeroed() }).collect();
344        memory
345            .read_values(
346                Addr::<libc::iovec>::from_raw(message.msg_iov as usize)?,
347                &mut iovecs,
348            )
349            .ok()?;
350        segments.extend(
351            iovecs
352                .iter()
353                .map(|iov| (iov.iov_base as usize, iov.iov_len)),
354        );
355    }
356    Some(MessageFields {
357        name: message.msg_name as usize,
358        iov: message.msg_iov as usize,
359        iovlen: message.msg_iovlen,
360        control: message.msg_control as usize,
361        segments,
362    })
363}

365/// Whether any output range overlaps any input range other than its own
366/// counterpart: `outputs` pairs each range with whether an identical input
367/// range is its own (a header written back into itself, a control buffer
368/// filled with its own control data). Counted with sorted interval ends:
369/// the inputs overlapping `[start, end)` are those starting before `end`
370/// less those ending at or before `start`.
371fn outputs_overlap_inputs(inputs: &[Range], outputs: &[(Range, bool)]) -> bool {
372    let live = |range: &&Range| range.1 > 0;
373    let mut starts: Vec<usize> = inputs.iter().filter(live).map(|range| range.0).collect();
374    let mut ends: Vec<usize> = inputs
375        .iter()
376        .filter(live)
377        .map(|range| range.0.saturating_add(range.1))
378        .collect();
379    starts.sort_unstable();
380    ends.sort_unstable();
381    outputs.iter().any(|&((start, length), own)| {
382        if length == 0 {
383            return false;
384        }
385        let end = start.saturating_add(length);
386        let overlapping =
387            starts.partition_point(|&s| s < end) - ends.partition_point(|&e| e <= start);
388        overlapping > usize::from(own)
389    })
390}

456/// What an address a guest passed names, for `AF_UNIX` pairing

459pub(crate) enum UnixAddress {
460    /// Not an `AF_UNIX` address (its family is another, or it is too short
461    /// to have one).
462    Other,
463    /// An `AF_UNIX` name Detcore can compare: an abstract name's bytes after
464    /// `sun_family`, its leading NUL included, which Linux compares whole
465    /// (`unix_find_abstract`), or an absolute path up to its first NUL.
466    Named(Box<[u8]>),
467    /// An `AF_UNIX` address whose socket Detcore cannot name: a relative
468    /// path, which names a different file from each working directory, an
469    /// unnamed address, or one it could not read (a `connect` or `bind`
470    /// through an unreadable address fails with `EFAULT`, so only a call
471    /// that succeeded is ever attributed).
472    Unnamed,
473}

475/// What the address at `address` in guest memory (`length` bytes) names
476/// ([`UnixAddress`]).
477pub(crate) fn unix_address<M: MemoryAccess>(
478    memory: &M,
479    address: usize,
480    length: usize,
481) -> UnixAddress {
482    const PATH: usize = std::mem::offset_of!(libc::sockaddr_un, sun_path);
483    let length = length.min(size_of::<libc::sockaddr_un>());
484    if length < size_of::<libc::sa_family_t>() {
485        return UnixAddress::Other;
486    }
487    let mut bytes = vec![0u8; length];
488    let read = Addr::<u8>::from_raw(address)
489        .is_some_and(|address| memory.read_exact(address, &mut bytes).is_ok());
490    if !read {
491        return UnixAddress::Unnamed;
492    }
493    if u16::from_ne_bytes([bytes[0], bytes[1]]) != libc::AF_UNIX as u16 {
494        return UnixAddress::Other;
495    }
496    let path = bytes.get(PATH..).unwrap_or_default();
497    match path.first() {
498        Some(0) => UnixAddress::Named(path.into()),
499        Some(b'/') => path
500            .split(|&byte| byte == 0)
501            .next()
502            .map_or(UnixAddress::Unnamed, |path| UnixAddress::Named(path.into())),
503        _ => UnixAddress::Unnamed,
504    }
505}

521/// The most connections kept waiting for an `accept` on one name
522/// ([`UnixConnections`]); beyond it the name's order is unknown.
523const MAX_PENDING_CONNECTIONS: usize = 4096;
524
525/// The connections guests made to one `AF_UNIX` name a guest bound
526/// ([`UnixConnections`]).
527#[derive(Default)]
528struct PendingConnections {
529    /// Which bind of the name this is: a listener bound before the name was
530    /// unlinked and bound again keeps the earlier one, and its accepts take
531    /// connections Detcore no longer tracks.
532    generation: u64,
533    /// The connecting sockets' descriptions, oldest first, as Linux queues
534    /// the connections on the listener for `accept` to take: at the tail
535    /// (`unix_stream_connect`), from the head (`unix_accept`).
536    sockets: VecDeque<OpenFileHandle>,
537    /// A `connect` or `accept` on the name completed outside its caller's
538    /// turn, a connect Detcore could not attribute may have reached it, or
539    /// too many connections waited: which connection an `accept` takes is
540    /// unknown until a guest binds the name again.
541    unknown: bool,
542}
543
544impl PendingConnections {
545    fn lose_order(&mut self) {
546        self.sockets.clear();
547        self.unknown = true;
548    }
549}

551/// The connections waiting for an `accept` on each `AF_UNIX` name a guest
552/// bound, so that an accepted connection and the socket whose `connect` made
553/// it are paired (`Detcore::note_unix_accept`). One per run: every task of
554/// the process tree shares it (`ThreadState::unix_connections`), as it shares
555/// the guest clock, so a bind, a connect and an accept in different threads
556/// or processes meet.
557///
558/// A connect Detcore cannot attribute to one of these names may have
559/// reached any of them: one through a relative path or another spelling of
560/// a path (a doubled slash, a `..`, a symlink or hard link, a renamed
561/// socket file), to a name no guest bound here, through an absolute path
562/// from a task whose root may not be the container's (`chroot`, where one
563/// path names another file), or of a socket whose type Detcore did not see
564/// made. Every name's order is then unknown until it is bound again
565/// ([`UnixConnections::lost`]), so no accept pairs with a socket whose
566/// connection it may not have taken. A bind through an absolute path from
567/// such a task is not tracked. A connection made from outside Hermit is not
568/// seen at all.
569///
570/// That costs precision, never correctness: one stream connect to a socket
571/// no guest bound here, as a glibc user or group lookup makes through NSS
572/// (nscd, systemd-userdb), stops pairing for every name until it is bound
573/// again, and descriptors received over those connections are then handled
574/// as on main.
575#[derive(Default)]
576pub(crate) struct UnixConnections {
577    names: BTreeMap<Box<[u8]>, PendingConnections>,
578    /// The last bind's generation ([`PendingConnections::generation`]).
579    binds: u64,
580}
581
582impl UnixConnections {
583    /// A guest bound a socket to `name`: its listener's queue starts empty.
584    /// Which bind of the name it was, for the listener to keep.
585    fn bound(&mut self, name: &[u8]) -> u64 {
586        self.binds += 1;
587        self.names.insert(
588            name.into(),
589            PendingConnections {
590                generation: self.binds,
591                ..Default::default()
592            },
593        );
594        self.binds
595    }
596
597    /// A guest's `connect` to `name` completed: `socket` is the connecting
598    /// socket where it completed in the caller's turn, `None` where it did
599    /// not. A name no guest bound here may be another spelling of one that
600    /// was ([`Self::lost`]).
601    fn connected(&mut self, name: &[u8], socket: Option<OpenFileHandle>) {
602        let Some(pending) = self.names.get_mut(name) else {
603            self.lost();
604            return;
605        };
606        match socket {
607            _ if pending.unknown => {}
608            Some(socket) if pending.sockets.len() < MAX_PENDING_CONNECTIONS => {
609                pending.sockets.push_back(socket)
610            }
611            _ => pending.lose_order(),
612        }
613    }
614
615    /// A guest's stream or seqpacket `connect` completed that Detcore cannot
616    /// attribute to one name ([`UnixConnections`]): every name's order is
617    /// unknown.
618    fn lost(&mut self) {
619        self.names
620            .values_mut()
621            .for_each(PendingConnections::lose_order);
622    }
623
624    /// A guest's `accept` on the listener bound to `name` by bind
625    /// `generation` completed, in the caller's turn or not (`in_turn`): the
626    /// socket whose connection it took, if that is known. A listener whose
627    /// name was bound again since has none: the connections Detcore tracks
628    /// are the later listener's.
629    fn accepted(&mut self, name: &[u8], generation: u64, in_turn: bool) -> Option<OpenFileHandle> {
630        let pending = self
631            .names
632            .get_mut(name)
633            .filter(|pending| pending.generation == generation)?;
634        if !in_turn {
635            pending.lose_order();
636        }
637        if pending.unknown {
638            return None;
639        }
640        pending.sockets.pop_front()
641    }
642}

656impl ReceiveGeometry {
657    /// The geometry of `call`, a `recvmsg` or `recvmmsg`, read from guest
658    /// memory before it runs; `None` for any other call or an unreadable
659    /// `recvmsg` header. A `recvmmsg` vector is read in full, up to the
660    /// `vlen` Linux may process (at most [`MAX_SNAPSHOT_ENTRIES`] entries);
661    /// an entry or iovec array that cannot be read makes the geometry
662    /// unusable, and the call's descriptors are not recorded.
663    pub(crate) fn before<M: MemoryAccess>(memory: &M, call: &Syscall) -> Option<Self> {
664        let message_input = |header: Range, message: &Msghdr| -> Option<MessageInput> {
665            Some(MessageInput {
666                header,
667                control: (message.msg_control as usize, message.msg_controllen),
668                name: (message.msg_name as usize, message.msg_namelen as usize),
669                iov_array: (
670                    message.msg_iov as usize,
671                    message.msg_iovlen.min(libc::UIO_MAXIOV as usize) * size_of::<libc::iovec>(),
672                ),
673                fields: message_fields(memory, message)?,
674            })
675        };
676        match call {
677            Syscall::Recvmsg(call) => {
678                let address = call.msg()?;
679                let message: Msghdr = memory.read_value(address).ok()?;
680                let header = (address.as_raw(), size_of::<Msghdr>());
681                let (messages, unusable) = match message_input(header, &message) {
682                    Some(input) => (vec![input], None),
683                    None => (vec![], Some("its iovec array cannot be read")),
684                };
685                Some(ReceiveGeometry {
686                    messages,
687                    batch: false,
688                    timeout: None,
689                    unusable,
690                })
691            }
692            Syscall::Recvmmsg(call) => {
693                let base = call.mmsg().map_or(0, |vector| vector.as_raw());
694                let timeout = call
695                    .timeout()
696                    .map(|timeout| (timeout.as_raw(), size_of::<libc::timespec>()));
697                if call.vlen() as usize > MAX_SNAPSHOT_ENTRIES {
698                    return Some(ReceiveGeometry {
699                        messages: Vec::new(),
700                        batch: true,
701                        timeout,
702                        unusable: Some("its vector is too long to read before the call"),
703                    });
704                }
705                let mut messages = Vec::new();
706                let mut unusable = None;
707                for index in 0..call.vlen() as usize {
708                    let at = base.saturating_add(index * size_of::<Mmsghdr>());
709                    let Some(Ok(entry)) =
710                        Addr::<Mmsghdr>::from_raw(at).map(|entry| memory.read_value(entry))
711                    else {
712                        unusable = Some("an entry of its vector cannot be read");
713                        break;
714                    };
715                    let entry: Mmsghdr = entry;
716                    match message_input((at, size_of::<Mmsghdr>()), &entry.msg_hdr) {
717                        Some(input) => messages.push(input),
718                        None => {
719                            unusable = Some("an iovec array cannot be read");
720                            break;
721                        }
722                    }
723                }
724                Some(ReceiveGeometry {
725                    messages,
726                    batch: true,
727                    timeout,
728                    unusable,
729                })
730            }
731            _ => None,
732        }
733    }
734
735    /// Whether an output range of the call overlaps an input range other
736    /// than its own: every range Linux may write for any entry it may
737    /// process (a header's written-back fields and `msg_len`, a name
738    /// buffer, an iovec segment, a control buffer, the timeout) against
739    /// every range it reads (headers, iovec arrays, control buffers).
740    fn overlapping(&self) -> bool {
741        let mut inputs = Vec::new();
742        let mut outputs = Vec::new();
743        for message in &self.messages {
744            inputs.extend([message.header, message.iov_array, message.control]);
745            outputs.extend([
746                (message.header, true),
747                (message.control, true),
748                (message.name, false),
749            ]);
750            outputs.extend(
751                message
752                    .fields
753                    .segments
754                    .iter()
755                    .map(|&segment| (segment, false)),
756            );
757        }
758        outputs.extend(self.timeout.map(|timeout| (timeout, false)));
759        outputs_overlap_inputs(&inputs, &outputs)
760    }
761
762    /// Whether the input-only fields read now, after the call, are the
763    /// ones read before it. After a successful attempt that ran in the
764    /// caller's turn no other guest thread ran, so these are the values that
765    /// attempt used: a sibling that changed them during an earlier attempt's
766    /// wait (`EAGAIN`, then polling) is detected here.
767    fn still_named<M: MemoryAccess>(&self, memory: &M) -> bool {
768        self.messages.iter().all(|message| {
769            Addr::<Msghdr>::from_raw(message.header.0)
770                .and_then(|at| memory.read_value(at).ok())
771                .and_then(|now: Msghdr| message_fields(memory, &now))
772                .is_some_and(|now| now == message.fields)
773        })
774    }
775
776    /// The descriptors a receive with this geometry, which returned `ret`,
777    /// installed: for each delivered message (one for `recvmsg`, the first
778    /// `ret` for `recvmmsg`), the control bytes Linux reports writing (the
779    /// `msg_controllen` it writes back) at the control buffer named before
780    /// the call. None are named if an output of the call overlaps one of its
781    /// inputs, if the inputs changed before the attempt that succeeded, or if
782    /// Linux reports more control bytes than the buffer named before the call
783    /// held.
784    pub(crate) fn delivered<M: MemoryAccess>(&self, memory: &M, ret: i64) -> Delivered {
785        let refused = |reason| Delivered {
786            fds: Vec::new(),
787            messages: Vec::new(),
788            refused: Some(reason),
789        };
790        if ret < 0 {
791            return Delivered::default();
792        }
793        if let Some(reason) = self.unusable {
794            return refused(reason);
795        }
796        if self.overlapping() {
797            return refused("a buffer it writes overlaps a buffer or header it reads");
798        }
799        if !self.still_named(memory) {
800            return refused("its buffers changed before the attempt that succeeded");
801        }
802        let count = if self.batch {
803            (ret as usize).min(self.messages.len())
804        } else {
805            self.messages.len().min(1)
806        };
807        let mut fds = Vec::new();
808        let mut messages = Vec::new();
809        for message in &self.messages[..count] {
810            // Linux writes the message's flags back too.
811            let flags = message.header.0 + std::mem::offset_of!(Msghdr, msg_flags);
812            let flags: Option<libc::c_int> =
813                Addr::<libc::c_int>::from_raw(flags).and_then(|at| memory.read_value(at).ok());
814            let received = if message.control.0 == 0 || message.control.1 == 0 {
815                Vec::new()
816            } else {
817                let written = message.header.0 + std::mem::offset_of!(Msghdr, msg_controllen);
818                let Some(length) =
819                    Addr::<usize>::from_raw(written).and_then(|at| memory.read_value(at).ok())
820                else {
821                    return refused("its control length cannot be read back");
822                };
823                if length > message.control.1 {
824                    return refused("its control buffer grew before the attempt that succeeded");
825                }
826                let length = length.min(MAX_CONTROL_BYTES);
827                let mut control = vec![0; length];
828                match Addr::<u8>::from_raw(message.control.0)
829                    .map(|at| memory.read_exact(at, &mut control))
830                {
831                    _ if length == 0 => Vec::new(),
832                    Some(Ok(())) => received_descriptors(&control),
833                    _ => return refused("its control data cannot be read back"),
834                }
835            };
836            if received.is_empty() {
837                // With no room for even one descriptor (no control buffer,
838                // or too small a one), Linux releases them all and sets
839                // `MSG_CTRUNC` (`scm_detach_fds`, `scm_recv_unix`): the
840                // message may have carried some. So may one whose flags
841                // cannot be read back.
842                if flags.is_none_or(|flags| flags & libc::MSG_CTRUNC != 0) {
843                    messages.push(DeliveredMessage {
844                        count: 0,
845                        truncated: true,
846                    });
847                }
848                continue;
849            }
850            // Flags that cannot be read back count as complete, so that only
851            // all of a queued message can match.
852            let truncated = flags.is_some_and(|flags| flags & libc::MSG_CTRUNC != 0);
853            messages.push(DeliveredMessage {
854                count: received.len(),
855                truncated,
856            });
857            fds.extend(received);
858        }
859        Delivered {
860            fds,
861            messages,
862            refused: None,
863        }
864    }
865}

913/// How this run handles descriptors received over `SCM_RIGHTS` or in a
914/// binder transaction.

917    /// The tool shares the guest's descriptor table and discovers a received
918    /// descriptor when a call first names it.
919    Discovered,

921    Recorded,

926impl<T: RecordOrReplay> Detcore<T> {
927    /// How this run handles received descriptors. Recorded only where the
928    /// tool does not share the guest's descriptor table (it discovers them
929    /// there), and with sequentialized threads (otherwise another thread could
930    /// close a number, or `dup2` another file over it, between the receive
931    /// and the facts taken here; a received rendered procfs descriptor is
932    /// refused by name there when first named,
933    /// `Detcore::adopt_received_placeholders`). Under record and replay the
934    /// facts come from the recording ([`Self::probe_received`]), so replay,
935    /// which stands in a placeholder for each received descriptor, takes the
936    /// recording's.
937    fn receipt_mode<G: Guest<Self>>(&self, guest: &G) -> ReceiptMode {
938        if self.cfg.backend.tool_shares_guest_descriptor_table {
939            ReceiptMode::Discovered
940        } else if !guest.config().sequentialize_threads {
941            ReceiptMode::Unrecorded("without sequentialized threads")
942        } else {
943            ReceiptMode::Recorded
944        }
945    }

947    /// Whether a send or receive through `call` completes in the caller's
948    /// turn, decided before the call: the descriptor is one Detcore polls in
949    /// turn (`IOAction::NonblockizeRetry`) or one already nonblocking
950    /// (`IOAction::PassThru`). Any other call runs on the background path
951    /// Whether a receive through `call` completes in the caller's turn,
952    /// decided before the call: the descriptor is one Detcore polls in turn
953    /// (`IOAction::NonblockizeRetry`), or one already nonblocking or a call
954    /// whose own flags keep it from waiting (`MSG_DONTWAIT`;
955    /// `IOAction::PassThru`). Any other receive runs on the background path
956    /// (`BlockingExternalIO`: a physically blocking socket, or one Detcore
957    /// keeps no model of), where other tasks run between the kernel's
958    /// completion and the caller's continuation and could close or replace a
959    /// delivered number, or rewrite the control data; the descriptors such a
960    /// receive delivers are never recorded, nor those such a send carries
961    /// queued.
962    pub(crate) fn completes_in_turn<G, C>(&self, guest: &mut G, call: C) -> bool
963    where
964        G: Guest<Self>,
965        C: crate::syscalls::helpers::NonblockableSyscall + Into<Syscall>,
966    {
967        matches!(
968            crate::syscalls::helpers::ioaction_based_on_fd_status(guest, call),
969            Ok(crate::syscalls::helpers::IOAction::NonblockizeRetry
970                | crate::syscalls::helpers::IOAction::PassThru)
971        )
972    }

974    /// Whether the tool discovers received descriptors itself (it shares the
975    /// guest's descriptor table), so that a receive records none.
976    pub(crate) fn discovers_received_descriptors<G: Guest<Self>>(&self, guest: &G) -> bool {
977        self.receipt_mode(guest) == ReceiptMode::Discovered
978    }

980    /// Record in this thread's descriptor table each descriptor a receive
981    /// from `from` installed (`delivered`), where this run records received
982    /// descriptors and the receive completed in the caller's turn (`in_turn`,
983    /// [`Self::completes_in_turn`]), and return those it recorded as open
984    /// files new to the table. One that joined the open file its sender's
985    /// table modeled (see the module documentation) is not returned: it brings
986    /// the lock ledger no new identity, and `refresh_description_locks` would
987    /// mark that shared open file, the sender's too, as received. The guest's
988    /// result is never changed. A descriptor left out of the table, as every
989    /// received descriptor was before, is named in a warning: for each receive
990    /// whose layout cannot be trusted, each receive on the background path,
991    /// each number that already has a record, each anonymous inode other than
992    /// an inotify instance, and each descriptor whose facts cannot be taken.
993    /// Without sequentialized threads none is recorded, logged at debug level
994    /// only (a warning per call, or per tool process, would differ between
995    /// runs that share a process). `cloexec` is whether the receive asked for
996    /// its descriptors close-on-exec (`MSG_CMSG_CLOEXEC`), which a descriptor
997    /// listed without its facts keeps. A tool error, after which record and
998    /// replay could no longer follow each other, ends the run.
999    pub(crate) async fn record_received_descriptors<G: Guest<Self>>(
1000        &self,
1001        guest: &mut G,
1002        delivered: &Delivered,
1003        channel: Channel,
1004        in_turn: bool,
1005        cloexec: bool,
1006        from: ReceivedFrom,
1007    ) -> Result<Vec<RawFd>, Error> {
1008        match self.receipt_mode(guest) {
1009            ReceiptMode::Discovered => return Ok(Vec::new()),
1010            ReceiptMode::Unrecorded(why) => {
1011                if !delivered.fds.is_empty() || delivered.refused.is_some() {
1012                    // A listing of this table cannot come from the model now
1013                    // (`syscalls::files::descriptor_directory`).
1014                    guest.thread_state().note_unaccounted_receipt();
1015                }
1016                if !delivered.fds.is_empty() {
1017                    debug!(
1018                        "[detcore] descriptors {:?}, received {channel}, are not recorded ({why})",
1019                        delivered.fds
1020                    );
1021                }
1022                return Ok(Vec::new());
1023            }
1024            ReceiptMode::Recorded => {}
1025        }
1026        if let Some(reason) = delivered.refused {
1027            guest.thread_state().note_unaccounted_receipt();
1028            warn!(
1029                "[detcore] the descriptors a receive got {channel}, if any, are not recorded: \
1030                 {reason}"
1031            );
1032            self.lose_lockstep_if_queued(guest, from);
1033            return Ok(Vec::new());
1034        }
1035        if !in_turn {
1036            self.lose_lockstep_if_queued(guest, from);
1037            if !delivered.fds.is_empty() {
1038                guest.thread_state().note_unaccounted_receipt();
1039                warn!(
1040                    "[detcore] descriptors {:?}, received {channel} on the background path, are \
1041                     not recorded: another task may have closed or replaced their numbers, or \
1042                     rewritten the control data, before this one resumed",
1043                    delivered.fds
1044                );
1045            }
1046            return Ok(Vec::new());
1047        }
1048        let mut recorded = Vec::new();
1049        let mut rest = delivered.fds.as_slice();
1050        for message in &delivered.messages {
1051            if message.count == 0 {
1052                // Linux may have released the descriptors of a message this
1053                // receive took.
1054                self.lose_lockstep_if_queued(guest, from);
1055                continue;
1056            }
1057            let (fds, after) = rest.split_at(message.count.min(rest.len()));
1058            rest = after;
1059            let mut facts = Vec::with_capacity(fds.len());
1060            for &fd in fds {
1061                match self.received_facts(guest, fd, channel).await {
1062                    Err(Error::Tool(error)) => return Err(Error::Tool(error)),
1063                    taken => facts.push(taken),
1064                }
1065            }
1066            let (sent, lockstep) =
1067                Self::queued_rights(guest, from, &facts, message.truncated).unzip();
1068            let lockstep = lockstep.unwrap_or(false);
1069            for (index, (&fd, facts)) in fds.iter().zip(facts).enumerate() {
1070                let facts = match facts {
1071                    Ok(Some(facts)) => facts,
1072                    Ok(None) => continue,
1073                    Err(error) => {
1074                        // Open, but without its facts: listed, never modelled.
1075                        guest.thread_state().note_unmodelled_descriptor(fd, cloexec);
1076                        warn!(
1077                            "[detcore] descriptor {fd}, received {channel}, is not \
1078                             recorded: {error}"
1079                        );
1080                        continue;
1081                    }
1082                };
1083                let sent = sent.as_ref().and_then(|sent| sent.get(index));
1084                match self
1085                    .record_received_facts(guest, fd, &facts, sent, lockstep, channel)
1086                    .await
1087                {
1088                    Ok(Receipt::New) => recorded.push(fd),
1089                    Ok(Receipt::Joined | Receipt::Unrecorded) => {}
1090                    Err(Error::Tool(error)) => return Err(Error::Tool(error)),
1091                    Err(error) => {
1092                        // Open, but without its facts: listed, never modelled.
1093                        guest.thread_state().note_unmodelled_descriptor(fd, cloexec);
1094                        warn!(
1095                            "[detcore] descriptor {fd}, received {channel}, is not \
1096                             recorded: {error}"
1097                        )
1098                    }
1099                }
1100            }
1101        }
1102        Ok(recorded)
1103    }

1105    /// The kernel's facts about descriptor `fd`, which Linux has just
1106    /// installed through `SCM_RIGHTS`: `None` for a number that already has a
1107    /// record, which is kept as it is.
1108    async fn received_facts<G: Guest<Self>>(
1109        &self,
1110        guest: &mut G,
1111        fd: RawFd,
1112        channel: Channel,
1113    ) -> Result<Option<ReceivedFacts>, Error> {
1114        if fd < 0 {
1115            return Ok(None);

1217    /// Record descriptor `fd`, which Linux has just installed through
1218    /// `SCM_RIGHTS`, from the kernel's facts about it (`facts`), and say how:
1219    /// as an alias of the open file description its sender's table modeled
1220    /// (`sent`, the descriptor the send queued in its place, taken from a
1221    /// queue in lockstep with the socket's messages or not, `lockstep`), or
1222    /// as an open file of its own.
1223    async fn record_received_facts<G: Guest<Self>>(
1224        &self,
1225        guest: &mut G,
1226        fd: RawFd,
1227        facts: &ReceivedFacts,
1228        sent: Option<&SentDescriptor>,
1229        lockstep: bool,
1230        channel: Channel,
1231    ) -> Result<Receipt, Error> {
1232        let cloexec = facts.descriptor_flags & libc::FD_CLOEXEC != 0;
1233        // Every anonymous inode has one file identity, so out of lockstep
1234        // only order could say which queued one this is: none is joined.
1235        let anonymous = facts.stat.st_mode & libc::S_IFMT == 0;
1236        // Linux installed the sender's `struct file`, so the received
1237        // descriptor shares its status flags, lock state, directory position
1238        // and scheduler resource, as `dup` would make it: an `O_NONBLOCK` set
1239        // through either shows through both, and a blocking read through the
1240        // received end of a pipe Detcore keeps physically nonblocking still
1241        // waits for the writer. Checked before the anonymous-inode refusal, so
1242        // a received eventfd is the sender's eventfd.
1243        if let Some(open_file) = sent
1244            .filter(|sent| sent.file == facts.file() && (lockstep || !anonymous))
1245            .and_then(|sent| sent.open_file.as_ref())
1246            && self
1247                .join_sent_open_file(guest, fd, cloexec, open_file)
1248                .await?
1249        {
1250            // The copy is no longer in flight: it was received, so its
1251            // description may take a placeholder lock again
1252            // (`procfs::locks::LockLedger::placeholder_copies`).
1253            if let Ok(open_file_id) = guest
1254                .thread_state()
1255                .with_detfd(fd, |detfd| detfd.open_file_id())
1256            {
1257                let _ = crate::tool_global::placeholder_copies(
1258                    guest,
1259                    crate::procfs::locks::PlaceholderCopies::Received(open_file_id),
1260                )
1261                .await;
1262            }
1263            return Ok(Receipt::Joined);
1264        }
1265        let stat = &facts.stat;
1266        // An anonymous inode (an eventfd, signalfd, timerfd, epoll set,
1267        // inotify instance, pidfd, userfaultfd, ...) has no file type, and
1268        // `fstat` cannot tell which it is. Recorded as an ordinary file, its
1269        // reads and flag changes would take paths that are wrong for it (a
1270        // blocking signalfd read held in the caller's turn, an
1271        // `EFD_SEMAPHORE` eventfd read twice). Its link names an inotify
1272        // instance, which is recorded as one, so its reads renumber rename
1273        // cookies (`crate::syscalls::inotify`); any other is left unrecorded,
1274        // as before. Under record and replay the link is read through the
1275        // recording (`Self::received_descriptor_link`), so replay, whose slot
1276        // holds a stand-in eventfd, classifies the descriptor as the
1277        // recording did.
1278        let link = if stat.st_mode & libc::S_IFMT == 0 {
1279            self.received_descriptor_link(guest, fd).await?
1280        } else {
1281            None
1282        };
1283        if stat.st_mode & libc::S_IFMT == 0
1284            && link.as_deref() != Some(crate::syscalls::inotify::INOTIFY_LINK)
1285        {
1286            // Open, and listed in the table's descriptor directory, but not
1287            // modelled.
1288            guest.thread_state().note_unmodelled_descriptor(fd, cloexec);
1289            match &link {
1290                Some(link) => warn!(
1291                    "[detcore] descriptor {fd}, received {channel}, is an anonymous inode ({}) \
1292                     that an ordinary record would mishandle: not recorded",
1293                    String::from_utf8_lossy(link)
1294                ),
1295                None => warn!(
1296                    "[detcore] descriptor {fd}, received {channel}, is an anonymous inode whose \
1297                     link cannot be read, so its kind is unknown: not recorded"
1298                ),
1299            }
1300            return Ok(Receipt::Unrecorded);
1301        }
1302        if may_be_placeholder(stat)
1303            && placeholders_exist()
1304            && self.renders_procfs(guest)
1305            && let Some(path) = placeholder_identity(stat.st_dev, stat.st_ino)
1306        {
1307            self.adopt_received_placeholder(guest, fd, path, (stat.st_dev, stat.st_ino))
1308                .await?;
1309            return Ok(Receipt::New);
1310        }
1311        // Any other received descriptor is a description of its own in the
1312        // model (see the module documentation), made exactly as the in-guest
1313        // discovery makes it: a directory gets a sorted stream of its own.
1314        guest.thread_state().add_discovered_fd(
1315            fd,
1316            facts.descriptor_flags,
1317            facts.status_flags,
1318            stat,
1319            link.as_deref(),
1320        )?;
1321        // A placeholder descriptor, which its identity and its tag tell apart
1322        // (`descriptor_directory`).
1323        self.recognize_received_placeholder(guest, fd, stat, facts.status_flags)
1324            .await;
1325        if stat.st_mode & libc::S_IFMT == libc::S_IFSOCK {
1326            self.classify_socket_peer(guest, fd, SocketRole::Received)
1327                .await;
1328        }
1329        Ok(Receipt::New)
1330    }

1333    /// its sender's table modeled, as `dup` would, with `FD_CLOEXEC` as
1334    /// `cloexec` says; whether it did. Not once every modeled descriptor of
1335    /// that description is closed. Under record and replay only where this
1336    /// table holds a descriptor of it (the lowest numbered, `other`): replay
1337    /// holds a stand-in in `fd` and first duplicates `other` over it, so that
1338    /// the slot names the live open file (`Detcore::install_live_alias`).

1340        &self,
1341        guest: &mut G,
1342        fd: RawFd,
1343        cloexec: bool,
1344        open_file: &OpenFileHandle,

1348        };

1351                .thread_state()
1352                .lowest_slot_naming(alias.open_file_id())
1353            else {
1354                return Ok(false);
1355            };
1356            if self.cfg.replaying {
1357                let flags = if cloexec {
1358                    OFlag::O_CLOEXEC

1370            }
1371        }
1372        guest.thread_state().install_alias(alias);

1374    }

1377    /// recording: recorded under record, served from the recording under
1378    /// replay (which holds a stand-in where the recording held the
1379    /// descriptor), injected otherwise. Retried while a signal stops it
1380    /// before it runs; every attempt is an event, so replay retries as the
1381    /// recording did.
1382    async fn probe_received<G, S>(&self, guest: &mut G, call: S) -> Result<i64, Errno>
1383    where
1384        G: Guest<Self>,
1385        S: Into<Syscall> + Copy,
1386    {

1391                Err(errno @ (Errno::EINTR | Errno::ERESTARTSYS)) => last = errno,
1392                answer => return answer,
1393            }
1394        }
1395        Err(last)
1396    }

1419    /// After a send through `socket` that completed in the caller's turn
1420    /// ([`Self::completes_in_turn`]) and queues the open files it carries
1421    /// ([`Self::rights_peer_is_stream`] says whether the pair is a stream,
1422    /// `stream`), queue on the socket's peer, for each message Linux reports
1423    /// sending (`sent`: the descriptors its `SCM_RIGHTS` messages carried,
1424    /// and the bytes it sent), the open file description this table modeled
1425    /// for each descriptor and the file's identity from an injected `fstat`,
1426    /// so that the receipt can name the open file each received descriptor
1427    /// is (see the module documentation).
1428    ///
1429    /// A stream socket's message of no bytes carried nothing: Linux attaches
1430    /// the descriptors to the first buffer it queues, and queues none. A
1431    /// message whose descriptors' facts cannot all be taken queues nothing,
1432    /// so its receipt names no open file, as before. A send that failed
1433    /// queued nothing in Linux and queues nothing here. A tool error (an
1434    /// `fstat` under record and replay that could not be recorded) ends the
1435    /// run.
1436    pub(crate) async fn queue_sent_rights<G: Guest<Self>>(
1437        &self,
1438        guest: &mut G,
1439        socket: RawFd,
1440        stream: bool,
1441        sent: SentRights,
1442    ) -> Result<(), Error> {
1443        if sent.unread {
1444            self.lose_peer_lockstep(guest, socket);
1445        }
1446        // A datagram send that names its destination reaches the socket it
1447        // names, not the peer (`unix_dgram_sendmsg`); a seqpacket send
1448        // ignores a name (`unix_seqpacket_sendmsg`) and a stream send with
1449        // one fails (`unix_stream_sendmsg`).
1450        let datagram = guest
1451            .thread_state()
1452            .with_detfd(socket, |socket| socket.unix_type())
1453            .ok()
1454            .flatten()
1455            == Some(libc::SOCK_DGRAM);
1456        for (fds, bytes, addressed) in sent.messages {
1457            if stream && bytes == 0 {
1458                continue;
1459            }
1460            if datagram && addressed {
1461                // The named socket may be the peer itself, which then holds a
1462                // message its queue does not.
1463                self.lose_peer_lockstep(guest, socket);
1464                continue;
1465            }
1466            let mut descriptors = Vec::with_capacity(fds.len());
1467            for &fd in &fds {
1468                // Through the recording, as the receipt's facts are, so that
1469                // replay matches what the recording matched.
1470                let stat = match self.received_descriptor_fstat(guest, fd).await {
1471                    Ok(stat) => stat,
1472                    Err(Error::Tool(error)) => return Err(Error::Tool(error)),
1473                    Err(_) => break,
1474                };
1475                descriptors.push(SentDescriptor {
1476                    file: (stat.st_dev, stat.st_ino),
1477                    open_file: guest
1478                        .thread_state()
1479                        .with_detfd(fd, |detfd| detfd.open_file_handle())
1480                        .ok(),
1481                });
1482            }
1483            if descriptors.len() == fds.len() {
1484                let mut descriptors = Some(descriptors);
1485                let _ = guest.thread_state().with_detfd(socket, |socket| {
1486                    descriptors
1487                        .take()
1488                        .is_some_and(|descriptors| socket.queue_rights_to_peer(descriptors))
1489                });
1490            } else {
1491                self.lose_peer_lockstep(guest, socket);
1492            }
1493        }
1494        Ok(())
1495    }

1665        else {
1666            return;
1667        };
1668        let peer = with_connections(guest, |connections| {
1669            connections.accepted(&name, generation, in_turn)
1670        });
1671        let _ = guest.thread_state().with_detfd(fd, |detfd| {
1672            detfd.set_unix_type(kind);

1679    /// What descriptor `fd` of the calling thread links to, or `None` where
1680    /// that read fails or the link is longer than any anonymous inode's.
1681    ///
1682    /// Under record and replay the link is read through the recording
1683    /// (`Detcore::recorded_descriptor_link`): replay's slot holds a stand-in
1684    /// eventfd until the recording's answers say otherwise, so a live read
1685    /// there would name the stand-in. A buffer that cannot be prepared ends
1686    /// the run there, as for the received descriptor's `fstat`: no readlink
1687    /// ran, so the other phase could consume an event this one did not.
1688    ///
1689    /// Otherwise it is read in the guest (`readlinkat` of
1690    /// `/proc/thread-self/fd/<fd>`, injected). The path and the result share
1691    /// one buffer, staged where `inject_fstat` stages its own
1692    /// ([`crate::syscalls::scratch::inject_with_scratch`]).
1693    async fn received_descriptor_link<G: Guest<Self>>(
1694        &self,
1695        guest: &mut G,
1696        fd: RawFd,
1697    ) -> Result<Option<Vec<u8>>, Error> {
1698        if self.cfg.recordreplay_modes {
1699            return self
1700                .recorded_descriptor_link(guest, fd)
1701                .await
1702                .map_err(|errno| {
1703                    Error::Tool(anyhow::anyhow!(
1704                        "cannot record descriptor {fd}, received over SCM_RIGHTS, under record \
1705                         and replay: no buffer for its link ({errno})"
1706                    ))
1707                });
1708        }
1709        let mut buffer = [0_u8; LINK_PATH + LINK_TARGET];
1710        let spelled = format!("/proc/thread-self/fd/{fd}");
1711        let Some(slot) = buffer.get_mut(..spelled.len()) else {
1712            return Ok(None);
1713        };
1714        slot.copy_from_slice(spelled.as_bytes());
1715        let Ok((length, bytes)) =
1716            crate::syscalls::scratch::inject_with_scratch(guest, buffer, |base| {
1717                // SAFETY: the buffer holds LINK_PATH + LINK_TARGET bytes.
1718                let target = unsafe { base.add(LINK_PATH) };
1719                syscalls::Readlinkat::new()
1720                    .with_dirfd(libc::AT_FDCWD)
1721                    .with_path(PathPtr::from_ptr(base.as_raw() as *const libc::c_char))
1722                    .with_buf(Some(target.cast::<libc::c_char>()))
1723                    .with_buf_len(LINK_TARGET)
1724                    .into()
1725            })
1726            .await
1727        else {
1728            return Ok(None);
1729        };
1730        Ok(usize::try_from(length)
1731            .ok()
1732            .filter(|length| *length < LINK_TARGET)
1733            .map(|length| bytes[LINK_PATH..LINK_PATH + length].to_vec()))
1734    }
1735}
