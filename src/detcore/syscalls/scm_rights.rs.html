9//! Descriptors a guest receives over `SCM_RIGHTS`.
10//!
11//! `recvmsg` and `recvmmsg` are the only calls that install descriptors
12//! another process sent: Linux's `scm_detach_fds` installs each descriptor
13//! that fits the receiver's control buffer, with `O_CLOEXEC` when the call
14//! passed `MSG_CMSG_CLOEXEC`, writes one `SCM_RIGHTS` message holding exactly
15//! the numbers it installed, releases the rest and sets `MSG_CTRUNC`; a
16//! `MSG_PEEK` receive installs them too. The control data the call leaves at
17//! the control buffer it was given, read up to the `msg_controllen` Linux
18//! writes back, therefore names exactly the descriptors that now exist
19//! ([`ReceiveGeometry::delivered`]).
20//!
21//! Where the tool shares the guest's descriptor table (the in-guest
22//! backends), Detcore discovers such a descriptor when a call first names it
23//! (`FileMetadata::discover_fd_from_current_process`). Elsewhere (ptrace,
24//! KVM) nothing would, and every later call through it that consults
25//! Detcore's table failed with `EBADF`
26//! (<https://github.com/rrnewton/hermit/issues/4547>). So there Detcore records
27//! each received descriptor as the receive returns
28//! ([`Detcore::record_received_descriptors`]), from the facts the in-guest
29//! discovery takes (`fcntl(F_GETFD)`, `fcntl(F_GETFL)` and `fstat`, here
30//! taken through the recording), through the same
31//! `FileMetadata::add_discovered_fd`, so the
32//! record is the description the in-guest discovery makes: a directory, for
33//! one, gets a sorted stream of its own. Unlike that discovery, a received
34//! descriptor is never given the container's stdio resource (it is not the
35//! container's stdio), nor rebuilt as a fixed procfs file or held for the
36//! session's `/proc/cpuinfo` decision (those are an exec image's own
37//! descriptors); a rendered procfs placeholder is adopted through the
38//! placeholder registry instead, as `Detcore::adopt_received_placeholders`
39//! adopts one when it is first named, or, where Detcore runs in each guest
40//! process (LiteInst and in-guest-trap record received descriptors too), by
41//! the name and seals of a placeholder another process made
42//! (`Detcore::received_placeholder`).
43//!
44//! An anonymous inode has no file type, so `fstat` does not tell its kind.
45//! Its descriptor link does: one that reads `anon_inode:inotify` (an injected
46//! `readlinkat` of `/proc/thread-self/fd/<fd>`) is recorded as an inotify
47//! instance, as the in-guest discovery records it, so its reads renumber
48//! rename cookies (`crate::syscalls::inotify`).
49//!
50//! Not recorded, as before, each named in a warning: any other anonymous
51//! inode (eventfd, signalfd, timerfd, epoll, pidfd, userfaultfd, ...), which
52//! an ordinary record would mishandle
53//! (<https://github.com/rrnewton/hermit/issues/4107>'s signalfd mode), and
54//! one whose link cannot be read; a receive whose buffers overlap so that the
55//! call may have overwritten its
56//! own inputs, whose vector cannot be read in full, or whose inputs changed
57//! before the attempt that succeeded; and every receive on the background
58//! path. Without sequentialized threads no receive is recorded, logged at
59//! debug level only (`ReceiptMode`).
60//!
61//! Under record and replay every fact is taken through the recording, so
62//! replay, which serves the receive from the log and holds a stand-in in each
63//! received slot, rebuilds the table the recording built. Where the recording
64//! joined a received descriptor to an open file the receiving table holds,
65//! replay also makes the received slot name the live open file
66//! (`Detcore::install_live_alias`), and a received socket whose peer is a
67//! guest is polled in the caller's turn (`Detcore::classify_socket_peer`).
68//!
69//! Linux installs the sender's `struct file` (`receive_fd`): the received
70//! descriptor shares its status flags, directory position and lock ownership
71//! with every descriptor of that open file, the sender's included, in
72//! whichever process holds them. Detcore names that open file without asking
73//! the kernel, as <https://github.com/rrnewton/hermit/issues/4670> proposes:
74//! at the send, it queues on the receiving socket the open file description
75//! its table modeled for each descriptor carried, with the file's
76//! `(st_dev, st_ino)` from an injected `fstat`
77//! ([`Detcore::queue_sent_rights`]); at the receipt, it takes the oldest
78//! queued message whose identities are the received descriptors', in order
79//! (all of them, or a prefix where Linux set `MSG_CTRUNC`; a `MSG_PEEK`
80//! receive leaves it queued), and each received descriptor joins the
81//! description its sender's table modeled, as `dup` would, before the
82//! anonymous-inode refusal, so a received eventfd is the sender's eventfd.
83//! The decision depends only on Detcore's own model and the facts its
84//! injected `fcntl` and `fstat` take, so it is the same on every backend that
85//! records received descriptors (ptrace, KVM); before, it asked the kernel
86//! through `kcmp(KCMP_FILE)`, which KVM's executor does not answer and which
87//! the host's kernel configuration and seccomp profile can refuse.
88//!
89//! A queued message holds the descriptions it carries
90//! ([`crate::fd::InFlightOpenFile`]), as Linux holds the `struct file` of each
91//! descriptor a message carries: the send takes a reference on each
92//! (`scm_fp_copy`,
93//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/core/scm.c?h=v6.17#n69>),
94//! which the queued message keeps (`unix_attach_fds`,
95//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n1962>)
96//! until a receive installs the descriptors that fit and drops the rest
97//! (`scm_detach_fds`,
98//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/core/scm.c?h=v6.17#n354>),
99//! or the message is freed unreceived (`unix_destruct_scm`,
100//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n1989>):
101//! by the close of the receiving socket (`unix_release_sock`,
102//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n665>)
103//! or a datagram `connect` (`unix_dgram_disconnected`,
104//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n616>).
105//! So the receipt names the description even when the sender closed every
106//! descriptor of it, or exited, first: a sender's own table is released when
107//! the backend runs the end of its exit hook, which KVM does after the parent
108//! can already wait for the child, at no particular point of the guest's
109//! schedule, and a receipt that depended on that release decided by host
110//! timing (<https://github.com/rrnewton/hermit/issues/4930>).
111//!
112//! A description counts the copies of it in flight
113//! (`OpenFileDescription::in_flight`): one more when a send queues one, one
114//! fewer when a receipt installs it or a guest call makes Linux release it.
115//! Only guest calls change the count, never a backend's teardown, so whether
116//! a close drops a description's last reference, which decides its port and,
117//! for a socket, whether its queue goes with it, is decided from the
118//! descriptors that name it and that count (`DetFd::is_last_reference`).
119//!
120//! Detcore lets go where Linux does, each time when the guest call that makes
121//! Linux let go completes, in its turn ([`Detcore::settle_released_rights`]):
122//! - a receive that takes the message: the descriptors it could not install
123//!   (`MSG_CTRUNC`) go with it, and so do those recorded as open files of
124//!   their own;
125//! - a receive that takes a later message, which releases the ones queued
126//!   before it, which calls Detcore could not match took;
127//! - where the queue holds every message (see below), a call that takes a
128//!   message without installing what it carried: a read without a control
129//!   buffer, a receive that delivered its message without descriptors
130//!   (`MSG_CTRUNC` with no room), and a datagram or seqpacket receive that
131//!   failed with `EFAULT` copying the message's bytes, or without room for a
132//!   descriptor;
133//! - a `connect` of the datagram socket, and a send through it that finds its
134//!   connected peer gone (`ECONNREFUSED`), which purge its receive queue
135//!   (`unix_dgram_disconnected`, `DetFd::unpair_rights_peer`);
136//! - the close, `dup2` or `close_range` that drops the receiving socket's last
137//!   descriptor (`unix_release_sock`, `FileMetadata::release_detfd`);
138//! - the exit that leaves a descriptor table to no holder (a thread's `exit`,
139//!   or an `exit_group`, which ends its whole process), as guest calls alone
140//!   count a table's holders (`FileMetadata::holders`): it lets go of every
141//!   descriptor of the table in the exiting thread's turn, once the scheduler
142//!   has granted the exit (`ResourceID::Exit`) and just before the native
143//!   call (`Detcore::release_table_at_exit`), as Linux releases a table with
144//!   its last holder's exit (`exit_files`,
145//!   <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/kernel/exit.c?h=v6.17#n956>);
146//! - a `SIGKILL` a process sends itself (a `kill`, `tgkill`, `tkill` or
147//!   `pidfd_send_signal` naming its own process or thread), which ends it as
148//!   an `exit_group` does: its table goes the same way, after the grant and
149//!   just before the call that sends it
150//!   (`Detcore::reserve_controlled_self_sigkill_exit`,
151//!   `Detcore::send_reserved_sigkill`);
152//! - on KVM, the death of a process by the default action of a fatal signal
153//!   (its own `SIGTERM`, `abort()`'s `SIGABRT`, a fault's `SIGSEGV`), which
154//!   no guest call of the dying process carries: its terminal receipt, which
155//!   the scheduler consumes while the control barrier it installs holds every
156//!   later turn, lets go of each table the dying threads named
157//!   (`Detcore::name_table_for_death`) that no other process holds, before
158//!   the backend publishes the death to the parent or retires the process
159//!   (`GlobalState::release_tables_at_death`), as Linux's `do_exit` runs
160//!   `exit_files`, and the deferred last `fput`s in `exit_task_work`, before
161//!   `exit_notify` lets the parent reap it
162//!   (<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/kernel/exit.c?h=v7.1.3#n971>,
163//!   `#n976`, `#n988`): the receiving socket's last reference purges its
164//!   queue (`unix_release_sock`,
165//!   <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v7.1.3#n721>),
166//!   and the last reference of a description a purged message held removes
167//!   its locks (`__fput`'s `locks_remove_file`,
168//!   <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/fs/file_table.c?h=v7.1.3#n502>);
169//! - the `exec` that drops the receiving socket's last descriptor by
170//!   close-on-exec, where threads of the exec'ing process alone hold its
171//!   table, as guest calls count them (`FileMetadata::holders`): Linux kills
172//!   the other threads (`de_thread`), copies the table only where another
173//!   process holds it (`unshare_files`), and closes the close-on-exec
174//!   descriptors of the table the exec keeps (`do_close_on_exec`,
175//!   <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/fs/exec.c?h=v6.17#n1194>);
176//!   Detcore lets go of the replaced table's descriptors at the new image's
177//!   first callback, still in the exec's turn
178//!   (`Detcore::release_exec_dropped_descriptors`): the close-on-exec ones,
179//!   and the others, which the new table holds too, so their going releases
180//!   nothing.
181//!
182//! A description whose last reference a release drops goes with it, with the
183//! messages queued to it in turn, as Linux's last `fput` releases them: a
184//! socket's port with it (`GlobalRequest::ReleasePort`), and the lock
185//! ledger's count of that copy in flight, which held the description's locks
186//! meanwhile (`crate::procfs::locks::LockLedger`). A peek, a read of no bytes
187//! and a receive that fails before it reads the socket let go of nothing.
188//!
189//! Residuals, each named with whether it is deterministic or host-timed:
190//! - deterministic: a receiving socket whose last descriptor goes with a
191//!   table Detcore did not let go takes its queue with it when that table is
192//!   released, without the releases above. Those tables are: the table of a
193//!   process another process's `SIGKILL` killed, which Detcore holds only in
194//!   the victim's exit hook (KVM refuses a signal to another process); on a
195//!   backend that sends no terminal receipt (every backend but KVM), the
196//!   table of a process another fatal signal ended, where the delivery's
197//!   commit does not tell Detcore whether the process ends (a PID
198//!   namespace's init survives it, and an exec in flight changes which
199//!   threads die); one a thread made without `CLONE_FILES` held when another
200//!   thread's `exit_group` or `exec` ended it, and, outside KVM's terminal
201//!   receipt, a fatal signal; and one carried across a snapshot, whose
202//!   holders are not known, also at an `exec`. The copies in flight such a
203//!   queue held stay counted for the rest of the run, so the lock ledger
204//!   keeps counting their locks, and a socket among them keeps its port, as a
205//!   socket an exiting process held keeps its port. Where `/proc/locks` is
206//!   the kernel's file, filtered by the ledger (ptrace), no row shows for
207//!   those locks once the kernel has none, so only the port is kept. Where
208//!   Detcore renders `/proc/locks` from the ledger (KVM), a terminal receipt
209//!   that cannot decide about a table it ended (a dying thread that named
210//!   none, in a process one of whose threads has a table of its own, or a
211//!   table whose holders do not name the process) refuses every later
212//!   snapshot by name, for the rest of the run, if the ledger counts any copy
213//!   in flight at the receipt, rather than list a lock Linux has released.
214//!   The count never depends on when that table is released;
215//! - host-timed, as before this queue existed: a table Detcore did not let go
216//!   at an exit still names its descriptions until the backend tears the
217//!   exited thread's state down, at no particular point of the guest's
218//!   schedule, so whether another table's later close of a description it
219//!   shared is the last reference, and with it that description's port and a
220//!   receiving socket's queue, follows that teardown. A table whose last
221//!   holder leaves through `exit` or `exit_group` (an ordinary forked
222//!   child's, or a threaded process's whose threads all exit or one of which
223//!   calls `exit_group`), or through a `SIGKILL` of its own, goes at that
224//!   exit, and one an exec replaced where only the exec'ing process held it
225//!   goes at the exec, so this never applies to them;
226//! - deterministic: a socket queued, directly or through other queued
227//!   sockets, on its own queue keeps its description, and every description
228//!   queued on it, until the run ends, where Linux's garbage collector
229//!   (`__unix_gc`,
230//!   <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/garbage.c?h=v6.17#n559>)
231//!   frees such a cycle once no descriptor reaches it;
232//! - deterministic: a datagram socket's `connect` to the peer it already has
233//!   purges its queue here where Linux keeps it (`unix_dgram_connect` purges
234//!   only on a change of peer,
235//!   <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n1600>):
236//!   the receipts of its messages join nothing, and what they held is
237//!   released early (a socket among them frees its port);
238//! - deterministic: where a socket's queue no longer holds every message
239//!   (see below), a read without a control buffer that may have taken a
240//!   message's descriptors leaves that message suspect until a later receipt
241//!   or the receiving socket's last close releases it: a socket it carried
242//!   keeps its port until then. So does a stream receive that failed with
243//!   `EFAULT` after it took bytes, whose count Linux does not report, where
244//!   Detcore cannot count them: its queue no longer holds every message, the
245//!   receive had room to install descriptors, or the memory map does not
246//!   show every byte it took writable;
247//! - deterministic: a receipt of an anonymous inode that more than one queued
248//!   message can be (an eventfd received after such a stream receive, which
249//!   may have taken an earlier eventfd's message) joins neither, and the
250//!   received descriptor is refused, as any anonymous inode Detcore cannot
251//!   classify;
252//! - deterministic: a receive that installed descriptors and then failed
253//!   writing its header back (`EFAULT`) leaves them in the receiving table
254//!   unrecorded, as before;
255//! - deterministic: a lock on a description in flight over a socket Detcore
256//!   does not pair is not held by the ledger between the sender's last close
257//!   and the receipt, which shows it again. Nor is a lock taken through a
258//!   description after a copy of it was sent: a copy counts for the ledger
259//!   only where the ledger followed the description's locks when the send
260//!   queued it (`SentDescriptor::lock_copy`), so from the sender's last close
261//!   to the receipt no row shows for that lock, on ptrace and on KVM, while
262//!   Linux lists it and refuses a conflicting lock (Codex's notes on K8-h
263//!   reb7).
264//!
265//! The receiving socket is known only where Detcore knows a socket's peer,
266//! in any process that holds it and through any of its aliases: the two
267//! sockets of a `socketpair`, and an `AF_UNIX` stream or seqpacket connection
268//! and the socket whose `connect` made it. Linux queues each connection on
269//! the listener's receive queue at the tail (`unix_stream_connect`,
270//! `__skb_queue_tail(&other->sk_receive_queue, skb)`,
271//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n1811>)
272//! and `accept` takes it from the head (`unix_accept`, `skb_recv_datagram`,
273//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n1880>),
274//! so Detcore queues each guest's connection to a name a guest bound,
275//! abstract or an absolute path, where the `connect` completed in the
276//! caller's turn, and pairs the oldest with the socket an `accept` on that
277//! listener returns, also in its turn ([`Detcore::note_unix_accept`]).
278//!
279//! That needs every connection a listener gets. So a connect or accept on
280//! the name outside the turn leaves its order unknown until the name is
281//! bound again, and so does any `AF_UNIX` stream connect Detcore cannot
282//! attribute to one bound name, for every name: one through a relative path
283//! or another spelling of a path, to a name no guest bound here, or of a
284//! socket whose type Detcore did not see made ([`UnixConnections`]). A
285//! listener bound before its path was unlinked and bound again pairs
286//! nothing: the connections Detcore tracks for the name are the later
287//! listener's. A connection made from outside Hermit is not seen at all, and
288//! shifts the pairing of those queued after it.
289//!
290//! A `socketpair` datagram socket reaches its peer only while it stays
291//! connected to it and names no other destination. A `connect` gives it
292//! another peer, or none, and Linux then purges its receive queue
293//! (`unix_dgram_connect`, `unix_dgram_disconnected`), so Detcore unpairs the
294//! two and neither queue is in lockstep any more
295//! (`DetFd::unpair_rights_peer`). A send that names its destination
296//! (`msg_namelen`, `unix_dgram_sendmsg`,
297//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n2172>)
298//! queues nothing, and its peer's queue is no longer in lockstep, since the
299//! named socket may be the peer itself. A seqpacket send ignores the name
300//! (`unix_seqpacket_sendmsg`) and a stream send with one fails
301//! (`unix_stream_sendmsg`).
302//!
303//! A descriptor received any other way is a description of its own in
304//! Detcore's model, as before: through any other socket (a datagram socket
305//! not made by `socketpair`, a connection Detcore did not pair), from a
306//! sender outside Hermit or whose send Detcore did not see complete in its
307//! turn, one whose sender's table modeled no description for it, or one
308//! whose queued message may be a stale entry (see below). The in-guest
309//! backends discover received descriptors lazily and keep the separate
310//! model they had.
311//!
312//! The identities confirm what order proposes, except for anonymous inodes:
313//! every eventfd, timerfd, signalfd and epoll set has one file identity. So
314//! once a message may have reached a socket without being queued, no
315//! anonymous inode received through it joins anything
316//! (`SocketRights::lockstep_lost`, `Detcore::record_received_facts`): from
317//! the first message sent to it that was not queued (unreadable control
318//! data, facts that could not be taken, a send outside the turn, a datagram
319//! send that named its destination, more than 4096 waiting), a `connect` of
320//! a datagram socket of the pair, or a receipt that names no queued message,
321//! or a later one than Linux can have delivered.
322//!
323//! A call that took a message from the socket Detcore could not match keeps
324//! the queue: Linux still delivers the messages it did not take. Such a
325//! call is a `read`, `readv`, `recvfrom`, `preadv2` at the current offset or
326//! `splice` that took one, a receive that released descriptors
327//! (`MSG_CTRUNC` with none installed), one outside the turn or with an
328//! untrusted layout, one whose descriptors' facts could not be taken, a
329//! receive that failed with `EFAULT` after it read the socket (below), or a
330//! `recvmmsg` that stopped short with messages queued. Each took at most one
331//! message, the oldest Linux held (a stream read detaches the descriptors of
332//! one buffer at most, `unix_stream_read_generic`), so after `n` of them only
333//! the first `n` queued messages can be gone (`SocketRights::suspects`). A
334//! receipt that matches one of those, or the first message after them, joins
335//! only where no later one of them, nor that first message after them, names
336//! the same files; one that matches a message past that names a message
337//! Linux cannot have delivered yet, so it took one never queued here or one
338//! a call Detcore did not count took: it joins nothing and takes nothing,
339//! and every message up to the match stays queued, suspect, with the queue
340//! out of lockstep (`DetFd::take_queued_rights`). So a message Linux
341//! released is never joined, whatever the files it names, and no message
342//! Linux still holds is released. A peek may reach a later message
343//! (`SO_PEEK_OFF`): it joins wherever it is, while the queue is in lockstep
344//! and no other queued message names the same files. Other files out of
345//! lockstep still join where their identities match: two open files of one
346//! file, or the two ends of one pipe, which share its identity, are then told
347//! apart only by order where one of them was sent without being queued.
348//!
349//! Where nothing but its peer can reach a socket, the queue can hold every
350//! message, data alone included, in Linux's order (`SocketRights::complete`):
351//! the two sockets of a `socketpair` while neither has a name, outside record
352//! and replay, where Detcore notes every send between them
353//! (`Detcore::note_send_without_control`, `Detcore::queue_sent_rights`). On a
354//! datagram or seqpacket socket a call that takes one message without naming
355//! its descriptors then took the oldest queued one, which must agree with
356//! what the call reports (a read returns as many of its bytes as fit,
357//! `DetFd::take_head_message`). On a stream socket a receive takes the bytes
358//! it reports from the oldest messages on, and detaches the descriptors of
359//! the first message whose bytes it reaches, past which it takes nothing
360//! (`DetFd::take_stream_bytes`, and `DetFd::take_queued_rights` for one that
361//! installed them). Either way what the call took without installing it is
362//! released, as Linux releases it. The queue stops holding every message for
363//! good once a message may reach the socket unseen or be taken unseen: a
364//! `bind` or `SO_PASSCRED` (which names it, `unix_autobind`), a `connect`, a
365//! send to it outside the turn or naming a destination, a datagram `splice`
366//! into it, out-of-band data on a stream, a call outside the turn or whose
367//! result does not fit the queue, more than 4096 waiting, or either socket of
368//! the pair passed over `SCM_RIGHTS` or binder, where a receipt may record it
369//! as an open file of its own, through which sends and receives go unseen
370//! (`DetFd::give_up_pair_completeness`).
371//!
372//! Which receives that fail with `EFAULT` took a message is Linux's copy
373//! order (v6.17): one that fails copying its inputs in, before it reads the
374//! socket, takes nothing: a buffer outside user space (`import_ubuf`,
375//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/lib/iov_iter.c?h=v6.17#n1528>),
376//! an iovec array it cannot read or an iovec outside user space
377//! (`__import_iovec`,
378//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/lib/iov_iter.c?h=v6.17#n1447>),
379//! a `msghdr` or a `recvmmsg` timeout it cannot read (`recvmsg_copy_msghdr`,
380//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/socket.c?h=v6.17#n2864>).
381//! Past those, a datagram or seqpacket receive dequeues its message before it
382//! copies the bytes, and frees it when that copy fails (`__unix_dgram_recvmsg`,
383//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n2645>),
384//! so it took one. A stream receive fails only where it copied nothing, and
385//! then keeps the bytes, descriptors and all (`unix_stream_read_generic`,
386//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/unix/af_unix.c?h=v6.17#n3059>),
387//! unless it succeeded and a copy out after it failed: the sender's address
388//! (`move_addr_to_user`,
389//! <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/socket.c?h=v6.17#n2281>)
390//! or the header's lengths and flags (`____sys_recvmsg`,

396//! and a received descriptor joins its sender's description only where the
397//! receiving table holds a descriptor of it: replay holds a stand-in in the
398//! received slot and can put the live open file there only by duplicating a
399//! descriptor of the same table. One whose description only another
400//! process's table, or only its queued message, holds is recorded from the
401//! kernel's facts, in both runs alike. The queue there keeps every decision
402//! existing recordings were made with (`Detcore::keeps_recorded_decisions`),
403//! so a recording made before replays after: a queued message keeps the
404//! ownership they were made with, which keeps nothing alive
405//! (`DetFd::in_flight_open_file`), so every decision that reaches a
406//! description through it (a receipt's join, a pending connection's pairing,
407//! [`UnixConnections`]) decides as before; a `read`, `readv`, `recvfrom` or
408//! `splice` that returns puts a queue holding messages out of lockstep, and
409//! a `preadv2` does not, as before; a receipt joins the message it matches,
410//! wherever it is, forgetting those before it; no queue holds messages of
411//! data alone, an `EFAULT` receive, a short batch and a send to a gone peer
412//! change nothing, and a table goes when the backend tears it down. The lock
413//! ledger feeds nothing the guest reads there
414//! (`Detcore::refresh_received_locks`), and counts no copy in flight for

469/// Release `released`, queued descriptors Linux released without a receive:
470/// each uncounts its copy in flight, and a description whose last reference
471/// such a copy was goes with it, with the messages queued to it in turn
472/// ([`InFlightOpenFile::release`]), as Linux's last `fput` releases them. What
473/// that releases in the global state comes back, for the caller to apply
474/// (`Detcore::settle_released_rights` in the releasing call, and the global
475/// state at the terminal receipt of a death by a fatal signal,
476/// `GlobalState::release_tables_at_death`).
477pub(crate) fn settle(released: Vec<SentDescriptor>) -> Settled {
478    let mut pending = released;
479    let mut settled = Settled::default();
480    while let Some(sent) = pending.pop() {
481        settled.lock_copies.extend(sent.lock_copy);
482        if let Some((open_file, ty, queued)) = sent.open_file.and_then(InFlightOpenFile::release) {
483            if ty == crate::fd::FdType::Socket {
484                settled.ports.push(open_file);
485            }
486            pending.extend(queued);
487        }
488    }
489    settled
490}

512/// The descriptors carried by the `SCM_RIGHTS` messages in a sent or
513/// received control buffer.
514pub(crate) fn received_descriptors(control: &[u8]) -> Vec<RawFd> {
515    const HEADER: usize = size_of::<libc::cmsghdr>();
516    let align = |length: usize| length.next_multiple_of(size_of::<usize>());
517    let mut descriptors = Vec::new();
518    let mut offset = 0;
519    while let Some(header) = control.get(offset..offset + HEADER) {
520        let length = usize::from_ne_bytes(header[..8].try_into().unwrap());
521        let level = i32::from_ne_bytes(header[8..12].try_into().unwrap());
522        let kind = i32::from_ne_bytes(header[12..16].try_into().unwrap());
523        let Some(data) = control.get(offset + HEADER..offset.saturating_add(length)) else {
524            break;
525        };
526        if level == libc::SOL_SOCKET && kind == libc::SCM_RIGHTS {
527            descriptors.extend(
528                data.as_chunks::<{ size_of::<RawFd>() }>()
529                    .0
530                    .iter()
531                    .map(|fd| RawFd::from_ne_bytes(*fd)),
532            );
533        }
534        if length < HEADER {
535            break;
536        }
537        offset += align(length);
538    }
539    descriptors
540}

542/// The descriptors a `struct msghdr`, read after a receive, says Linux
543/// installed through `SCM_RIGHTS`: Linux updates `msg_controllen` to the
544/// control bytes it wrote, so bytes past it (a reused buffer's earlier
545/// messages) are not read.
546fn delivered_through<M: MemoryAccess>(memory: &M, header: &Msghdr) -> Vec<RawFd> {
547    if header.msg_control.is_null() || header.msg_controllen == 0 {
548        return Vec::new();
549    }
550    let Some(address) = Addr::<u8>::from_raw(header.msg_control as usize) else {
551        return Vec::new();
552    };
553    let mut control = vec![0; header.msg_controllen.min(MAX_CONTROL_BYTES)];
554    if memory.read_exact(address, &mut control).is_err() {
555        return Vec::new();
556    }
557    received_descriptors(&control)
558}

560/// The descriptors `call`, which returned `ret`, installed through
561/// `SCM_RIGHTS`, in the order Linux reports them: those of a `recvmsg`, or of
562/// the `ret` messages a `recvmmsg` received. `None` for any other call and
563/// for a failed one. Read from guest memory after the call; a header that
564/// cannot be read names none.
565pub(crate) fn delivered_descriptors<M: MemoryAccess>(
566    memory: &M,
567    call: &Syscall,
568    ret: i64,
569) -> Option<Vec<RawFd>> {
570    if ret < 0 {
571        return None;
572    }
573    match call {
574        Syscall::Recvmsg(call) => {
575            let header: Option<Msghdr> = call
576                .msg()
577                .and_then(|address| memory.read_value(address).ok());
578            Some(header.map_or_else(Vec::new, |header| delivered_through(memory, &header)))
579        }
580        Syscall::Recvmmsg(call) => {
581            let Some(address) = call.mmsg() else {
582                return Some(Vec::new());
583            };
584            let count = (ret as usize).min(libc::UIO_MAXIOV as usize);
585            // SAFETY: `mmsghdr` is a plain C record; all-zero values are
586            // valid staging values that `read_values` overwrites.
587            let mut messages: Vec<Mmsghdr> =
588                (0..count).map(|_| unsafe { std::mem::zeroed() }).collect();
589            if memory.read_values(address.into(), &mut messages).is_err() {
590                return Some(Vec::new());
591            }
592            Some(
593                messages
594                    .iter()
595                    .flat_map(|message| delivered_through(memory, &message.msg_hdr))
596                    .collect(),
597            )
598        }
599        _ => None,
600    }
601}

646/// Reads the input-only fields of `message`; `None` if its iovec array
647/// cannot be read (Linux then fails that message with EFAULT).
648fn message_fields<M: MemoryAccess>(memory: &M, message: &Msghdr) -> Option<MessageFields> {
649    let mut segments = Vec::new();
650    if !message.msg_iov.is_null() && message.msg_iovlen > 0 {
651        let count = message.msg_iovlen.min(libc::UIO_MAXIOV as usize);
652        // SAFETY: `iovec` is a plain C record; all-zero values are valid
653        // staging values that `read_values` overwrites.
654        let mut iovecs: Vec<libc::iovec> =
655            (0..count).map(|_| unsafe { std::mem::zeroed() }).collect();
656        memory
657            .read_values(
658                Addr::<libc::iovec>::from_raw(message.msg_iov as usize)?,
659                &mut iovecs,
660            )
661            .ok()?;
662        segments.extend(
663            iovecs
664                .iter()
665                .map(|iov| (iov.iov_base as usize, iov.iov_len)),
666        );
667    }
668    Some(MessageFields {
669        name: message.msg_name as usize,
670        iov: message.msg_iov as usize,
671        iovlen: message.msg_iovlen,
672        control: message.msg_control as usize,
673        segments,
674    })
675}

677/// Whether the `count` iovecs at `iov` ask for no bytes: there are none, or
678/// each is of length 0. An array that cannot be read counts as one that asks
679/// for some.
680pub(crate) fn iovecs_are_empty<M: MemoryAccess>(
681    memory: &M,
682    iov: Option<Addr<libc::iovec>>,
683    count: usize,
684) -> bool {

686        return true;
687    }

690    };

695}

697/// Whether any output range overlaps any input range other than its own
698/// counterpart: `outputs` pairs each range with whether an identical input
699/// range is its own (a header written back into itself, a control buffer
700/// filled with its own control data). Counted with sorted interval ends:
701/// the inputs overlapping `[start, end)` are those starting before `end`
702/// less those ending at or before `start`.
703fn outputs_overlap_inputs(inputs: &[Range], outputs: &[(Range, bool)]) -> bool {
704    let live = |range: &&Range| range.1 > 0;
705    let mut starts: Vec<usize> = inputs.iter().filter(live).map(|range| range.0).collect();
706    let mut ends: Vec<usize> = inputs
707        .iter()
708        .filter(live)
709        .map(|range| range.0.saturating_add(range.1))
710        .collect();
711    starts.sort_unstable();
712    ends.sort_unstable();
713    outputs.iter().any(|&((start, length), own)| {
714        if length == 0 {
715            return false;
716        }
717        let end = start.saturating_add(length);
718        let overlapping =
719            starts.partition_point(|&s| s < end) - ends.partition_point(|&e| e <= start);
720        overlapping > usize::from(own)
721    })
722}

885/// The buffers a receive's bytes go to, as Linux checks them before it asks
886/// the socket (Linux v6.17): `import_ubuf` and `vfs_read` require a buffer in
887/// user space
888/// (<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/lib/iov_iter.c?h=v6.17#n1528>),
889/// and `__import_iovec` reads the iovec array and requires each iovec in user
890/// space
891/// (<https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/lib/iov_iter.c?h=v6.17#n1447>).
892/// `None` where that check fails with `EFAULT`, so that the call took
893/// nothing from the socket.
894pub(crate) fn receive_buffers<M: MemoryAccess>(
895    memory: &M,
896    request: Request,
897) -> Option<Vec<(usize, usize)>> {
898    match request {
899        Request::Bytes(at, length) => in_user_space(at, length).then(|| vec![(at, length)]),
900        Request::Spliced(_) => Some(Vec::new()),
901        Request::Iovecs(_, 0) => Some(Vec::new()),
902        Request::Iovecs(at, count) => {
903            if count > libc::UIO_MAXIOV as usize {
904                return None;
905            }
906            let iov = Addr::<libc::iovec>::from_raw(at)?;
907            // SAFETY: `iovec` is a plain C record; all-zero values are valid
908            // staging values that `read_values` overwrites.
909            let mut iovecs: Vec<libc::iovec> =
910                (0..count).map(|_| unsafe { std::mem::zeroed() }).collect();
911            memory.read_values(iov, &mut iovecs).ok()?;
912            iovecs
913                .iter()

921/// The buffers the first message of a `recvmsg` or `recvmmsg` (`call`)
922/// receives into, as Linux checks them before it asks the socket
923/// (`recvmsg_copy_msghdr`, `___sys_recvmsg`,
924/// <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/socket.c?h=v6.17#n2864>):
925/// its header must be readable, a `recvmmsg` timeout too, and its iovecs as
926/// [`receive_buffers`] says; and whether its control buffer has room for
927/// one descriptor, without which Linux releases every descriptor the message
928/// carried (`scm_detach_fds`). `None` where that check fails with `EFAULT`.
929pub(crate) fn message_receive_buffers<M: MemoryAccess>(
930    memory: &M,
931    call: &Syscall,
932) -> Option<(Vec<(usize, usize)>, bool)> {
933    let header: Msghdr = match call {
934        Syscall::Recvmsg(call) => memory.read_value(call.msg()?).ok()?,
935        Syscall::Recvmmsg(call) => {
936            if let Some(timeout) = call.timeout() {
937                let _: libc::timespec = memory.read_value(timeout.cast()).ok()?;
938            }
939            let entry: Mmsghdr = memory.read_value(call.mmsg()?).ok()?;
940            entry.msg_hdr
941        }
942        _ => return Some((Vec::new(), false)),
943    };
944    // SAFETY: CMSG_LEN computes a length; it reads nothing.
945    let one = unsafe { libc::CMSG_LEN(std::mem::size_of::<RawFd>() as u32) } as usize;
946    let room = !header.msg_control.is_null() && header.msg_controllen >= one;
947    receive_buffers(
948        memory,
949        Request::Iovecs(header.msg_iov as usize, header.msg_iovlen),
950    )
951    .map(|buffers| (buffers, room))
952}

960/// What an address a guest passed names, for `AF_UNIX` pairing
961/// ([`unix_address`]).
962#[derive(Clone, Debug, PartialEq, Eq)]
963pub(crate) enum UnixAddress {
964    /// Not an `AF_UNIX` address (its family is another, or it is too short
965    /// to have one).
966    Other,
967    /// An `AF_UNIX` name Detcore can compare: an abstract name's bytes after
968    /// `sun_family`, its leading NUL included, which Linux compares whole
969    /// (`unix_find_abstract`), or an absolute path up to its first NUL.
970    Named(Box<[u8]>),
971    /// An `AF_UNIX` address whose socket Detcore cannot name: a relative
972    /// path, which names a different file from each working directory, an
973    /// unnamed address, or one it could not read (a `connect` or `bind`
974    /// through an unreadable address fails with `EFAULT`, so only a call
975    /// that succeeded is ever attributed).
976    Unnamed,
977}

979/// What the address at `address` in guest memory (`length` bytes) names
980/// ([`UnixAddress`]).
981pub(crate) fn unix_address<M: MemoryAccess>(
982    memory: &M,
983    address: usize,
984    length: usize,
985) -> UnixAddress {
986    const PATH: usize = std::mem::offset_of!(libc::sockaddr_un, sun_path);
987    let length = length.min(size_of::<libc::sockaddr_un>());
988    if length < size_of::<libc::sa_family_t>() {
989        return UnixAddress::Other;
990    }
991    let mut bytes = vec![0u8; length];
992    let read = Addr::<u8>::from_raw(address)
993        .is_some_and(|address| memory.read_exact(address, &mut bytes).is_ok());
994    if !read {
995        return UnixAddress::Unnamed;
996    }
997    if u16::from_ne_bytes([bytes[0], bytes[1]]) != libc::AF_UNIX as u16 {
998        return UnixAddress::Other;
999    }
1000    let path = bytes.get(PATH..).unwrap_or_default();
1001    match path.first() {
1002        Some(0) => UnixAddress::Named(path.into()),
1003        Some(b'/') => path
1004            .split(|&byte| byte == 0)
1005            .next()
1006            .map_or(UnixAddress::Unnamed, |path| UnixAddress::Named(path.into())),
1007        _ => UnixAddress::Unnamed,
1008    }
1009}

1057/// The connections waiting for an `accept` on each `AF_UNIX` name a guest
1058/// bound, so that an accepted connection and the socket whose `connect` made
1059/// it are paired (`Detcore::note_unix_accept`). One per run: every task of
1060/// the process tree shares it (`ThreadState::unix_connections`), as it shares
1061/// the guest clock, so a bind, a connect and an accept in different threads
1062/// or processes meet.
1063///
1064/// A connect Detcore cannot attribute to one of these names may have
1065/// reached any of them: one through a relative path or another spelling of
1066/// a path (a doubled slash, a `..`, a symlink or hard link, a renamed
1067/// socket file), to a name no guest bound here, through an absolute path
1068/// from a task whose root may not be the container's (`chroot`, where one
1069/// path names another file), or of a socket whose type Detcore did not see
1070/// made. Every name's order is then unknown until it is bound again
1071/// ([`UnixConnections::lost`]), so no accept pairs with a socket whose
1072/// connection it may not have taken. A bind through an absolute path from
1073/// such a task is not tracked. A connection made from outside Hermit is not
1074/// seen at all.
1075///
1076/// That costs precision, never correctness: one stream connect to a socket
1077/// no guest bound here, as a glibc user or group lookup makes through NSS
1078/// (nscd, systemd-userdb), stops pairing for every name until it is bound
1079/// again, and descriptors received over those connections are then handled
1080/// as on main.
1081#[derive(Default)]
1082pub(crate) struct UnixConnections {
1083    names: BTreeMap<Box<[u8]>, PendingConnections>,
1084    /// The last bind's generation ([`PendingConnections::generation`]).
1085    binds: u64,
1086}
1087
1088impl UnixConnections {
1089    /// A guest bound `listener` to `name`: its listener's queue starts
1090    /// empty. Which bind of the name it was, for the listener to keep.
1091    pub(crate) fn bound(&mut self, name: &[u8], listener: OpenFileHandle) -> u64 {
1092        self.binds += 1;
1093        self.names.insert(
1094            name.into(),
1095            PendingConnections {
1096                generation: self.binds,
1097                listener: Some(listener),
1098                ..Default::default()
1099            },
1100        );
1101        self.binds
1102    }
1103
1104    /// The socket the last guest bind of `name` bound, if a guest bound it.
1105    fn listener(&self, name: &[u8]) -> Option<&OpenFileHandle> {
1106        self.names.get(name)?.listener.as_ref()
1107    }
1108
1109    /// How many connections wait for an `accept` on `name`, or `None` where
1110    /// their order is unknown or no guest bound it.
1111    #[cfg(test)]
1112    pub(crate) fn waiting(&self, name: &[u8]) -> Option<usize> {
1113        self.names
1114            .get(name)
1115            .filter(|pending| !pending.unknown)
1116            .map(|pending| pending.sockets.len())
1117    }
1118
1119    /// A guest's `connect` to `name` completed: `socket` is the connecting
1120    /// socket where it completed in the caller's turn, `None` where it did
1121    /// not. A name no guest bound here may be another spelling of one that
1122    /// was ([`Self::lost`]).
1123    fn connected(&mut self, name: &[u8], socket: Option<OpenFileHandle>) {
1124        let Some(pending) = self.names.get_mut(name) else {
1125            self.lost();
1126            return;
1127        };
1128        match socket {
1129            _ if pending.unknown => {}
1130            Some(socket) if pending.sockets.len() < MAX_PENDING_CONNECTIONS => {
1131                pending.sockets.push_back(socket)
1132            }
1133            _ => pending.lose_order(),
1134        }
1135    }
1136
1137    /// A guest's stream or seqpacket `connect` completed that Detcore cannot
1138    /// attribute to one name ([`UnixConnections`]): every name's order is
1139    /// unknown.
1140    fn lost(&mut self) {
1141        self.names
1142            .values_mut()
1143            .for_each(PendingConnections::lose_order);
1144    }
1145
1146    /// A guest's `accept` on the listener bound to `name` by bind
1147    /// `generation` completed, in the caller's turn or not (`in_turn`): the
1148    /// socket whose connection it took, if that is known. A listener whose
1149    /// name was bound again since has none: the connections Detcore tracks
1150    /// are the later listener's.
1151    fn accepted(&mut self, name: &[u8], generation: u64, in_turn: bool) -> Option<OpenFileHandle> {
1152        let pending = self
1153            .names
1154            .get_mut(name)
1155            .filter(|pending| pending.generation == generation)?;
1156        if !in_turn {
1157            pending.lose_order();
1158        }
1159        if pending.unknown {
1160            return None;
1161        }
1162        pending.sockets.pop_front()
1163    }
1164}

1194impl ReceiveGeometry {
1195    /// The geometry of `call`, a `recvmsg` or `recvmmsg`, read from guest
1196    /// memory before it runs; `None` for any other call or an unreadable
1197    /// `recvmsg` header. A `recvmmsg` vector is read in full, up to the
1198    /// `vlen` Linux may process (at most [`MAX_SNAPSHOT_ENTRIES`] entries);
1199    /// an entry or iovec array that cannot be read makes the geometry
1200    /// unusable, and the call's descriptors are not recorded.
1201    pub(crate) fn before<M: MemoryAccess>(memory: &M, call: &Syscall) -> Option<Self> {
1202        let message_input = |header: Range, message: &Msghdr| -> Option<MessageInput> {
1203            Some(MessageInput {
1204                header,
1205                control: (message.msg_control as usize, message.msg_controllen),
1206                name: (message.msg_name as usize, message.msg_namelen as usize),
1207                iov_array: (
1208                    message.msg_iov as usize,
1209                    message.msg_iovlen.min(libc::UIO_MAXIOV as usize) * size_of::<libc::iovec>(),
1210                ),
1211                fields: message_fields(memory, message)?,
1212            })
1213        };
1214        match call {
1215            Syscall::Recvmsg(call) => {
1216                let address = call.msg()?;
1217                let message: Msghdr = memory.read_value(address).ok()?;
1218                let header = (address.as_raw(), size_of::<Msghdr>());
1219                let (messages, unusable) = match message_input(header, &message) {
1220                    Some(input) => (vec![input], None),
1221                    None => (vec![], Some("its iovec array cannot be read")),
1222                };
1223                Some(ReceiveGeometry {
1224                    messages,
1225                    batch: false,
1226                    timeout: None,
1227                    unusable,
1228                })
1229            }
1230            Syscall::Recvmmsg(call) => {
1231                let base = call.mmsg().map_or(0, |vector| vector.as_raw());
1232                let timeout = call
1233                    .timeout()
1234                    .map(|timeout| (timeout.as_raw(), size_of::<libc::timespec>()));
1235                if call.vlen() as usize > MAX_SNAPSHOT_ENTRIES {
1236                    return Some(ReceiveGeometry {
1237                        messages: Vec::new(),
1238                        batch: true,
1239                        timeout,
1240                        unusable: Some("its vector is too long to read before the call"),
1241                    });
1242                }
1243                let mut messages = Vec::new();
1244                let mut unusable = None;
1245                for index in 0..call.vlen() as usize {
1246                    let at = base.saturating_add(index * size_of::<Mmsghdr>());
1247                    let Some(Ok(entry)) =
1248                        Addr::<Mmsghdr>::from_raw(at).map(|entry| memory.read_value(entry))
1249                    else {
1250                        unusable = Some("an entry of its vector cannot be read");
1251                        break;
1252                    };
1253                    let entry: Mmsghdr = entry;
1254                    match message_input((at, size_of::<Mmsghdr>()), &entry.msg_hdr) {
1255                        Some(input) => messages.push(input),
1256                        None => {
1257                            unusable = Some("an iovec array cannot be read");
1258                            break;
1259                        }
1260                    }
1261                }
1262                Some(ReceiveGeometry {
1263                    messages,
1264                    batch: true,
1265                    timeout,
1266                    unusable,
1267                })
1268            }
1269            _ => None,
1270        }
1271    }
1272
1273    /// Whether an output range of the call overlaps an input range other
1274    /// than its own: every range Linux may write for any entry it may
1275    /// process (a header's written-back fields and `msg_len`, a name
1276    /// buffer, an iovec segment, a control buffer, the timeout) against
1277    /// every range it reads (headers, iovec arrays, control buffers).
1278    fn overlapping(&self) -> bool {
1279        let mut inputs = Vec::new();
1280        let mut outputs = Vec::new();
1281        for message in &self.messages {
1282            inputs.extend([message.header, message.iov_array, message.control]);
1283            outputs.extend([
1284                (message.header, true),
1285                (message.control, true),
1286                (message.name, false),
1287            ]);
1288            outputs.extend(
1289                message
1290                    .fields
1291                    .segments
1292                    .iter()
1293                    .map(|&segment| (segment, false)),
1294            );
1295        }
1296        outputs.extend(self.timeout.map(|timeout| (timeout, false)));
1297        outputs_overlap_inputs(&inputs, &outputs)
1298    }
1299
1300    /// Whether the input-only fields read now, after the call, are the
1301    /// ones read before it. After a successful attempt that ran in the
1302    /// caller's turn no other guest thread ran, so these are the values that
1303    /// attempt used: a sibling that changed them during an earlier attempt's
1304    /// wait (`EAGAIN`, then polling) is detected here.
1305    fn still_named<M: MemoryAccess>(&self, memory: &M) -> bool {
1306        self.messages.iter().all(|message| {
1307            Addr::<Msghdr>::from_raw(message.header.0)
1308                .and_then(|at| memory.read_value(at).ok())
1309                .and_then(|now: Msghdr| message_fields(memory, &now))
1310                .is_some_and(|now| now == message.fields)
1311        })
1312    }
1313
1314    /// The descriptors a receive with this geometry, which returned `ret`,
1315    /// installed: for each delivered message (one for `recvmsg`, the first
1316    /// `ret` for `recvmmsg`), the control bytes Linux reports writing (the
1317    /// `msg_controllen` it writes back) at the control buffer named before
1318    /// the call. None are named if an output of the call overlaps one of its
1319    /// inputs, if the inputs changed before the attempt that succeeded, or if
1320    /// Linux reports more control bytes than the buffer named before the call
1321    /// held.
1322    pub(crate) fn delivered<M: MemoryAccess>(&self, memory: &M, ret: i64) -> Delivered {
1323        let refused = |reason| Delivered {
1324            fds: Vec::new(),
1325            messages: Vec::new(),
1326            refused: Some(reason),
1327        };
1328        if ret < 0 {
1329            return Delivered::default();
1330        }
1331        if let Some(reason) = self.unusable {
1332            return refused(reason);
1333        }
1334        if self.overlapping() {
1335            return refused("a buffer it writes overlaps a buffer or header it reads");
1336        }
1337        if !self.still_named(memory) {
1338            return refused("its buffers changed before the attempt that succeeded");
1339        }
1340        let count = if self.batch {
1341            (ret as usize).min(self.messages.len())
1342        } else {
1343            self.messages.len().min(1)
1344        };
1345        let mut fds = Vec::new();
1346        let mut messages = Vec::new();
1347        for message in &self.messages[..count] {
1348            // Linux writes the message's flags back too.
1349            let flags = message.header.0 + std::mem::offset_of!(Msghdr, msg_flags);
1350            let flags: Option<libc::c_int> =
1351                Addr::<libc::c_int>::from_raw(flags).and_then(|at| memory.read_value(at).ok());
1352            // And a batch entry's length (`mmsghdr::msg_len`, after its
1353            // header); a single receive's result is its length.
1354            let bytes = if self.batch {
1355                Addr::<u32>::from_raw(message.header.0 + std::mem::size_of::<Msghdr>())
1356                    .and_then(|at| memory.read_value(at).ok())
1357                    .map(|length: u32| length as usize)
1358            } else {
1359                usize::try_from(ret).ok()
1360            };
1361            let received = if message.control.0 == 0 || message.control.1 == 0 {
1362                Vec::new()
1363            } else {
1364                let written = message.header.0 + std::mem::offset_of!(Msghdr, msg_controllen);
1365                let Some(length) =
1366                    Addr::<usize>::from_raw(written).and_then(|at| memory.read_value(at).ok())
1367                else {
1368                    return refused("its control length cannot be read back");
1369                };
1370                if length > message.control.1 {
1371                    return refused("its control buffer grew before the attempt that succeeded");
1372                }
1373                let length = length.min(MAX_CONTROL_BYTES);
1374                let mut control = vec![0; length];
1375                match Addr::<u8>::from_raw(message.control.0)
1376                    .map(|at| memory.read_exact(at, &mut control))
1377                {
1378                    _ if length == 0 => Vec::new(),
1379                    Some(Ok(())) => received_descriptors(&control),
1380                    _ => return refused("its control data cannot be read back"),
1381                }
1382            };
1383            if received.is_empty() {
1384                // With no room for even one descriptor (no control buffer,
1385                // or too small a one), Linux releases them all and sets
1386                // `MSG_CTRUNC` (`scm_detach_fds`, `scm_recv_unix`): the
1387                // message may have carried some. So may one whose flags
1388                // cannot be read back. Any other carried none.
1389                messages.push(DeliveredMessage {
1390                    count: 0,
1391                    truncated: flags.is_none_or(|flags| flags & libc::MSG_CTRUNC != 0),
1392                    bytes,
1393                });
1394                continue;
1395            }
1396            // Flags that cannot be read back count as complete, so that only
1397            // all of a queued message can match.
1398            let truncated = flags.is_some_and(|flags| flags & libc::MSG_CTRUNC != 0);
1399            messages.push(DeliveredMessage {
1400                count: received.len(),
1401                truncated,
1402                bytes,
1403            });
1404            fds.extend(received);
1405        }
1406        Delivered {
1407            fds,
1408            messages,
1409            refused: None,
1410        }
1411    }
1412}

1477enum ReceiptMode {
1478    /// The tool shares the guest's descriptor table and discovers a received
1479    /// descriptor when a call first names it.
1480    Discovered,
1481    /// Detcore records each one as the receive returns.
1482    Recorded,
1483    /// Detcore keeps no record of them, for the reason given.

1488    /// How this run handles received descriptors. Recorded only where the
1489    /// tool does not share the guest's descriptor table (it discovers them
1490    /// there), and with sequentialized threads (otherwise another thread could
1491    /// close a number, or `dup2` another file over it, between the receive
1492    /// and the facts taken here; a received rendered procfs descriptor is
1493    /// refused by name there when first named,
1494    /// `Detcore::adopt_received_placeholders`). Under record and replay the
1495    /// facts come from the recording ([`Self::probe_received`]), so replay,
1496    /// which stands in a placeholder for each received descriptor, takes the
1497    /// recording's.
1498    fn receipt_mode<G: Guest<Self>>(&self, guest: &G) -> ReceiptMode {
1499        if self.cfg.backend.tool_shares_guest_descriptor_table {
1500            ReceiptMode::Discovered
1501        } else if !guest.config().sequentialize_threads {
1502            ReceiptMode::Unrecorded("without sequentialized threads")
1503        } else {
1504            ReceiptMode::Recorded
1505        }
1506    }

1508    /// Whether a send or receive through `call` completes in the caller's
1509    /// turn, decided before the call: the descriptor is one Detcore polls in
1510    /// turn (`IOAction::NonblockizeRetry`) or one already nonblocking
1511    /// (`IOAction::PassThru`). Any other call runs on the background path
1512    /// Whether a receive through `call` completes in the caller's turn,
1513    /// decided before the call: the descriptor is one Detcore polls in turn
1514    /// (`IOAction::NonblockizeRetry`), or one already nonblocking or a call
1515    /// whose own flags keep it from waiting (`MSG_DONTWAIT`;
1516    /// `IOAction::PassThru`). Any other receive runs on the background path
1517    /// (`BlockingExternalIO`: a physically blocking socket, or one Detcore
1518    /// keeps no model of), where other tasks run between the kernel's
1519    /// completion and the caller's continuation and could close or replace a
1520    /// delivered number, or rewrite the control data; the descriptors such a
1521    /// receive delivers are never recorded, nor those such a send carries
1522    /// queued.
1523    pub(crate) fn completes_in_turn<G, C>(&self, guest: &mut G, call: C) -> bool
1524    where
1525        G: Guest<Self>,
1526        C: crate::syscalls::helpers::NonblockableSyscall + Into<Syscall>,
1527    {
1528        matches!(
1529            crate::syscalls::helpers::ioaction_based_on_fd_status(guest, call),
1530            Ok(crate::syscalls::helpers::IOAction::NonblockizeRetry
1531                | crate::syscalls::helpers::IOAction::PassThru)
1532        )
1533    }

1536    /// whether it completes in the caller's turn ([`Self::completes_in_turn`]).
1537    /// Asked only where it matters, of an `AF_UNIX` socket whose type
1538    /// Detcore saw made, outside record and replay
1539    /// (`Detcore::note_receive_without_control`); false elsewhere.

1542        G: Guest<Self>,
1543        C: crate::syscalls::helpers::NonblockableSyscall + Into<Syscall>,

1547            && guest

1569    /// Where the tool discovers received descriptors (DBT, whose Tool shares
1570    /// the guest's descriptor table), the receiver's description is made from
1571    /// the host's status flags (`ThreadState::with_detfd`), and an inotify
1572    /// instance's host O_NONBLOCK may be the one Detcore set when its sender
1573    /// made it (`Detcore::handle_inotify_init1`) rather than the sender's own.
1574    /// So each inotify instance a receive delivered (`delivered`) whose host
1575    /// description is nonblocking has a guest blocking mode that is unknown
1576    /// until the guest sets it (`DetFd::blocking_mode_unknown`), as an
1577    /// unmatched receipt's is where receipts are recorded: an `F_GETFL` of
1578    /// it, and a read of it that finds nothing queued, are refused by name
1579    /// rather than answered with a mode that may be wrong (a blocking read
1580    /// answered with EAGAIN, which Linux never gives it).
1581    fn mark_discovered_inotify_receipts<G: Guest<Self>>(&self, guest: &G, delivered: &Delivered) {
1582        if !self.marks_discovered_inotify_receipts(guest) {
1583            return;
1584        }
1585        for &fd in &delivered.fds {
1586            // A number another thread has closed meanwhile is not discovered.
1587            let _ = guest.thread_state().with_detfd(fd, |detfd| {
1588                if detfd.ty() == crate::fd::FdType::Inotify
1589                    && detfd.status_flags() & libc::O_NONBLOCK != 0
1590                {
1591                    detfd.mark_blocking_mode_unknown();
1592                }
1593            });
1594        }
1595    }

1597    /// Record in this thread's descriptor table each descriptor a receive
1598    /// from `from` installed (`delivered`), where this run records received
1599    /// descriptors and the receive completed in the caller's turn (`in_turn`,
1600    /// [`Self::completes_in_turn`]), and return those it recorded as open
1601    /// files new to the table. One that joined the open file its sender's
1602    /// table modeled (see the module documentation) is not returned: it brings
1603    /// the lock ledger no new identity, and `refresh_description_locks` would
1604    /// mark that shared open file, the sender's too, as received. The guest's
1605    /// result is never changed. A descriptor left out of the table, as every
1606    /// received descriptor was before, is named in a warning: for each receive
1607    /// whose layout cannot be trusted, each receive on the background path,
1608    /// each number that already has a record, each anonymous inode other than
1609    /// an inotify instance, and each descriptor whose facts cannot be taken.
1610    /// Without sequentialized threads none is recorded, logged at debug level
1611    /// only (a warning per call, or per tool process, would differ between
1612    /// runs that share a process). Where the tool discovers them, none is
1613    /// recorded either, and the inotify instances among them are marked
1614    /// (`Self::mark_discovered_inotify_receipts`). `cloexec` is whether the receive asked for
1615    /// its descriptors close-on-exec (`MSG_CMSG_CLOEXEC`), which a descriptor
1616    /// listed without its facts keeps. A tool error, after which record and
1617    /// replay could no longer follow each other, ends the run.
1618    pub(crate) async fn record_received_descriptors<G: Guest<Self>>(
1619        &self,
1620        guest: &mut G,
1621        delivered: &Delivered,
1622        channel: Channel,
1623        in_turn: bool,
1624        cloexec: bool,
1625        from: ReceivedFrom,
1626    ) -> Result<Vec<RawFd>, Error> {
1627        match self.receipt_mode(guest) {
1628            ReceiptMode::Discovered => {
1629                self.mark_discovered_inotify_receipts(guest, delivered);
1630                return Ok(Vec::new());
1631            }
1632            ReceiptMode::Unrecorded(why) => {
1633                if !delivered.fds.is_empty() || delivered.refused.is_some() {
1634                    // A listing of this table cannot come from the model now
1635                    // (`syscalls::files::descriptor_directory`).
1636                    guest.thread_state().note_unaccounted_receipt();
1637                }
1638                if !delivered.fds.is_empty() {
1639                    debug!(
1640                        "[detcore] descriptors {:?}, received {channel}, are not recorded ({why})",
1641                        delivered.fds
1642                    );
1643                }
1644                return Ok(Vec::new());
1645            }
1646            ReceiptMode::Recorded => {}
1647        }
1648        if let Some(reason) = delivered.refused {
1649            guest.thread_state().note_unaccounted_receipt();
1650            warn!(
1651                "[detcore] the descriptors a receive got {channel}, if any, are not recorded: \
1652                 {reason}"
1653            );
1654            self.lose_lockstep_if_queued(guest, from, from.messages);
1655            return Ok(Vec::new());
1656        }
1657        if !in_turn {
1658            self.lose_lockstep_if_queued(guest, from, from.messages);
1659            if !delivered.fds.is_empty() {
1660                guest.thread_state().note_unaccounted_receipt();
1661                warn!(
1662                    "[detcore] descriptors {:?}, received {channel} on the background path, are \
1663                     not recorded: another task may have closed or replaced their numbers, or \
1664                     rewritten the control data, before this one resumed",
1665                    delivered.fds
1666                );
1667            }
1668            return Ok(Vec::new());
1669        }
1670        let mut recorded = Vec::new();
1671        let mut rest = delivered.fds.as_slice();
1672        for message in &delivered.messages {
1673            if message.count == 0 {
1674                self.note_message_without_descriptors(
1675                    guest,
1676                    from,
1677                    message.truncated,
1678                    message.bytes,
1679                );
1680                continue;
1681            }
1682            let (fds, after) = rest.split_at(message.count.min(rest.len()));
1683            rest = after;
1684            let mut facts = Vec::with_capacity(fds.len());
1685            for &fd in fds {
1686                match self.received_facts(guest, fd, channel).await {
1687                    Err(Error::Tool(error)) => return Err(Error::Tool(error)),
1688                    taken => facts.push(taken),
1689                }
1690            }
1691            let taken = Self::queued_rights(
1692                guest,
1693                from,
1694                &facts,
1695                message.truncated,
1696                self.keeps_recorded_decisions(),
1697                message.bytes,
1698            );
1699            let lockstep = taken.as_ref().is_some_and(|taken| taken.lockstep);
1700            let joinable = taken
1701                .as_ref()
1702                .is_some_and(|taken| taken.joinable || self.keeps_recorded_decisions());
1703            let (mut sent, forgotten) = taken
1704                .map(|taken| (taken.sent, taken.forgotten))
1705                .unwrap_or_default();
1706            // The messages before it, which calls Detcore could not match took,
1707            // are released with this receipt.
1708            guest.thread_state().defer_released_rights(forgotten);
1709            let mut joined = vec![false; sent.len()];
1710            for (index, (&fd, facts)) in fds.iter().zip(facts).enumerate() {
1711                let facts = match facts {
1712                    Ok(Some(facts)) => facts,
1713                    Ok(None) => continue,
1714                    Err(error) => {
1715                        // Open, but without its facts: listed, never modelled.
1716                        guest.thread_state().note_unmodelled_descriptor(fd, cloexec);
1717                        warn!(
1718                            "[detcore] descriptor {fd}, received {channel}, is not \
1719                             recorded: {error}"
1720                        );
1721                        continue;
1722                    }
1723                };
1724                let joins = sent.get(index).filter(|_| joinable);
1725                match self
1726                    .record_received_facts(
1727                        guest,
1728                        fd,
1729                        &facts,
1730                        TakenDescriptor {
1731                            sent: joins,
1732                            lockstep,
1733                            peek: from.peek,
1734                        },
1735                        channel,
1736                    )
1737                    .await
1738                {
1739                    Ok(Receipt::New) => recorded.push(fd),
1740                    Ok(Receipt::Joined) => joined[index] = true,
1741                    Ok(Receipt::Unrecorded) => {}
1742                    Err(Error::Tool(error)) => return Err(Error::Tool(error)),
1743                    Err(error) => {
1744                        // Open, but without its facts: listed, never modelled.
1745                        guest.thread_state().note_unmodelled_descriptor(fd, cloexec);
1746                        warn!(
1747                            "[detcore] descriptor {fd}, received {channel}, is not \
1748                             recorded: {error}"
1749                        )
1750                    }
1751                }
1752            }
1753            // What the message held and did not hand to this table goes with
1754            // it: the descriptors Linux could not install (`MSG_CTRUNC`) and
1755            // those this receipt recorded as open files of their own. A peek
1756            // took a copy of a message that stays queued: releasing the copy's
1757            // references releases nothing else.
1758            if !from.peek {
1759                guest.thread_state().defer_released_rights(
1760                    sent.drain(..)
1761                        .zip(joined)
1762                        .filter(|(_, joined)| !joined)
1763                        .map(|(sent, _)| sent),
1764                );
1765            }
1766        }
1767        Ok(recorded)
1768    }

1771    /// installed through `SCM_RIGHTS`: `None` for a number that already has a
1772    /// record, which is kept as it is.
1773    async fn received_facts<G: Guest<Self>>(
1774        &self,
1775        guest: &mut G,
1776        fd: RawFd,
1777        channel: Channel,
1778    ) -> Result<Option<ReceivedFacts>, Error> {
1779        if fd < 0 {
1780            return Ok(None);
1781        }
1782        // Linux gave the receiver free numbers. A record of one already
1783        // describes something Detcore does not know to be gone: kept as it is.
1784        if guest.thread_state().with_detfd(fd, |_| ()).is_ok() {
1785            warn!(
1786                "[detcore] descriptor {fd}, received {channel}, already has a record, which is \
1787                 kept"

1789            return Ok(None);

1792        // them before they ran.

1795                guest,

1797                    .with_fd(fd)
1798                    .with_cmd(syscalls::FcntlCmd::F_GETFD),
1799            )
1800            .await? as i32;

1802            .probe_received(
1803                guest,
1804                syscalls::Fcntl::new()
1805                    .with_fd(fd)
1806                    .with_cmd(syscalls::FcntlCmd::F_GETFL),

1819    /// facts are `facts` (`truncated` when Linux set `MSG_CTRUNC` for it), in
1820    /// the order sent, whether that queue is still in lockstep with the
1821    /// socket's messages, and whether the receipt may join them
1822    /// (`DetFd::take_queued_rights`, which takes a stream receive's `bytes`
1823    /// from a queue that holds every message): `None` when no queued message
1824    /// has their identities, or when one of them has no facts, which leaves
1825    /// the message, if queued, unmatched.
1826    fn queued_rights<G: Guest<Self>>(
1827        guest: &mut G,
1828        from: ReceivedFrom,
1829        facts: &[Result<Option<ReceivedFacts>, Error>],
1830        truncated: bool,
1831        legacy: bool,
1832        bytes: Option<usize>,
1833    ) -> Option<TakenRights> {

1835            .iter()
1836            .map(|facts| match facts {
1837                Ok(Some(facts)) => Some(facts.file()),
1838                _ => None,
1839            })
1840            .collect::<Option<Vec<FileIdentity>>>();
1841        let Some(received) = received else {
1842            if !from.peek {
1843                let _ = guest.thread_state().with_detfd(from.socket, |socket| {
1844                    socket.lose_lockstep_if_queued(1, legacy)
1845                });
1846            }
1847            return None;
1848        };
1849        guest
1850            .thread_state()
1851            .with_detfd(from.socket, |socket| {
1852                socket.take_queued_rights(&received, truncated, from.peek, legacy, bytes)
1853            })
1854            .ok()
1855            .flatten()

1875    /// A `read`, `readv`, `recvfrom`, `preadv2` at the current offset or
1876    /// `splice` through `fd` (`read`) returned `result`. On a socket with
1877    /// descriptors queued to it, it may have taken a message that carried
1878    /// some, which Linux then releases unseen ([`Self::take_or_suspect`]).
1879    ///
1880    /// Where the socket's queue holds every message, the call took the
1881    /// oldest queued message on a datagram or seqpacket socket, and on a
1882    /// stream socket the bytes it reports from the oldest messages on
1883    /// (`DetFd::take_stream_bytes`), and what it took is released.
1884    ///
1885    /// What takes a message is Linux's to say (Linux v6.17): a call with
1886    /// `MSG_PEEK` takes nothing; `read`, `readv` and `preadv2` of no bytes
1887    /// return at once (`sock_read_iter`, "Match SYS5 behaviour",
1888    /// <https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/tree/net/socket.c?h=v6.17#n1154>);
1889    /// a stream socket's read that returns 0 bytes found the stream ended,
1890    /// unless it asked for none, which only `recvfrom` passes on, and which
1891    /// takes the descriptors of the buffer at the head
1892    /// (`unix_stream_read_generic` detaches them before it looks at the
1893    /// length); a datagram or seqpacket read takes a message whatever the
1894    /// bytes it returns. One that fails with `EFAULT` took a message as
1895    /// [`Self::efault_may_have_taken`] says. Under record and replay the
1896    /// rule existing recordings were made with holds: the calls it noted
1897    /// (`ReceiveWithoutControl::noted_by_recordings`) lose lockstep whenever
1898    /// they return.
1899    pub(crate) fn note_receive_without_control<G: Guest<Self>>(
1900        &self,
1901        guest: &mut G,
1902        fd: RawFd,
1903        result: &Result<i64, Error>,
1904        read: ReceiveWithoutControl,
1905    ) {
1906        if !self.pairs_unix_sockets(guest) {
1907            return;
1908        }
1909        if self.keeps_recorded_decisions() {
1910            if read.noted_by_recordings && matches!(result, Ok(taken) if *taken >= 0) {
1911                let _ = guest
1912                    .thread_state()
1913                    .with_detfd(fd, |detfd| detfd.lose_lockstep_if_queued(1, true));
1914            }
1915            return;
1916        }
1917        if read.peek {
1918            return;
1919        }
1920        // Only a socket whose type Detcore saw made is queued to.
1921        let Some(kind) = guest
1922            .thread_state()
1923            .with_detfd(fd, |detfd| detfd.unix_type())
1924            .ok()
1925            .flatten()
1926        else {
1927            return;
1928        };
1929        let stream = kind == libc::SOCK_STREAM;
1930        let empty = || match read.request {
1931            Request::Bytes(_, length) | Request::Spliced(length) => length == 0,
1932            Request::Iovecs(at, count) => {
1933                iovecs_are_empty(&guest.memory(), Addr::from_raw(at), count)
1934            }
1935        };
1936        let took = match result {
1937            // Other tasks ran before this one resumed, and may have changed
1938            // the memory the call named: any return may have taken one.
1939            Ok(_) | Err(Error::Errno(Errno::EFAULT)) if !read.in_turn => true,
1940            Ok(0) if empty() => !read.returns_at_once_when_empty,
1941            Ok(0) => !stream,
1942            Ok(_) => true,
1943            Err(Error::Errno(Errno::EFAULT)) => {
1944                self.efault_may_have_taken(guest, stream, read.request, read.address_out)
1945            }
1946            Err(_) => false,
1947        };
1948        if !took {
1949            return;
1950        }
1951        if stream {
1952            // The bytes a stream read reports come from the oldest messages
1953            // on, whatever call took them (`DetFd::take_stream_bytes`). One
1954            // that failed copying the sender's address out after it took
1955            // them reports none, and had no control buffer to install
1956            // descriptors into ([`Self::take_faulted_stream_read`]).
1957            let released = match result {
1958                Ok(taken) if read.in_turn => guest
1959                    .thread_state()
1960                    .with_detfd(fd, |detfd| {
1961                        detfd.take_stream_bytes(*taken as usize, |_| true)
1962                    })
1963                    .ok()
1964                    .flatten(),
1965                Err(_) if read.in_turn => {
1966                    let buffers = receive_buffers(&guest.memory(), read.request);
1967                    buffers.and_then(|buffers| self.take_faulted_stream_read(guest, fd, &buffers))
1968                }
1969                _ => None,
1970            };
1971            match released {
1972                Some(released) => guest.thread_state().defer_released_rights(released),
1973                None => self.take_or_suspect(guest, fd, false, |_| true),
1974            }
1975            return;
1976        }
1977        // A datagram or seqpacket read takes one message, the oldest Linux
1978        // holds, and returns as many of its bytes as fit, or all of them
1979        // (`MSG_TRUNC`).
1980        let fits = match (read.request, result) {
1981            (Request::Bytes(_, asked), Ok(read)) => Some((asked, *read as usize)),
1982            (Request::Iovecs(at, count), Ok(read)) => {
1983                receive_buffers(&guest.memory(), Request::Iovecs(at, count)).map(|buffers| {
1984                    (
1985                        buffers.iter().map(|buffer| buffer.1).sum::<usize>(),
1986                        *read as usize,
1987                    )
1988                })
1989            }
1990            _ => None,
1991        };
1992        let one = read.takes == Takes::Counted && read.in_turn;
1993        self.take_or_suspect(guest, fd, one, move |head| match fits {
1994            Some((asked, read)) => read == asked.min(head.bytes) || read == head.bytes,
1995            None => true,
1996        });
1997    }

1999    /// A call through the socket `fd` took a message from it without naming
2000    /// its descriptors. Where Detcore knows which (`one`: the oldest Linux
2001    /// held, for a call completed in the caller's turn) and the socket's
2002    /// queue holds every message, that is the oldest queued one, which `fits`
2003    /// must agree with (`DetFd::take_head_message`): it goes, and what it
2004    /// carried is released when the call completes, as Linux releases it.
2005    /// Otherwise the call may have taken a message unseen
2006    /// (`DetFd::lose_lockstep_if_queued`), suspect until a later receipt.
2007    fn take_or_suspect<G: Guest<Self>>(
2008        &self,
2009        guest: &mut G,
2010        fd: RawFd,
2011        one: bool,
2012        fits: impl FnOnce(&crate::fd::QueuedMessage) -> bool,
2013    ) {
2014        let mut fits = Some(fits);
2015        let taken = guest
2016            .thread_state()
2017            .with_detfd(fd, |detfd| {
2018                if one
2019                    && let Some(fits) = fits.take()
2020                    && let Some(taken) = detfd.take_head_message(fits)
2021                {
2022                    return Some(taken);
2023                }
2024                detfd.lose_lockstep_if_queued(1, false);
2025                None

2692    /// Record descriptor `fd`, which Linux has just installed through
2693    /// `SCM_RIGHTS` or a binder transaction (`channel`), from the kernel's
2694    /// facts about it (`facts`), and say how: as an alias of the open file
2695    /// description its sender's table modeled (`taken`), or as an open file
2696    /// of its own.
2697    async fn record_received_facts<G: Guest<Self>>(
2698        &self,
2699        guest: &mut G,
2700        fd: RawFd,
2701        facts: &ReceivedFacts,
2702        taken: TakenDescriptor<'_>,
2703        channel: Channel,
2704    ) -> Result<Receipt, Error> {
2705        let TakenDescriptor {
2706            sent,
2707            lockstep,
2708            peek,
2709        } = taken;
2710        // Exited senders' exit hooks may run meanwhile (docs/RACE_PROBES.md).
2711        #[cfg(debug_assertions)]
2712        crate::race_probe::delay_on_any_backend(
2713            crate::race_probe::RECEIPT_DECISION,
2714            self.cfg.backend.tool_shares_guest_descriptor_table,
2715        )
2716        .await;
2717        let cloexec = facts.descriptor_flags & libc::FD_CLOEXEC != 0;
2718        // Every anonymous inode has one file identity, so out of lockstep
2719        // only order could say which queued one this is: none is joined.
2720        let anonymous = facts.stat.st_mode & libc::S_IFMT == 0;
2721        // Linux installed the sender's `struct file`, so the received
2722        // descriptor shares its status flags, lock state, directory position
2723        // and scheduler resource, as `dup` would make it: an `O_NONBLOCK` set
2724        // through either shows through both, and a blocking read through the
2725        // received end of a pipe Detcore keeps physically nonblocking still
2726        // waits for the writer. Checked before the anonymous-inode refusal, so
2727        // a received eventfd is the sender's eventfd.
2728        if let Some(open_file) = sent
2729            .filter(|sent| sent.file == facts.file() && (lockstep || !anonymous))
2730            .and_then(|sent| sent.open_file.as_ref())
2731            && self
2732                .join_sent_open_file(guest, fd, cloexec, open_file)
2733                .await?
2734        {
2735            // This table holds the description now: the copy left flight.
2736            if !peek {
2737                open_file.land();
2738            }
2739            // The lock ledger follows this description's locks: this table
2740            // holds it now, as Linux's receiver does, and is noted with the
2741            // locks its fdinfo shows before the copy in flight that kept them
2742            // is uncounted, so they never lapse.
2743            if self.follows_lock_copies()
2744                && guest
2745                    .thread_state()
2746                    .with_detfd(fd, |detfd| detfd.is_lock_tracked())
2747                    .unwrap_or(false)
2748            {
2749                Box::pin(self.refresh_description_locks(
2750                    guest,
2751                    fd,
2752                    super::files::LockCall::Joined,
2753                    None,
2754                ))
2755                .await?;
2756            }
2757            // The copy is no longer in flight: it was received, so its
2758            // description may take a placeholder lock again
2759            // (`procfs::locks::LockLedger::placeholder_copies`). A peek leaves
2760            // a copy whose locks the ledger follows in flight, to be
2761            // uncounted by the receive that takes it, or its release.
2762            let peeked_lock_copy = peek && sent.is_some_and(|sent| sent.lock_copy.is_some());
2763            if !peeked_lock_copy
2764                && let Ok(open_file_id) = guest
2765                    .thread_state()
2766                    .with_detfd(fd, |detfd| detfd.open_file_id())
2767            {
2768                let _ = crate::tool_global::placeholder_copies(
2769                    guest,
2770                    crate::procfs::locks::PlaceholderCopies::Received(open_file_id),
2771                )
2772                .await;
2773            }
2774            return Ok(Receipt::Joined);
2775        }
2776        let stat = &facts.stat;
2777        // An anonymous inode (an eventfd, signalfd, timerfd, epoll set,
2778        // inotify instance, pidfd, userfaultfd, ...) has no file type, and
2779        // `fstat` cannot tell which it is. Recorded as an ordinary file, its
2780        // reads and flag changes would take paths that are wrong for it (a
2781        // blocking signalfd read held in the caller's turn, an
2782        // `EFD_SEMAPHORE` eventfd read twice). Its link names an inotify
2783        // instance, which is recorded as one, so its reads renumber rename
2784        // cookies (`crate::syscalls::inotify`); any other is left unrecorded,
2785        // as before. Under record and replay the link is read through the
2786        // recording (`Self::received_descriptor_link`), so replay, whose slot
2787        // holds a stand-in eventfd, classifies the descriptor as the
2788        // recording did.
2789        let link = if stat.st_mode & libc::S_IFMT == 0 {
2790            self.received_descriptor_link(guest, fd).await?
2791        } else {
2792            None
2793        };
2794        if stat.st_mode & libc::S_IFMT == 0
2795            && link.as_deref() != Some(crate::syscalls::inotify::INOTIFY_LINK)
2796        {
2797            // Open, and listed in the table's descriptor directory, but not
2798            // modelled.
2799            guest.thread_state().note_unmodelled_descriptor(fd, cloexec);
2800            match &link {
2801                Some(link) => warn!(
2802                    "[detcore] descriptor {fd}, received {channel}, is an anonymous inode ({}) \
2803                     that an ordinary record would mishandle: not recorded",
2804                    String::from_utf8_lossy(link)
2805                ),
2806                None => warn!(
2807                    "[detcore] descriptor {fd}, received {channel}, is an anonymous inode whose \
2808                     link cannot be read, so its kind is unknown: not recorded"
2809                ),
2810            }
2811            return Ok(Receipt::Unrecorded);
2812        }
2813        // A rendered procfs file's placeholder, by the identity this tool
2814        // process registered or, where Detcore runs in each guest process, by
2815        // its name and seals (`Detcore::received_placeholder`): the file again,
2816        // never the empty memfd behind it.
2817        if may_be_placeholder(stat)
2818            && self.renders_procfs(guest)
2819            && let Some((path, named)) = self.received_placeholder(guest, fd, stat).await?
2820        {
2821            self.adopt_received_placeholder(guest, fd, path, (stat.st_dev, stat.st_ino), named)
2822                .await?;
2823            return Ok(Receipt::New);
2824        }
2825        // Any other received descriptor is a description of its own in the
2826        // model (see the module documentation), made exactly as the in-guest
2827        // discovery makes it: a directory gets a sorted stream of its own.
2828        guest.thread_state().add_discovered_fd(
2829            fd,
2830            facts.descriptor_flags,
2831            facts.status_flags,
2832            stat,
2833            link.as_deref(),
2834        )?;
2835        // A per-process file that follows its record's sequence which the
2836        // kernel opened, received without joining the open file its sender's
2837        // table modeled (above): where the tool runs in each guest process
2838        // (LiteInst, in-guest-trap), every such receipt; where one tool
2839        // process serves every guest, one Detcore could not match. That
2840        // sequence belongs to the open file, which every holder shares and
2841        // the sender's Detcore keeps, and which this table cannot know, so
2842        // every read and seek through it is refused by name
2843        // (`Detcore::refuse_unknown_record_sequence`), as the in-guest
2844        // discovery of DBT and SaBRe refuses one
2845        // (`FileMetadata::discover_fd_from_current_process`). Before, it read
2846        // the kernel's file, where the sender's captures had left it (end of
2847        // file), unsanitized. Its link is read through the recording, as
2848        // every received fact is.
2849        if stat.st_mode & libc::S_IFMT == libc::S_IFREG
2850            && stat.st_size == 0
2851            && stat.st_nlink > 0
2852            && let Some(link) = self.received_descriptor_link(guest, fd).await?
2853            && let Some(path) = crate::tool_local::kernel_record_file_link(stat, &link)
2854        {
2855            guest.thread_state().with_detfd(fd, |detfd| {
2856                detfd.set_path(path.clone());
2857                detfd.mark_record_sequence_unknown();
2858            })?;
2859        }
2860        // An inotify instance whose host description is nonblocking, in a run
2861        // where Detcore makes every inotify instance it creates physically
2862        // nonblocking (`Detcore::handle_inotify_init1`): received without the
2863        // open file description its sender modelled, its O_NONBLOCK may be
2864        // Detcore's own rather than the sender's, so the guest's blocking mode
2865        // is unknown until the guest sets it (`DetFd::blocking_mode_unknown`).
2866        if link.as_deref() == Some(crate::syscalls::inotify::INOTIFY_LINK)
2867            && facts.status_flags & libc::O_NONBLOCK != 0
2868            && self.cfg.use_nonblocking_sockets()
2869            && !self.cfg.recordreplay_modes
2870        {
2871            guest
2872                .thread_state()
2873                .with_detfd(fd, |detfd| detfd.mark_blocking_mode_unknown())?;
2874        }
2875        // A placeholder descriptor, which its identity and its tag tell apart
2876        // (`descriptor_directory`).
2877        self.recognize_received_placeholder(guest, fd, stat, facts.status_flags)
2878            .await;
2879        if stat.st_mode & libc::S_IFMT == libc::S_IFSOCK {
2880            self.classify_socket_peer(guest, fd, SocketRole::Received)
2881                .await;
2882        }

2977    /// ([`Self::rights_peer_is_stream`] says whether the pair is a stream,
2978    /// `stream`), queue on the socket's peer, for each message Linux reports
2979    /// sending (`sent`: the descriptors its `SCM_RIGHTS` messages carried,
2980    /// and the bytes it sent), the open file description this table modeled
2981    /// for each descriptor and the file's identity from an injected `fstat`,
2982    /// so that the receipt can name the open file each received descriptor
2983    /// is (see the module documentation).
2984    ///
2985    /// A message of data alone is queued only where the peer's queue holds
2986    /// every message (`SocketRights::complete`), never under record and
2987    /// replay, whose recordings saw none. A stream send of out-of-band data
2988    /// (`out_of_band`, `MSG_OOB`) queues nothing and leaves the peer's queue
2989    /// out of lockstep. A stream socket's message of no
2990    /// bytes carried nothing: Linux attaches the descriptors to the first
2991    /// buffer it queues, and queues none. A message whose descriptors' facts
2992    /// cannot all be taken queues nothing, so its receipt names no open file,
2993    /// as before. A send that failed queued nothing in Linux and queues
2994    /// nothing here. A tool error (an `fstat` under record and replay that
2995    /// could not be recorded) ends the run.
2996    pub(crate) async fn queue_sent_rights<G: Guest<Self>>(
2997        &self,
2998        guest: &mut G,
2999        socket: RawFd,
3000        stream: bool,
3001        sent: SentRights,
3002        out_of_band: bool,
3003    ) -> Result<(), Error> {
3004        if sent.unread {
3005            self.lose_peer_lockstep(guest, socket);
3006        }
3007        // Out-of-band data is not among the bytes a stream's reads count, and
3008        // descriptors may ride its byte (`queue_oob`): the queue keeps no
3009        // place for such a send. Recordings made before queued as usual.
3010        if out_of_band && stream && !self.keeps_recorded_decisions() {
3011            self.lose_peer_lockstep(guest, socket);
3012            return Ok(());
3013        }
3014        // A datagram send that names its destination reaches the socket it
3015        // names, not the peer (`unix_dgram_sendmsg`); a seqpacket send
3016        // ignores a name (`unix_seqpacket_sendmsg`) and a stream send with
3017        // one fails (`unix_stream_sendmsg`).
3018        let datagram = guest
3019            .thread_state()
3020            .with_detfd(socket, |socket| socket.unix_type())
3021            .ok()
3022            .flatten()
3023            == Some(libc::SOCK_DGRAM);
3024        // Held as Linux holds them, except under record and replay, where the
3025        // ownership existing recordings were made with stays
3026        // (`DetFd::in_flight_open_file`).
3027        let held = !self.cfg.recordreplay_modes;
3028        let follows_locks = self.follows_lock_copies();
3029        for (fds, bytes, addressed) in sent.messages {
3030            if fds.is_empty() && self.keeps_recorded_decisions() {
3031                continue;
3032            }
3033            if stream && bytes == 0 {
3034                continue;
3035            }
3036            if datagram && addressed {
3037                // The named socket may be the peer itself, which then holds a
3038                // message its queue does not.
3039                self.lose_peer_lockstep(guest, socket);
3040                continue;
3041            }
3042            if fds.is_empty() {
3043                let _ = guest.thread_state().with_detfd(socket, |socket| {
3044                    let _ = socket.queue_rights_to_peer(Vec::new(), bytes);
3045                });
3046                continue;
3047            }
3048            let mut descriptors = Vec::with_capacity(fds.len());
3049            for &fd in &fds {
3050                // Through the recording, as the receipt's facts are, so that
3051                // replay matches what the recording matched.
3052                let stat = match self.received_descriptor_fstat(guest, fd).await {
3053                    Ok(stat) => stat,
3054                    Err(Error::Tool(error)) => return Err(Error::Tool(error)),
3055                    Err(_) => break,
3056                };
3057                let (open_file, lock_copy) = guest
3058                    .thread_state()
3059                    .with_detfd(fd, |detfd| {
3060                        // A placeholder's copies are counted at the send
3061                        // (`Detcore::inspect_placeholder_send`).
3062                        let lock_copy = (follows_locks
3063                            && detfd.is_lock_tracked()
3064                            && detfd.placeholder().is_none())
3065                        .then(|| detfd.open_file_id());
3066                        (detfd.in_flight_open_file(held), lock_copy)
3067                    })
3068                    .ok()
3069                    .unzip();
3070                descriptors.push(SentDescriptor {
3071                    file: (stat.st_dev, stat.st_ino),
3072                    open_file,
3073                    lock_copy: lock_copy.flatten(),
3074                });
3075            }
3076            if descriptors.len() != fds.len() {
3077                self.lose_peer_lockstep(guest, socket);
3078                continue;
3079            }
3080            let copies: Vec<_> = descriptors
3081                .iter()
3082                .filter_map(|sent| sent.lock_copy)
3083                .collect();
3084            let mut descriptors = Some(descriptors);
3085            let queued = guest
3086                .thread_state()
3087                .with_detfd(socket, |socket| {
3088                    socket.queue_rights_to_peer(descriptors.take().unwrap_or_default(), bytes)
3089                })
3090                .ok();
3091            // Not queued, nothing was counted, and the sender's descriptors
3092            // still hold what the message names.
3093            if matches!(queued, Some(Ok(()))) && !copies.is_empty() {
3094                // The sender's descriptors still hold the descriptions, so
3095                // their locks were never in danger before this count.
3096                let _ = Box::pin(crate::tool_global::placeholder_copies(
3097                    guest,
3098                    crate::procfs::locks::PlaceholderCopies::Sending(copies),
3099                ))
3100                .await;
3101            }
3102        }
3103        Ok(())
3104    }

3216    /// A `connect` of socket `fd` to `address` succeeded, in the caller's
3217    /// turn or not (`in_turn`, decided before the call,
3218    /// [`Self::completes_in_turn`]). `address` is read after the call: in the
3219    /// turn, it is what the attempt that connected read.
3220    ///
3221    /// A datagram socket now sends to the socket it connected to, or to
3222    /// none (`AF_UNSPEC`), not to the peer Detcore paired it with
3223    /// (`DetFd::unpair_rights_peer`). A stream or seqpacket connection to a
3224    /// name a guest bound queues for that listener's `accept`; only one
3225    /// completed in the turn has a known place among the others. One
3226    /// completed outside the turn read its address at a host-chosen moment,
3227    /// after other threads may have rewritten it, so it may have reached any
3228    /// listener, and every name's order is unknown (Codex review of
3229    /// https://github.com/rrnewton/hermit/pull/4862). Any other `AF_UNIX`
3230    /// connect may have reached any listener: through a relative path or
3231    /// another spelling of a path, or from a socket whose type Detcore did
3232    /// not see made ([`UnixConnections`]).
3233    pub(crate) fn note_unix_connect<G: Guest<Self>>(
3234        &self,
3235        guest: &mut G,
3236        fd: RawFd,
3237        address: &UnixAddress,
3238        in_turn: bool,
3239    ) {
3240        if !self.pairs_unix_sockets(guest) {
3241            return;
3242        }
3243        let kind = guest
3244            .thread_state()
3245            .with_detfd(fd, |detfd| detfd.unix_type())
3246            .ok()
3247            .flatten();
3248        if kind == Some(libc::SOCK_DGRAM) {
3249            let purged = guest
3250                .thread_state()
3251                .with_detfd(fd, |detfd| detfd.unpair_rights_peer())
3252                .unwrap_or_default();
3253            guest.thread_state().defer_released_rights(purged);
3254            return;
3255        }
3256        if !in_turn {
3257            with_connections(guest, UnixConnections::lost);
3258            return;
3259        }

3261            UnixAddress::Named(name) if Self::path_names_another_file(guest, name) => {
3262                &UnixAddress::Unnamed
3263            }
3264            address => address,
3265        };
3266        match (address, kind) {
3267            (UnixAddress::Other, _) => {}
3268            (UnixAddress::Named(name), Some(libc::SOCK_STREAM | libc::SOCK_SEQPACKET)) => {
3269                let socket = guest

3272                    .ok();

3277            // where no guest bound it here, is unknown.
3278            (UnixAddress::Named(name), None) => {
3279                with_connections(guest, |connections| connections.connected(name, None));
3280            }
3281            (UnixAddress::Named(_), Some(_)) => {}
3282            (UnixAddress::Unnamed, _) => with_connections(guest, UnixConnections::lost),
3283        }
3284    }

3332    /// that read fails or the link is longer than any anonymous inode's.
3333    ///
3334    /// Under record and replay the link is read through the recording
3335    /// (`Detcore::recorded_descriptor_link`): replay's slot holds a stand-in
3336    /// eventfd until the recording's answers say otherwise, so a live read
3337    /// there would name the stand-in. A buffer that cannot be prepared ends
3338    /// the run there, as for the received descriptor's `fstat`: no readlink
3339    /// ran, so the other phase could consume an event this one did not.
3340    ///
3341    /// Otherwise it is read in the guest (`readlinkat` of
3342    /// `/proc/thread-self/fd/<fd>`, injected). The path and the result share
3343    /// one buffer, staged where `inject_fstat` stages its own
3344    /// ([`crate::syscalls::scratch::inject_with_scratch`]).
3345    async fn received_descriptor_link<G: Guest<Self>>(
3346        &self,
3347        guest: &mut G,
3348        fd: RawFd,
3349    ) -> Result<Option<Vec<u8>>, Error> {
3350        if self.cfg.recordreplay_modes {
3351            return self
3352                .recorded_descriptor_link(guest, fd)
3353                .await
3354                .map_err(|errno| {
3355                    Error::Tool(anyhow::anyhow!(
3356                        "cannot record descriptor {fd}, received over SCM_RIGHTS, under record \
3357                         and replay: no buffer for its link ({errno})"
3358                    ))
3359                });
3360        }
3361        let mut buffer = [0_u8; LINK_PATH + LINK_TARGET];
3362        let spelled = format!("/proc/thread-self/fd/{fd}");
3363        let Some(slot) = buffer.get_mut(..spelled.len()) else {
3364            return Ok(None);
3365        };
3366        slot.copy_from_slice(spelled.as_bytes());
3367        let Ok((length, bytes)) =
3368            crate::syscalls::scratch::inject_with_scratch(guest, buffer, |base| {
3369                // SAFETY: the buffer holds LINK_PATH + LINK_TARGET bytes.
3370                let target = unsafe { base.add(LINK_PATH) };
3371                syscalls::Readlinkat::new()
3372                    .with_dirfd(libc::AT_FDCWD)
3373                    .with_path(PathPtr::from_ptr(base.as_raw() as *const libc::c_char))
3374                    .with_buf(Some(target.cast::<libc::c_char>()))
3375                    .with_buf_len(LINK_TARGET)
3376                    .into()
3377            })
3378            .await
3379        else {
3380            return Ok(None);
3381        };
3382        Ok(usize::try_from(length)
3383            .ok()
3384            .filter(|length| *length < LINK_TARGET)
3385            .map(|length| bytes[LINK_PATH..LINK_PATH + length].to_vec()))
3386    }
