9//! The `/proc` directories Detcore serves itself, each on a placeholder
10//! descriptor: the caller's own descriptor directory, `/proc/<pid>/fd`, from
11//! Detcore's own descriptor table (package K slice F1, toward
12//! <https://github.com/rrnewton/hermit/issues/4604>), and `/proc` itself, from
13//! Detcore's procfs model (`procfs::listing`, package K slice P1). The models,
14//! and the parts of Linux they follow, are in [`crate::procfs::fd_directory`].
15//!
16//! An open of such a directory injects an open of the descriptor's object,
17//! with the caller's `O_CLOEXEC`, and records which directory the descriptor
18//! stands for (`DetFd::placeholder`). The object depends on one capability,
19//! whether the guest's procfs is the kernel's
20//! (`procfs_inode::tool_can_name_guest_descriptors`), and on nothing else:
21//! - where it is (ptrace), the kernel's procfs root, `openat(AT_FDCWD,
22//!   "/proc", O_RDONLY | O_DIRECTORY)`, as slice F1 opened it. The kernel
23//!   resolves every path through the descriptor: below `/proc` itself, and
24//!   through its descriptor link, exactly as Linux does. A name looked up
25//!   below a descriptor directory is looked up below that directory's own
26//!   path within procfs, from the descriptor itself (`<pid>/fd/<name>`
27//!   relative to it), and a path through a descriptor link to one goes on
28//!   below that path after the link (`/proc/self/fd/D/<pid>/fd/<name>`), so
29//!   that every lookup starts where the guest's does, whatever the caller's
30//!   root or PID namespace ([`Detcore::respelled_below_descriptor_directory`]);
31//! - where it is not (KVM, whose executor serves no procfs directory), the
32//!   placeholder directory, the empty, read-only
33//!   tmpfs hermit-cli mounts at the container's `/proc/fs/nfsd`
34//!   (`DetConfig::directory_placeholder`), procfs's own permanently empty
35//!   mount point. A name looked up below the descriptor, or through its
36//!   link, is looked up at the directory's absolute spelling (`/proc/x`,
37//!   `/proc/self/fd/N`) instead, for each injection that carries it.
38//!
39//! Either way Detcore answers every call through the descriptor from its
40//! model, with one implementation ([`Detcore::answer_placeholder_call`]):
41//! `getdents` and `getdents64`, `lseek`, `fstat` and `statx`, `fstatfs`, the
42//! fdinfo, `fcntl`'s status flags and write hints, the `O_PATH` refusals,
43//! `fchdir`, `flock` (each directory its own lock, as each has an inode of its
44//! own on Linux), and every call procfs refuses, with procfs's errno, in
45//! Linux's order of checks. Only the object differs, and the guest never sees
46//! it: the placeholder directory is hidden. Detcore's `--proc` level table
47//! hides `/proc/fs` at every level, and KVM's executor hides every other
48//! spelling of the placeholder too, for hermit-cli reserves it there
49//! (`reverie_kvm::KvmBackend::reserve_tool_directory`, which requires a
50//! read-only file system, as the fresh read-only tmpfs is): every lookup by
51//! such a spelling, and every call that changes a name whose parent the
52//! executor does not find on procfs, fails with `ENOENT`, as for the absent
53//! `/proc/fs`. Where Detcore leaves such a spelling to the executor and its
54//! parent is procfs's own `/proc/fs` (a path relative to the working
55//! directory, <https://github.com/rrnewton/hermit/issues/4541>, or a lookup
56//! from an inherited procfs descriptor,
57//! <https://github.com/rrnewton/hermit/issues/4816>), the calls that check
58//! that parent first answer procfs's `EACCES` instead: `mkdir`, `mknod`,
59//! `unlink`, `rmdir`, `rename` (from, over and exchange), `link`,
60//! `symlink`'s new path, `fchmodat` (`chmod`) and `utimensat` (`utimes`). A
61//! creation through a final symbolic link into the placeholder, and the
62//! other cases Reverie's contract names (a race between a check and its
63//! call; a creation below another user's link under
64//! `fs.protected_symlinks`), get the read-only file system's `EROFS` (or
65//! `EXDEV` for a racing `rename`) and create nothing. An open or stat that
66//! reaches it by a spelling Detcore made itself is hidden after the call
67//! ([`Detcore::hidden_placeholder_reached`]). hermit-cli mounts the
68//! placeholder only where the guest's procfs is not the kernel's
69//! ([`crate::needs_directory_placeholder`]): on ptrace there is none.
70//!
71//! The table a descriptor directory lists is Detcore's own, which the tool
72//! keeps for the guest (ptrace, KVM) and F0a made complete: every descriptor
73//! it models, and every one it knows is open but does not model
74//! (`FileMetadata::present_unmodelled`). Where a receive may have installed
75//! descriptors Detcore cannot name (`FileMetadata::unaccounted_receipts`),
76//! and for another process's or thread's table (a descriptor a fork's child
77//! inherited), the kernel beneath the backend lists `/proc/<pid>/fd`, as
78//! before.
79//!
80//! Where Detcore runs in the guest process and discovers descriptors only as
81//! they are used (`BackendCapabilities::tool_shares_guest_descriptor_table`:
82//! DBT, SaBRe, LiteInst, in-guest-trap), the guest's table also holds the
83//! backend runtime's own descriptors, which no fact names but the one
84//! `Guest::is_runtime_owned_fd` reports (DBT's RPC socket): measured,
85//! DynamoRIO's 197 to 201 under DBT, and SaBRe's 3, 101 and 1025, in a
86//! listing of the guest's table. A listing of that table could not be
87//! Linux's, so there both directories stay the kernel's, as before (a
88//! capability-keyed residual, until a provider fact names the runtime's
89//! descriptors). Without a placeholder (`--no-namespace`, library callers,
90//! record and replay, a user mount that covers it) Detcore serves neither
91//! directory: on ptrace each is the kernel's, and where the guest's procfs is
92//! not the kernel's an open of either is refused with `EACCES` before it
93//! reaches the backend ([`Detcore::refuses_backend_procfs_directory`]), whose
94//! executor would refuse it too.

264/// Whether `sysno`'s lookup of its path argument `path` (by index) follows
265/// a final symbolic link, so that a path that is a descriptor link to a
266/// placeholder, and nothing more (`/proc/self/fd/D`), names the directory
267/// the link reaches rather than the link: as each call's `LOOKUP_FOLLOW`
268/// says (v6.17). The calls that operate on a final link itself (`lstat`,
269/// `readlink`, the `l*xattr` calls, `lchown`, the calls that make, remove or
270/// rename a name, `AT_SYMLINK_NOFOLLOW`, `inotify_add_watch`'s
271/// `IN_DONT_FOLLOW`) do not; nor `open` and `openat`, whose open of such a
272/// link Detcore makes itself (`OpenedDirectory::Reopened`), or which opens
273/// the link itself with `O_NOFOLLOW`.
274fn follows_final(sysno: Sysno, args: &syscalls::SyscallArgs, path: usize) -> bool {
275    const IN_DONT_FOLLOW: i32 = 0x0200_0000;
276    let flags = |index: usize| args_flag(args, index);
277    match sysno {
278        Sysno::stat
279        | Sysno::access
280        | Sysno::faccessat
281        | Sysno::chdir
282        | Sysno::chroot
283        | Sysno::chmod
284        | Sysno::fchmodat
285        | Sysno::chown
286        | Sysno::truncate
287        | Sysno::utime
288        | Sysno::utimes
289        | Sysno::futimesat
290        | Sysno::statfs
291        | Sysno::getxattr
292        | Sysno::setxattr
293        | Sysno::listxattr
294        | Sysno::removexattr => true,
295        Sysno::newfstatat | Sysno::faccessat2 | Sysno::fchmodat2 | Sysno::utimensat => {
296            flags(3) & libc::AT_SYMLINK_NOFOLLOW == 0
297        }
298        Sysno::statx => flags(2) & libc::AT_SYMLINK_NOFOLLOW == 0,
299        Sysno::fchownat => flags(4) & libc::AT_SYMLINK_NOFOLLOW == 0,
300        Sysno::name_to_handle_at => flags(4) & libc::AT_SYMLINK_FOLLOW != 0,
301        Sysno::linkat => path == 1 && flags(4) & libc::AT_SYMLINK_FOLLOW != 0,
302        Sysno::inotify_add_watch => flags(2) & IN_DONT_FOLLOW == 0,
303        _ => false,
304    }
305}

329/// `relative`, a path looked up below a placeholder directory, below `base`,
330/// the directory's absolute spelling: with its `.` components and repeated
331/// slashes left out, which name nothing (so that a valid path of `./`
332/// repeats, up to Linux's limit, stays one), keeping a final `/` where the
333/// path ends in one or in `.` (Linux then requires a directory and follows
334/// a final link; a final `..` is a directory already). A path of only `.`
335/// components, or none, is the directory itself, `base/.`. The bytes of each
336/// component are kept as they are, whatever they hold.
337fn below(base: &Path, relative: &[u8]) -> Vec<u8> {
338    let components = relative
339        .split(|byte| *byte == b'/')
340        .filter(|component| !component.is_empty() && *component != b".")
341        .collect::<Vec<_>>();
342    let mut out = base.as_os_str().as_bytes().to_vec();
343    if components.is_empty() {
344        out.extend_from_slice(b"/.");
345        return out;
346    }
347    for component in &components {
348        out.push(b'/');
349        out.extend_from_slice(component);
350    }
351    let last = relative
352        .rsplit(|byte| *byte == b'/')
353        .next()
354        .unwrap_or_default();
355    if relative.ends_with(b"/") || last == b"." {
356        out.push(b'/');
357    }
358    out
359}

361/// What one component of a path below `/proc` is, for
362/// [`resolved_procfs_dotdot`]: a directory every procfs has, which a `..`
363/// can leave as Linux's walk does, by kind; or anything else, which it
364/// cannot (a file, a link that leads elsewhere, a name that may not exist).
365#[derive(Clone, Copy, PartialEq, Eq, Debug)]
366enum ProcfsLevel {
367    /// `/proc`.
368    Proc,
369    /// A process's directory: `self`, or a number.
370    Process,
371    /// A process's `task`.
372    Tasks,
373    /// A thread's directory: a number in `task`.
374    Thread,
375    /// `thread-self`'s thread, which spells back as `thread-self`.
376    ThreadSelf,
377    /// A process's or thread's `fd`.
378    Descriptors,
379    /// Anything else.
380    Opaque,
381}

383/// A task that a path below `/proc` names by number on the way, which
384/// Linux's walk looks up there and which must exist for the walk to go on
385/// (`proc_pid_lookup`, `proc_task_lookup`, v6.17 `fs/proc/base.c`): a task
386/// by its number at the top (`/proc/<n>`, any thread's number, as Linux finds
387/// any task there), or a thread of a process (`/proc/<n>/task/<m>`), the
388/// process `None` for the caller's own (`self`, `thread-self`).
389#[derive(Clone, Copy, Debug, PartialEq, Eq)]
390pub(super) struct NamedTask {
391    /// The number at the top, `None` for the caller's own process. A number
392    /// no task can have (one past any `pid_t`) is 0, which names none.
393    pub(super) process: Option<i32>,
394    /// The thread below `task`, if one is named.
395    pub(super) thread: Option<i32>,
396}

398/// `path`, absolute, with each `..` resolved as Linux's walk resolves it
399/// where every component a `..` leaves is a directory every procfs has on
400/// the way down from `/proc`, so no symbolic link or file can be on the way:
401/// `self` (a link to the caller's process directory, one level down) and a
402/// numbered process directory, `thread-self` (a link to `<pid>/task/<tid>`,
403/// three levels down), a process's `task` and a numbered thread in it, and
404/// `fd`. A `..` at the root stays there. With it, every task the path names
405/// by number on the way, in order ([`NamedTask`]): the walk looks each up, so
406/// the path names what this resolves it to only while each exists, and
407/// fails with `ENOENT` at the first that does not
408/// ([`Detcore::named_tasks_exist`]). `None` for a path without `..`, and for
409/// one whose `..` follows anything else, which only the kernel's walk can
410/// resolve.
411pub(super) fn resolved_procfs_dotdot(path: &Path) -> Option<(PathBuf, Vec<NamedTask>)> {
412    let bytes = path.as_os_str().as_bytes();
413    if !bytes.starts_with(b"/") {
414        return None;
415    }
416    let components = bytes
417        .split(|byte| *byte == b'/')
418        .filter(|component| !component.is_empty() && *component != b".")
419        .collect::<Vec<_>>();
420    if !components.contains(&b"..".as_slice()) {
421        return None;
422    }
423    // A decimal number procfs looks up (no leading zero, as `name_to_int`
424    // takes), as the task number it names: 0 for one no task can have.
425    let number = |name: &[u8]| {
426        (!name.is_empty() && name[0] != b'0' && name.iter().all(u8::is_ascii_digit)).then(|| {
427            std::str::from_utf8(name)
428                .ok()
429                .and_then(|name| name.parse::<i32>().ok())
430                .unwrap_or(0)
431        })
432    };
433    // Each component kept, with what it is, whether `thread-self`'s
434    // expansion pushed it, and the process number it names (for a process
435    // directory: `None` for `self`).
436    let mut kept: Vec<(&[u8], ProcfsLevel, bool, Option<i32>)> = Vec::new();
437    let mut tasks = Vec::new();
438    for name in components {
439        if name == b".." {
440            match kept.last() {
441                None => {}
442                Some((_, ProcfsLevel::Opaque, _, _)) => return None,
443                Some(_) => {
444                    kept.pop();
445                }
446            }
447            continue;
448        }
449        let parent = kept.last().map(|(_, level, _, _)| *level);
450        let level = match (parent, name) {
451            (None, b"proc") => ProcfsLevel::Proc,
452            (Some(ProcfsLevel::Proc), b"self") => {
453                kept.push((name, ProcfsLevel::Process, false, None));
454                continue;
455            }
456            (Some(ProcfsLevel::Proc), b"thread-self") => {
457                kept.push((b"self", ProcfsLevel::Process, true, None));
458                kept.push((b"task", ProcfsLevel::Tasks, true, None));
459                kept.push((b"thread-self", ProcfsLevel::ThreadSelf, true, None));
460                continue;
461            }
462            (Some(ProcfsLevel::Proc), name) if number(name).is_some() => {
463                let process = number(name);
464                tasks.push(NamedTask {
465                    process,
466                    thread: None,
467                });
468                kept.push((name, ProcfsLevel::Process, false, process));
469                continue;
470            }
471            (Some(ProcfsLevel::Process), b"task") => ProcfsLevel::Tasks,
472            (Some(ProcfsLevel::Tasks), name) if number(name).is_some() => {
473                // The process directory two levels up.
474                let process = kept.len().checked_sub(2).and_then(|index| kept[index].3);
475                tasks.push(NamedTask {
476                    process,
477                    thread: number(name),
478                });
479                ProcfsLevel::Thread
480            }
481            (Some(ProcfsLevel::Process | ProcfsLevel::Thread | ProcfsLevel::ThreadSelf), b"fd") => {
482                ProcfsLevel::Descriptors
483            }
484            _ => ProcfsLevel::Opaque,
485        };
486        kept.push((name, level, false, None));
487    }
488    let mut out = Vec::new();
489    let mut index = 0;
490    while index < kept.len() {
491        // `thread-self`'s expansion, whole, spells back as itself.
492        if kept[index].2
493            && kept
494                .get(index + 2)
495                .is_some_and(|(_, level, _, _)| *level == ProcfsLevel::ThreadSelf)
496        {
497            out.extend_from_slice(b"/thread-self");
498            index += 3;
499            continue;
500        }
501        out.push(b'/');
502        out.extend_from_slice(kept[index].0);
503        index += 1;
504    }
505    if out.is_empty() {
506        out.push(b'/');
507    }
508    Some((PathBuf::from(std::ffi::OsString::from_vec(out)), tasks))
509}

511/// Whether the absolute guest path `path` names `/proc` itself: its
512/// components, with the empty and `.` ones left out, are `proc` alone, or
513/// reach it back through `..` from directories every procfs has
514/// ([`resolved_procfs_dotdot`]), as `Some` of the tasks that spelling names
515/// by number on the way, each of which must exist for it to
516/// ([`Detcore::named_tasks_exist`]). Any other spelling is the kernel's to
517/// resolve.
518fn names_procfs_root(path: &Path) -> Option<Vec<NamedTask>> {
519    let (resolved, tasks) =
520        resolved_procfs_dotdot(path).unwrap_or_else(|| (path.to_path_buf(), Vec::new()));
521    (resolved.as_os_str().as_bytes().starts_with(b"/")
522        && resolved
523            .components()
524            .filter(|component| *component != std::path::Component::CurDir)

529/// Whether the absolute path `path` spells a descriptor directory, the
530/// caller's or another task's, whatever its numbers: `/proc/<n>/fd`,
531/// `/proc/<n>/task/<m>/fd` (`<n>` a number, `self` or `thread-self`), or
532/// `/dev/fd`, with empty and `.` components left out
533/// ([`Detcore::refuses_backend_procfs_directory`]).
534fn spells_a_descriptor_directory(path: &Path) -> bool {
535    let task = |name: &str| {
536        name == "self"
537            || name == "thread-self"
538            || (!name.is_empty() && name.bytes().all(|byte| byte.is_ascii_digit()))
539    };
540    let names = path
541        .components()
542        .filter_map(|component| match component {
543            std::path::Component::Normal(name) => name.to_str(),
544            _ => None,
545        })
546        .collect::<Vec<_>>();
547    path.is_absolute()
548        && !path
549            .components()
550            .any(|component| component == std::path::Component::ParentDir)
551        && match names.as_slice() {
552            ["dev", "fd"] => true,
553            ["proc", pid, "fd"] => task(pid),
554            ["proc", pid, "task", tid, "fd"] => {
555                task(pid) && !tid.is_empty() && tid.bytes().all(|byte| byte.is_ascii_digit())
556            }
557            _ => false,
558        }
559}

561/// The leading descriptor link of an absolute path (`/proc/self/fd/D`,
562/// `/dev/fd/D`, `/proc/thread-self/fd/D`, `/proc/<pid>/task/<tid>/fd/D`),
563/// spelled canonically, and the index in `path` just past its last
564/// component, whatever follows. Empty and `.` components before the
565/// descriptor's number name nothing, as in Linux's walk, and are skipped
566/// (`//proc/self/fd/D`, `/proc//self/fd/D`, `/proc/./self/fd/D`). The link's
567/// components are ASCII. Any other spelling (a `..` before the number, a
568/// symbolic link of the guest's to `/proc/self/fd/D`) is not recognized
569/// (named residual).
570fn descriptor_link_prefix(path: &[u8]) -> Option<(PathBuf, usize)> {
571    if !path.starts_with(b"/") {
572        return None;
573    }
574    let mut names: Vec<&str> = Vec::new();
575    let mut at = 0;
576    loop {
577        while path.get(at) == Some(&b'/') {
578            at += 1;
579        }
580        let start = at;
581        while at < path.len() && path[at] != b'/' {
582            at += 1;
583        }
584        if start == at {
585            return None;
586        }
587        let name = &path[start..at];
588        if name == b"." {
589            continue;
590        }
591        if !name.is_ascii() {
592            return None;
593        }
594        names.push(std::str::from_utf8(name).ok()?);
595        match names.as_slice() {
596            ["dev", "fd", _] | ["proc", _, "fd", _] | ["proc", _, "task", _, "fd", _] => break,
597            ["dev"]
598            | ["dev", "fd"]
599            | ["proc"]
600            | ["proc", _]
601            | ["proc", _, "fd"]
602            | ["proc", _, "task"]
603            | ["proc", _, "task", _]
604            | ["proc", _, "task", _, "fd"] => {}
605            _ => return None,
606        }
607    }
608    Some((PathBuf::from(format!("/{}", names.join("/"))), at))
609}

611/// The leading descriptor link and the rest of an absolute path that leads
612/// through one ([`descriptor_link_prefix`]), if the path goes on past the
613/// link: a rest, or a final `/`, which follows the link (an empty rest then,
614/// the directory itself). The rest is kept byte for byte, whatever it holds.
615fn through_descriptor_link(path: &[u8]) -> Option<(PathBuf, Vec<u8>)> {
616    let (link, end) = descriptor_link_prefix(path)?;
617    let rest = &path[end..];
618    if rest.is_empty() {
619        return None;
620    }
621    let rest = &rest[rest.iter().take_while(|byte| **byte == b'/').count()..];
622    Some((link, rest.to_vec()))
623}

625/// How many symbolic links Linux follows to reach the directory of the
626/// descriptor link `link` ([`through_descriptor_link`]) before the link
627/// itself: `/dev/fd` (a link to `/proc/self/fd`) and then `self`, 2;
628/// `/proc/self` or `/proc/thread-self`, 1; a numbered task, 0. Each of these
629/// counts against the lookup's `MAXSYMLINKS`, as the descriptor link does
630/// (`pick_link`'s `total_link_count`).
631fn selector_links(link: &Path) -> usize {
632    let mut names = link.components().filter_map(|component| match component {
633        std::path::Component::Normal(name) => Some(name),
634        _ => None,
635    });
636    match (names.next(), names.next()) {
637        (Some(first), _) if first == "dev" => 2,
638        (_, Some(second)) if second == "self" || second == "thread-self" => 1,
639        _ => 0,
640    }
641}

666/// The argument of a call that names the descriptor it operates on, for the
667/// calls Detcore answers through a placeholder descriptor
668/// ([`Detcore::answer_placeholder_call`]): `Some(index)` for a call that
669/// operates on its descriptor operand `index`, the path calls among them that

672/// kernel's descriptor table does (`close`, the `dup`s, `fcntl`'s
673/// table commands, `poll` and `epoll`, which see a directory with no `poll`
674/// method alike on every file system), or looks a name up below it

684                |pointer| {
685                    pointer
686                        .read(memory)

688                },
689            )
690    };
691    match sysno {
692        Sysno::getdents
693        | Sysno::getdents64
694        | Sysno::lseek
695        | Sysno::fchdir
696        | Sysno::fcntl
697        | Sysno::read
698        | Sysno::readv
699        | Sysno::pread64
700        | Sysno::preadv
701        | Sysno::preadv2
702        | Sysno::write
703        | Sysno::writev
704        | Sysno::pwrite64
705        | Sysno::pwritev
706        | Sysno::pwritev2
707        | Sysno::ioctl
708        | Sysno::fsync
709        | Sysno::fdatasync
710        | Sysno::syncfs
711        | Sysno::flock
712        | Sysno::fchmod
713        | Sysno::fchown
714        | Sysno::fgetxattr
715        | Sysno::fsetxattr
716        | Sysno::flistxattr
717        | Sysno::fremovexattr
718        | Sysno::ftruncate
719        | Sysno::fallocate
720        | Sysno::fadvise64
721        | Sysno::readahead
722        | Sysno::sync_file_range
723        | Sysno::fstatfs => Some(0),
724        // A file-backed mapping only: an anonymous one ignores its
725        // descriptor argument (`ksys_mmap_pgoff`).
726        Sysno::mmap if args.arg3 as i32 & libc::MAP_ANONYMOUS == 0 => Some(4),
727        // `futimens`: no path at all names the descriptor itself.
728        Sysno::utimensat if args.arg1 == 0 => Some(0),

733        // `name_to_handle_at` is not here: Detcore answers every one with
734        // `EOPNOTSUPP` (`Detcore::handle_syscall_event`), Linux's answer for
735        // procfs, which exports no handles.
736        _ => None,
737    }
738}

857    /// absolute spelling) names, whose procfs spelling is `spelling`
858    /// (`Detcore::procfs_spelling_at`), if Detcore serves it: one of the
859    /// caller's own descriptor directories ([`fd_directory::classify`]),
860    /// `/proc` itself by any spelling that reaches it ([`names_procfs_root`]),
861    /// `/dev/fd` where it is the symbolic link to `/proc/self/fd` it is on
862    /// Linux, or a descriptor link of the caller's to a placeholder. The last
863    /// two are symbolic links: an open with `O_NOFOLLOW` that does not follow
864    /// them anyway (a trailing `/`) opens the link itself (`O_PATH`) or fails
865    /// with `ELOOP`, which the kernel answers.
866    pub(super) async fn descriptor_directory_opened<G: Guest<Self>>(
867        &self,
868        guest: &mut G,
869        observed: &Path,
870        spelling: &Path,
871        flags: OFlag,
872    ) -> Option<Result<OpenedDirectory, Errno>> {
873        if !self.serves_descriptor_directories(guest) {
874            return None;
875        }
876        let own = Self::descriptor_directory_caller(guest)?;
877        // A spelling through a descriptor link to a placeholder directory
878        // (`/proc/self/fd/D/.`, `/proc/self/fd/D/N`) names what Linux
879        // resolves it to, with the links it followed on the way counted.
880        let (decided, links) = match Self::decided_path(guest, observed) {
881            Ok(decided) => decided,
882            Err(errno) => return Some(Err(errno)),
883        };
884        let (observed, spelling) = if decided.as_path() == observed {
885            (observed, spelling)
886        } else {
887            (decided.as_path(), decided.as_path())
888        };
889        if let Some(table) = fd_directory::classify(spelling, own) {
890            return Some(Ok(OpenedDirectory::Own(table)));
891        }
892        if let Some(tasks) = names_procfs_root(spelling) {
893            // A task the spelling names on the way that does not exist ends
894            // Linux's walk there.
895            return Some(if Self::named_tasks_exist(guest, &tasks).await {
896                Ok(OpenedDirectory::Root)
897            } else {
898                Err(Errno::ENOENT)
899            });
900        }
901        if super::opens_the_link_itself(observed, flags) {
902            return None;
903        }
904        if let Some(directory) = Self::own_link_directory(guest, observed) {
905            // The open follows this last link too, within the one budget.
906            if links + selector_links(observed) + 1 > LINK_LIMIT {
907                return Some(Err(Errno::ELOOP));
908            }
909            return Some(Ok(OpenedDirectory::Reopened(directory)));
910        }
911        let dev_fd = observed
912            .components()
913            .filter(|component| *component != std::path::Component::CurDir)
914            .eq(Path::new("/dev/fd").components());
915        if dev_fd
916            && self
917                .injected_link_target(guest, b"/dev/fd")
918                .await
919                .as_deref()
920                == Some(Path::new("/proc/self/fd"))
921        {
922            return Some(Ok(OpenedDirectory::Own(DescriptorDirectoryTable::Process)));
923        }
924        None
925    }

960    /// The target of the symbolic link at the absolute guest path `link`, by
961    /// one injected `readlinkat`, or `None`.
962    async fn injected_link_target<G: Guest<Self>>(
963        &self,
964        guest: &mut G,
965        link: &[u8],
966    ) -> Option<PathBuf> {
967        const LINK_CAPACITY: usize = 32;
968        const TARGET_CAPACITY: usize = 64;
969        let mut stack = guest.stack().await;
970        let link = stack.push(super::rendered_procfs::c_string::<LINK_CAPACITY>(link));
971        let target = stack.reserve::<[u8; TARGET_CAPACITY]>();
972        let stack_guard = stack.commit().ok()?;
973        let length = guest
974            .inject(
975                syscalls::Readlinkat::new()
976                    .with_dirfd(libc::AT_FDCWD)
977                    .with_path(PathPtr::from_ptr(link.as_raw() as *const libc::c_char))
978                    .with_buf(Some(target.cast::<libc::c_char>()))
979                    .with_buf_len(TARGET_CAPACITY),
980            )
981            .await;
982        let bytes = match length.map(|length| length as usize) {
983            Ok(length) if length < TARGET_CAPACITY => {
984                let mut bytes = vec![0; length];
985                guest
986                    .memory()
987                    .read_exact(target.cast::<u8>(), &mut bytes)
988                    .ok()
989                    .map(|()| bytes)
990            }
991            _ => None,
992        };
993        drop(stack_guard);
994        Some(PathBuf::from(String::from_utf8(bytes?).ok()?))
995    }

1091    /// injected `newfstatat` from `AT_FDCWD`, the path and the buffer staged
1092    /// together on Reverie's guest stack.
1093    async fn injected_path_stat<G: Guest<Self>>(
1094        guest: &mut G,
1095        path: &[u8],
1096    ) -> Result<libc::stat, Errno> {
1097        const PATH_CAPACITY: usize = 64;
1098        if path.len() >= PATH_CAPACITY {
1099            return Err(Errno::ENAMETOOLONG);
1100        }
1101        let mut stack = guest.stack().await;
1102        let staged = stack.push(super::rendered_procfs::c_string::<PATH_CAPACITY>(path));
1103        let buffer = stack.reserve::<libc::stat>();
1104        let stack_guard = stack.commit().map_err(|_| Errno::EFAULT)?;
1105        let looked_up = guest
1106            .inject(
1107                syscalls::Newfstatat::new()
1108                    .with_dirfd(libc::AT_FDCWD)
1109                    .with_path(PathPtr::from_ptr(staged.as_raw() as *const libc::c_char))
1110                    .with_stat(Some(reverie::syscalls::StatPtr(buffer)))
1111                    .with_flags(nix::fcntl::AtFlags::empty()),
1112            )
1113            .await;
1114        let stat = looked_up.and_then(|_| guest.memory().read_value(buffer));
1115        drop(stack_guard);
1116        stat
1117    }

1246    /// Open the placeholder directory `opened` names, with the guest's open
1247    /// `flags`: refuse what Linux refuses for a directory, then inject the
1248    /// open of the object that stands for it ([`PlaceholderObject`]), record
1249    /// the descriptor and which directory it is, register it for its tag, and
1250    /// name its description to the lock ledger, which follows every table
1251    /// that references it from now on (`procfs::locks::LockLedger`, for its
1252    /// `flock` locks).
1253    pub(super) async fn open_placeholder<G: Guest<Self>>(
1254        &self,
1255        guest: &mut G,
1256        flags: OFlag,
1257        opened: OpenedDirectory,
1258    ) -> Result<i64, Error> {
1259        // As Linux refuses an open of a directory: invalid combinations
1260        // first (`build_open_flags`), then an existing name with
1261        // `O_CREAT|O_EXCL` (EEXIST), an `O_TMPFILE` below a directory that has
1262        // no `tmpfile` (EOPNOTSUPP), `O_CREAT` (`do_open`'s EISDIR), a write
1263        // or `O_TRUNC` (`may_open`'s EISDIR), `O_NOATIME` for a caller that
1264        // neither owns the directory nor may act as its owner (the end of
1265        // `may_open`, EPERM), and last `O_DIRECT`, which procfs cannot do
1266        // (`do_dentry_open`'s EINVAL). An `O_PATH` open makes none of these
1267        // checks. Measured on Linux 7.1.
1268        if let Some(errno) = super::rendered_procfs::open_flags_refused(flags) {
1269            return Err(errno.into());
1270        }
1271        let path_only = flags.contains(OFlag::O_PATH);
1272        let (pid, tid) = Self::descriptor_directory_caller(guest).ok_or(Errno::ENOENT)?;
1273        let directory = match opened {
1274            OpenedDirectory::Own(table) => {
1275                let thread = (table == DescriptorDirectoryTable::Thread).then_some(tid);
1276                let answer = crate::tool_global::procfs_task(
1277                    guest,
1278                    crate::procfs::BoundTask {
1279                        process: pid,
1280                        thread,
1281                    },
1282                )
1283                .await;
1284                PlaceholderDirectory::Descriptors(DescriptorDirectoryBinding {
1285                    table,
1286                    pid,
1287                    tid,
1288                    process_incarnation: answer.process_incarnation,
1289                    thread_incarnation: answer.thread_incarnation,
1290                    device: Self::procfs_key_device(guest),
1291                    files: (table == DescriptorDirectoryTable::Thread)
1292                        .then(|| guest.thread_state().files_id()),
1293                })
1294            }
1295            OpenedDirectory::Root => PlaceholderDirectory::Root,
1296            OpenedDirectory::Reopened(directory) => directory,
1297        };
1298        if !path_only {
1299            if flags.contains(OFlag::O_CREAT | OFlag::O_EXCL) {
1300                return Err(Errno::EEXIST.into());
1301            }
1302            if flags.contains(OFlag::O_TMPFILE) {
1303                return Err(Errno::EOPNOTSUPP.into());
1304            }
1305            if flags.contains(OFlag::O_CREAT)
1306                || flags & OFlag::O_ACCMODE != OFlag::O_RDONLY
1307                || flags.contains(OFlag::O_TRUNC)
1308            {
1309                return Err(Errno::EISDIR.into());
1310            }
1311            if flags.contains(OFlag::O_NOATIME) && !placeholder_owner_or_capable(&directory)? {
1312                return Err(Errno::EPERM.into());
1313            }
1314            if flags.contains(OFlag::O_DIRECT) {
1315                return Err(Errno::EINVAL.into());
1316            }
1317        }
1318        let object = Self::placeholder_object(guest);
1319        let object_path = match object {
1320            PlaceholderObject::ProcfsRoot => PathBuf::from("/proc"),
1321            PlaceholderObject::Placeholder => guest
1322                .config()
1323                .directory_placeholder
1324                .clone()
1325                .ok_or(Errno::ENOENT)?,
1326        };
1327        // A path-only open is an `O_PATH` descriptor on the object as well,
1328        // so that every call Linux refuses on one is refused beneath too, as
1329        // on Linux, those Detcore does not answer itself included (`epoll_ctl`,
1330        // `poll`, the socket calls). Such a descriptor takes no tag, which
1331        // `lseek` refuses on it, and so is not sent over `SCM_RIGHTS`
1332        // ([`Self::placeholder_copies_for_send`]).
1333        let cloexec = flags & OFlag::O_CLOEXEC;
1334        let object_flags = if path_only {
1335            OFlag::O_PATH | OFlag::O_DIRECTORY | cloexec
1336        } else {
1337            OFlag::O_RDONLY | OFlag::O_DIRECTORY | cloexec
1338        };
1339        let fd = Self::inject_openat(
1340            guest,
1341            libc::AT_FDCWD,
1342            object_path.as_os_str().as_bytes(),
1343            object_flags,
1344        )
1345        .await?;
1346        // The status flags Linux keeps: an `O_PATH` open keeps only
1347        // `O_PATH_FLAGS` (`build_open_how`); any other gets `O_LARGEFILE`
1348        // (`force_o_largefile`) and loses the open-time-only flags
1349        // (`do_dentry_open`).
1350        let status = if path_only {
1351            flags & (OFlag::O_PATH | OFlag::O_DIRECTORY | OFlag::O_NOFOLLOW | OFlag::O_CLOEXEC)
1352        } else {
1353            // The kernel's `O_LARGEFILE`, which the C library's value (0 on
1354            // x86_64) does not name.
1355            (flags & !(OFlag::O_CREAT | OFlag::O_EXCL | OFlag::O_NOCTTY | OFlag::O_TRUNC))
1356                | OFlag::from_bits_retain(0o100000)
1357        };
1358        let stat = match self
1359            .add_fd_with_stat(guest, fd, status, FdType::Regular)
1360            .await
1361        {
1362            Ok(Some(stat)) => Ok(stat),
1363            Ok(None) => self.inject_fstat(guest, fd).await,
1364            Err(errno) => Err(errno),
1365        };
1366        let stat = match stat {
1367            Ok(stat) => stat,
1368            Err(errno) => {
1369                guest.thread_state().remove_fd(fd);
1370                let _ = guest.inject(syscalls::Close::new().with_fd(fd)).await;
1371                return Err(errno.into());
1372            }
1373        };
1374        PLACEHOLDER_IDENTITIES
1375            .lock()
1376            .unwrap()
1377            .insert((stat.st_dev, stat.st_ino));
1378        if object == PlaceholderObject::Placeholder {
1379            HIDDEN_IDENTITY
1380                .lock()
1381                .unwrap()
1382                .get_or_insert((stat.st_dev, stat.st_ino));
1383        }
1384        OPENED_ANY.store(true, Ordering::SeqCst);
1385        // Registered with the open file description it is, which a receiver
1386        // of the descriptor takes as its own ([`Self::recognize_received_placeholder`]).
1387        let open_file = guest
1388            .thread_state()
1389            .with_detfd(fd, |detfd| detfd.open_file_id())?;
1390        let tag = if path_only {
1391            None
1392        } else {
1393            crate::tool_global::register_placeholder(guest, directory, open_file).await
1394        };
1395        // The kernel position tags the descriptor for whoever meets it without
1396        // its record. A backend that cannot seek it leaves it untagged.
1397        let tag = match tag {
1398            Some(tag) => guest
1399                .inject(
1400                    syscalls::Lseek::new()
1401                        .with_fd(fd)
1402                        .with_offset(tag as i64)
1403                        .with_whence(syscalls::Whence::SEEK_SET),
1404                )
1405                .await
1406                .ok()
1407                .filter(|position| *position as u64 == tag)
1408                .map(|_| tag),
1409            None => None,
1410        };
1411        let canonical = directory.canonical();
1412        guest.thread_state().with_detfd(fd, |detfd| {
1413            detfd.set_path(canonical.clone());
1414            detfd.set_placeholder(PlaceholderState {
1415                directory,
1416                tag,
1417                position: 0,
1418                path_only,
1419            });
1420        })?;
1421        self.follow_placeholder_references(guest, fd).await;
1422        tracing::debug!(
1423            "[detcore] descriptor {fd}: {} served on {}",
1424            canonical.display(),
1425            object_path.display()
1426        );
1427        Ok(fd as i64)
1428    }

1477        }

1479            .inject(
1480                syscalls::Lseek::new()
1481                    .with_fd(fd)

1503                directory,
1504                tag: Some(position),

1510            guest,
1511            crate::procfs::locks::PlaceholderCopies::Received(open_file),
1512        )

1517    /// Before a send whose messages pass the descriptors `sent` over
1518    /// `SCM_RIGHTS`: the open file descriptions of the placeholders among
1519    /// them, one per copy, counted in flight
1520    /// (`procfs::locks::LockLedger::placeholder_copies`), so that none takes
1521    /// a placeholder `flock` until its copy is received
1522    /// ([`Self::recognize_received_placeholder`]) or the send fails (the
1523    /// caller then uncounts them). Refused by name instead (`Err`, the
1524    /// refusal): a placeholder whose description holds a placeholder `flock`,
1525    /// which Linux keeps while the message is queued, a reference the ledger
1526    /// does not follow; an untagged placeholder (an `O_PATH` one), which its
1527    /// receiver could not tell for one; and any placeholder `sendmmsg` sends,
1528    /// of whose messages Detcore does not know which the batch sent.
1529    pub(crate) async fn placeholder_copies_for_send<G: Guest<Self>>(
1530        &self,
1531        guest: &mut G,
1532        sysno: Sysno,
1533        sent: &[RawFd],
1534    ) -> Result<Vec<crate::types::OpenFileId>, Result<i64, Error>> {
1535        if !OPENED_ANY.load(Ordering::SeqCst) || !Self::serves_placeholders(guest) {
1536            return Ok(Vec::new());
1537        }
1538        let mut copies = Vec::new();
1539        for fd in sent {
1540            let Some(state) = Self::placeholder_of(guest, *fd) else {
1541                continue;
1542            };
1543            let unsupported = if state.tag.is_none() {
1544                Some("carries no tag (an O_PATH descriptor) that its receiver could tell it by")
1545            } else if sysno == Sysno::sendmmsg {
1546                Some("is sent in a batch, of whose messages Detcore does not know which it sent")
1547            } else {
1548                None
1549            };
1550            if let Some(why) = unsupported {
1551                let reason = format!(
1552                    "descriptor {fd}, which stands for {}, a /proc directory Detcore serves, \
1553                     is passed over SCM_RIGHTS and {why}",
1554                    state.directory.canonical().display()
1555                );
1556                return Err(self
1557                    .refuse_placeholder_call(guest, sysno, Errno::EOPNOTSUPP, &reason)
1558                    .await);
1559            }
1560            match guest
1561                .thread_state()
1562                .with_detfd(*fd, |detfd| detfd.open_file_id())
1563            {
1564                Ok(open_file) => copies.push(open_file),
1565                Err(error) => return Err(Err(error.into())),
1566            }
1567        }
1568        if copies.is_empty() {
1569            return Ok(copies);
1570        }
1571        match crate::tool_global::placeholder_copies(
1572            guest,
1573            crate::procfs::locks::PlaceholderCopies::Sending(copies.clone()),
1574        )
1575        .await
1576        {
1577            Ok(()) => Ok(copies),
1578            Err(_) => {
1579                let reason = "a descriptor it passes over SCM_RIGHTS stands for a /proc directory \
1580                              Detcore serves and holds a flock on it, which Linux keeps while the \
1581                              message is queued, a reference Detcore does not follow";
1582                Err(self
1583                    .refuse_placeholder_call(guest, sysno, Errno::EOPNOTSUPP, reason)
1584                    .await)
1585            }
1586        }
1587    }

1615    /// are at the guest addresses `headers`, read here for the descriptors
1616    /// they pass over `SCM_RIGHTS` (`syscalls::io::sent_descriptors`; `unread`
1617    /// below where a header or control buffer cannot be read in full, so that
1618    /// the list may be incomplete), where Detcore serves placeholders
1619    /// ([`Self::may_send_placeholders`]): the open file
1620    /// descriptions of the placeholders among them, counted in flight
1621    /// ([`Self::placeholder_copies_for_send`]), and what each attempt of the
1622    /// send checks again ([`SendInspection`]), or the refusal by name. Besides
1623    /// the refusals [`Self::placeholder_copies_for_send`] makes, a send is
1624    /// refused while this process holds a placeholder and its socket can
1625    /// pass descriptors (`AF_UNIX`, [`Self::socket_carries_descriptors`]),
1626    /// where Detcore cannot know which descriptors Linux reads:
1627    /// - its messages cannot be read in full (`unread`): a control buffer
1628    ///   longer than the 65536 bytes Detcore reads, which Linux takes up to
1629    ///   the socket's `net.core.optmem_max` (128 KiB in a new network
1630    ///   namespace, a host setting in the initial one), or memory Detcore
1631    ///   cannot read. Detcore refuses rather than reading as much as the
1632    ///   kernel takes: that limit is the host's to raise, and no length helps
1633    ///   with memory Detcore cannot read;
1634    /// - the send runs outside this thread's turn in a run that sequentializes
1635    ///   threads (`outside_turn`, a blocking call on a descriptor that blocks
1636    ///   in the kernel, `Detcore::nonblockable_call_runs_outside_turn`), where
1637    ///   another thread may rewrite its messages, or what their descriptor
1638    ///   numbers name, before Linux reads them, whatever this inspection read.
1639    ///   Without sequentialized threads no thread has a turn, and every check
1640    ///   Detcore makes may race the guest's other threads (that mode's named
1641    ///   residual).

1643        &self,
1644        guest: &mut G,
1645        sysno: Sysno,
1646        socket: RawFd,
1647        headers: &[usize],
1648        outside_turn: bool,
1649    ) -> Result<(Vec<crate::types::OpenFileId>, SendInspection), Result<i64, Error>> {
1650        let (sent, unread) = crate::syscalls::io::sent_descriptors(guest, headers);
1651        if (unread || outside_turn)
1652            && guest.thread_state().holds_placeholder()
1653            && Self::socket_carries_descriptors(guest, socket).await
1654        {
1655            let reason = if unread {
1656                format!(
1657                    "a message whose SCM_RIGHTS control data Detcore cannot read in full (more \
1658                     than {MAX_SEND_CONTROL_BYTES} bytes of it, which Linux takes up to the \
1659                     socket's net.core.optmem_max, or memory Detcore cannot read) may pass a \
1660                     descriptor that stands for a /proc directory Detcore serves, whose copies \
1661                     and lock Detcore follows"
1662                )
1663            } else {
1664                "a send on a socket that passes descriptors runs outside Detcore's turn, where \
1665                 another thread may change its SCM_RIGHTS messages, or what their descriptor \
1666                 numbers name, before Linux reads them, while this process holds a descriptor \
1667                 that stands for a /proc directory Detcore serves, whose copies and lock Detcore \
1668                 follows"
1669                    .to_string()
1670            };
1671            return Err(self
1672                .refuse_placeholder_call(guest, sysno, Errno::EOPNOTSUPP, &reason)
1673                .await);
1674        }
1675        let copies = self
1676            .placeholder_copies_for_send(guest, sysno, &sent)
1677            .await?;
1678        let inspection = SendInspection {
1679            sysno,
1680            socket,
1681            headers: headers.to_vec(),
1682            placeholders: Self::placeholders_among(guest, &sent),
1683        };
1684        Ok((copies, inspection))
1685    }

1850    /// Whether the guest's `lseek(fd, offset, whence)` of a descriptor that
1851    /// Detcore does not answer itself would move the kernel position of a
1852    /// descriptor on a placeholder's object into the tags' range, where it
1853    /// would pass for a placeholder ([`Self::recognize_received_placeholder`]):
1854    /// a descriptor on procfs's root, where that is the object (ptrace), or
1855    /// on the placeholder directory (KVM). `handle_lseek` refuses that seek
1856    /// with `EINVAL`; Linux accepts any position up to 2^31 - 1 on procfs's
1857    /// root, and lists nothing from one this high (named difference).
1858    ///
1859    /// Decided whether or not a placeholder has been opened yet, whether or
1860    /// not Detcore recorded the descriptor's metadata
1861    /// (`--no-virtualize-metadata`), and whether or not the guest's table has
1862    /// a free slot, for nothing is opened to decide: the target position
1863    /// first, from the call alone (a negative or zero `SEEK_CUR` step cannot
1864    /// reach the range from a position below it, which every position of
1865    /// procfs's root is, this guard included), then the descriptor itself
1866    /// ([`Self::on_placeholder_object`]). A descriptor whose kind or
1867    /// filesystem cannot be told is refused (fail closed). Not where Detcore
1868    /// serves no placeholder ([`Self::serves_placeholders`]), where no
1869    /// placeholder is served or recognized.
1870    pub(crate) async fn seek_would_place_a_tag<G: Guest<Self>>(
1871        &self,
1872        guest: &mut G,
1873        fd: RawFd,
1874        offset: i64,
1875        whence: i32,
1876    ) -> bool {
1877        if !Self::serves_placeholders(guest) {
1878            return false;
1879        }
1880        let in_range = |target: i64| {
1881            u64::try_from(target)
1882                .ok()
1883                .and_then(fd_directory::tag_index)
1884                .is_some()
1885        };
1886        match whence {
1887            libc::SEEK_SET | libc::SEEK_END if !in_range(offset) => return false,
1888            libc::SEEK_SET | libc::SEEK_END => {}
1889            libc::SEEK_CUR if offset <= 0 => return false,
1890            libc::SEEK_CUR => {}
1891            _ => return false,
1892        }
1893        let recorded = guest
1894            .thread_state()
1895            .with_detfd(fd, |detfd| detfd.stat())
1896            .ok()
1897            .flatten()
1898            .map(|stat| (stat.mode, stat.dev, stat.inode));
1899        let identity = match recorded {
1900            Some(identity) => identity,
1901            None => match self.inject_fstat(guest, fd).await {
1902                Ok(stat) => (stat.st_mode, stat.st_dev, stat.st_ino),
1903                // Not a descriptor: the kernel's own EBADF.
1904                Err(Errno::EBADF) => return false,
1905                // A descriptor that cannot be told is refused (fail closed).
1906                Err(_) => return true,
1907            },
1908        };
1909        if identity.0 & libc::S_IFMT != libc::S_IFDIR {
1910            return false;
1911        }
1912        let filesystem = match Self::placeholder_object(guest) {
1913            PlaceholderObject::ProcfsRoot => Some(Self::inject_fstatfs_type(guest, fd).await),
1914            PlaceholderObject::Placeholder => None,
1915        };
1916        if !Self::on_placeholder_object(
1917            (identity.1, identity.2),
1918            filesystem,
1919            &PLACEHOLDER_IDENTITIES.lock().unwrap(),
1920        ) {
1921            return false;
1922        }
1923        if whence != libc::SEEK_CUR {
1924            return true;
1925        }
1926        let current = guest
1927            .inject(
1928                syscalls::Lseek::new()
1929                    .with_fd(fd)
1930                    .with_offset(0)
1931                    .with_whence(syscalls::Whence::SEEK_CUR),
1932            )
1933            .await;
1934        match current {
1935            Ok(current) => in_range(current.wrapping_add(offset)),
1936            Err(_) => false,
1937        }
1938    }

1963    /// The filesystem type (`f_type`) of descriptor `fd`, by one injected
1964    /// `fstatfs` whose buffer is in Reverie's guest scratch or, where that
1965    /// cannot hold it, in a transient private page unmapped before the guest
1966    /// resumes (as `Detcore::inject_fstat`,
1967    /// <https://github.com/rrnewton/hermit/issues/3328>). No descriptor is
1968    /// opened.
1969    // GNU declares this kernel word as i64, musl as u64; retain its bits in
1970    // the common signed result, including filesystem magic values with bit 63 set.
1971    #[allow(clippy::unnecessary_cast)]
1972    async fn inject_fstatfs_type<G: Guest<Self>>(guest: &mut G, fd: RawFd) -> Result<i64, Errno> {
1973        let fstatfs = |buf: AddrMut<'_, libc::statfs>| {
1974            syscalls::Fstatfs::new().with_fd(fd).with_buf(Some(buf))
1975        };
1976        let on_stack = {
1977            let mut stack = guest.stack().await;
1978            let buf = stack.reserve::<libc::statfs>();
1979            match stack.commit() {
1980                Ok(guard) => {
1981                    let result = match guest.inject_with_retry(fstatfs(buf)).await {
1982                        Ok(_) => guest
1983                            .memory()
1984                            .read_value(buf)
1985                            .map(|statfs| statfs.f_type as i64),
1986                        Err(errno) => Err(errno),
1987                    };
1988                    drop(guard);
1989                    Some(result)
1990                }
1991                Err(_) => None,
1992            }
1993        };
1994        match on_stack {
1995            Some(Err(Errno::EFAULT)) | None => {}
1996            Some(result) => return result,
1997        }
1998        let length = std::mem::size_of::<libc::statfs>();
1999        let page = super::procfs_levels::map_transient(guest, length)
2000            .await
2001            .ok_or(Errno::ENOMEM)?;
2002        let buf = page.cast::<libc::statfs>();
2003        let result = match guest.inject_with_retry(fstatfs(buf)).await {
2004            Ok(_) => guest
2005                .memory()
2006                .read_value(buf)
2007                .map(|statfs| statfs.f_type as i64),
2008            Err(errno) => Err(errno),
2009        };
2010        super::procfs_levels::unmap_transient(guest, page, length).await;
2011        result
2012    }

2014    /// The descriptors of the table a descriptor directory bound to `binding`
2015    /// lists now, ascending, with the table's capacity, read by the caller:
2016    /// `Ok(None)` for a process whose thread group leader has exited (Linux
2017    /// has released its `files`), `ENOENT` for a task that is gone
2018    /// (`get_proc_task` finds none). The caller's own table (the process's
2019    /// for its process, or a thread's for a thread whose table it holds) comes
2020    /// from Detcore's model unless a receive may have installed descriptors
2021    /// the model cannot name; that, and another process's or thread's table,
2022    /// is listed by the kernel beneath the backend, through `object`, a
2023    /// placeholder descriptor on procfs's root where there is one
2024    /// ([`Self::kernel_listing_base`]).
2025    async fn descriptor_directory_table<G: Guest<Self>>(
2026        &self,
2027        guest: &mut G,
2028        binding: &DescriptorDirectoryBinding,
2029        object: Option<RawFd>,
2030    ) -> Result<Option<(Vec<i32>, u64)>, Errno> {
2031        let caller = Self::caller_numbers(guest).ok_or(Errno::EACCES)?;
2032        let (answer, current) = Self::bound_task(guest, binding).await;
2033        if !current {
2034            return Err(Errno::ENOENT);
2035        }
2036        if binding.table == DescriptorDirectoryTable::Process && answer.without_mm {
2037            return Ok(None);
2038        }
2039        let own = {
2040            let state = guest.thread_state();
2041            match binding.table {
2042                DescriptorDirectoryTable::Process => {
2043                    caller.0 == binding.pid
2044                        && (state.dettid.as_raw() == caller.0 || state.holds_process_files())
2045                }
2046                DescriptorDirectoryTable::Thread => {
2047                    caller.1 == binding.tid || binding.files == Some(state.files_id())
2048                }
2049            }
2050        };
2051        let base = self.kernel_listing_base(guest, object);
2052        if own {
2053            let (numbers, capacity, unaccounted) = guest.thread_state().descriptor_table();
2054            if !unaccounted {
2055                return Ok(Some((numbers, capacity)));
2056            }
2057            let path: &[u8] = match binding.table {
2058                DescriptorDirectoryTable::Process => b"self/fd",
2059                DescriptorDirectoryTable::Thread => b"thread-self/fd",
2060            };
2061            let listed = self
2062                .kernel_descriptor_numbers(guest, base, path, true)
2063                .await?;
2064            let capacity = capacity.max(fd_directory::capacity(&listed));
2065            return Ok(Some((listed, capacity)));
2066        }
2067        // Another table: the descriptor opened to read it is in the caller's,
2068        // and a descriptor of the same number in the one listed stays listed
2069        // (a fork's child listing the directory it inherited). (A process
2070        // that shares its table with another process, `CLONE_FILES` without
2071        // `CLONE_THREAD`, and lists that process's directory sees that
2072        // descriptor too: named.)
2073        let within = binding.within().into_os_string().into_encoded_bytes();
2074        let listed = self
2075            .kernel_descriptor_numbers(guest, base, &within[1..], false)
2076            .await?;
2077        let capacity = fd_directory::capacity(&listed);
2078        Ok(Some((listed, capacity)))
2079    }

2094    /// A descriptor table as the kernel beneath the backend lists the
2095    /// descriptor directory at `path` within procfs (`self/fd`,
2096    /// `<pid>/task/<tid>/fd`), looked up from `base` (a descriptor on procfs's
2097    /// root, or `AT_FDCWD`, below `/proc`): one injected open, `getdents64`
2098    /// until the end into a buffer on Reverie's guest stack, and a close,
2099    /// leaving out the descriptor this opens to read it where the table
2100    /// listed is the caller's own (`own`), which holds it.
2101    async fn kernel_descriptor_numbers<G: Guest<Self>>(
2102        &self,
2103        guest: &mut G,
2104        base: RawFd,
2105        path: &[u8],
2106        own: bool,
2107    ) -> Result<Vec<i32>, Errno> {
2108        const PATH_CAPACITY: usize = 64;
2109        const BUFFER: usize = 512;
2110        let mut spelled = Vec::with_capacity(path.len() + 6);
2111        if base == libc::AT_FDCWD {
2112            spelled.extend_from_slice(b"/proc/");
2113        }
2114        spelled.extend_from_slice(path);
2115        if spelled.len() >= PATH_CAPACITY {
2116            return Err(Errno::ENAMETOOLONG);
2117        }

2717    /// Answer `call` if it operates on a placeholder descriptor
2718    /// ([`placeholder_operand`]), from Detcore's model, with one implementation
2719    /// whatever the descriptor's object ([`PlaceholderObject`]), so that no
2720    /// call through it reaches that object's filesystem, whose answers are
2721    /// not the directory's. The calls, and their answers, as Linux answers
2722    /// them for procfs's root and for a descriptor directory, each in Linux's
2723    /// order of checks (v6.17; measured on Linux 7.1):
2724    /// - `getdents`, `getdents64`: the listing (above); `lseek`:
2725    ///   `generic_file_llseek` on an empty directory (`fd_directory::seek`),
2726    ///   on the listing's position;
2727    /// - `fchdir`: the directory entered ([`Self::enter_placeholder`]);
2728    /// - `fcntl` ([`Self::placeholder_fcntl`]): the status flags, as `setfl`
2729    ///   keeps them; the table commands, which reach the descriptor; the
2730    ///   query commands; the write hints, kept for the directory's inode; the
2731    ///   record locks refused by name (`ENOLCK`: named residual); the lease,
2732    ///   seal, pipe and notify commands as Linux answers them for a directory;
2733    /// - `read` and its relatives: the position's `EINVAL` where one is given,
2734    ///   the buffer's `access_ok` (`EFAULT`), the vectors, then `EISDIR`
2735    ///   ([`read_answer`]); `write` and its relatives: a negative position's
2736    ///   `EINVAL`, then `EBADF`, the description cannot write;
2737    /// - `ioctl` ([`Self::placeholder_ioctl`]);
2738    /// - `fsync`, `fdatasync`: `EINVAL` (procfs has no `fsync`); `syncfs`: 0;
2739    /// - `flock`: each directory its own lock (`procfs::locks::LockLedger::
2740    ///   placeholder_flock`), as each is its own inode on Linux;
2741    /// - `fchmod` and the path-less `fchmodat2`: `EPERM`; `fchown` and the
2742    ///   path-less `fchownat`: 0, Detcore's virtual root's answer
2743    ///   (`handle_ownership_change_noop`) with no change to report;
2744    /// - the `f*xattr` calls: procfs's answers (no attribute handlers);
2745    /// - `ftruncate`: a negative length's `EINVAL`, then `EINVAL` (not a
2746    ///   regular file); `fallocate`: `vfs_fallocate`'s checks, then `EBADF`;
2747    ///   `fadvise64`: `generic_fadvise` on a filesystem with no backing
2748    ///   device; `readahead`: `EINVAL`; `sync_file_range`: its argument
2749    ///   checks, then 0;
2750    /// - `fstatfs`: procfs's (`write_procfs_statfs`);
2751    /// - a file-backed `mmap`: as for a procfs file without `mmap`
2752    ///   (`answer_rendered_procfs_mapping`);
2753    /// - the path-less `utimensat`: `EPERM` with times or `EACCES` without on
2754    ///   global root's `/proc`, 0 on the caller's own directory;
2755    ///   `faccessat2`: `EACCES` for write access to `/proc`, else 0;
2756    /// - `sendfile`, `splice`, `tee` and `copy_file_range` with a placeholder
2757    ///   on either side ([`Self::answer_placeholder_transfer`]).
2758    ///
2759    /// An `O_PATH` descriptor fails with `EBADF` where Linux's descriptor
2760    /// lookup refuses it (`fdget`), which is first for most calls and after
2761    /// the arguments a call checks first for the others (a negative position
2762    /// or length, `flock`'s command, the attribute name); `fchdir`, `fstatfs`,
2763    /// `fcntl`'s table and query commands and the path calls take it. A
2764    /// placeholder Detcore keeps no record of (one received without
2765    /// sequentialized threads) has no state to answer from, and its call is
2766    /// refused by name. `None` for every other call.
2767    pub(crate) async fn answer_placeholder_call<G: Guest<Self>>(
2768        &self,
2769        guest: &mut G,
2770        call: &Syscall,
2771    ) -> Option<Result<i64, Error>> {
2772        let (sysno, args) = (*call).into_parts();
2773        if !Self::serves_placeholders(guest) {
2774            return None;
2775        }
2776        // Calls with two descriptor operands, either a placeholder.
2777        if matches!(
2778            sysno,
2779            Sysno::sendfile | Sysno::splice | Sysno::tee | Sysno::copy_file_range
2780        ) {
2781            return self.answer_placeholder_transfer(guest, sysno, &args).await;
2782        }
2783        let fd_position = placeholder_operand(&guest.memory(), sysno, &args)?;
2784        let fd = argument(&args, fd_position) as i32;
2785        let state = match Self::placeholder_of(guest, fd) {
2786            Some(state) => state,
2787            None => {
2788                let directory = Self::unrecorded_placeholder(guest, fd).await?;
2789                return Some(
2790                    self.refuse_placeholder_call(
2791                        guest,
2792                        sysno,
2793                        Errno::EBADF,
2794                        &format!(
2795                            "descriptor {fd} stands for {}, a /proc directory Detcore serves, \
2796                             but was received without sequentialized threads, and Detcore \
2797                             keeps no state to answer it from",
2798                            directory.canonical().display()
2799                        ),
2800                    )
2801                    .await,
2802                );
2803            }
2804        };
2805        // `flock` ignores `LOCK_MAND` before it looks at the descriptor.
2806        if sysno == Sysno::flock && args.arg1 as i32 & LOCK_MAND != 0 {
2807            return Some(Ok(0));
2808        }
2809        // The calls whose descriptor lookup (`fdget`, `fdget_pos`) refuses
2810        // an `O_PATH` descriptor before they look at anything else.
2811        let path_only_refused = state.path_only
2812            && matches!(
2813                sysno,
2814                Sysno::getdents
2815                    | Sysno::getdents64
2816                    | Sysno::lseek
2817                    | Sysno::read
2818                    | Sysno::readv
2819                    | Sysno::write
2820                    | Sysno::writev
2821                    | Sysno::ioctl
2822                    | Sysno::fsync
2823                    | Sysno::fdatasync
2824                    | Sysno::syncfs
2825                    | Sysno::fchmod
2826                    | Sysno::fchown
2827                    | Sysno::fallocate
2828                    | Sysno::fadvise64
2829                    | Sysno::readahead
2830                    | Sysno::sync_file_range
2831                    | Sysno::flistxattr
2832                    | Sysno::mmap
2833            );
2834        if path_only_refused {
2835            return Some(Err(Errno::EBADF.into()));
2836        }
2837        // The calls that check an argument before their descriptor lookup
2838        // refuses an `O_PATH` descriptor: a negative position or length.
2839        let positioned = |position: i64, minus_one_reads_on: bool| {
2840            if position < 0 && !(minus_one_reads_on && position == -1) {
2841                Some(Err(Errno::EINVAL.into()))
2842            } else if state.path_only {
2843                Some(Err(Errno::EBADF.into()))
2844            } else {
2845                None
2846            }
2847        };
2848        let early = match sysno {
2849            Sysno::pread64 | Sysno::pwrite64 | Sysno::preadv | Sysno::pwritev => {
2850                positioned(args.arg3 as i64, false)
2851            }
2852            Sysno::preadv2 | Sysno::pwritev2 => positioned(args.arg3 as i64, true),
2853            Sysno::ftruncate => positioned(args.arg1 as i64, false),
2854            _ => None,
2855        };
2856        if let Some(answer) = early {
2857            return Some(answer);
2858        }
2859        Some(match call {
2860            Syscall::Getdents(_) | Syscall::Getdents64(_)
2861                if state.directory == PlaceholderDirectory::Root =>
2862            {
2863                self.serve_root_placeholder(guest, call, fd, state).await
2864            }
2865            Syscall::Getdents(c) => {
2866                self.serve_descriptor_directory(
2867                    guest,
2868                    fd,
2869                    state,
2870                    c.dirent().map(|dirent| dirent.cast::<u8>()),
2871                    c.count() as usize,
2872                    DirentFormat::Legacy,
2873                )
2874                .await
2875            }
2876            Syscall::Getdents64(c) => {
2877                self.serve_descriptor_directory(
2878                    guest,
2879                    fd,
2880                    state,
2881                    c.dirent().map(|dirent| dirent.cast::<u8>()),
2882                    c.count() as usize,
2883                    DirentFormat::Dirent64,
2884                )
2885                .await
2886            }
2887            Syscall::Lseek(c) => {
2888                self.seek_placeholder(guest, fd, state, c.offset(), args.arg2 as i32)
2889            }
2890            Syscall::Fchdir(_) => self.enter_placeholder(guest, fd, &state.directory).await?,
2891            Syscall::Fcntl(c) => self.placeholder_fcntl(guest, fd, state, c).await?,
2892            Syscall::Read(_)
2893            | Syscall::Readv(_)
2894            | Syscall::Pread64(_)
2895            | Syscall::Preadv(_)
2896            | Syscall::Preadv2(_) => read_answer(&guest.memory(), sysno, &args).map_err(Into::into),
2897            Syscall::Write(_)
2898            | Syscall::Writev(_)
2899            | Syscall::Pwrite64(_)
2900            | Syscall::Pwritev(_)
2901            | Syscall::Pwritev2(_) => Err(Errno::EBADF.into()),
2902            Syscall::Ioctl(_) => self
2903                .placeholder_ioctl(guest, fd, args.arg1 as u32, args.arg2)
2904                .await?
2905                .map_err(Into::into),
2906            Syscall::Fsync(_) | Syscall::Fdatasync(_) => Err(Errno::EINVAL.into()),
2907            Syscall::Flock(c) => {
2908                self.placeholder_flock(guest, fd, state, c.operation())
2909                    .await
2910            }
2911            Syscall::Fchmod(_) => Err(Errno::EPERM.into()),
2912            Syscall::Fchown(_) => Ok(0),
2913            Syscall::Fgetxattr(_)
2914            | Syscall::Fsetxattr(_)
2915            | Syscall::Flistxattr(_)
2916            | Syscall::Fremovexattr(_) => self.placeholder_xattr(guest, call, state).await,
2917            Syscall::Ftruncate(_) => Err(Errno::EINVAL.into()),
2918            Syscall::Fallocate(_) => {
2919                Err(fallocate_answer(args.arg1 as i32, args.arg2 as i64, args.arg3 as i64).into())
2920            }
2921            Syscall::Readahead(_) => Err(Errno::EINVAL.into()),
2922            Syscall::Fstatfs(c) => self.write_procfs_statfs(guest, c.buf()).map(|()| 0),
2923            Syscall::Mmap(_) => return None,
2924            _ => match sysno {
2925                Sysno::syncfs => Ok(0),
2926                Sysno::fadvise64 => {
2927                    fadvise_answer(args.arg2 as i64, args.arg3 as i32).map_err(Into::into)
2928                }
2929                Sysno::sync_file_range => {
2930                    sync_file_range_answer(args.arg1 as i64, args.arg2 as i64, args.arg3 as u32)
2931                        .map_err(Into::into)
2932                }
2933                Sysno::utimensat => {
2934                    self.placeholder_utimensat(
2935                        guest,
2936                        state,
2937                        args.arg1 == 0,
2938                        args.arg2,
2939                        args.arg3 as i32,
2940                    )
2941                    .await
2942                }
2943                // `do_fchmodat`'s flags, then procfs's answer to a mode change.
2944                Sysno::fchmodat2
2945                    if args.arg3 as i32 & !(libc::AT_SYMLINK_NOFOLLOW | libc::AT_EMPTY_PATH)
2946                        != 0 =>
2947                {
2948                    Err(Errno::EINVAL.into())
2949                }
2950                Sysno::fchmodat2 => Err(Errno::EPERM.into()),
2951                // `do_fchownat`'s flags, then Detcore's virtual root's answer.
2952                Sysno::fchownat
2953                    if args.arg4 as i32 & !(libc::AT_SYMLINK_NOFOLLOW | libc::AT_EMPTY_PATH)
2954                        != 0 =>
2955                {
2956                    Err(Errno::EINVAL.into())
2957                }
2958                Sysno::fchownat => Ok(0),
2959                Sysno::faccessat2 => self
2960                    .placeholder_access(&state.directory, args.arg2 as i32, args.arg3 as i32)
2961                    .map_err(Into::into),
2962                _ => return None,
2963            },
2964        })
2965    }

2982    /// The named refusal (ARCHITECTURE.md rule 6) of a call whose path leads
2983    /// below a placeholder directory, and which Detcore does not respell for
2984    /// the backend ([`Self::respelled_lookup`]): `execve` and `execveat`,
2985    /// which read their image before an injection could carry a respelled
2986    /// path, and the pathname `AF_UNIX` addresses of `bind`, `connect`,
2987    /// `sendto`, `sendmsg` and `sendmmsg`, which live in the guest's own
2988    /// structures. Such a path would reach the placeholder's object, not the
2989    /// directory, where Linux reaches the directory: on ptrace only a
2990    /// descriptor directory (`/proc` itself is its descriptor's object), on
2991    /// KVM either. A path that is a descriptor link and nothing more is left
2992    /// to the backend: an exec of a directory and an `AF_UNIX` address on one
2993    /// fail alike there (`EACCES`, `ECONNREFUSED` or `EADDRINUSE`). A send's
2994    /// address is looked up only by a datagram socket (`unix_dgram_sendmsg`):
2995    /// a stream socket refuses it without a lookup (`EISCONN` or
2996    /// `EOPNOTSUPP`, `unix_stream_sendmsg`) and a sequenced-packet socket
2997    /// ignores it (`unix_seqpacket_sendmsg`), so their sends go on as Linux's
2998    /// do; where the socket's type cannot be asked, the send is refused.
2999    /// `None` for every other call and path.
3000    pub(crate) async fn refuse_lookup_below_placeholder<G: Guest<Self>>(
3001        &self,
3002        guest: &mut G,
3003        call: &Syscall,
3004    ) -> Option<Result<i64, Error>> {
3005        if !OPENED_ANY.load(Ordering::SeqCst) || !Self::serves_placeholders(guest) {
3006            return None;
3007        }
3008        let (sysno, args) = call.into_parts();
3009        let read_path = |guest: &G, pointer: usize| -> Option<Vec<u8>> {
3010            PathPtr::from_ptr(pointer as *const libc::c_char)
3011                .and_then(|pointer| pointer.read(&guest.memory()).ok())
3012                .map(|path: PathBuf| path.into_os_string().into_encoded_bytes())
3013                .filter(|path| !path.is_empty())
3014        };
3015        let lookups: Vec<(Option<RawFd>, Vec<u8>)> = match sysno {
3016            Sysno::execve => read_path(guest, args.arg0)
3017                .map(|path| (None, path))
3018                .into_iter()
3019                .collect(),
3020            Sysno::execveat => read_path(guest, args.arg1)
3021                .map(|path| (Some(args.arg0 as RawFd), path))
3022                .into_iter()
3023                .collect(),
3024            Sysno::bind | Sysno::connect => {
3025                unix_address_path(&guest.memory(), args.arg1, args.arg2)
3026                    .map(|path| (None, path))
3027                    .into_iter()
3028                    .collect()
3029            }
3030            Sysno::sendto => unix_address_path(&guest.memory(), args.arg4, args.arg5)
3031                .map(|path| (None, path))
3032                .into_iter()
3033                .collect(),
3034            Sysno::sendmsg => message_addresses(&guest.memory(), args.arg1, 1, 0)
3035                .into_iter()
3036                .map(|path| (None, path))
3037                .collect(),
3038            Sysno::sendmmsg => message_addresses(&guest.memory(), args.arg1, args.arg2, 64)
3039                .into_iter()
3040                .map(|path| (None, path))
3041                .collect(),
3042            _ => return None,
3043        };
3044        let send = matches!(sysno, Sysno::sendto | Sysno::sendmsg | Sysno::sendmmsg);
3045        for (dirfd, path) in lookups {
3046            let looked_up = Self::respelled_lookup(guest, dirfd, &path, false, 0).await;
3047            if matches!(looked_up, Ok(None)) {
3048                continue;
3049            }
3050            // Only a datagram socket looks a send's address up, so no answer
3051            // of the lookup's, its errors included, is a stream or
3052            // sequenced-packet socket's; one socket makes every send of the
3053            // call.
3054            if send
3055                && self
3056                    .socket_is_datagram(guest, args.arg0 as RawFd)
3057                    .await
3058                    .is_some_and(|datagram| !datagram)
3059            {
3060                return None;
3061            }
3062            if let Err(errno) = looked_up {
3063                return Some(Err(errno.into()));
3064            }
3065            return Some(
3066                self.refuse_placeholder_call(
3067                    guest,
3068                    sysno,
3069                    Errno::ENOENT,
3070                    &format!(
3071                        "the path {} leads below a /proc directory Detcore serves on a \
3072                         placeholder descriptor, and Detcore cannot spell it for this call as \
3073                         Linux resolves it",
3074                        String::from_utf8_lossy(&path)
3075                    ),
3076                )
3077                .await,
3078            );
3079        }
3080        None
3081    }

3117    /// `fchdir` to placeholder descriptor `fd`, which enters the directory it
3118    /// stands for as Linux's `fchdir` enters it (`set_fs_pwd`), so that the
3119    /// working directory, `getcwd`, `/proc/self/cwd` and every name looked
3120    /// up from it are the directory's own:
3121    /// - on procfs's root (ptrace): `/proc` itself is the descriptor's own
3122    ///   object, which the guest's `fchdir` enters (`None`: the kernel answers
3123    ///   it); a descriptor directory is entered from the descriptor, in every
3124    ///   state of the caller: one injected `openat` of the directory's path
3125    ///   within procfs (`<pid>/fd`, `O_PATH`), `fchdir` to it and its
3126    ///   `close`. Where the caller's table has no free slot for that
3127    ///   descriptor, one injected `chdir` to the directory's absolute path,
3128    ///   where Detcore knows that path reaches it (the caller has not changed
3129    ///   its root and is in no nested PID namespace), and otherwise a refusal
3130    ///   by name: either way the working directory changes only if the call
3131    ///   succeeds, as Linux's `fchdir` changes it;
3132    /// - on the placeholder (KVM): an injected `chdir` to the directory's
3133    ///   path, which the backend resolves (KVM's executor refuses a working
3134    ///   directory on procfs with `EACCES`, as it does for the guest's own
3135    ///   `chdir("/proc")`).
3136    ///
3137    /// A descriptor directory whose task is gone (or whose numbers another
3138    /// task holds now) is one Linux still enters, a directory below which no
3139    /// lookup finds anything, and whose `getcwd` fails; no object of the
3140    /// backend's stands for it, so that `fchdir` is refused by name.
3141    async fn enter_placeholder<G: Guest<Self>>(
3142        &self,
3143        guest: &mut G,
3144        fd: RawFd,
3145        directory: &PlaceholderDirectory,
3146    ) -> Option<Result<i64, Error>> {
3147        let object = Self::placeholder_object(guest);
3148        if object == PlaceholderObject::ProcfsRoot && *directory == PlaceholderDirectory::Root {
3149            return None;
3150        }
3151        if !Self::placeholder_current(guest, directory).await {
3152            return Some(
3153                self.refuse_placeholder_call(
3154                    guest,
3155                    Sysno::fchdir,
3156                    Errno::ENOENT,
3157                    &format!(
3158                        "fchdir to {}, a descriptor directory whose task has exited, which \
3159                         Linux enters though nothing below it exists; Detcore has no directory \
3160                         to stand for it",
3161                        directory.canonical().display()
3162                    ),
3163                )
3164                .await,
3165            );
3166        }
3167        Some(match (object, directory) {
3168            (PlaceholderObject::ProcfsRoot, PlaceholderDirectory::Descriptors(binding)) => {
3169                let within = binding.within().into_os_string().into_encoded_bytes();
3170                let within = &within[1..];
3171                match Self::inject_openat(
3172                    guest,
3173                    fd,
3174                    within,
3175                    OFlag::O_PATH | OFlag::O_DIRECTORY | OFlag::O_CLOEXEC,
3176                )
3177                .await
3178                {
3179                    Ok(opened) => {
3180                        let entered = guest
3181                            .inject_with_retry(syscalls::Fchdir::new().with_fd(opened))
3182                            .await;
3183                        let _ = guest.inject(syscalls::Close::new().with_fd(opened)).await;
3184                        entered.map_err(Into::into)
3185                    }
3186                    Err(Errno::EMFILE | Errno::ENFILE)
3187                        if Self::descriptor_directory_caller(guest).is_some() =>

3242    /// [`Self::answer_placeholder_call`]), as `do_fcntl` answers it for the
3243    /// directory, or `None` for a command that reaches the descriptor
3244    /// (v6.17 `fs/fcntl.c`):
3245    /// - an `O_PATH` descriptor takes only `F_DUPFD`, `F_DUPFD_CLOEXEC`,
3246    ///   `F_DUPFD_QUERY`, `F_GETFD`, `F_SETFD`, `F_GETFL` and
3247    ///   `F_CREATED_QUERY` (`check_fcntl_cmd`), every other `EBADF`;
3248    /// - `F_GETFL`: the description's status flags; `F_SETFL` (`setfl`):
3249    ///   setting `O_NOATIME` needs the directory's owner or one who may act
3250    ///   as it (`EPERM` on global root's `/proc`), `O_DIRECT` is `EINVAL` (no
3251    ///   direct I/O), and only `SETFL_MASK` is kept, which `O_ASYNC` is not
3252    ///   (a directory has no `fasync`: the call succeeds, the flag stays as
3253    ///   the open left it);
3254    /// - `F_DUPFD_QUERY`: whether another descriptor names the same
3255    ///   description (`EBADF` for one not open); `F_CREATED_QUERY`: 0, the
3256    ///   open created no directory;
3257    /// - the write hints are the directory's inode's (`i_write_hint`), kept
3258    ///   for every open of it (`procfs::locks::LockLedger::
3259    ///   placeholder_write_hint`): `F_GET_RW_HINT` writes it, 0 until set;
3260    ///   `F_SET_RW_HINT` needs the owner (`EPERM`) before it reads the hint
3261    ///   (`EFAULT`) and checks it (`EINVAL` past 5);
3262    /// - the record locks are refused by name (`ENOLCK`: named residual); a
3263    ///   lease is an invalid type's `EINVAL`, then `EACCES` without the
3264    ///   owner (global root's `/proc`), then `EINVAL` for a directory;
3265    ///   `F_GETLEASE` is `F_UNLCK`; `F_ADD_SEALS` `EPERM` (not writable),
3266    ///   `F_GET_SEALS` `EINVAL`; the pipe sizes `EBADF`; `F_NOTIFY` 0, with no
3267    ///   event ever sent (named residual); any other command `EINVAL`.

3269        &self,
3270        guest: &mut G,
3271        fd: RawFd,
3272        state: PlaceholderState,
3273        call: &syscalls::Fcntl,
3274    ) -> Option<Result<i64, Error>> {
3275        let (_, args) = Syscall::Fcntl(*call).into_parts();
3276        let command = args.arg1 as libc::c_int;
3277        Some(match command {
3278            libc::F_GETFL => {
3279                let status = guest
3280                    .thread_state()
3281                    .with_detfd(fd, |detfd| detfd.status_flags())
3282                    .unwrap_or(libc::O_DIRECTORY);
3283                Ok(i64::from(status & !libc::O_CLOEXEC))
3284            }
3285            // The table commands, which the kernel's descriptor table answers
3286            // for every file, `O_PATH` ones included.
3287            libc::F_DUPFD | libc::F_DUPFD_CLOEXEC | libc::F_GETFD | libc::F_SETFD => return None,
3288            // Whether another descriptor names this one's description
3289            // (`f_dupfd_query`, which takes an `O_PATH` one too): `EBADF` for
3290            // one that is not open.
3291            F_DUPFD_QUERY => {

3293                let mine = guest

3295                    .with_detfd(fd, |detfd| detfd.open_file_id())
3296                    .ok();

3298                    .thread_state()

3300                {

3307                                .with_cmd(FcntlCmd::F_GETFD),
3308                        )
3309                        .await
3310                    {
3311                        Ok(_) => Ok(0),
3312                        Err(errno) => Err(errno.into()),
3313                    },

3316            // A directory the open did not create (`FMODE_CREATED`).
3317            F_CREATED_QUERY => Ok(0),
3318            // `check_fcntl_cmd`: no other command is allowed on `O_PATH`.
3319            _ if state.path_only => Err(Errno::EBADF.into()),
3320            libc::F_SETFL => {
3321                // `setfl` keeps only `SETFL_MASK`.
3322                const SETFL_MASK: i32 =
3323                    libc::O_APPEND | libc::O_NONBLOCK | libc::O_DIRECT | libc::O_NOATIME;

3325                let status = guest
3326                    .thread_state()
3327                    .with_detfd(fd, |detfd| detfd.status_flags())
3328                    .unwrap_or(libc::O_DIRECTORY);

3344                }
3345            }
3346            // The owner and signal commands, which act on the description
3347            // alike for every file.
3348            libc::F_SETOWN
3349            | libc::F_GETOWN
3350            | F_SETSIG

3352            | F_SETOWN_EX
3353            | F_GETOWN_EX

3356            // (on procfs's root every placeholder is one inode), where Linux's

3361            | libc::F_SETLKW

3363            | libc::F_OFD_SETLK

3371            }
3372            // A lease of an invalid type first (`lease_alloc`); then the
3373            // file's owner, or CAP_LEASE in the initial user namespace, which
3374            // no guest in a user namespace has (`vfs_setlease`); then a

3378                    args.arg2 as libc::c_int,
3379                    libc::F_RDLCK | libc::F_WRLCK | libc::F_UNLCK
3380                ) =>
3381            {
3382                Err(Errno::EINVAL.into())
3383            }
3384            libc::F_SETLEASE => match placeholder_lease_owner(&state.directory) {
3385                Ok(true) => Err(Errno::EINVAL.into()),
3386                Ok(false) => Err(Errno::EACCES.into()),
3387                Err(errno) => Err(errno.into()),
3388            },
3389            libc::F_GETLEASE => Ok(i64::from(libc::F_UNLCK)),
3390            // Adding seals needs a writable descriptor, before Linux looks

3392            libc::F_ADD_SEALS => Err(Errno::EPERM.into()),
3393            libc::F_GET_SEALS => Err(Errno::EINVAL.into()),
3394            // Not a pipe (`get_pipe_info`).
3395            libc::F_SETPIPE_SZ | libc::F_GETPIPE_SZ => Err(Errno::EBADF.into()),
3396            // dnotify takes the directory; Detcore sends no event.
3397            libc::F_NOTIFY => Ok(0),
3398            F_GET_RW_HINT => {

3400                    guest,
3401                    state.directory.lock_key(),
3402                    None,

3404                .await;

3406                    Some(address) => guest
3407                        .memory()
3408                        .write_value(address, &hint)
3409                        .map(|()| 0)

3411                    None => Err(Errno::EFAULT.into()),
3412                }
3413            }
3414            F_SET_RW_HINT => {
3415                match placeholder_owner_or_capable(&state.directory) {
3416                    Ok(true) => {}
3417                    Ok(false) => return Some(Err(Errno::EPERM.into())),
3418                    Err(errno) => return Some(Err(errno.into())),
3419                }

3421                    .map(|hint| guest.memory().read_value(hint))

3423                    Some(Ok(hint)) if hint <= RWH_WRITE_LIFE_EXTREME => {

3425                            guest,
3426                            state.directory.lock_key(),
3427                            Some(hint),
3428                        )
3429                        .await;
3430                        Ok(0)
3431                    }
3432                    Some(Ok(_)) => Err(Errno::EINVAL.into()),
3433                    _ => Err(Errno::EFAULT.into()),
3434                }
3435            }
3436            _ => Err(Errno::EINVAL.into()),
3437        })

3440    /// `ioctl` through placeholder descriptor `fd`
3441    /// (see [`Self::answer_placeholder_call`]), as `do_vfs_ioctl` answers it
3442    /// for the directory, or `None` for a command that reaches the descriptor
3443    /// (v6.17 `fs/ioctl.c`):
3444    /// - `FIOCLEX` and `FIONCLEX` reach the descriptor's table slot;
3445    /// - `FIONBIO` reads its flag (`EFAULT`) and sets or clears
3446    ///   `O_NONBLOCK` in the description's status flags; `FIOASYNC` reads its
3447    ///   flag, then a change of the description's `O_ASYNC` needs a `fasync`
3448    ///   the directory has not (`ENOTTY`), and no change is 0;
3449    /// - `FIGETBSZ` procfs's 1024; `FIOQSIZE` 0;
3450    /// - `FIFREEZE` and `FITHAW` need `CAP_SYS_ADMIN` in procfs's user
3451    ///   namespace, the guest's (`EPERM`), then procfs cannot freeze
3452    ///   (`EOPNOTSUPP`) and is not frozen (`thaw_super`'s `EINVAL`);
3453    ///   `FS_IOC_FIEMAP` `EOPNOTSUPP`;
3454    /// - `FICLONE` and `FICLONERANGE` (whose argument is read first): the
3455    ///   source descriptor (`EBADF`), then another filesystem's (`EXDEV`),
3456    ///   then a directory (`EISDIR`); `FIDEDUPERANGE`: its destination count
3457    ///   (`EFAULT`), a request past a page (`ENOMEM`), the request
3458    ///   (`EFAULT`), the reserved fields (`EINVAL`), then this directory
3459    ///   (`EISDIR`);
3460    /// - `FS_IOC_SETFLAGS` reads its argument (`EFAULT`); it and every other
3461    ///   command, `FS_IOC_GETFLAGS` among them, are `ENOTTY`: procfs has no
3462    ///   `fileattr_get` and directories no `unlocked_ioctl`.
3463    async fn placeholder_ioctl<G: Guest<Self>>(
3464        &self,
3465        guest: &mut G,
3466        fd: RawFd,
3467        command: u32,
3468        argument: usize,
3469    ) -> Option<Result<i64, Errno>> {
3470        const FIONBIO: usize = 0x5421;
3471        const FIOASYNC: usize = 0x5452;
3472        const FIGETBSZ: usize = 2;
3473        const FIOQSIZE: usize = 0x5460;
3474        const FIFREEZE: usize = 0xc004_5877;
3475        const FITHAW: usize = 0xc004_5878;
3476        const FS_IOC_FIEMAP: usize = 0xc020_660b;
3477        const FICLONE: usize = 0x4004_9409;
3478        const FICLONERANGE: usize = 0x4020_940d;
3479        const FIDEDUPERANGE: usize = 0xc018_9436;
3480        const FS_IOC_SETFLAGS: usize = 0x4008_6602;
3481        const CAP_SYS_ADMIN: u32 = 21;
3482        let flag = |guest: &G| -> Result<bool, Errno> {
3483            let address =
3484                reverie::syscalls::Addr::<libc::c_int>::from_raw(argument).ok_or(Errno::EFAULT)?;
3485            guest
3486                .memory()
3487                .read_value(address)
3488                .map(|value| value != 0)
3489                .map_err(|_| Errno::EFAULT)
3490        };

3492            // FIONCLEX and FIOCLEX, on the descriptor's table slot.
3493            0x5450 | 0x5451 => return None,
3494            FIONBIO => flag(guest).and_then(|on| {
3495                guest
3496                    .thread_state()
3497                    .with_detfd(fd, |detfd| {
3498                        let status = detfd.status_flags();
3499                        detfd.set_status_flags(if on {
3500                            status | libc::O_NONBLOCK
3501                        } else {
3502                            status & !libc::O_NONBLOCK
3503                        });
3504                    })
3505                    .map(|()| 0)
3506            }),
3507            FIOASYNC => flag(guest).and_then(|on| {
3508                let asynchronous = guest
3509                    .thread_state()
3510                    .with_detfd(fd, |detfd| detfd.status_flags() & libc::O_ASYNC != 0)
3511                    .unwrap_or(false);
3512                if on == asynchronous {
3513                    Ok(0)
3514                } else {
3515                    Err(Errno::ENOTTY)
3516                }
3517            }),
3518            FIGETBSZ => match AddrMut::<libc::c_int>::from_raw(argument) {
3519                Some(address) => guest
3520                    .memory()
3521                    .write_value(address, &(procfs_inode::PROC_BLOCK_SIZE as libc::c_int))
3522                    .map(|()| 0),
3523                None => Err(Errno::EFAULT),
3524            },
3525            // The bytes the directory uses: none.
3526            FIOQSIZE => match AddrMut::<libc::loff_t>::from_raw(argument) {
3527                Some(address) => guest.memory().write_value(address, &0).map(|()| 0),
3528                None => Err(Errno::EFAULT),
3529            },
3530            FIFREEZE | FITHAW => {
3531                let effective = match Self::inject_capget(
3532                    guest,
3533                    super::rendered_procfs::CapabilitySet::Effective,
3534                )
3535                .await
3536                {
3537                    Ok(effective) => effective.unwrap_or(0),
3538                    Err(_) => 0,
3539                };
3540                if effective & (1 << CAP_SYS_ADMIN) == 0 {
3541                    Err(Errno::EPERM)
3542                } else if command as usize == FIFREEZE {
3543                    Err(Errno::EOPNOTSUPP)
3544                } else {
3545                    Err(Errno::EINVAL)
3546                }
3547            }
3548            FS_IOC_FIEMAP => Err(Errno::EOPNOTSUPP),
3549            FICLONE => self.placeholder_clone_answer(guest, argument as i32).await,
3550            // The whole `struct file_clone_range` is read first.
3551            FICLONERANGE => match reverie::syscalls::Addr::<[u64; 4]>::from_raw(argument)
3552                .map(|address| guest.memory().read_value(address))
3553            {
3554                Some(Ok(range)) => self.placeholder_clone_answer(guest, range[0] as i32).await,
3555                _ => Err(Errno::EFAULT),
3556            },
3557            FIDEDUPERANGE => {
3558                // `struct file_dedupe_range`: src_offset, src_length,
3559                // dest_count (u16), reserved1 (u16), reserved2 (u32), then
3560                // dest_count 32-byte `struct file_dedupe_range_info`.
3561                let count = (argument != 0)
3562                    .then(|| reverie::syscalls::Addr::<u16>::from_raw(argument.wrapping_add(16)))
3563                    .flatten()
3564                    .ok_or(Errno::EFAULT)
3565                    .and_then(|address| {
3566                        guest
3567                            .memory()
3568                            .read_value(address)
3569                            .map_err(|_| Errno::EFAULT)

3571                match count {
3572                    Err(errno) => Err(errno),

3577                            .map(|address| guest.memory().read_exact(address, &mut request))
3578                        {
3579                            Some(Ok(())) if request[18..24].iter().any(|byte| *byte != 0) => {
3580                                Err(Errno::EINVAL)
3581                            }
3582                            Some(Ok(())) => Err(Errno::EISDIR),
3583                            _ => Err(Errno::EFAULT),
3584                        }
3585                    }
3586                }
3587            }
3588            FS_IOC_SETFLAGS => flag(guest).and(Err(Errno::ENOTTY)),
3589            // Every other command, FS_IOC_GETFLAGS and FS_IOC_FSGETXATTR
3590            // among them: procfs has no `fileattr_get` and directories no
3591            // `unlocked_ioctl`.
3592            _ => Err(Errno::ENOTTY),
3593        })

3678    /// [`Self::answer_placeholder_call`]): each directory is locked apart
3679    /// (`procfs::locks::LockLedger::placeholder_flock`), the description
3680    /// owning the lock as on Linux, and losing it with its last reference. A
3681    /// contended blocking request is refused as `Detcore::handle_flock`
3682    /// refuses one, and so is a lock asked for by a process whose descriptor
3683    /// tables the ledger cannot tell apart (named residual).
3684    async fn placeholder_flock<G: Guest<Self>>(
3685        &self,
3686        guest: &mut G,
3687        fd: RawFd,
3688        state: PlaceholderState,
3689        operation: i32,
3690    ) -> Result<i64, Error> {
3691        use crate::procfs::locks::FlockMode;
3692        use crate::procfs::locks::PlaceholderFlockOutcome;
3693        let mode = match operation & !libc::LOCK_NB {
3694            libc::LOCK_SH => Some(FlockMode::Shared),
3695            libc::LOCK_EX => Some(FlockMode::Exclusive),
3696            libc::LOCK_UN => None,
3697            _ => return Err(Errno::EINVAL.into()),
3698        };
3699        // An `O_PATH` descriptor, after the command (`flock_translate_cmd`).
3700        if state.path_only {
3701            return Err(Errno::EBADF.into());

3947                    }

4692/// A read of a directory (`read`, `readv`, `pread64`, `preadv`, `preadv2`),
4693/// in Linux's order of checks (v6.17 `fs/read_write.c`, `lib/iov_iter.c`),
4694/// after the descriptor lookup and a negative position's `EINVAL`
4695/// ([`Detcore::answer_placeholder_call`]): for `read` and `pread64` the
4696/// buffer's `access_ok` (`EFAULT`, which also refuses every count past
4697/// `SSIZE_MAX`) and a position whose end overflows (`EINVAL`); for the
4698/// vectored reads `import_iovec` (more than `UIO_MAXIOV` vectors `EINVAL`
4699/// before the array is read, an unreadable array `EFAULT`, a length past
4700/// `SSIZE_MAX` `EINVAL`, a vector `access_ok` refuses `EFAULT`, a lone
4701/// vector's length clamped to `MAX_RW_COUNT` first), nothing to read (0),
4702/// and a `preadv2` flag the loop does not take (`EOPNOTSUPP`); then
4703/// `generic_read_dir`'s `EISDIR`, also for a count of 0.
4704fn read_answer<M: MemoryAccess>(
4705    memory: &M,
4706    sysno: Sysno,
4707    args: &syscalls::SyscallArgs,
4708) -> Result<i64, Errno> {
4709    const UIO_MAXIOV: usize = 1024;
4710    const RWF_HIPRI: u32 = 1;
4711    const MAX_RW_COUNT: usize = 0x7fff_f000;
4712    let position_overflows =
4713        |position: i64, count: usize| position.checked_add(count as i64).is_none_or(|end| end < 0);
4714    match sysno {
4715        Sysno::read | Sysno::pread64 => {
4716            let count = args.arg2;
4717            if !access_ok(args.arg1, count) {
4718                return Err(Errno::EFAULT);
4719            }
4720            if sysno == Sysno::pread64 && position_overflows(args.arg3 as i64, count) {
4721                return Err(Errno::EINVAL);
4722            }
4723            Err(Errno::EISDIR)
4724        }
4725        _ => {
4726            // `import_iovec` takes the count as an `unsigned int`.
4727            let count = args.arg2 as u32 as usize;
4728            if count > UIO_MAXIOV {
4729                return Err(Errno::EINVAL);
4730            }
4731            let mut total: usize = 0;
4732            for index in 0..count {
4733                let Some(vector) = reverie::syscalls::Addr::<[u64; 2]>::from_raw(
4734                    args.arg1.wrapping_add(index * 16),
4735                ) else {
4736                    return Err(Errno::EFAULT);
4737                };
4738                let [base, length] = memory.read_value(vector).map_err(|_| Errno::EFAULT)?;
4739                if i64::try_from(length).is_err() {
4740                    return Err(Errno::EINVAL);
4741                }
4742                let length = if count == 1 {
4743                    (length as usize).min(MAX_RW_COUNT)
4744                } else {
4745                    length as usize
4746                };
4747                if !access_ok(base as usize, length) {
4748                    return Err(Errno::EFAULT);
4749                }
4750                total = total.saturating_add(length);
4751            }
4752            if total == 0 {
4753                return Ok(0);
4754            }
4755            if sysno != Sysno::readv
4756                && !(sysno == Sysno::preadv2 && args.arg3 as i64 == -1)
4757                && position_overflows(args.arg3 as i64, total)
4758            {
4759                return Err(Errno::EINVAL);
4760            }
4761            // The flags are an `rwf_t`, an `int`: Linux reads the register's
4762            // low 32 bits.
4763            if sysno == Sysno::preadv2 && args.arg5 as u32 & !RWF_HIPRI != 0 {
4764                return Err(Errno::EOPNOTSUPP);
4765            }
4766            Err(Errno::EISDIR)
4767        }
4768    }
4769}

4772/// descriptor looks the descriptor up, and the error the first that fails
4773/// gives (v6.17 `fs/xattr.c`): for `fsetxattr` the flags (`EINVAL`), the
4774/// name, the size (`E2BIG` past `XATTR_SIZE_MAX`) and the value (`EFAULT`);
4775/// for `fgetxattr` and `fremovexattr` the name: an unreadable one `EFAULT`,
4776/// an empty one or one of 256 bytes or more `ERANGE` (`import_xattr_name`).
4777fn xattr_arguments_answer<M: MemoryAccess>(memory: &M, call: &Syscall) -> Result<(), Errno> {
4778    const XATTR_NAME_MAX: usize = 255;
4779    const XATTR_SIZE_MAX: usize = 65536;
4780    let (sysno, args) = call.into_parts();
4781    let name = |address: usize| -> Result<(), Errno> {
4782        let mut bytes = Vec::with_capacity(XATTR_NAME_MAX + 1);
4783        for offset in 0..=XATTR_NAME_MAX {
4784            let byte = reverie::syscalls::Addr::<u8>::from_raw(address.wrapping_add(offset))
4785                .ok_or(Errno::EFAULT)
4786                .and_then(|address| memory.read_value(address).map_err(|_| Errno::EFAULT))?;
4787            if byte == 0 {
4788                break;
4789            }
4790            bytes.push(byte);
4791        }
4792        if bytes.is_empty() || bytes.len() > XATTR_NAME_MAX {
4793            return Err(Errno::ERANGE);
4794        }
4795        Ok(())
4796    };
4797    match sysno {
4798        Sysno::fsetxattr => {
4799            if args.arg4 as i32 & !(libc::XATTR_CREATE | libc::XATTR_REPLACE) != 0 {
4800                return Err(Errno::EINVAL);
4801            }
4802            name(args.arg1)?;
4803            let size = args.arg3;
4804            if size > XATTR_SIZE_MAX {
4805                return Err(Errno::E2BIG);
4806            }
4807            if size > 0 {
4808                let mut value = vec![0u8; size];
4809                reverie::syscalls::Addr::<u8>::from_raw(args.arg2)
4810                    .ok_or(Errno::EFAULT)
4811                    .and_then(|address| {
4812                        memory
4813                            .read_exact(address, &mut value)
4814                            .map_err(|_| Errno::EFAULT)
4815                    })?;
4816            }
4817            Ok(())
4818        }
4819        Sysno::fgetxattr | Sysno::fremovexattr => name(args.arg1),
4820        _ => Ok(()),
4821    }
4822}

4913/// `fallocate` of a directory Linux refuses in `vfs_fallocate`'s order: a
4914/// negative offset or a length that is not positive (`EINVAL`), an unknown
4915/// mode bit or a mode with a flag it does not take (`EOPNOTSUPP`), then a
4916/// description opened without write access (`EBADF`), as every directory's
4917/// is.
4918fn fallocate_answer(mode: i32, offset: i64, length: i64) -> Errno {
4919    const KEEP_SIZE: i32 = 0x01;
4920    const PUNCH_HOLE: i32 = 0x02;
4921    const COLLAPSE_RANGE: i32 = 0x08;
4922    const ZERO_RANGE: i32 = 0x10;
4923    const INSERT_RANGE: i32 = 0x20;
4924    const UNSHARE_RANGE: i32 = 0x40;
4925    const WRITE_ZEROES: i32 = 0x80;
4926    const MODE_MASK: i32 =
4927        PUNCH_HOLE | COLLAPSE_RANGE | ZERO_RANGE | INSERT_RANGE | UNSHARE_RANGE | WRITE_ZEROES;
4928    if offset < 0 || length <= 0 {
4929        return Errno::EINVAL;
4930    }
4931    if mode & !(MODE_MASK | KEEP_SIZE) != 0 {
4932        return Errno::EOPNOTSUPP;
4933    }
4934    match mode & MODE_MASK {
4935        0 | UNSHARE_RANGE | ZERO_RANGE => {}
4936        PUNCH_HOLE if mode & KEEP_SIZE == 0 => return Errno::EOPNOTSUPP,
4937        PUNCH_HOLE => {}
4938        COLLAPSE_RANGE | INSERT_RANGE | WRITE_ZEROES if mode & KEEP_SIZE != 0 => {
4939            return Errno::EOPNOTSUPP;
4940        }
4941        COLLAPSE_RANGE | INSERT_RANGE | WRITE_ZEROES => {}
4942        _ => return Errno::EOPNOTSUPP,
4943    }
4944    Errno::EBADF
4945}
