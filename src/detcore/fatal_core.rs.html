9//! Opt-in core files for guest threads killed by a core-dumping signal.
10//!
11//! The ptrace backend offers each thread of such a process at its exit stop
12//! ([`reverie::GlobalTool::on_fatal_signal_exit`]), after the kernel's fatal
13//! decision. The first thread of the process to be offered keeps one core for
14//! the whole process, if one of its threads ran the kernel's core dump step
15//! ([`Death::of`]); the threads offered after it keep nothing ([`Kept`]). A
16//! process the kernel would not dump, for example one that is not dumpable,
17//! gets no core. The core holds the registers of every thread the kernel's
18//! own dump would hold, the thread that took the signal first ([`gather`]).
19//! It is one ELF core, compressed as a sequence of zstd frames, in
20//! [`FatalCoreCapture::dir`]. The capture only reads the stopped guest,
21//! through procfs and ptrace register reads, so the guest observes nothing and
22//! its exit status is already fixed. Each thread's general registers are the
23//! ones the backend's tracer holds for it ([`install_register_reader`]), which
24//! can be newer than the kernel's copy.
25//!
26//! The thread's memory is normally still mapped at the exit stop, but nothing
27//! pins it: it can be reaped before or during the capture. A page that cannot
28//! be read, or reads short, is stored as zeros and the core is kept as a
29//! partial one; when `/proc/<tid>/mem` cannot be opened at all, the core holds
30//! only the notes and the mapping layout. Neither fails the capture.
31//!
32//! A core stores only what the kernel's own dump would (see [`dump_rule`]):
33//! nothing the guest marked `MADV_DONTDUMP`, nothing of an I/O or raw-PFN
34//! mapping, and only the kinds of mapping its `coredump_filter` selects, so
35//! shared file mappings are left out by default.
36//!
37//! Every core gets a name no other core has: the caller's
38//! [`FatalCoreCapture::file_prefix`] is unique to the invocation, and a
39//! repeated guest process ID within a run gets a numbered name.
40//!
41//! The capture is best effort and bounded. One core never exceeds
42//! `max_core_bytes`; the regular files in the directory never exceed
43//! `max_total_bytes` together, counted under a directory lock that every
44//! writer takes. It never runs past `time_limit`, nor past `exit.deadline`
45//! when the run has already failed and the backend must finish cleaning up.
46//! A core that would break either cap, or that takes too long, is retried
47//! with less memory: first only the live part of each thread's stack, then
48//! only the notes (registers, signal, process identity, auxiliary vector and
49//! mapped files) and the mapping layout. A core that cannot fit even then is
50//! not written. Once a Full core runs out of time, later captures in the same
51//! hermit process start at the Stack tier. The tracer waits for a capture only
52//! until its end, even when a read or write blocks in the kernel (see
53//! [`capture`]), and a capture deletes temporary files that dead writers left
54//! before it sizes the remaining total. Every failure is returned for the
55//! caller to log.

109/// Installs `read`, which gives a core the general registers of each of its
110/// threads but the offered one as the backend's tracer holds them. Returns
111/// false if one was installed already. Without one, a core holds the kernel's
112/// copy of those registers.
113///
114/// The two can differ. Reverie's ptrace backend keeps a register write it
115/// makes at a stop in its own cache, and hands it to the kernel only when the
116/// thread runs again or a request reads the kernel's copy. A thread that
117/// Detcore parks after Reverie ran a syscall for it on Reverie's private page
118/// keeps that syscall's registers in the kernel, with its instruction pointer
119/// in that page, while its own registers wait in the cache; a fatal signal
120/// takes it to its exit stop without the write. The offered thread's
121/// registers ([`FatalSignalExit::regs`]) already come from that cache. Read
122/// from the kernel, every other parked thread's would not, and which thread
123/// is offered first is decided by host timing, so two runs of one guest could
124/// keep different cores.
125///
126/// The crate that hosts Detcore on the ptrace backend calls this before the
127/// tracer starts.
128pub fn install_register_reader(read: RegisterReader) -> bool {
129    REGISTER_READER.set(read).is_ok()
130}

141/// How much memory a core holds. Every tier keeps only what the kernel's own
142/// dump would: see [`dump_rule`].
143#[derive(Clone, Copy, Debug, PartialEq, Eq)]
144pub(crate) enum Tier {
145    /// Every mapping the kernel would dump whole, and the first page of each
146    /// file mapped from offset 0 (its ELF header).
147    Full,
148    /// Of those, only the main stack and, of each mapping holding a thread's
149    /// stack pointer, the part from just below that pointer up (see
150    /// [`Snapshot::stored`]), plus the ELF header pages.
151    Stack,
152    /// No memory: notes and the mapping layout only.
153    NotesOnly,
154}

156/// Keeps a core for the death of `exit`'s process under `cfg`, if `exit`'s
157/// thread is the first of that death to be offered and one of the process's
158/// threads ran the kernel's core dump step, and reports the outcome on
159/// stderr. Never fails the run.
160///
161/// The first offer decides for the whole death, so a later offer neither
162/// writes a second core nor scans the process's threads again; the core is
163/// written while no thread of the process has left its exit stop.
164///
165/// The report goes to stderr, not to the tracing log, which a `--verify` run
166/// compares. Hermit's stderr can still be the guest's stderr, which `--verify`
167/// also compares, so the report names only the dumping thread and the file:
168/// the core's size and tier depend on host timing and memory pressure, and so
169/// does which thread is offered first, and they would make two identical runs
170/// differ.
171pub(crate) fn capture_and_log(cfg: &FatalCoreCapture, exit: &FatalSignalExit, kept: &Kept) {
172    let Some(process) = ProcessKey::of(exit.tid.as_raw()) else {
173        return;
174    };
175    if !kept.claim(process) {
176        return;
177    }
178    let Some(death) = Death::of(exit, process.tgid) else {
179        return;
180    };
181    let report = match capture(cfg, exit, &death) {
182        Ok(Outcome::Written { path }) => format!(
183            "kept as {}",
184            path.file_name().unwrap_or_default().to_string_lossy()
185        ),
186        Ok(Outcome::NoRoom { .. }) => {
187            "not kept: no core fits within its size and time limits".to_string()
188        }
189        Err(error) => format!("not kept: {error:#}"),
190    };
191    let line = format!(
192        "hermit: fatal core for thread {} ({}): {report}\n",
193        death.dumper, exit.signal
194    );
195    crate::nonwaiting_write::write_without_waiting(libc::STDERR_FILENO, line.as_bytes());
196}

198/// A guest process, named by its TGID and its leader's start time
199/// (`/proc/<tgid>/stat` field 22), which no later process that reuses the TGID
200/// shares. The leader stays readable, as a zombie if need be, until every
201/// other thread of the process has exited.
202#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
203pub(crate) struct ProcessKey {
204    tgid: i32,
205    started: u64,
206}
207
208impl ProcessKey {
209    /// The process of the thread `tid`.
210    fn of(tid: i32) -> Option<Self> {
211        let tgid = Process::new(tid).ok()?.status().ok()?.tgid;
212        let started = Process::new(tgid).ok()?.stat().ok()?.starttime;
213        Some(Self { tgid, started })
214    }
215}

217/// The processes whose death this run has already decided on, with or without
218/// a core.

232/// A process a core-dumping signal is ending, one of whose threads ran the
233/// kernel's core dump step.
234#[derive(Clone, Copy, Debug, PartialEq, Eq)]
235pub(crate) struct Death {
236    tgid: i32,
237    /// The thread that took the signal and ran the core dump step.
238    dumper: i32,
239}
240
241impl Death {
242    /// The death of `exit`'s process `tgid`, if one of its threads ran the
243    /// core dump step: `exit`'s own thread, or another one marked
244    /// `PF_DUMPCORE`.
245    ///
246    /// When `exit`'s thread is the first of its process to be offered, no
247    /// thread of the process has left its exit stop, so the dumping thread is
248    /// still there to be found: the kernel marks it in `zap_threads`
249    /// (fs/coredump.c) before any other thread dies. No thread is marked when
250    /// the kernel skipped the dump step, for a process that is not dumpable.
251    fn of(exit: &FatalSignalExit, tgid: i32) -> Option<Self> {
252        let dumper = if exit.dumping {
253            exit.tid.as_raw()
254        } else {
255            dumper_among(thread_ids(tgid), task_flags)?
256        };
257        Some(Self { tgid, dumper })
258    }
259}

261/// The first of `tids` whose kernel flags, as `flags_of` reads them, carry
262/// `PF_DUMPCORE`.
263fn dumper_among(
264    tids: impl IntoIterator<Item = i32>,
265    flags_of: impl Fn(i32) -> Option<u32>,
266) -> Option<i32> {
267    tids.into_iter()
268        .find(|&tid| flags_of(tid).is_some_and(|flags| flags & PF_DUMPCORE != 0))
269}

271/// Writes one core for `death`, from the thread `exit` names, held at its
272/// exit stop as the first of its process to be offered.
273///
274/// The threads' registers are read here, on the tracing thread, which alone
275/// may make ptrace requests of the guest ([`gather`]). The rest of the work
276/// runs on a helper thread that the tracer waits for only until the capture's
277/// end, plus [`HELPER_SLACK`]. The capture checks its end between frames, but
278/// one read of a file mapping on a hung network filesystem, or a write into a
279/// core directory on one, can block in the kernel past any check. The tracer
280/// then gives up, so the guest waits no longer, and the helper deletes what it
281/// was writing if it ever returns.
282pub(crate) fn capture(
283    cfg: &FatalCoreCapture,
284    exit: &FatalSignalExit,
285    death: &Death,
286) -> anyhow::Result<Outcome> {
287    let start = Instant::now();
288    let end = capture_end(start, cfg.time_limit, exit.deadline);
289    let threads = gather(
290        exit,
291        death,
292        start + end.saturating_duration_since(start) / 10,
293    )?;
294    let (cfg, exit, death) = (cfg.clone(), *exit, *death);
295    run_within(end + HELPER_SLACK, move |abandoned| {
296        // A memory that is already gone still leaves the notes worth keeping.
297        let mem = File::open(format!("/proc/{}/mem", exit.tid.as_raw())).ok();
298        let dying = Dying {
299            exit: &exit,
300            death: &death,
301            threads: &threads,
302            start,
303        };
304        capture_abandonable(&cfg, &dying, mem.as_ref(), &FULL_TIER_TIMED_OUT, abandoned)
305    })
306}

308/// How long past a capture's own end the tracer still waits for it. A healthy
309/// capture overruns its end by at most one frame: one read of up to 1 MiB and
310/// its compression.
311const HELPER_SLACK: Duration = Duration::from_millis(500);
312
313/// Runs `work` on a helper thread and returns its result if it arrives by
314/// `end`. Otherwise sets the flag `work` was given and returns an error: the
315/// helper is left to finish on its own and must not keep anything once the
316/// flag is set. A panic in `work` is an error too, not a tracer panic.
317///
318/// A helper that finishes in the instant between the timeout and the flag
319/// can still keep its core while the report says it was not kept.
320fn run_within(
321    end: Instant,
322    work: impl FnOnce(&AtomicBool) -> anyhow::Result<Outcome> + Send + 'static,
323) -> anyhow::Result<Outcome> {
324    let abandoned = Arc::new(AtomicBool::new(false));
325    let (send, receive) = std::sync::mpsc::sync_channel(1);
326    let flag = Arc::clone(&abandoned);
327    std::thread::Builder::new()
328        .name("fatal-core".to_string())
329        .spawn(move || {
330            let _ = send.send(work(&flag));
331        })
332        .map_err(|error| anyhow::anyhow!("cannot start the capture thread: {error}"))?;
333    match receive.recv_timeout(end.saturating_duration_since(Instant::now())) {
334        Ok(result) => result,
335        Err(RecvTimeoutError::Timeout) => {
336            abandoned.store(true, Ordering::SeqCst);
337            match receive.try_recv() {
338                Ok(result) => result,
339                Err(_) => anyhow::bail!("gave up: a read or write blocked past the time limit"),
340            }
341        }
342        Err(RecvTimeoutError::Disconnected) => anyhow::bail!("the capture thread panicked"),
343    }
344}

354    exit: &'a FatalSignalExit,

362/// [`capture`] of a test's own thread, which is the dumping thread of its
363/// death, with `mem`, or `None` when memory cannot be read at all, in which
364/// case only the notes and the mapping layout are kept. `full_timed_out` is
365/// [`FULL_TIER_TIMED_OUT`] outside tests. Tests call it directly; [`capture`]
366/// goes through [`capture_abandonable`].
367#[cfg(test)]
368fn capture_from(
369    cfg: &FatalCoreCapture,
370    exit: &FatalSignalExit,
371    mem: Option<&File>,
372    full_timed_out: &AtomicBool,
373) -> anyhow::Result<Outcome> {
374    let death = Death::of(exit, std::process::id() as i32).expect("not a dumping thread");
375    let threads = gather(exit, &death, Instant::now())?;
376    let dying = Dying {
377        exit,
378        death: &death,
379        threads: &threads,
380        start: Instant::now(),
381    };
382    capture_abandonable(cfg, &dying, mem, full_timed_out, &AtomicBool::new(false))
383}

385/// [`capture_from`] for a helper the tracer may give up on: once `abandoned`
386/// is set, a finished core is deleted instead of kept.
387fn capture_abandonable(
388    cfg: &FatalCoreCapture,
389    dying: &Dying<'_>,
390    mem: Option<&File>,
391    full_timed_out: &AtomicBool,
392    abandoned: &AtomicBool,
393) -> anyhow::Result<Outcome> {
394    let end = capture_end(dying.start, cfg.time_limit, dying.exit.deadline);
395    let snapshot = Snapshot::read(dying)?;
396    fs::create_dir_all(&cfg.dir)?;
397    let _lock = DirLock::acquire(&cfg.dir, end)?;
398    remove_orphaned_temps(&cfg.dir, cfg.time_limit * 2)?;
399    let used = regular_file_bytes(&cfg.dir)?;
400    let budget = cfg
401        .max_core_bytes
402        .min(cfg.max_total_bytes.saturating_sub(used));
403    let stem = format!(
404        "{}core.{}.{}.{}",
405        cfg.file_prefix,
406        dying.death.tgid,
407        dying.death.dumper,
408        dying.exit.signal.as_str()
409    );
410    let name = free_name(&cfg.dir, &stem)?;
411    let path = cfg.dir.join(&name);
412    let temp = cfg.dir.join(format!(".{name}.tmp"));
413    let written = try_tiers(
414        mem.is_some(),
415        full_timed_out,
416        dying.start,
417        end,
418        |tier, deadline| {
419            let segments = snapshot.segments(tier);
420            let result = write_core(&temp, budget, deadline, &snapshot, &segments, mem);
421            if result.is_err() {
422                let _ = fs::remove_file(&temp);
423            }
424            result
425        },
426    )?;
427    if written.is_some() {
428        if abandoned.load(Ordering::SeqCst) {
429            let _ = fs::remove_file(&temp);
430            anyhow::bail!("the tracer gave up on this capture");
431        }
432        fs::rename(&temp, &path)?;
433        return Ok(Outcome::Written { path });
434    }
435    Ok(Outcome::NoRoom { budget })
436}

438/// Try the existing capture tiers and remember only a Full deadline failure.
439/// The attempt owns writing and cleaning up its temporary file; returning the
440/// successful tier lets the unit fixture prove what it actually wrote.
441fn try_tiers(
442    has_memory: bool,
443    full_timed_out: &AtomicBool,
444    start: Instant,
445    end: Instant,
446    mut attempt: impl FnMut(Tier, Instant) -> Result<u64, WriteError>,
447) -> std::io::Result<Option<(Tier, u64)>> {
448    let span = end.saturating_duration_since(start);
449    let tiers: &[(Tier, u32)] = match has_memory {
450        true if !full_timed_out.load(Ordering::Relaxed) => {
451            &[(Tier::Full, 7), (Tier::Stack, 9), (Tier::NotesOnly, 10)]
452        }
453        true => &[(Tier::Stack, 9), (Tier::NotesOnly, 10)],
454        false => &[(Tier::NotesOnly, 10)],
455    };
456    for &(tier, tenths) in tiers {
457        let deadline = start + span * tenths / 10;
458        match attempt(tier, deadline) {
459            Ok(bytes) => return Ok(Some((tier, bytes))),
460            Err(error) => match error {
461                WriteError::Deadline if tier == Tier::Full => {
462                    full_timed_out.store(true, Ordering::Relaxed);
463                }
464                WriteError::OverBudget | WriteError::Deadline => {}
465                WriteError::Io(error) => return Err(error),
466            },
467        }
468    }
469    Ok(None)
470}

472/// When a capture started at `start` must be over: after `time_limit`, or at
473/// the backend's cleanup `deadline` if that comes first.
474fn capture_end(start: Instant, time_limit: Duration, deadline: Option<Instant>) -> Instant {
475    let limit = start + time_limit;
476    deadline.map_or(limit, |deadline| deadline.min(limit))
477}

479/// An exclusive `flock` on the core directory itself, held for the whole
480/// sizing and writing of one core, so two writers cannot both spend the same
481/// remaining total. Locking the directory leaves no lock file behind.
482struct DirLock {
483    _held: File,
484}
485
486impl DirLock {
487    fn acquire(dir: &Path, deadline: Instant) -> anyhow::Result<Self> {
488        let file = File::open(dir)?;
489        loop {
490            // SAFETY: flock on a descriptor this function owns.
491            if unsafe { libc::flock(file.as_raw_fd(), libc::LOCK_EX | libc::LOCK_NB) } == 0 {
492                return Ok(Self { _held: file });
493            }
494            let error = std::io::Error::last_os_error();
495            if error.raw_os_error() != Some(libc::EWOULDBLOCK) {
496                return Err(error.into());
497            }
498            if Instant::now() >= deadline {
499                anyhow::bail!("timed out waiting for the lock on {}", dir.display());
500            }
501            std::thread::sleep(Duration::from_millis(5));
502        }
503    }
504}

506/// `<stem>.zst`, or `<stem>.<n>.zst` for the first `n` that names no file yet,
507/// so a core never replaces another: a guest process ID can be reused within
508/// a run. Called under [`DirLock`], so two writers cannot pick the same name.
509fn free_name(dir: &Path, stem: &str) -> std::io::Result<String> {
510    let mut name = format!("{stem}.zst");
511    for n in 1u32.. {
512        if !dir.join(&name).try_exists()? {
513            break;
514        }
515        name = format!("{stem}.{n}.zst");
516    }
517    Ok(name)
518}

520/// Removes the temporary files of writers that died mid-core, so they stop
521/// counting against `max_total_bytes`. Every writer creates its temp only while
522/// it holds [`DirLock`], so one found while the caller holds the lock has no
523/// live writer on this host. Only hermit's own core temp names
524/// (`.hermit-*core.*.zst.tmp`) are touched, and only ones last written at
525/// least `min_age` ago, which also covers a writer on another host whose lock
526/// this host cannot see on some network filesystems. A temp that cannot be
527/// removed, such as another user's in a sticky directory, is skipped: it keeps
528/// counting, but it never stops this capture.
529fn remove_orphaned_temps(dir: &Path, min_age: Duration) -> std::io::Result<()> {
530    let now = SystemTime::now();
531    // Listed without the C library's heap (util::find_in_directory): this
532    // can run in the guest's process. As with std's read_dir, a directory
533    // that cannot be opened is the caller's error, and a listing error ends
534    // the cleanup without failing the capture.
535    drop(crate::util::RawFd::open(
536        dir,
537        libc::O_RDONLY | libc::O_DIRECTORY,
538    )?);
539    let _ = crate::util::find_in_directory(dir, |name| {
540        let text = name.to_string_lossy();
541        if !(text.starts_with(".hermit-") && text.contains("core.") && text.ends_with(".zst.tmp")) {
542            return None::<()>;
543        }
544        let path = dir.join(name);
545        let Ok(metadata) = fs::symlink_metadata(&path) else {
546            return None;
547        };
548        let old = metadata
549            .modified()
550            .ok()
551            .and_then(|modified| now.duration_since(modified).ok())
552            .is_some_and(|age| age >= min_age);
553        if metadata.is_file() && old {
554            let _ = fs::remove_file(&path);
555        }
556        None
557    });
558    Ok(())
559}

561/// Bytes held by the regular files directly in `dir`.
562fn regular_file_bytes(dir: &Path) -> std::io::Result<u64> {
563    let mut total = 0u64;
564    let failed =
565        crate::util::find_in_directory(dir, |name| match fs::symlink_metadata(dir.join(name)) {
566            Ok(metadata) => {
567                if metadata.file_type().is_file() {
568                    total = total.saturating_add(metadata.len());
569                }
570                None
571            }
572            Err(error) => Some(error),
573        })?;
574    match failed {
575        Some(error) => Err(error),
576        None => Ok(total),
577    }

580/// `PF_DUMPCORE` and `PF_SIGNALED` from include/linux/sched.h: the kernel
581/// marks the thread that ran the core dump step, and every thread a fatal

586/// One thread's part of a core: the fields of its `NT_PRSTATUS` that are its
587/// own, and the further register notes the kernel writes for it.
588struct ThreadNotes {
589    tid: i32,
590    regs: libc::user_regs_struct,
591    /// Its own pending signals (`SigPnd`, without the process's shared ones)
592    /// and its blocked ones, as `fill_prstatus` (fs/binfmt_elf.c) takes them.
593    sigpend: u64,
594    sighold: u64,
595    /// Its regset notes after `NT_PRSTATUS`, in the kernel's regset order.
596    regsets: Vec<RegsetNote>,
597}

599/// One note holding a regset as `PTRACE_GETREGSET` returns it.
600struct RegsetNote {
601    kind: u32,
602    name: &'static [u8],
603    desc: Vec<u8>,
604}

606/// The threads of `death` a core holds, each read at its exit stop, with
607/// the dumping thread first and the others by TID.
608///
609/// They are the threads the kernel's own dump holds: those that waited in
610/// `coredump_task_exit` (kernel/exit.c) during the dump, which are the ones
611/// marked `PF_SIGNALED`. `exit`'s thread, which the backend has already found
612/// to be one, is always among them. The kernel lists the dumping thread first
613/// and the others in the order they reached that wait (`fill_note_info`,
614/// fs/binfmt_elf.c), which host timing decides; ordering them by TID instead
615/// makes the list a function of the guest's schedule.
616///
617/// Runs on the tracing thread, whose ptrace requests the guest's threads
618/// answer. The dumping thread wakes the others from that wait
619/// (`coredump_finish`, fs/coredump.c) and goes on to exit, so each of them
620/// reaches its exit stop without the tracer, and none leaves it while the
621/// tracer is held here: their registers are read there. Their general
622/// registers come from the same source as the offered thread's, the backend's
623/// tracer ([`install_register_reader`]), so the core does not depend on which
624/// thread was offered. Another thread not held by `deadline` is left out, and
625/// so is a regset ptrace refuses, as the kernel leaves out an inactive one. A
626/// dumping thread not held by then fails the capture: without it the core
627/// would name another thread as the one that took the signal.
628fn gather(
629    exit: &FatalSignalExit,
630    death: &Death,
631    deadline: Instant,
632) -> anyhow::Result<Vec<ThreadNotes>> {
633    let read = REGISTER_READER.get().copied();
634    let offered = exit.tid.as_raw();
635    let mut tids: Vec<i32> = thread_ids(death.tgid)
636        .into_iter()
637        .filter(|&tid| {
638            tid != offered && task_flags(tid).is_some_and(|flags| flags & PF_SIGNALED != 0)
639        })
640        .collect();
641    tids.push(offered);
642    let threads: Vec<ThreadNotes> = in_core_order(tids, death.dumper)
643        .into_iter()
644        .filter_map(|tid| {
645            let regs = if tid == offered {
646                exit.regs
647            } else {
648                regs_at_exit_stop(tid, deadline, read)?
649            };
650            let status = Process::new(tid).and_then(|thread| thread.status()).ok();
651            Some(ThreadNotes {
652                tid,
653                regs,
654                sigpend: status.as_ref().map_or(0, |status| status.sigpnd),
655                sighold: status.as_ref().map_or(0, |status| status.sigblk),
656                regsets: arch::REGSETS
657                    .iter()
658                    .filter_map(|&(kind, name)| {
659                        let desc = getregset(tid, kind).ok()?;
660                        Some(RegsetNote { kind, name, desc })
661                    })
662                    .collect(),
663            })
664        })
665        .collect();
666    if threads.first().map(|thread| thread.tid) != Some(death.dumper) {
667        anyhow::bail!(
668            "the dumping thread {} was not held at its exit stop",
669            death.dumper
670        );
671    }
672    Ok(threads)
673}

677    tids.sort_by_key(|&tid| (tid != dumper, tid));
678    tids

696/// `tid`'s general registers once it is held at its exit stop, as
697/// [`tracer_view`] gives them, or `None` when it is gone or still not held at
698/// `deadline`. Until it stops, a ptrace request of it fails, as of any thread
699/// that is not stopped, so a read of the kernel's copy tells when it is held.
700fn regs_at_exit_stop(
701    tid: i32,
702    deadline: Instant,
703    read: Option<RegisterReader>,
704) -> Option<libc::user_regs_struct> {
705    loop {
706        if let Ok(kernel) = general_regs(tid) {
707            return Some(tracer_view(tid, kernel, read));
708        }
709        let gone = Process::new(tid)
710            .and_then(|thread| thread.stat())
711            .map_or(true, |stat| matches!(stat.state, 'Z' | 'X'));
712        if gone || Instant::now() >= deadline {
713            return None;
714        }
715        std::thread::sleep(Duration::from_micros(100));
716    }
717}

719/// The general registers of `tid`, held at a ptrace stop, as `read` (see
720/// [`install_register_reader`]) gives them, or `kernel`, the kernel's copy,
721/// when there is no `read` or it cannot read them.
722fn tracer_view(
723    tid: i32,
724    kernel: libc::user_regs_struct,
725    read: Option<RegisterReader>,
726) -> libc::user_regs_struct {
727    read.and_then(|read| read(tid)).unwrap_or(kernel)
728}

730/// Bytes [`getregset`] offers the kernel: more than any x86-64 regset needs,
731/// the largest being the XSAVE area, under 12 KiB even with AMX tile data.
732const REGSET_BUFFER: usize = 32 << 10;
733
734/// The regset `kind` of `tid`, a thread this thread traces and holds at a
735/// ptrace stop, as `PTRACE_GETREGSET` returns it.
736fn getregset(tid: i32, kind: u32) -> std::io::Result<Vec<u8>> {
737    let mut bytes = vec![0u8; REGSET_BUFFER];
738    let len = getregset_into(tid, kind, &mut bytes)?;
739    bytes.truncate(len);
740    Ok(bytes)
741}
742
743/// `tid`'s general registers, the regset `NT_PRSTATUS` stores.
744fn general_regs(tid: i32) -> std::io::Result<libc::user_regs_struct> {
745    let mut bytes = [0u8; std::mem::size_of::<libc::user_regs_struct>()];
746    if getregset_into(tid, NT_PRSTATUS, &mut bytes)? != bytes.len() {
747        return Err(std::io::ErrorKind::InvalidData.into());
748    }
749    // SAFETY: user_regs_struct is plain old data of exactly these bytes.
750    Ok(unsafe { std::ptr::read_unaligned(bytes.as_ptr().cast()) })
751}
752
753/// `PTRACE_GETREGSET` of `kind` into `buf`; returns the bytes written.
754fn getregset_into(tid: i32, kind: u32, buf: &mut [u8]) -> std::io::Result<usize> {
755    let mut iov = libc::iovec {
756        iov_base: buf.as_mut_ptr().cast(),
757        iov_len: buf.len(),
758    };
759    // SAFETY: the kernel writes at most `iov_len` bytes to `buf`, which is
760    // writable for that long, and stores how many it wrote in `iov_len`.
761    let result = unsafe {
762        libc::ptrace(
763            libc::PTRACE_GETREGSET,
764            tid,
765            kind as usize as *mut libc::c_void,
766            &mut iov as *mut libc::iovec,
767        )
768    };
769    if result == -1 {
770        return Err(std::io::Error::last_os_error());
771    }
772    Ok(iov.iov_len)
773}

775/// Everything a core needs except memory contents, read before writing.
776struct Snapshot {
777    /// Every thread's stack pointer, for [`Tier::Stack`].
778    stack_pointers: Vec<u64>,
779    notes: Vec<u8>,
780    maps: Vec<MemoryMap>,
781    /// What may be stored of each of `maps`, by [`dump_rule`].
782    rules: Vec<Dump>,
783}
784
785impl Snapshot {
786    /// Reads the process through `dying.exit`'s thread, held at its exit stop.
787    /// The other threads of the process may still be on their way to theirs,
788    /// but they share its memory and mappings.
789    fn read(dying: &Dying<'_>) -> anyhow::Result<Self> {
790        let tid = dying.exit.tid.as_raw();
791        let process = Process::new(tid)?;
792        // smaps carries the kernel's VmFlags, which say what a dump must skip;
793        // without them, keep the layout and store no memory at all.
794        let (maps, flags_known) = match process.smaps() {
795            Ok(maps) => (maps.0, true),
796            Err(_) => (process.maps()?.0, false),
797        };
798        let filter = coredump_filter(tid);
799        let rules = maps
800            .iter()
801            .map(|map| {
802                let flags = map.extension.vm_flags;
803                dump_rule(
804                    map,
805                    (flags_known && !flags.is_empty()).then_some(flags),
806                    filter,
807                )
808            })
809            .collect();
810        let cmdline = process.cmdline().unwrap_or_default().join(" ");
811        let auxv = fs::read(format!("/proc/{tid}/auxv")).ok();
812        let identity = Identity::read(dying.death, cmdline)?;
813        let mut notes = Vec::new();
814        for (index, thread) in dying.threads.iter().enumerate() {
815            note(
816                &mut notes,
817                CORE,
818                NT_PRSTATUS,
819                &arch::prstatus(dying.exit.signal as i32, &identity, thread),
820            );
821            // The process-wide notes follow the first thread's NT_PRSTATUS
822            // (`write_note_info`, fs/binfmt_elf.c).
823            if index == 0 {
824                note(&mut notes, CORE, NT_PRPSINFO, &prpsinfo(&identity));
825                if let Some(auxv) = &auxv {
826                    note(&mut notes, CORE, NT_AUXV, auxv);
827                }
828                note(&mut notes, CORE, NT_FILE, &nt_file(&maps));
829            }
830            for regset in &thread.regsets {
831                note(&mut notes, regset.name, regset.kind, &regset.desc);
832            }
833        }
834        Ok(Self {
835            stack_pointers: dying
836                .threads
837                .iter()
838                .map(|thread| arch::stack_pointer(&thread.regs))
839                .collect(),
840            notes,
841            maps,
842            rules,
843        })
844    }
845
846    /// One `PT_LOAD` per mapping, holding the bytes [`Snapshot::stored`]
847    /// keeps from its start, and a second, unstored one before it for the
848    /// bottom of a mapping kept only from part way up.
849    fn segments(&self, tier: Tier) -> Vec<Segment> {
850        let mut segments = Vec::new();
851        for (map, rule) in self.maps.iter().zip(&self.rules) {
852            if !dumpable(map) {
853                continue;
854            }
855            let (start, end) = map.address;
856            let stored = self.stored(map, *rule, tier);
857            let flags = segment_flags(map.perms);
858            if stored.start > start {
859                segments.push(Segment {
860                    vaddr: start,
861                    memsz: stored.start - start,
862                    filesz: 0,
863                    flags,
864                });
865            }
866            segments.push(Segment {
867                vaddr: stored.start,
868                memsz: end - stored.start,
869                filesz: stored.end - stored.start,
870                flags,
871            });
872        }
873        segments
874    }
875
876    /// The bytes of `map` that `tier` stores. The Stack tier keeps the main
877    /// stack whole, and a mapping that holds a thread's stack pointer from
878    /// just below that pointer (its red zone included, rounded down to a page)
879    /// to its top: the part that holds the thread's frames.
880    fn stored(&self, map: &MemoryMap, rule: Dump, tier: Tier) -> Range<u64> {
881        let (start, end) = map.address;
882        let from = match tier {
883            _ if !rule.whole => None,
884            Tier::Full => Some(start),
885            Tier::Stack if matches!(map.pathname, MMapPath::Stack) => Some(start),
886            Tier::Stack => self
887                .stack_pointers
888                .iter()
889                .filter(|sp| (start..end).contains(*sp))
890                .min()
891                .map(|sp| (sp.saturating_sub(RED_ZONE) / core_page() * core_page()).max(start)),
892            Tier::NotesOnly => None,
893        };
894        match from {
895            Some(from) => from..end,
896            None if tier != Tier::NotesOnly && rule.elf_header => {
897                start..start + (end - start).min(core_page())
898            }
899            None => start..start,
900        }
901    }
902}

904/// What a core may store of one mapping.
905#[derive(Clone, Copy, Debug, PartialEq, Eq)]
906struct Dump {
907    /// All of it.
908    whole: bool,
909    /// Its first page, the ELF header of a file mapped from offset 0.
910    elf_header: bool,
911}
912
913/// What the kernel's own dump (`vma_dump_size` in fs/coredump.c) would keep of
914/// `map`, given its VmFlags (`None` when unknown, which keeps nothing) and the
915/// process's `coredump_filter`:
916///
917/// - nothing of a mapping the guest excluded with `MADV_DONTDUMP` (`dd`), or
918///   of an I/O or raw-PFN mapping (`io`, `pf`), whose read could touch a
919///   device;
920/// - hugetlb and shared mappings only if the filter bit for their kind is set
921///   (shared file mappings are off by default);
922/// - anonymous memory, and a private file mapping that is writable or holds
923///   pages the guest wrote, under the anonymous-private bit. The kernel keeps
924///   a private mapping whole once it has an `anon_vma`, which its first
925///   written page creates; smaps shows written pages as anonymous (see
926///   [`holds_anonymous_pages`]). That covers a table the dynamic linker
927///   relocated and then made read-only, such as the executable's `.dynamic`,
928///   through which a debugger finds the loaded libraries. Any other private
929///   file mapping is kept under the file-private bit (off by default);
930/// - the first page of a file mapped from offset 0 under the ELF-headers bit.
931fn dump_rule(map: &MemoryMap, flags: Option<VmFlags>, filter: CoredumpFlags) -> Dump {
932    const NOTHING: Dump = Dump {
933        whole: false,
934        elf_header: false,
935    };
936    let Some(flags) = flags else {
937        return NOTHING;
938    };
939    if flags.intersects(VmFlags::DD | VmFlags::IO | VmFlags::PF) {
940        return NOTHING;
941    }
942    let file = matches!(map.pathname, MMapPath::Path(_));
943    let shared = flags.contains(VmFlags::SH);
944    let whole = if flags.contains(VmFlags::HT) {
945        filter.contains(if shared {
946            CoredumpFlags::SHARED_HUGEPAGES
947        } else {
948            CoredumpFlags::PROVATE_HUGEPAGES
949        })
950    } else if shared {
951        filter.contains(if file {
952            CoredumpFlags::FILEBACKED_SHARED_MAPPINGS
953        } else {
954            CoredumpFlags::ANONYMOUS_SHARED_MAPPINGS
955        })
956    } else if !file || map.perms.contains(MMPermissions::WRITE) || holds_anonymous_pages(map) {
957        filter.contains(CoredumpFlags::ANONYMOUS_PRIVATE_MAPPINGS)
958            || (file && filter.contains(CoredumpFlags::FILEBACKED_PRIVATE_MAPPINGS))
959    } else {
960        filter.contains(CoredumpFlags::FILEBACKED_PRIVATE_MAPPINGS)
961    };
962    Dump {
963        whole,
964        elf_header: file && map.offset == 0 && filter.contains(CoredumpFlags::ELF_HEADERS),
965    }
966}

968/// Whether smaps counts anonymous pages in `map`: pages the guest wrote to a
969/// private file mapping. Such a page means the mapping has an `anon_vma`, but
970/// not the other way round: a mapping keeps its `anon_vma` after
971/// `MADV_DONTNEED` drops its pages, and shares it when `mprotect` splits it,
972/// so this misses a written mapping that holds no written page now.
973fn holds_anonymous_pages(map: &MemoryMap) -> bool {
974    map.extension
975        .map
976        .get("Anonymous")
977        .is_some_and(|&bytes| bytes > 0)
978}

980/// The thread's `/proc/<tid>/coredump_filter`, or the kernel default (0x33:
981/// anonymous private and shared, ELF headers, private hugetlb) when it cannot
982/// be read. Unknown bits are ignored.
983fn coredump_filter(tid: i32) -> CoredumpFlags {
984    fs::read_to_string(format!("/proc/{tid}/coredump_filter"))
985        .ok()
986        .and_then(|text| u32::from_str_radix(text.trim(), 16).ok())
987        .map_or(
988            CoredumpFlags::from_bits_truncate(0x33),
989            CoredumpFlags::from_bits_truncate,
990        )
991}

1081/// `pr_state` and `pr_sname` of the leader as the kernel's dump records them
1082/// (`fill_psinfo`, fs/binfmt_elf.c): 0 (`R`) when the leader runs the dump,
1083/// 2 (`D`) when it waits in `coredump_task_exit` (`TASK_IDLE`), and 8 (`.`,
1084/// `TASK_DEAD`) when it exited before the signal. Taken from the leader's
1085/// part in the dump rather than its state now, which is its exit stop's once
1086/// it gets there, so it does not depend on when the capture looks.
1087fn leader_state(death: &Death, leader_flags: u32) -> (u8, u8) {
1088    if death.dumper == death.tgid {
1089        (0, b'R')
1090    } else if leader_flags & PF_SIGNALED != 0 {
1091        (2, b'D')
1092    } else {
1093        (8, b'.')
1094    }
1095}

1097fn note(out: &mut Vec<u8>, name: &[u8], kind: u32, desc: &[u8]) {
1098    out.extend_from_slice(&(name.len() as u32).to_le_bytes());
1099    out.extend_from_slice(&(desc.len() as u32).to_le_bytes());
1100    out.extend_from_slice(&kind.to_le_bytes());
1101    out.extend_from_slice(name);
1102    pad4(out);
1103    out.extend_from_slice(desc);
1104    pad4(out);
1105}

1107fn pad4(out: &mut Vec<u8>) {
1108    out.resize(out.len().next_multiple_of(4), 0);
1109}

1115/// `struct elf_prpsinfo` for a 64-bit process (136 bytes). Its `pr_zomb`
1116/// stays 0: the kernel sets it only for a `pr_sname` of `Z`, which
1117/// [`leader_state`] never gives.
1118fn prpsinfo(id: &Identity) -> Vec<u8> {
1119    let mut out = vec![0u8; 136];
1120    (out[0], out[1]) = id.state;
1121    out[3] = id.nice as i8 as u8;
1122    put(&mut out, 8, &u64::from(id.flags).to_le_bytes());
1123    put(&mut out, 16, &id.uid.to_le_bytes());
1124    put(&mut out, 20, &id.gid.to_le_bytes());
1125    put(&mut out, 24, &id.tgid.to_le_bytes());
1126    put(&mut out, 28, &id.ppid.to_le_bytes());
1127    put(&mut out, 32, &id.pgrp.to_le_bytes());
1128    put(&mut out, 36, &id.sid.to_le_bytes());
1129    let comm = id.comm.as_bytes();
1130    put(&mut out, 40, &comm[..comm.len().min(15)]);
1131    let args = id.cmdline.as_bytes();
1132    put(&mut out, 56, &args[..args.len().min(79)]);
1133    out
1134}

1136/// `NT_FILE`: the file-backed mappings, so a debugger can find the files.
1137fn nt_file(maps: &[MemoryMap]) -> Vec<u8> {
1138    let files: Vec<(&MemoryMap, &Path)> = maps
1139        .iter()
1140        .filter_map(|map| match &map.pathname {
1141            MMapPath::Path(path) => Some((map, path.as_path())),

1296/// Compresses what is pushed into zstd frames of [`CHUNK`] bytes and appends
1297/// them to a file, refusing any frame that would pass `budget` or start after
1298/// `deadline`.
1299struct Compressed {
1300    file: File,
1301    buf: Vec<u8>,
1302    written: u64,
1303    budget: u64,
1304    deadline: Instant,
1305}
1306
1307impl Compressed {
1308    fn push(&mut self, mut data: &[u8]) -> Result<(), WriteError> {
1309        while !data.is_empty() {
1310            let take = data.len().min(CHUNK - self.buf.len());
1311            self.buf.extend_from_slice(&data[..take]);
1312            data = &data[take..];
1313            if self.buf.len() == CHUNK {
1314                self.flush()?;
1315            }
1316        }
1317        Ok(())
1318    }
1319
1320    fn push_zeros(&mut self, mut len: u64) -> Result<(), WriteError> {
1321        while len > 0 {
1322            let take = len.min(CHUNK as u64) as usize;
1323            self.push(&ZEROS[..take])?;
1324            len -= take as u64;
1325        }
1326        Ok(())
1327    }
1328
1329    fn flush(&mut self) -> Result<(), WriteError> {
1330        if self.buf.is_empty() {
1331            return Ok(());
1332        }
1333        if Instant::now() >= self.deadline {
1334            return Err(WriteError::Deadline);
1335        }
1336        let frame = ruzstd::encoding::compress_to_vec(&self.buf[..], CompressionLevel::Fastest);
1337        self.buf.clear();
1338        if self.written + frame.len() as u64 > self.budget {
1339            return Err(WriteError::OverBudget);
1340        }
1341        self.file.write_all(&frame)?;
1342        self.written += frame.len() as u64;
1343        Ok(())
1344    }
1345}

1347/// The ELF header and program headers for `segments`, with their stored
1348/// bytes laid out page-aligned after `notes_len` bytes of notes.
1349fn headers(notes_len: u64, segments: &[Segment]) -> (Vec<u8>, u64) {
1350    let phnum = 1 + segments.len() as u64;
1351    let notes_offset = EHDR_SIZE + PHDR_SIZE * phnum;
1352    let data_offset = (notes_offset + notes_len).next_multiple_of(core_page());
1353    let mut out = Vec::with_capacity(notes_offset as usize);
1354    out.extend_from_slice(b"\x7fELF\x02\x01\x01");
1355    out.resize(16, 0);
1356    out.extend_from_slice(&4u16.to_le_bytes()); // e_type: ET_CORE
1357    out.extend_from_slice(&arch::MACHINE.to_le_bytes());
1358    out.extend_from_slice(&1u32.to_le_bytes()); // e_version
1359    out.extend_from_slice(&0u64.to_le_bytes()); // e_entry
1360    out.extend_from_slice(&EHDR_SIZE.to_le_bytes()); // e_phoff
1361    out.extend_from_slice(&0u64.to_le_bytes()); // e_shoff
1362    out.extend_from_slice(&0u32.to_le_bytes()); // e_flags
1363    out.extend_from_slice(&(EHDR_SIZE as u16).to_le_bytes());
1364    out.extend_from_slice(&(PHDR_SIZE as u16).to_le_bytes());
1365    out.extend_from_slice(&(phnum as u16).to_le_bytes());
1366    out.extend_from_slice(&[0; 6]); // e_shentsize, e_shnum, e_shstrndx
1367    let mut phdr =
1368        |kind: u32, flags: u32, offset: u64, vaddr: u64, filesz: u64, memsz: u64, align: u64| {
1369            out.extend_from_slice(&kind.to_le_bytes());
1370            out.extend_from_slice(&flags.to_le_bytes());
1371            out.extend_from_slice(&offset.to_le_bytes());
1372            out.extend_from_slice(&vaddr.to_le_bytes());
1373            out.extend_from_slice(&0u64.to_le_bytes()); // p_paddr
1374            out.extend_from_slice(&filesz.to_le_bytes());
1375            out.extend_from_slice(&memsz.to_le_bytes());
1376            out.extend_from_slice(&align.to_le_bytes());
1377        };
1378    phdr(PT_NOTE, 0, notes_offset, 0, notes_len, 0, 4);
1379    let mut offset = data_offset;
1380    for segment in segments {
1381        phdr(
1382            PT_LOAD,
1383            segment.flags,
1384            offset,
1385            segment.vaddr,
1386            segment.filesz,
1387            segment.memsz,
1388            core_page(),
1389        );
1390        offset += segment.filesz.next_multiple_of(core_page());
1391    }
1392    (out, data_offset)
1393}

1395fn write_core(
1396    temp: &Path,
1397    budget: u64,
1398    deadline: Instant,
1399    snapshot: &Snapshot,
1400    segments: &[Segment],
1401    mem: Option<&File>,
1402) -> Result<u64, WriteError> {
1403    let _ = fs::remove_file(temp);
1404    let file = fs::OpenOptions::new()
1405        .write(true)
1406        .create_new(true)
1407        .mode(0o600)
1408        .open(temp)?;
1409    let mut out = Compressed {
1410        file,
1411        buf: Vec::with_capacity(CHUNK),
1412        written: 0,
1413        budget,
1414        deadline,
1415    };
1416    let (headers, data_offset) = headers(snapshot.notes.len() as u64, segments);
1417    out.push(&headers)?;
1418    out.push(&snapshot.notes)?;
1419    out.push_zeros(data_offset - headers.len() as u64 - snapshot.notes.len() as u64)?;
1420    let mut page = vec![0u8; CHUNK];
1421    for segment in segments {
1422        match mem {
1423            Some(mem) => copy_memory(&mut out, mem, segment.vaddr, segment.filesz, &mut page)?,
1424            None => out.push_zeros(segment.filesz)?,
1425        }
1426        out.push_zeros(segment.filesz.next_multiple_of(core_page()) - segment.filesz)?;
1427    }
1428    out.flush()?;
1429    Ok(out.written)
1430}

1432/// Pushes `len` bytes of guest memory from `addr`; a page procfs cannot read
1433/// is stored as zeros.
1434fn copy_memory(
1435    out: &mut Compressed,
1436    mem: &File,
1437    mut addr: u64,
1438    len: u64,
1439    buf: &mut [u8],
1440) -> Result<(), WriteError> {
1441    let end = addr + len;
1442    while addr < end {
1443        let want = (end - addr).min(buf.len() as u64) as usize;
1444        match read_fully(mem, &mut buf[..want], addr) {
1445            Ok(()) => out.push(&buf[..want])?,
1446            Err(_) => {
1447                for page in buf[..want].chunks_mut(core_page() as usize) {
1448                    let page_addr = addr;
1449                    addr += page.len() as u64;
1450                    if read_fully(mem, page, page_addr).is_err() {
1451                        page.fill(0);
1452                    }
1453                }
1454                out.push(&buf[..want])?;
1455                continue;
1456            }
1457        }
1458        addr += want as u64;
1459    }
1460    Ok(())
1461}
1462
1463fn read_fully(mem: &File, buf: &mut [u8], addr: u64) -> std::io::Result<()> {
1464    let mut done = 0;
1465    while done < buf.len() {
1466        match mem.read_at(&mut buf[done..], addr + done as u64)? {
1467            0 => return Err(std::io::ErrorKind::UnexpectedEof.into()),
1468            n => done += n,
1469        }
1470    }
1471    Ok(())
1472}

1996    fn parse_notes(mut notes: &[u8]) -> Vec<(Vec<u8>, u32, Vec<u8>)> {
1997        let mut parsed = Vec::new();
1998        let u32_at = |bytes: &[u8], at: usize| {
1999            u32::from_le_bytes(bytes[at..at + 4].try_into().unwrap()) as usize

2002            let (namesz, descsz) = (u32_at(notes, 0), u32_at(notes, 4));

2006                notes[12..12 + namesz].to_vec(),

2008                notes[desc..desc + descsz].to_vec(),

2010            notes = &notes[desc + descsz.next_multiple_of(4)..];
2011        }
2012        parsed
