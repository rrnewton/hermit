8//! The thread of a multi-threaded process that takes a process-directed
9//! signal a guest sends (<https://github.com/rrnewton/hermit/issues/4034>).
10//!
11//! Linux queues such a signal on the process's shared queue
12//! (`__send_signal_locked`) and then `complete_signal` picks the thread it
13//! wakes to take it (kernel/signal.c:963-997 at v6.16):
14//!
15//! 1. the task the call names, `p` (the leader for a process id, the named
16//!    thread for one of its thread ids), if it `wants_signal`;
17//! 2. otherwise the first thread that does, walking the thread list from the
18//!    process's `signal->curr_target`, which then becomes that thread;
19//! 3. when no thread does, none: the signal waits in the shared queue, and the
20//!    first thread that unblocks it, or that finishes the signals it already
21//!    has pending, takes it.
22//!
23//! `wants_signal` (signal.c:946-961) asks that the thread not block the
24//! signal, not be exiting (`PF_EXITING`) and not be stopped or traced, and
25//! that it be running (`task_curr`) or have no signal pending
26//! (`task_sigpending`).
27//!
28//! Under ptrace every thread the scheduler holds is traced, so the kernel's
29//! own choice degenerates: `wants_signal` passes over every stopped thread,
30//! and the signal waits in the shared queue for whichever thread resumes
31//! first and does not block it (`ptrace_stop` ends with
32//! `recalc_sigpending_tsk`, signal.c:2491-2496). So Detcore makes the choice, by
33//! the same rule over its own model, and then keeps the call itself: it
34//! forwards the guest's `kill`, `rt_sigqueueinfo` or `pidfd_send_signal`
35//! unchanged, so the copy is the kernel's own, in the shared queue, with
36//! Linux's siginfo, coalescing, retargeting and visibility; and it resumes
37//! the chosen thread before any other that could take it, until it does
38//! (`process_signal_takers`, `Scheduler::first_process_signal_taker`).
39//!
40//! The model, in which the guest's threads share one CPU and only the sender
41//! runs:
42//!
43//! - The thread list is thread-ID order. `copy_process` appends each new
44//!   thread at the list's tail (kernel/fork.c:2396-2397), and in a PID
45//!   namespace `alloc_pid` hands out ids cyclically upward
46//!   (`idr_alloc_cyclic`, kernel/pid.c:237), so a later thread has the higher
47//!   id until the ids wrap.
48//! - `curr_target` starts at the leader (kernel/fork.c:1662) and moves to each
49//!   thread step 2 chooses. Linux moves it on when that thread exits
50//!   (`__exit_signal`, kernel/exit.c:187-188); here the walk starts at the
51//!   first live thread at or after it, which is the same thread unless a
52//!   thread was created after the last thread in the list exited.
53//! - A thread is exiting once its exit is granted, it was killed at a turn, or
54//!   its exit waits for a delivery permit.
55//! - `task_curr` holds for the sender alone, and SIGKILL is wanted whatever is
56//!   pending (signal.c:954-955). A thread "has a signal pending" when its own
57//!   queue holds a signal it does not block, other than one a host-timed
58//!   source may have posted (`Scheduler::host_timed_signals`) or Reverie's
59//!   preemption marker. A copy in the shared queue does not count: Linux sets
60//!   `TIF_SIGPENDING` for it only on the thread it woke.
61//!
62//! Every input is the schedule's: the scheduler's committed records, and the
63//! `/proc` masks and private queues of threads stopped at a request or
64//! parked, which change only when they run, while the sender holds the turn.
65//!
66//! Two cases keep the fail-closed refusal they had before this choice existed
67//! (<https://github.com/rrnewton/hermit/issues/4034>), because the forwarded
68//! copy would not reach the chosen thread:
69//!
70//! - a thread sleeping outside the schedule (external I/O, a real
71//!   `rt_sigsuspend`) is not traced, so the kernel can wake it for the signal
72//!   at a moment host timing sets, whatever Detcore chose
73//!   (`ProcessSignalReceiver::OutOfSchedule`);
74//! - a thread that can take the copy outside its turn, whatever its own mask
75//!   says: its filed call installs a temporary mask that admits the signal
76//!   (`rt_sigsuspend`, `ppoll`, `pselect6`, `epoll_pwait`), a signalfd of the
77//!   process covers it, or a thread waits for it in `rt_sigtimedwait`
78//!   (`ProcessSignalReceiver::TakenOutOfTurn`);
79//! - a send to the sender's own process that Linux gives to another thread:
80//!   the sender is running, so `task_curr` makes it the one thread
81//!   `wants_signal` admits, and it takes the copy at its return to user mode
82//!   before any other thread runs (`ProcessSignalReceiver::SenderTakesIt`).
83//!   The sends Linux gives to the sender itself are forwarded, here and by
84//!   the earlier admission that holds the sender's turn
85//!   (`Detcore::own_process_signal`).
86//!
87//! A signal whose default action ends the process is exempt from all three:
88//! Linux ends the whole group with the same status whichever thread takes it
89//! (`get_signal` calls `do_group_exit(signr)`, signal.c:3034), and no thread
90//! runs further user code, so nothing the refusals protect is left to decide.
91//! A guest's own abort or fault (`raise(SIGABRT)` after a handler resets the
92//! disposition, a watchdog's `pidfd_send_signal(self, SIGSEGV)`) takes this
93//! path. Which thread carries the death out, and so how far a thread
94//! sleeping outside the schedule gets first, is the kernel's; the status and
95//! the death itself are not.
96//!
97//! A standard signal the shared queue already holds is queued no second time
98//! (`legacy_queue`, signal.c:1037-1040), so such a send reaches no
99//! `complete_signal`: it chooses nothing, marks nothing, and moves
100//! `curr_target` no further.
101//!
102//! Linux's group-exit shortcut at the send (signal.c:1003-1025) needs a
103//! thread that wants the signal, which no ptrace-stopped thread does, so for
104//! a fatal signal it is the receiver's delivery that ends the group, one turn
105//! later than native; the exit status is the same.

121/// Which thread takes a process-directed signal
122/// (`Scheduler::process_signal_receiver`).
123#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
124pub enum ProcessSignalReceiver {
125    /// The thread `complete_signal` gives the signal, which the scheduler
126    /// resumes first until it takes the forwarded copy
127    /// (`Scheduler::first_process_signal_taker`). `sole`: every other live
128    /// thread blocks the signal or is exiting, so no other thread can take
129    /// the copy before it anyway, and nothing is marked.
130    Thread { thread: DetTid, sole: bool },
131    /// No thread wants it: it waits in the process's shared queue.
132    SharedQueue,
133    /// This thread sleeps outside the schedule and does not block the
134    /// signal, so the kernel can wake it for the copy at a host-timed moment.
135    OutOfSchedule(DetTid),
136    /// This thread can take the copy from the shared queue outside its turn,
137    /// whatever its own mask says: its filed call installs a temporary mask
138    /// that admits the signal, or it reads a signalfd that covers it, or a
139    /// sibling waits for it in `rt_sigtimedwait`.
140    TakenOutOfTurn(DetTid),
141    /// The sender's own process, with the sender not blocking the signal and
142    /// another thread the receiver: the sender is the one thread Linux's
143    /// `wants_signal` admits (it is `task_curr`, and every other thread is
144    /// ptrace-stopped), so it takes the forwarded copy at its return to user
145    /// mode, before the receiver can run.
146    SenderTakesIt,
147    /// The choice depends on this thread, whose signal mask is unknown.
148    UnknownMask(DetTid),
149    /// The process's shared queue already holds the signal, so Linux queues
150    /// no second copy and chooses no thread (`legacy_queue`).
151    AlreadyQueued,
152    /// An exec is in flight in the process; its `de_thread` decides which
153    /// threads remain.
154    ExecInFlight,
155    /// This scheduler does not model signal targets (only ptrace does).
156    NotModeled,
157    /// A schedule replay chose `receiver`, as its recording did, but the
158    /// recorded schedule next runs `first`, another thread of the process
159    /// that could take the copy before it: the replay has left its recording.
160    ScheduleRunsFirst { receiver: DetTid, first: DetTid },
161}
162
163/// Whether one thread `wants_signal`, in the model above.
164#[derive(Clone, Copy, Debug, PartialEq, Eq)]
165pub(crate) enum Wants {
166    Yes,
167    /// It blocks the signal, or is exiting.
168    No,
169    /// It leaves the signal unblocked but already has one pending
170    /// (`task_sigpending`), so Linux passes it over; it can still take the
171    /// copy from the shared queue once it is done with those.
172    Busy,
173    /// Its mask is unknown.
174    Unknown,
175}
176
177/// A live thread of the process to read its shared queue through: the
178/// sender when it belongs to the process, else its first live thread.
179fn sender_or_member(threads: &[(DetTid, Wants)], sender: DetTid) -> DetTid {
180    if threads.iter().any(|(thread, _)| *thread == sender) {
181        sender
182    } else {
183        threads.first().map_or(sender, |(thread, _)| *thread)
184    }
185}

187/// `complete_signal`'s choice among `threads` (every live thread of the
188/// process in list order, with whether each wants the signal), trying `named`
189/// first and then walking from `curr_target`. Returns the receiver and, when
190/// the walk chose it, the process's new `curr_target`.
191///
192/// When no thread wants it, Linux leaves it in the shared queue for the first
193/// thread that can take it.
194pub(crate) fn complete_signal(
195    threads: &[(DetTid, Wants)],
196    named: DetTid,
197    curr_target: DetTid,
198) -> (ProcessSignalReceiver, Option<DetTid>) {
199    let chosen = |thread: DetTid| ProcessSignalReceiver::Thread {
200        thread,
201        sole: threads
202            .iter()
203            .all(|(tid, wants)| *tid == thread || *wants == Wants::No),
204    };
205    match threads.iter().find(|(tid, _)| *tid == named) {
206        Some((_, Wants::Yes)) => return (chosen(named), None),
207        Some((_, Wants::Unknown)) => return (ProcessSignalReceiver::UnknownMask(named), None),
208        Some((_, Wants::No | Wants::Busy)) | None => {}
209    }
210    let start = threads
211        .iter()
212        .position(|(tid, _)| *tid >= curr_target)
213        .unwrap_or(0);
214    let walk = || threads[start..].iter().chain(&threads[..start]);
215    for (tid, wants) in walk() {
216        match wants {
217            Wants::Yes => return (chosen(*tid), Some(*tid)),
218            Wants::Unknown => return (ProcessSignalReceiver::UnknownMask(*tid), None),
219            Wants::No | Wants::Busy => {}
220        }
221    }
222    (ProcessSignalReceiver::SharedQueue, None)
223}

225impl Scheduler {
226    /// The thread of `process` that takes the process-directed signal
227    /// `signo`, which `sender` sends naming `named` (module docs), decided in
228    /// `sender`'s turn. A chosen thread found by the walk becomes the
229    /// process's `curr_target`, and one that siblings could take the copy
230    /// before is marked as its taker (`process_signal_takers`).
231    pub(crate) fn process_signal_receiver(
232        &mut self,
233        process: DetPid,
234        named: DetTid,
235        sender: DetTid,
236        signo: i32,
237    ) -> ProcessSignalReceiver {
238        if !self.models_signal_targets {
239            return ProcessSignalReceiver::NotModeled;
240        }
241        if self.exec_teardowns.contains_key(&process) {
242            return ProcessSignalReceiver::ExecInFlight;
243        }
244        let bit = kernel_signal_bit(signo);
245        let threads: Vec<(DetTid, Wants)> = self
246            .process_signal_targets(process)
247            .into_iter()
248            .map(|thread| (thread, self.wants_signal(thread, sender, bit)))
249            .collect();
250        // A signal whose default action ends the process needs no choice at
251        // all: whichever thread takes it, Linux ends the whole thread group
252        // with the same status (`get_signal` calls `do_group_exit(signr)`,
253        // signal.c:3034; for a core-dumping signal `do_coredump` kills the
254        // others first, signal.c:3010-3020), and no thread runs further user
255        // code. So the two refusals below, which are about WHICH thread takes
256        // the copy, do not apply to it; the kernel's own choice under ptrace
257        // is as good as Linux's. The aborts and faults a guest raises in its
258        // own multi-threaded process take this path.
259        if threads
260            .first()
261            .and_then(|(thread, _)| self.stopped_thread_signal_state(*thread).ok())
262            .is_some_and(|state| state.default_action_ends_process(signo))
263        {
264            let thread = threads
265                .iter()
266                .find(|(thread, wants)| *wants != Wants::No || *thread == sender)
267                .map_or(sender, |(thread, _)| *thread);
268            tracing::info!(
269                "[scheduler] process-directed signal {} from {} to process {} ends its thread \
270                 group whichever thread takes it; thread {} is named",
271                signo,
272                sender,
273                process,
274                thread,
275            );
276            return ProcessSignalReceiver::Thread { thread, sole: true };
277        }
278        // The kernel wakes such a thread itself, at a host-timed moment, so
279        // which thread takes the copy is not the schedule's.
280        if let Some((thread, _)) = threads
281            .iter()
282            .find(|(thread, wants)| *wants != Wants::No && self.out_of_schedule(*thread))
283        {
284            return ProcessSignalReceiver::OutOfSchedule(*thread);
285        }
286        // A thread whose turn is not where it takes the copy: its call's
287        // temporary mask admits the signal although its own mask blocks it, a
288        // signalfd it reads in the background covers it, or a sibling's
289        // `rt_sigtimedwait` set does. Each takes the copy at a moment host
290        // timing sets, as it does for the scheduler's own sends
291        // (`another_call_may_take_waiting_signal`), so no choice here holds.
292        if let Some(thread) = self.may_take_out_of_turn(process, bit) {
293            return ProcessSignalReceiver::TakenOutOfTurn(thread);
294        }
295        // Linux does not queue a standard signal the shared queue already
296        // holds (`legacy_queue`, signal.c:1037-1040 through
297        // `__send_signal_locked`, signal.c:1063-1064), so the send reaches no
298        // `complete_signal`: the thread chosen for the copy already there
299        // keeps it, and this send decides nothing.
300        if bit & STANDARD_SIGNALS != 0
301            && self
302                .read_shared_pending(sender_or_member(&threads, sender))
303                .is_some_and(|pending| pending & bit != 0)
304        {
305            tracing::info!(
306                "[scheduler] process-directed signal {} from {} to process {} is already in its \
307                 shared queue; Linux queues no second copy",
308                signo,
309                sender,
310                process,
311            );
312            return ProcessSignalReceiver::AlreadyQueued;
313        }
314        let curr_target = self
315            .signal_curr_targets
316            .get(&process)
317            .copied()
318            .unwrap_or_else(|| DetTid::from_raw(process.as_raw()));
319        let (receiver, moved) = complete_signal(&threads, named, curr_target);
320        // A schedule replay decides as its recording did, from the same
321        // schedule, and resumes the threads in the recorded order, so the
322        // chosen thread, which the recording resumed before any other that
323        // could take the copy (`first_process_signal_taker`), is the next of
324        // them its schedule runs. If it is not, the replay has left its
325        // recording, and another thread could take the copy first.
326        if let ProcessSignalReceiver::Thread {
327            thread,
328            sole: false,
329        } = receiver
330            && thread != sender
331            && let Some(first) = self.replayer.as_ref().and_then(|replayer| {
332                let process_threads: Vec<DetTid> = threads.iter().map(|(tid, _)| *tid).collect();
333                replayer.next_thread_among(&process_threads, sender)
334            })
335            && first != thread
336        {
337            return ProcessSignalReceiver::ScheduleRunsFirst {
338                receiver: thread,
339                first,
340            };
341        }
342        // A signal Linux discards as it is sent never reaches
343        // `complete_signal` (`prepare_signal`, signal.c:1053-1054), so it
344        // moves nothing and takes no thread; its copy is dropped at the send.
345        let discarded = self.discarded_when_sent_to(named, signo, Some(sender));
346        // Under ptrace the sender is the only thread the kernel's own
347        // `complete_signal` admits, so a forwarded copy reaches it first.
348        // This refusal is decided before `curr_target` moves: Linux moves
349        // the pointer only on a successful walk choice, and a refused send
350        // chooses nothing.
351        if let ProcessSignalReceiver::Thread { thread, .. } = receiver
352            && thread != sender
353            && process == self.sigchld_process(sender)
354            && self
355                .stopped_thread_mask(sender)
356                .is_none_or(|mask| mask & bit == 0)
357        {
358            return ProcessSignalReceiver::SenderTakesIt;
359        }
360        if let Some(thread) = moved
361            && !discarded
362        {
363            self.signal_curr_targets.insert(process, thread);
364        }
365        if let ProcessSignalReceiver::Thread {
366            thread,
367            sole: false,
368        } = receiver
369            && !discarded
370        {
371            *self.process_signal_takers.entry(thread).or_default() |= bit;
372        }
373        tracing::info!(
374            "[scheduler] process-directed signal {} from {} naming {} to process {}: {:?} (curr_target {}, threads {:?})",
375            signo,
376            sender,
377            named,
378            process,
379            receiver,
380            curr_target,
381            threads
382        );
383        receiver
384    }

386    /// The thread step 3 resumes before any other because it is to take a
387    /// process-directed signal a guest sent (`process_signal_takers`,
388    /// `process_signal_receiver`), if any: the first whose mark still stands.
389    ///
390    /// A mark stands while the copy is still in its process's shared queue
391    /// and the thread still leaves the signal unblocked, so no stale mark can
392    /// let a thread run first for ever: the copy goes when the thread takes
393    /// it, when another thread does (which `/proc` shows), or when the signal
394    /// is flushed; and a thread that blocks the signal would not take it, so
395    /// another thread may, as Linux retargets a shared signal
396    /// (`retarget_shared_pending`, signal.c:3090). Only a thread queued to run
397    /// is chosen; one parked in a wait is woken by the ordinary path, and its
398    /// mark stands until then.
399    pub(super) fn first_process_signal_taker(&mut self) -> Option<DetTid> {
400        let threads: Vec<DetTid> = self.process_signal_takers.keys().copied().collect();
401        for thread in threads {
402            let shared = self.read_shared_pending(thread).unwrap_or(0);
403            let unblocked = self.stopped_thread_mask(thread).map_or(0, |mask| !mask);
404            let standing = self
405                .process_signal_takers
406                .get(&thread)
407                .copied()
408                .unwrap_or(0)
409                & shared
410                & unblocked;
411            if standing == 0 {
412                self.process_signal_takers.remove(&thread);
413            } else {
414                self.process_signal_takers.insert(thread, standing);
415            }
416        }
417        self.process_signal_takers
418            .keys()
419            .copied()
420            .find(|thread| self.run_queue.contains_non_polling_tid(*thread))
421    }

423    /// A thread of `process` that can take a copy of the signal `bit` from
424    /// the shared queue outside the turn the scheduler gives it.
425    ///
426    /// Its filed call installs a temporary mask that admits the signal
427    /// (`Resources::blocked_signal_mask`: `rt_sigsuspend`, `ppoll`,
428    /// `pselect6`, `epoll_pwait`), or publishes none the scheduler can read
429    /// (`blocked_signal_mask_unknown`); or a signalfd of the process covers
430    /// the signal, which any thread's read can dequeue
431    /// (`signalfd_notify`, signal.c:1136); or a thread waits for it in
432    /// `rt_sigtimedwait`.
433    fn may_take_out_of_turn(&self, process: DetPid, bit: u64) -> Option<DetTid> {
434        if self.signalfd_may_read(bit) {
435            return self.process_signal_targets(process).into_iter().next();
436        }
437        self.process_signal_targets(process)
438            .into_iter()
439            .find(|thread| {
440                self.sigtimedwait_sets
441                    .get(thread)
442                    .is_some_and(|set| set & bit != 0)
443                    || self.filed_temporary_mask_admits(*thread, bit)
444            })
445    }

447    /// Whether `thread`'s filed request carries a temporary signal mask that
448    /// admits the signal `bit`, or one the scheduler cannot read.
449    fn filed_temporary_mask_admits(&self, thread: DetTid, bit: u64) -> bool {
450        self.next_turns
451            .get(&thread)
452            .and_then(|turn| turn.req.try_read())
453            .and_then(Result::ok)
454            .is_some_and(|request| {
455                request.blocked_signal_mask_unknown
456                    || request
457                        .blocked_signal_mask
458                        .is_some_and(|mask| mask & bit == 0)
459            })
460    }

462    /// Whether `thread` runs outside the schedule, where the kernel can wake
463    /// it for a signal at a moment host timing sets.
464    fn out_of_schedule(&self, thread: DetTid) -> bool {
465        self.blocked.external_io_blockers.contains_key(&thread)
466            || self.blocked.rt_sigsuspend_blockers.contains_key(&thread)
467    }

469    /// Whether `thread` wants the signal `bit` sent now by `sender`, in the
470    /// model of the module docs.
471    fn wants_signal(&self, thread: DetTid, sender: DetTid, bit: u64) -> Wants {
472        if self.parked.exit_fences.contains_key(&thread)
473            || self.logically_killed_threads.contains(&thread)
474            || self.filed_exit_request(thread)
475        {
476            return Wants::No;
477        }
478        let mask = if self.out_of_schedule(thread) {
479            match self.blocked.out_of_scheduler_masks.get(&thread) {
480                Some(Some(mask)) => *mask,
481                _ => return Wants::Unknown,
482            }
483        } else {
484            match self.stopped_thread_mask(thread) {
485                Some(mask) => mask,
486                None => return Wants::Unknown,
487            }
488        };
489        if mask & bit != 0 {
490            return Wants::No;
491        }
492        // Linux's `wants_signal` takes SIGKILL whatever else is pending, and
493        // the running sender is `task_curr`.
494        if bit == kernel_signal_bit(libc::SIGKILL) || thread == sender {
495            return Wants::Yes;
496        }
497        if self.out_of_schedule(thread) {
498            // Its own queue is not read: only the scheduler's own sends reach
499            // it there, and they are recorded.
500            return if self.blocked.signaled_background.contains(&thread) {
501                Wants::Busy
502            } else {
503                Wants::Yes
504            };
505        }
506        // A thread already chosen for a copy still in the shared queue has
507        // been woken for it, so Linux passes it over
508        // (`signal_wake_up`, signal.c:1027, sets `TIF_SIGPENDING`).
509        if self
510            .process_signal_takers
511            .get(&thread)
512            .is_some_and(|signals| *signals != 0)
513        {
514            return Wants::Busy;
515        }
516        match self.reliable_pending(thread) {
517            Some(0) => Wants::Yes,
518            Some(_) => Wants::Busy,
519            None => Wants::Unknown,
520        }
521    }

523    /// Whether `thread`'s filed request is its own exit, which Linux runs to
524    /// completion: `wants_signal` passes over an exiting thread (`PF_EXITING`,
525    /// signal.c:951-952).
526    fn filed_exit_request(&self, thread: DetTid) -> bool {
527        self.next_turns
528            .get(&thread)
529            .and_then(|turn| turn.req.try_read())
530            .and_then(Result::ok)
531            .is_some_and(|request| {
532                request
533                    .resources
534                    .keys()
535                    .any(|rid| matches!(rid, ResourceID::Exit { .. }))
536            })
537    }

539    /// The mask of `thread`, stopped at a request or parked, as Linux's
540    /// `wants_signal` reads it: the guest's own while Detcore holds the thread
541    /// under a private one (`saved_guest_sigmasks`), less the set a polling
542    /// `rt_sigtimedwait` waits for, which Linux unblocks for the wait
543    /// (`do_sigtimedwait`, signal.c:3777).
544    fn stopped_thread_mask(&self, thread: DetTid) -> Option<u64> {
545        let mask = match self.saved_guest_sigmasks.get(&thread) {
546            Some(saved) => *saved,
547            None => self.stopped_thread_signal_state(thread).ok()?.blocked,
548        };
549        Some(mask & !self.sigtimedwait_sets.get(&thread).copied().unwrap_or(0))
550    }

552    /// The signals in `thread`'s own queue that it does not block, when it is
553    /// stopped at a request or parked, without those a host-timed source may
554    /// have posted (`host_timed_signals`) and Reverie's preemption marker,
555    /// which the schedule does not fix.
556    fn reliable_pending(&self, thread: DetTid) -> Option<u64> {
557        let mask = self.stopped_thread_mask(thread)?;
558        let state = self.stopped_thread_signal_state(thread).ok()?;
559        let unreliable =
560            self.host_timed_signals(thread) | kernel_signal_bit(reverie::PERF_EVENT_SIGNAL as i32);
561        Some(state.thread_pending & !mask & !unreliable)
562    }
563
564    /// The kernel's signal state for `thread`, stopped at a request or
565    /// parked. Unit tests script it (`test_kernel_signal_states`).
566    fn stopped_thread_signal_state(&self, thread: DetTid) -> Result<KernelSignalState, Errno> {
567        #[cfg(test)]
568        {
569            self.test_kernel_signal_states
570                .get(&thread)
571                .copied()
572                .ok_or(Errno::ESRCH)
573        }
574        #[cfg(not(test))]
575        {
576            read_kernel_signal_state(
577                reverie::Pid::from_raw(self.sigchld_process(thread).as_raw()),
578                reverie::Pid::from_raw(thread.as_raw()),
579            )
580        }
581    }
582}
