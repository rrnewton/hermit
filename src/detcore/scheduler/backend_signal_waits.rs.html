8//! `rt_sigsuspend` waits on a backend that reports the guest's signal state
9//! itself (SIGSHARE S2b; design `ai_docs/2026-10-29-kvm-sigshare-design.md`,
10//! S2 and S3).
11//!
12//! Where guest threads are not host tasks (`provides_process_signal_control`,
13//! KVM), the backend runs `rt_sigsuspend` itself, and its call never sleeps:
14//! it returns `EINTR` with the temporary mask installed for the delivery when
15//! a pending signal that the mask lets in ends the call, and declines to wait
16//! otherwise (`ENOSYS`). So Detcore parks the thread between two runs of the
17//! backend's call (`Detcore::handle_rt_sigsuspend`): a
18//! `SleepUntil(INDEFINITE)` request tagged `RT_SIGSUSPEND_FYI` that carries
19//! the temporary mask (`Resources::blocked_signal_mask`). A masked `ppoll`
20//! needs no decision here: it polls with the backend's own zero-timeout
21//! probes (`Detcore::backend_masked_ppoll_wait`), each of which runs in the
22//! thread's own turn and ends the wait when a signal its mask lets in is
23//! pending.
24//!
25//! This module decides when a parked `rt_sigsuspend` ends
26//! ([`Scheduler::wake_backend_signal_waits`]).
27//! It reads the waiter's signal state from the backend
28//! (`backend_signal_state`) and wakes it when a pending signal is unblocked by
29//! the temporary mask (Linux's `signal_pending` once `sigsuspend` has
30//! installed the mask). A caught or default-acting one ends the wait. An
31//! ignored one is one Linux discarded when it was sent (`sig_ignored`,
32//! kernel/signal.c: the mask installed then lets it in), which the backend
33//! keeps pending because the thread's own mask, not the temporary one, is
34//! installed while it waits; the woken thread removes it in its own turn
35//! (`settle_suspend_decline`) and parks again, before a later disposition
36//! change could make it deliverable (the other half of that rule is
37//! `Scheduler::suspend_holds_discarded`, which a call that stops ignoring a
38//! signal asks first). The woken thread runs the backend's call again in its
39//! own turn, and that call decides what the guest sees; if the signal is gone
40//! by then, the call declines again and the thread parks again, so a wake that
41//! finds nothing is never visible to the guest.
42//!
43//! A shared copy that a guest send chose one thread of the process for (its
44//! claim or taker mark, `guest_send_admission`), whether that thread waits
45//! here, runs, or polls, wakes no other waiter of that process, as Linux's
46//! `complete_signal` wakes only the thread it chooses (`signal_wake_up`,
47//! kernel/signal.c:963-1032 at v7.1.3): a sibling the same copy would end
48//! the wait of stays parked, with no turn, no `COMMIT` record and no charge
49//! of virtual time. A claim or mark speaks only for its own process's
50//! shared queue, so it never keeps another process's waiter asleep. A copy
51//! in a waiter's own queue, or one no send chose a thread for, wakes every
52//! waiter it ends, as before.
53//!
54//! It runs at one point: the end of the step-2 drain (`step2_drain_prefix`),
55//! after every barrier, which the controlled turn loop reaches only while no
56//! guest thread holds the turn and no exit fence, child-exit reservation,
57//! retirement or resume registration is outstanding. The backend's signal
58//! sets then change only by committed events (S1's contract for
59//! `ProcessSignalControl::signal_sets`): a guest thread's own turn, or a
60//! Detcore publication under the scheduler mutex, such as a timer expiry,
61//! whose waiter the next drain wakes. The one exception is a delivery under
62//! an observed parked wait's permit, which the observed thread's own host
63//! thread selects from the process's queues, so a process any of whose
64//! threads holds such a permit is passed over until it settles. An ordinary
65//! boundary permit does not count: its holder selected inside its own serial
66//! grant, before it filed the request that let this drain run, as
67//! `select_parked_alarm` reasons. Which waiters are scanned, in which
68//! order (DetTid), and what each read answers are therefore functions of the
69//! committed schedule. The decision is level-triggered, from the state alone:
70//! a signal that became pending by any committed event is seen at the first
71//! drain after it, whoever sent it.
72//!
73//! A child's exit `SIGCHLD` is no exception (SIGSHARE S4). The backend
74//! publishes it under the scheduler mutex, inside the child-exit reservation
75//! the exit grant installs, which is a control barrier: no drain runs between
76//! the grant and the publication's completion. So a `SIGCHLD` pending at a
77//! drain is pending by a committed event, whichever thread count the parent
78//! has, and it ends the wait as any other signal does.

96impl Scheduler {
97    /// The temporary mask of `dettid`'s parked `rt_sigsuspend`, if its filed
98    /// request is one this module decides: only on a backend that reports the
99    /// guest's signal state (`reads_signal_state_from_backend`) and outside
100    /// the in-guest delivery gate, a one-resource indefinite
101    /// `RT_SIGSUSPEND_FYI` sleep that carries its temporary mask.
102    pub(crate) fn backend_suspend_mask(&self, dettid: DetTid) -> Option<u64> {
103        if !reads_signal_state_from_backend(&self.backend) || self.in_guest_signal_delivery {
104            return None;
105        }
106        let resources = self.next_turns.get(&dettid)?.req.try_read()?.ok()?;
107        if resources.resources.len() != 1 {
108            return None;
109        }
110        let mask = resources.blocked_signal_mask?;
111        match resources.resources.iter().next() {
112            Some((ResourceID::SleepUntil(deadline), _))
113                if deadline.is_indefinite() && resources.fyi.as_str() == RT_SIGSUSPEND_FYI =>
114            {
115                Some(mask)
116            }
117            _ => None,
118        }
119    }

121    /// Called wherever a thread's filed request is replaced (a wake): if it
122    /// was a parked `rt_sigsuspend` this module decides, the thread's
123    /// temporary mask is kept (`backend_suspend_woken`) until its grant, so
124    /// `suspend_holds_discarded` still sees the waiter while it is woken but
125    /// not yet served, whatever woke it.
126    pub(crate) fn note_backend_suspend_replaced(&mut self, dettid: DetTid) {
127        if let Some(mask) = self.backend_suspend_mask(dettid) {
128            self.backend_suspend_woken.insert(dettid, mask);
129        }
130    }

132    /// The signals that end or settle a parked `rt_sigsuspend` under temporary
133    /// mask `mask`, given the waiter's signal state as the backend reports it:
134    /// pending for it, unblocked by `mask`, and caught or acting by default
135    /// (`KernelSignalState::interrupting`), or ignored at generation
136    /// (`ignored_at_generation`), which Linux discarded when they were sent
137    /// and the woken thread removes in its own turn. Held: the signals a host-timed
138    /// source armed by a guest can post (`host_timed_signals`). A child's exit
139    /// `SIGCHLD` counts as any other signal (see the module documentation).
140    pub(crate) fn backend_suspend_signals(
141        state: &KernelSignalState,
142        mask: u64,
143        host_timed: u64,
144    ) -> u64 {
145        let let_in = state.pending
146            & !host_timed
147            & !mask
148            & !kernel_signal_bit(reverie::PERF_EVENT_SIGNAL as i32);
149        let discarded = let_in & ignored_at_generation(state.ignored, state.caught);
150        (let_in & state.interrupting(mask)) | discarded
151    }

153    /// Whether an `rt_sigsuspend` of `process` whose temporary mask lets
154    /// `signal` in has it pending, on its own queue or the process's, while
155    /// the process ignores it: Linux discarded it when it was sent
156    /// (`sig_ignored`, kernel/signal.c), and the waiter has not yet removed it
157    /// in its own turn. The waiter is either parked (`backend_suspend_mask`)
158    /// or woken by the drain and not yet granted its turn
159    /// (`backend_suspend_woken`): its request is then the signal set, not the
160    /// park, and the signal is still pending until that turn. A call that
161    /// would stop ignoring `signal` (`Detcore::handle_rt_sigaction`) asks this
162    /// first, and does not change the action while it is true, so the change
163    /// never makes deliverable a signal Linux no longer holds. Waiters are
164    /// read from their committed state, in DetTid order; a gone or unreadable
165    /// one holds nothing (the scan names the latter).
166    pub(crate) fn suspend_holds_discarded(&self, process: DetPid, signal: i32) -> bool {
167        if !reads_signal_state_from_backend(&self.backend)
168            || self.in_guest_signal_delivery
169            || !(1..=64).contains(&signal)
170        {
171            return false;
172        }
173        let bit = kernel_signal_bit(signal);
174        self.next_turns.keys().any(|&dettid| {
175            self.backend_suspend_mask(dettid)
176                .or_else(|| self.backend_suspend_woken.get(&dettid).copied())
177                .is_some_and(|mask| mask & bit == 0)
178                && self.registered_process(dettid) == Some(process)
179                && self.backend_waiter_is_current(process, dettid)
180                && self.backend_wait_state(dettid).is_ok_and(|state| {
181                    state.pending & bit != 0
182                        && ignored_at_generation(state.ignored, state.caught) & bit != 0
183                })
184        })
185    }

187    /// `dettid`'s signal state for a wait decision, through the backend.
188    fn backend_wait_state(
189        &self,
190        dettid: DetTid,
191    ) -> Result<KernelSignalState, SleeperStateUnreadable> {
192        match self.backend_signal_state(dettid) {
193            Some(Ok(state)) => Ok(state),
194            Some(Err(Errno::ESRCH)) => Err(SleeperStateUnreadable::Gone),
195            Some(Err(errno)) => Err(SleeperStateUnreadable::Unreadable(errno)),
196            None => Err(SleeperStateUnreadable::Unreadable(Errno::ENOSYS)),
197        }
198    }

200    /// Whether some thread of `process` holds an observed parked wait's
201    /// delivery permit (`site` set): the observed thread's own host thread may
202    /// take a signal of the process for it, which changes the process's
203    /// pending set and the thread's mask without a turn of the scheduler's,
204    /// so the process's waits are not decided until it settles. An ordinary
205    /// boundary permit (`site` None) does not count, for the reason
206    /// `select_parked_alarm` gives: its holder selected inside its own serial
207    /// grant, before it filed the request that let the drain run, and the
208    /// delivery it completes runs in its own granted turn. Counting it held a
209    /// suspended thread forever behind a sibling that signals itself in a
210    /// loop (`run_kvm_signal_permits_are_per_thread`, `alarm-sigsuspend`).
211    fn process_holds_observation_permit(&self, process: DetPid) -> bool {
212        self.parked.permits.iter().any(|(holder, permit)| {
213            permit.site.is_some() && self.registered_process(*holder) == Some(process)
214        })
215    }

217    /// Whether `dettid` is still the live task lifetime its request was
218    /// filed by, as `select_parked_alarm` requires before acting for it.
219    fn backend_waiter_is_current(&self, process: DetPid, dettid: DetTid) -> bool {
220        if self.thread_is_logically_killed(dettid) {
221            return false;
222        }
223        self.real_timers
224            .task_identity(process, dettid)
225            .is_some_and(|(mm, _)| self.rpc_incarnation_matches(dettid, mm))
226    }

228    /// The shared copies a guest send to `thread`'s process chose it to take:
229    /// its claims (`guest_send_claims`) and its taker mark
230    /// (`process_signal_takers`).
231    fn shared_copies_chosen_for(&self, thread: DetTid) -> u64 {
232        self.guest_send_claims
233            .get(&thread)
234            .map_or(0, |claim| claim.shared)
235            | self
236                .process_signal_takers
237                .get(&thread)
238                .copied()
239                .unwrap_or(0)
240    }
241
242    /// The shared copies a guest send chose a thread of `process` other than
243    /// `thread` to take, whatever that thread is doing: claims and taker
244    /// marks speak for their own process's shared queue only.
245    fn shared_copies_chosen_for_another(&self, process: DetPid, thread: DetTid) -> u64 {
246        self.guest_send_claims
247            .keys()
248            .chain(self.process_signal_takers.keys())
249            .filter(|other| **other != thread && self.registered_process(**other) == Some(process))
250            .fold(0, |bits, other| {
251                bits | self.shared_copies_chosen_for(*other)
252            })
253    }

255    /// Ends every parked `rt_sigsuspend` this module decides
256    /// (`backend_suspend_mask`) that a pending signal now ends
257    /// (`backend_suspend_signals`). Called only at
258    /// the end of the step-2 drain (see the module documentation); waiters are
259    /// visited in DetTid order. A woken waiter's request becomes the signal
260    /// set (`WaitidSignals`) at the front of its band, as a woken sleep's does
261    /// (`drain_sleep_signals`), and its own turn runs the backend's call again.
262    /// A thread that is gone is left to its retirement; a state that cannot be
263    /// read otherwise ends the run with a diagnostic, never a guessed wake.
264    pub(crate) fn wake_backend_signal_waits(&mut self) {
265        if !reads_signal_state_from_backend(&self.backend) || self.in_guest_signal_delivery {
266            return;
267        }
268        let waiters: Vec<(DetTid, u64)> = self
269            .next_turns
270            .keys()
271            .filter_map(|&tid| self.backend_suspend_mask(tid).map(|mask| (tid, mask)))
272            .collect();
273        // Each waiter a signal ends the wait of: its thread, its process,
274        // its temporary mask, the signals, and those of them only its
275        // process's shared queue holds.
276        let mut ending: Vec<(DetTid, DetPid, u64, u64, u64)> = Vec::new();
277        for (dettid, mask) in waiters {
278            let Some(owner) = self.registered_process(dettid) else {
279                continue;
280            };
281            if self.process_holds_observation_permit(owner)
282                || !self.backend_waiter_is_current(owner, dettid)
283            {
284                continue;
285            }
286            let state = match self.backend_wait_state(dettid) {
287                Ok(state) => state,
288                Err(SleeperStateUnreadable::Gone) => {
289                    tracing::debug!(
290                        "[dtid {}] is gone; its rt_sigsuspend is left to its retirement.",
291                        dettid
292                    );
293                    continue;
294                }
295                Err(SleeperStateUnreadable::Unreadable(errno)) => {
296                    self.terminal_deadlock.get_or_insert_with(|| {
297                        format!(
298                            "HERMIT_DEADLOCK: cannot read the signal state of dettid {} ({}) to \
299                             decide whether a signal ends its rt_sigsuspend",
300                            dettid, errno
301                        )
302                    });
303                    return;
304                }
305            };
306            let signals =
307                Self::backend_suspend_signals(&state, mask, self.host_timed_signals(dettid));
308            if signals == 0 {
309                continue;
310            }
311            ending.push((
312                dettid,
313                owner,
314                mask,
315                signals,
316                signals & state.shared_pending & !state.thread_pending,
317            ));
318        }
319        for &(dettid, owner, mask, signals, shared_only) in &ending {
320            // Linux's `complete_signal` wakes the one thread it chooses for a
321            // process-directed signal (`signal_wake_up`). A waiter whose
322            // signals are all shared copies that a guest send chose another
323            // thread of its own process for (its claim or taker mark), and
324            // not it, is left asleep, whether that thread waits here or not:
325            // that thread takes them. A copy in its own queue, or one chosen
326            // for no thread of its process, still wakes it. The rule is
327            // judged again from the state at every drain, so a copy its chosen
328            // thread does not take (it blocks the signal, or exits) reaches
329            // this waiter once the claim and the mark are gone. Until then the
330            // claims audit refuses that case by name once it can read the
331            // chosen thread's state (`ClaimReason::Retarget`,
332            // `Scheduler::audit_guest_send_claims`); an unreadable claim it
333            // defers to its next pass.
334            let for_another = self.shared_copies_chosen_for_another(owner, dettid)
335                & shared_only
336                & !self.shared_copies_chosen_for(dettid);
337            if signals & !for_another == 0 {
338                tracing::info!(
339                    "[dtid {}] stays in its rt_sigsuspend: signals {:#x} it would end for are shared \
340                     copies a guest send chose another thread of its process for.",
341                    dettid,
342                    signals
343                );
344                continue;
345            }
346            let signals: Vec<SigWrapper> = (1..=64)
347                .filter(|signal| signals & kernel_signal_bit(*signal) != 0)
348                .map(SigWrapper)
349                .collect();
350            tracing::info!(
351                "[dtid {}] signals {:?} end or settle its rt_sigsuspend under mask {:#x}, as the backend \
352                 reports its signal state.",
353                dettid,
354                signals,
355                mask
356            );
357            if self.run_queue.contains_tid(dettid) {
358                let removed = self.run_queue.remove_tid(dettid);
359                debug_assert!(
360                    removed,
361                    "run_queue.contains_tid disagreed with remove_tid for {dettid}"
362                );
363            }
364            let mut resources = Resources::new(dettid);
365            resources.insert(ResourceID::WaitidSignals(signals), Permission::W);
366            self.force_unblock_thread_at(dettid, resources, true);
367        }
368    }
