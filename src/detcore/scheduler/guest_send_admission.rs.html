9//! The admission of a guest's signal to another process where the backend
10//! keeps the guest's signal queues itself (KVM): sections 2 and 5 of the KVM
11//! cross-process signal design
12//! (`ai_docs/plans/2026-11-10-kvm-cross-process-signal-delivery.md` in the
13//! dev-hermit workspace), stage X1 slice C.
14//!
15//! Such a backend performs a guest's `kill`, `tkill`, `tgkill`,
16//! `rt_sigqueueinfo`, `rt_tgsigqueueinfo` or `pidfd_send_signal` that names
17//! another process, or names its own process while that has another thread,
18//! only once the Tool declares that it selects the receiving thread
19//! (`ProcessSignalControl::enable_cross_process_signals`, which
20//! `Scheduler::install_signal_control` asks for). It then queues the signal
21//! as Linux's `__send_signal_locked` does, on the process's shared queue or
22//! the named thread's own, and wakes no thread: a thread takes it only at a
23//! boundary the scheduler authorizes (`authorize_signal_boundary`), or in a
24//! parked observation. So in the sender's turn, before the call is
25//! forwarded, the scheduler decides whether the delivery Linux would make is
26//! one it can order now (`Scheduler::guest_send_admission`):
27//!
28//! 1. What Linux does with the signal as it sends it
29//!    (`kernel/signal.c`, `prepare_signal` and `__send_signal_locked`): a
30//!    signal the named task ignores and does not block is discarded; a
31//!    standard signal its queue already holds is not queued again; one that
32//!    every thread that could take it blocks stays queued. None of these
33//!    needs a thread to act now.
34//! 2. The transition its disposition requires: a handler (*catch*); a
35//!    default stop; a default action that ends the process (*die*); or
36//!    SIGKILL (*kill*). Only *catch* is admitted at this stage: *stop* waits
37//!    for stage X2 (the backend refuses it too), *die* for slice F and *kill*
38//!    for slice G. A receiver waiting for the signal in `rt_sigtimedwait`,
39//!    which its own mask blocks outside the wait, takes even a default-fatal
40//!    signal by that wait, as Linux's `complete_signal` leaves the group
41//!    alone for a thread whose `real_blocked` holds the signal; that is a
42//!    catch too.
43//! 3. The receiver: the named thread for a thread-directed send, and for a
44//!    process-directed one the thread Linux's `complete_signal` chooses
45//!    (`process_signal_receiver::complete_signal`), each thread's wish read
46//!    under the mask Linux's `blocked` holds for it now, a call's temporary
47//!    mask included (`Scheduler::controlled_wants`). Where it chooses no
48//!    thread, the copy waits in the shared queue for the first thread that
49//!    can take it, as in Linux. A send to the sender's own process that the
50//!    sender does not block, but that Linux gives to another thread, is
51//!    refused (`SendRefusal::SenderTakesIt`): the sender's own delivery
52//!    permit would take the copy at its return first.
53//! 4. Whether the receiver's state lets it take the copy without a later
54//!    slice (`CatchReach`): at a boundary of its own (runnable, a posted
55//!    continuation, a delivery permit's holder, or held at a happens-before
56//!    gate), at its next probe (`pselect6`, a masked `ppoll`,
57//!    `rt_sigtimedwait`), through the drain (an internal IO poll with the
58//!    restart marker, a backend-served `rt_sigsuspend`). Every other state
59//!    is refused by name (`SendRefusal`), a raw `select` included
60//!    (`SendRefusal::RawSelect`).
61//!
62//! A signalfd reads its reader's own queue and its process's shared one. A
63//! read of a blocking signalfd runs outside the schedule, as a host call, and
64//! so does a host wait that includes a signalfd, which the backend wakes for
65//! a covered signal: either can take the copy, or see it, at a moment host
66//! timing sets. So where a signalfd may cover the signal, a send is refused
67//! while a thread that can read it is in a host call
68//! (`SendRefusal::SignalfdReadOutsideTurn`), and a caught copy is refused
69//! outright (`SendRefusal::SignalfdCovered`): such a read could begin before
70//! the receiver takes the copy.
71//!
72//! A refused send has no effect: nothing is queued, `curr_target` does not
73//! move, and no thread is marked.
74//!
75//! An admitted copy that its receiver is to take is claimed for it once the
76//! forwarded call succeeds (`Scheduler::guest_send_committed`), until the
77//! receiver takes it. A receiver chosen while runnable can still enter a wait
78//! before its next boundary: this backend's emulated `pause` and `nanosleep`
79//! do not look for a pending signal before they park
80//! (`supports_blocked_wait_signal_interruption`), and the observation that
81//! ends such a wait for a signal of the thread's own looks at its own queue
82//! only. Linux returns from such a wait at once. So at every pass that can
83//! begin a parked observation the claims are checked again
84//! (`Scheduler::audit_guest_send_claims`), and a claimed copy whose receiver
85//! now waits where it cannot take it ends the run with that refusal, as the
86//! design's retargeting rule ends it for a receiver in a refused state.
87//! Linux would also wake another thread for a shared copy whose receiver
88//! exited or blocked the signal first (`retarget_shared_pending`), which is
89//! slice E; until then that case is refused too.
90//!
91//! An observation begun for another reason (a SIGALRM, a parent-death signal)
92//! takes the lowest signal its thread leaves unblocked, from its own queue
93//! and then the shared one, which can be a copy claimed for another thread.
94//! Which of the two claims Linux settles first is the design's opportunity
95//! rule (slice D2); until then such an observation is refused
96//! (`Scheduler::contested_guest_send_claim`).
97//!
98//! A claim is a wake choice, not a reservation: it names the thread the
99//! scheduler wakes for the copy and does not reserve the copy for it.
100//! Linux's `complete_signal` only chooses which thread to wake and wakes it
101//! (`signal_wake_up`, kernel/signal.c:963-1032 at v7.1.3); the copy stays in
102//! the process's shared queue. Only the chosen thread is woken and flagged:
103//! `signal_wake_up_state` sets its `TIF_SIGPENDING` (:725), the per-task flag
104//! `signal_pending` reads (include/linux/sched/signal.h:382-396) and a return
105//! to user mode acts on (kernel/entry/common.c:63-64). An unchosen thread
106//! asleep in a call, a probe's sleep included, is not woken and does not
107//! take the copy. Another thread takes it only on a return to user mode with
108//! its own flag set, as after a change of its mask that leaves the signal
109//! unblocked (`__set_task_blocked` recalculates the flag, :3188-3197,
110//! through `recalc_sigpending_tsk`, :159-166); it then dequeues the copy
111//! (`dequeue_signal` reads the thread's own queue and then
112//! `signal->shared_pending`, :618-640). So an ordinary boundary of another
113//! thread of the process that leaves the signal unblocked, which the
114//! scheduler authorizes without reading the claims
115//! (`authorize_signal_boundary`), can take a copy claimed for a receiver
116//! that would take it at its next probe or once a gate releases it, if
117//! step 3 runs that thread first; the next audit finds the copy gone and
118//! drops the claim, and the run goes on. Linux permits that outcome for a
119//! thread whose own flag is set, as above. For a running thread whose flag
120//! nothing has recalculated, Linux would leave the copy to the chosen
121//! thread; deciding that case is follow-up work (the contested-claim rule
122//! at ordinary boundaries). That boundary is in its own thread's serial
123//! grant, a point the schedule fixes. Only an observation, whose dequeue the
124//! observed thread's host thread makes, is refused (above).
125//!
126//! A probe stands for a sleeping call Linux will not interrupt, enforced by
127//! ORDER. Linux leaves a sibling asleep in `select` or `pselect6`: its
128//! `do_select` ends the sleep only on its own `signal_pending`
129//! (fs/select.c:575, :603). Here the sibling's probe is a real call that
130//! takes any pending copy its mask lets in, so the chosen thread runs first
131//! instead (`Scheduler::first_process_signal_taker`, which on a controlled
132//! backend returns a polling taker too) and its call takes the copy before
133//! the sibling probes. Order is all that enforces it: a thread step 3 ranks
134//! above the process taker (a group-exit decider, a reserved SIGALRM probe,
135//! a SIGCHLD taker, a taker with a lower `DetTid`) still runs first and can
136//! take the copy, as a thread Linux woke for a reason of its own can.

156/// Whether a guest's send names one thread or its process.
157#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
158pub enum SendScope {
159    /// `tkill`, `tgkill`, `rt_tgsigqueueinfo`, or `pidfd_send_signal` with the
160    /// thread scope: the copy joins the named thread's own queue.
161    Thread,
162    /// `kill`, `rt_sigqueueinfo`, or `pidfd_send_signal` with the process
163    /// scope: the copy joins the process's shared queue.
164    Process,
165}

167/// How an admitted receiver takes a caught copy (the rows of section 2's
168/// table that slice C admits).
169#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
170pub enum CatchReach {
171    /// Runnable, a continuation posted and not yet granted, or a delivery
172    /// permit's holder waiting in its signal hook: at a later boundary of its
173    /// own.
174    Boundary,
175    /// Held at a happens-before gate: at its boundary once it is released.
176    Gate,
177    /// Probing in `pselect6`, a masked `ppoll` or
178    /// `rt_sigtimedwait`: its next probe takes the copy.
179    Probe,
180    /// Parked in an internal IO poll with the restart marker: the drain
181    /// answers its turn `Signaled` (`Scheduler::notify_signal_pending`).
182    RestartablePoll,
183    /// In a backend-served `rt_sigsuspend`: the drain wakes it
184    /// (`Scheduler::wake_backend_signal_waits`).
185    BackendSuspend,
186}

188/// Why a guest's send is refused at admission, each naming the state and
189/// what lifts the refusal.
190#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
191pub enum SendRefusal {
192    /// An exec is in flight in the target process; its `de_thread` decides
193    /// which threads remain.
194    ExecInFlight,
195    /// SIGKILL to another process: the kill transition, slice G.
196    Kill,
197    /// A default action that ends the process: the die transition, slice F.
198    Die,
199    /// A default stop: stage X2.
200    Stop,
201    /// This thread's signal mask is unknown.
202    UnknownMask(DetTid),
203    /// This thread's signal state, or what it waits in, cannot be read.
204    UnknownState(DetTid),
205    /// The sender does not block the signal, and Linux gives it to this other
206    /// thread of the sender's own process.
207    SenderTakesIt(DetTid),
208    /// The receiver is parked in an emulated `pause`, `nanosleep`, polled read
209    /// or child wait: slice D.
210    Parked(DetTid),
211    /// The receiver polls in a call whose probe never takes a pending signal
212    /// (`poll`, `epoll_wait`, an unmasked `ppoll`): slice D.
213    Poll(DetTid),
214    /// The receiver waits in a raw `select`, which has no signal mask the
215    /// backend's probe can check, so no probe of it takes the copy: refused
216    /// until its probes are lowered to `pselect6`
217    /// (<https://github.com/rrnewton/hermit/issues/5452>).
218    RawSelect(DetTid),
219    /// The receiver is a vfork parent waiting for its child, which no slice
220    /// of stage X1 admits as a receiver.
221    VforkParent(DetTid),
222    /// The receiver waits on a futex (N8a).
223    Futex(DetTid),
224    /// The receiver is in a host call outside the schedule.
225    ExternalIo(DetTid),
226    /// The receiver polls outside the run queue.
227    PollerOutsideRunQueue(DetTid),
228    /// The receiver is entering a background call.
229    BackgroundEntry(DetTid),
230    /// A signalfd may cover the signal, and this thread, which can read it
231    /// (its own queue, and its process's), is in a host call outside the
232    /// schedule.
233    SignalfdReadOutsideTurn(DetTid),
234    /// A signalfd may cover the caught signal that this thread is chosen to
235    /// take.
236    SignalfdCovered(DetTid),
237}

326/// The scheduler's decision on a guest's send (`Scheduler::guest_send_admission`).
327#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
328pub enum SendAdmission {
329    /// Not a send this admission decides: the backend keeps no signal queues
330    /// of its own, or performs the send within the sender's process as it
331    /// always has (a thread-directed send there, or a process-directed one
332    /// while the sender is its only thread), or the target has no live
333    /// thread, which Detcore answers from its model before this.
334    NotDecided,
335    /// Admitted, and no thread has to act now: the signal is discarded as it
336    /// is sent, coalesced with a copy already queued, blocked by every thread
337    /// that could take it, ignored when it is delivered, or left in the
338    /// shared queue for the first thread that can take it.
339    NoTransition,
340    /// Admitted: `receiver` takes the caught copy, as `reach` says.
341    Catch { receiver: DetTid, reach: CatchReach },
342    /// Refused by name, before any effect.
343    Refused(SendRefusal),
344}

346/// The copies a guest sent from another process that wait for the thread the

349pub(crate) struct GuestSendClaim {
350    /// Signals in the thread's process's shared queue.
351    pub(crate) shared: u64,
352    /// Signals in the thread's own queue.
353    pub(crate) private: u64,
354}

356/// Why a claimed copy can no longer be delivered as its admission decided
357/// (`Scheduler::audit_guest_send_claims`,
358/// `Scheduler::contested_guest_send_claim`). Ends the run.
359#[derive(Clone, Copy, Debug, PartialEq, Eq)]
360pub(crate) struct ClaimRefusal {
361    /// The thread the copy was chosen for.
362    pub(crate) receiver: DetTid,
363    /// The claimed signal.
364    pub(crate) signal: i32,
365    pub(crate) reason: ClaimReason,
366}
367
368/// What [`ClaimRefusal`] found.
369#[derive(Clone, Copy, Debug, PartialEq, Eq)]
370pub(crate) enum ClaimReason {
371    /// The receiver now waits in a state the admission refuses.
372    Waits(SendRefusal),
373    /// The receiver exited, or blocks the signal, before taking a shared
374    /// copy that another live thread leaves unblocked: Linux wakes that
375    /// thread for it (`retarget_shared_pending`), slice E.
376    Retarget,
377    /// An observation of this other thread, begun for a signal of its own
378    /// or of the scheduler's, would take the claimed copy first: slice D2.
379    Contested { observed: DetTid },
380}
381
382impl fmt::Display for ClaimRefusal {
383    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
384        write!(
385            f,
386            "HERMIT_KVM_SIGNAL_CLAIM_REFUSED: signal {} that another process sent is not \
387             supported: thread {} was chosen to take it, but ",
388            self.signal, self.receiver
389        )?;
390        match self.reason {
391            ClaimReason::Waits(refusal) => write!(
392                f,
393                "it began to wait before taking it, where it cannot take it: {refusal}"
394            ),
395            ClaimReason::Retarget => write!(
396                f,
397                "it exited or blocked the signal before taking it, and Linux wakes another \
398                 thread for the copy (retarget_shared_pending), which KVM does not yet do \
399                 (stage X1 slice E)"
400            ),
401            ClaimReason::Contested { observed } => write!(
402                f,
403                "a parked observation of thread {observed} would take it first, and which of \
404                 the two claims Linux settles first is not yet decided (stage X1 slice D2)"
405            ),
406        }
407    }
408}

410/// The lowest signal in `bits`, in Linux's numbering.
411fn lowest_signal(bits: u64) -> i32 {
412    bits.trailing_zeros() as i32 + 1
413}

415/// Whether `signal`'s default action stops the process.
416fn default_stop(signal: i32) -> bool {
417    matches!(
418        signal,
419        libc::SIGSTOP | libc::SIGTSTP | libc::SIGTTIN | libc::SIGTTOU
420    )
421}

423impl Scheduler {
424    /// Section 2's admission of the guest send of `signo` that `sender` makes
425    /// naming `named` (module docs), decided in `sender`'s turn and with no
426    /// effect. `process` is the process the call names, or `None` to take the
427    /// named thread's.
428    pub(crate) fn guest_send_admission(
429        &self,
430        sender: DetTid,
431        process: Option<DetPid>,
432        named: DetTid,
433        scope: SendScope,
434        signo: i32,
435    ) -> SendAdmission {
436        if !self.signal_control_installed() || !(1..=64).contains(&signo) {
437            return SendAdmission::NotDecided;
438        }
439        let Some(process) = process.or_else(|| self.registered_process(named)) else {
440            return SendAdmission::NotDecided;
441        };
442        let threads = self.process_signal_targets(process);
443        let own = process == self.sigchld_process(sender);
444        let decided =
445            !own || (scope == SendScope::Process && threads.iter().any(|thread| *thread != sender));
446        if !decided || threads.is_empty() {
447            return SendAdmission::NotDecided;
448        }
449        if scope == SendScope::Thread && !threads.contains(&named) {
450            return SendAdmission::NotDecided;
451        }
452        if self.exec_teardowns.contains_key(&process) {
453            return SendAdmission::Refused(SendRefusal::ExecInFlight);
454        }
455        if signo == libc::SIGKILL {
456            return SendAdmission::Refused(SendRefusal::Kill);
457        }
458        // Discarded as it is sent (`sig_ignored`, judged on the named task).
459        if self.discarded_when_sent_to(named, signo, Some(sender)) {
460            return SendAdmission::NoTransition;
461        }
462        let bit = kernel_signal_bit(signo);
463        // Dispositions are the process's, and the named task's queue is the
464        // one a thread-directed copy joins.
465        let reader = if threads.contains(&named) {
466            named
467        } else {
468            threads[0]
469        };
470        let Ok(state) = self.read_guest_signal_state(reader) else {
471            return SendAdmission::Refused(SendRefusal::UnknownState(reader));
472        };
473        // A standard signal already in the queue the copy would join is not
474        // queued again (`legacy_queue`).
475        let queue = match scope {
476            SendScope::Thread => state.thread_pending,
477            SendScope::Process => state.shared_pending,
478        };
479        if bit & STANDARD_SIGNALS != 0 && queue & bit != 0 {
480            return SendAdmission::NoTransition;
481        }
482        // A signalfd read of a blocking descriptor runs outside the schedule
483        // (`IOAction::Blocking`), and so does a host wait that includes a
484        // signalfd, which the backend wakes for a covered signal: either can
485        // take the copy, or see it, at a moment host timing sets. A signalfd
486        // reads its reader's own queue and its process's shared one
487        // (`signalfd_dequeue`, fs/signalfd.c).
488        let signalfd = self.signalfd_may_read(bit);
489        if signalfd {
490            let in_host_call = |thread: &DetTid| {
491                self.blocked.external_io_blockers.contains_key(thread)
492                    && !self.vfork_barriers.contains_key(thread)
493            };
494            let reader = match scope {
495                SendScope::Thread => Some(named).filter(in_host_call),
496                SendScope::Process => threads.iter().copied().find(in_host_call),
497            };
498            if let Some(reader) = reader {
499                return SendAdmission::Refused(SendRefusal::SignalfdReadOutsideTurn(reader));
500            }
501        }
502        let wants: Vec<(DetTid, Wants)> = match scope {
503            SendScope::Thread => vec![(named, self.controlled_wants(named, sender, bit))],
504            SendScope::Process => threads
505                .iter()
506                .map(|thread| (*thread, self.controlled_wants(*thread, sender, bit)))
507                .collect(),
508        };
509        // Blocked by every thread that could take it, or every such thread is
510        // exiting: it stays queued and no thread is woken.
511        if wants.iter().all(|(_, wants)| *wants == Wants::No) {
512            return SendAdmission::NoTransition;
513        }
514        let caught = state.caught & bit != 0;
515        if !caught {
516            // Ignored when it is delivered: nothing to carry out.
517            if state.ignored_at_generation() & bit != 0 {
518                return SendAdmission::NoTransition;
519            }
520            if default_stop(signo) {
521                return SendAdmission::Refused(SendRefusal::Stop);
522            }
523        }
524        let receiver = match scope {
525            SendScope::Thread => match wants[0].1 {
526                Wants::Unknown => return SendAdmission::Refused(SendRefusal::UnknownMask(named)),
527                Wants::Yes | Wants::Busy | Wants::No => Some(named),
528            },
529            SendScope::Process => {
530                match complete_signal(&wants, named, self.signal_curr_target(process)).0 {
531                    ProcessSignalReceiver::Thread { thread, .. } => Some(thread),
532                    ProcessSignalReceiver::UnknownMask(thread) => {
533                        return SendAdmission::Refused(SendRefusal::UnknownMask(thread));
534                    }
535                    _ => None,
536                }
537            }
538        };
539        // A default action that ends the process ends it whichever thread
540        // takes the copy, now or later, but for a thread that waits for the
541        // signal in `rt_sigtimedwait` and blocks it outside the wait: Linux's
542        // `complete_signal` ends the group only through a thread whose
543        // `real_blocked` leaves the signal out, and the wait dequeues it
544        // (`do_sigtimedwait`).
545        if !caught && !receiver.is_some_and(|receiver| self.waits_for_blocked_signal(receiver, bit))
546        {
547            return SendAdmission::Refused(SendRefusal::Die);
548        }
549        // No thread wants it now: the first that can takes it from the
550        // shared queue, as in Linux.
551        let Some(receiver) = receiver else {
552            return SendAdmission::NoTransition;
553        };
554        if signalfd {
555            return SendAdmission::Refused(SendRefusal::SignalfdCovered(receiver));
556        }
557        if receiver == sender {
558            return SendAdmission::Catch {
559                receiver,
560                reach: CatchReach::Boundary,
561            };
562        }
563        if own
564            && self
565                .controlled_mask(sender)
566                .is_none_or(|mask| mask & bit == 0)
567        {
568            return SendAdmission::Refused(SendRefusal::SenderTakesIt(receiver));
569        }
570        match self.catch_reach(receiver) {
571            Ok(reach) => SendAdmission::Catch { receiver, reach },
572            Err(refusal) => SendAdmission::Refused(refusal),
573        }
574    }

576    /// The mask Linux's `blocked` holds for `thread` now, where a process
577    /// signal control is installed: a call's temporary mask where one is
578    /// installed, and otherwise the thread's own
579    /// (`read_guest_signal_mask`), less the set a polling `rt_sigtimedwait`
580    /// waits for, which Linux unblocks for the wait (`do_sigtimedwait`).
581    /// `None` where it cannot be read.
582    pub(super) fn controlled_mask(&self, thread: DetTid) -> Option<u64> {
583        let mask = self.read_guest_signal_mask(thread)?;
584        Some(mask & !self.sigtimedwait_sets.get(&thread).copied().unwrap_or(0))
585    }

587    /// Whether `thread` waits for the signal `bit` in `rt_sigtimedwait` while
588    /// its own mask, Linux's `real_blocked` for the wait, blocks it.
589    fn waits_for_blocked_signal(&self, thread: DetTid, bit: u64) -> bool {
590        self.sigtimedwait_sets
591            .get(&thread)
592            .is_some_and(|set| set & bit != 0)
593            && self
594                .read_guest_signal_mask(thread)
595                .is_some_and(|mask| mask & bit != 0)
596    }

598    /// Whether `thread` wants the signal `bit` that `sender` sends now
599    /// (`wants_signal`, kernel/signal.c), where a process signal control is
600    /// installed: not exiting, not blocking it under the mask Linux's
601    /// `blocked` holds now (`controlled_mask`), and, but for the running
602    /// sender (`task_curr`), no signal of its own to take first and no copy
603    /// it was already chosen for (`task_sigpending`). A thread running a call
604    /// outside the schedule is never busy: the backend can post it a signal
605    /// when host timing ends that call, so its queue is not the schedule's.
606    pub(super) fn controlled_wants(&self, thread: DetTid, sender: DetTid, bit: u64) -> Wants {
607        if self.parked.exit_fences.contains_key(&thread)
608            || self.logically_killed_threads.contains(&thread)
609            || self.filed_exit_request(thread)
610        {
611            return Wants::No;
612        }
613        let Some(mask) = self.controlled_mask(thread) else {
614            return Wants::Unknown;
615        };
616        if mask & bit != 0 {
617            return Wants::No;
618        }
619        if thread == sender {
620            return Wants::Yes;
621        }
622        if (self.blocked.external_io_blockers.contains_key(&thread)
623            || self.blocked.rt_sigsuspend_blockers.contains_key(&thread))
624            && !self.vfork_barriers.contains_key(&thread)
625        {
626            return Wants::Yes;
627        }
628        let chosen = self
629            .process_signal_takers
630            .get(&thread)
631            .is_some_and(|signals| *signals != 0)
632            || self
633                .guest_send_claims
634                .get(&thread)
635                .is_some_and(|claim| claim.shared | claim.private != 0);
636        if chosen {
637            return Wants::Busy;
638        }
639        match self.read_guest_signal_state(thread) {
640            Ok(state) if self.own_signals_to_take(thread, &state, mask) != 0 => Wants::Busy,
641            Ok(_) => Wants::Yes,
642            Err(_) => Wants::Unknown,
643        }
644    }

646    /// How `thread` can take a caught copy, by its state (the rows of section
647    /// 2's table), from the scheduler's committed state: the pools of calls
648    /// outside the schedule, the parked request's origin, the futex waiters,
649    /// a backend-served `rt_sigsuspend`, the happens-before gates and
650    /// run-queue membership. A queued thread's request is read only for which
651    /// call it polls: it filed that request in its own turn. A state no row
652    /// admits is refused, an unknown one included.
653    pub(super) fn catch_reach(&self, thread: DetTid) -> Result<CatchReach, SendRefusal> {
654        if self.vfork_barriers.contains_key(&thread) {
655            return Err(SendRefusal::VforkParent(thread));
656        }
657        if self.background_entry_barriers.contains_key(&thread) {
658            return Err(SendRefusal::BackgroundEntry(thread));
659        }
660        if self.blocked.external_io_blockers.contains_key(&thread)
661            || self.blocked.rt_sigsuspend_blockers.contains_key(&thread)
662        {
663            return Err(SendRefusal::ExternalIo(thread));
664        }
665        let Some(turn) = self.next_turns.get(&thread) else {
666            return Err(SendRefusal::UnknownState(thread));
667        };
668        if turn.protocol.owner == NextTurnOwner::Ordinary
669            && turn.protocol.origin.is_some_and(|origin| {
670                matches!(
671                    origin.control,
672                    ControlCapability::ParkedWait { .. }
673                        | ControlCapability::PolledRead { .. }
674                        | ControlCapability::ChildWait { .. }
675                )
676            })
677            && !turn.req.is_empty()
678            && !turn.resp.is_full()
679        {
680            return Err(SendRefusal::Parked(thread));
681        }
682        if self
683            .parked_futex_waiter(thread)
684            .is_some_and(|waiter| !waiter.woken)
685        {
686            return Err(SendRefusal::Futex(thread));
687        }
688        if self.backend_suspend_mask(thread).is_some() {
689            return Ok(CatchReach::BackendSuspend);
690        }
691        if self
692            .happens_before
693            .as_ref()
694            .is_some_and(|hb| hb.parked.contains(&thread))
695        {
696            return Ok(CatchReach::Gate);
697        }
698        let request = turn.req.try_read().and_then(Result::ok);
699        let lone_poll = request.as_ref().is_some_and(|request| {
700            request.resources.len() == 1
701                && request
702                    .resources
703                    .contains_key(&ResourceID::InternalIOPolling)
704        });
705        if !self.run_queue.contains_tid(thread) {
706            return Err(if lone_poll {
707                SendRefusal::PollerOutsideRunQueue(thread)
708            } else {
709                SendRefusal::UnknownState(thread)
710            });
711        }
712        let Some(request) = request else {
713            return Err(SendRefusal::UnknownState(thread));
714        };
715        if !lone_poll {
716            return Ok(CatchReach::Boundary);
717        }
718        // A raw `select` has no mask of its own, and the backend's probe of
719        // it never takes a pending signal: no probe ends its wait.
720        if request.fyi.as_str() == "select" {
721            return Err(SendRefusal::RawSelect(thread));
722        }
723        // Each probe of these calls applies the call's mask and takes a
724        // pending signal it lets in (a `ppoll` only under a mask of its own:
725        // `Detcore::backend_masked_ppoll_wait`).
726        let probes = request.fyi.as_str() == "rt_sigtimedwait"
727            || (request.signal_interrupt_errno() == Some(Errno::EINTR.into_raw())
728                && (request.fyi.as_str() == "pselect6"
729                    || (request.fyi.as_str() == "ppoll" && request.blocked_signal_mask.is_some())));
730        if probes {
731            return Ok(CatchReach::Probe);
732        }
733        if self.restartable_internal_io_signals(thread).is_some() {
734            return Ok(CatchReach::RestartablePoll);
735        }
736        Err(SendRefusal::Poll(thread))
737    }

739    /// The guest send that `guest_send_admission` admitted for `receiver` to
740    /// take succeeded: the copy is claimed for it until it takes it
741    /// (`audit_guest_send_claims`), and Linux's `signal_wake_up` makes it busy
742    /// for a later choice (`controlled_wants`).
743    pub(crate) fn guest_send_committed(&mut self, receiver: DetTid, scope: SendScope, signo: i32) {
744        if !self.signal_control_installed() || !(1..=64).contains(&signo) {
745            return;
746        }
747        let bit = kernel_signal_bit(signo);
748        let claim = self.guest_send_claims.entry(receiver).or_default();
749        match scope {
750            SendScope::Thread => claim.private |= bit,
751            SendScope::Process => claim.shared |= bit,
752        }
753    }

755    /// Check every claimed copy again (module docs), at a pass that may begin
756    /// a parked observation, where no guest thread holds the turn: drop what
757    /// was taken, flushed, or is blocked now, and find a receiver that now
758    /// waits where it cannot take its copy, or a shared copy left behind by a
759    /// receiver that exited or blocked it while another live thread leaves
760    /// it unblocked. A thread parked where the observation of its own signals
761    /// reaches it (`observe_parked_thread_woken_by_its_own_signal`) takes a
762    /// copy in its own queue there, so only a shared copy is refused for it.
763    pub(crate) fn audit_guest_send_claims(&mut self) -> Option<ClaimRefusal> {
764        let claims: Vec<(DetTid, GuestSendClaim)> = self
765            .guest_send_claims
766            .iter()
767            .map(|(thread, claim)| (*thread, *claim))
768            .collect();
769        for (thread, claim) in claims {
770            let process = self.sigchld_process(thread);
771            let live = self.process_signal_targets(process).contains(&thread)
772                && !self.parked.exit_fences.contains_key(&thread)
773                && !self.logically_killed_threads.contains(&thread)
774                && !self.filed_exit_request(thread);
775            let (standing, refusal) = if live {
776                self.standing_claim(thread, process, claim)
777            } else {
778                // Its own queue went with it; a shared copy stays.
779                let shared = self
780                    .read_shared_pending_of(process, thread)
781                    .map_or(0, |pending| claim.shared & pending);
782                let refusal = (shared != 0)
783                    .then(|| self.retarget_refusal(thread, process, shared))
784                    .flatten();
785                (GuestSendClaim::default(), refusal)
786            };
787            if standing == GuestSendClaim::default() {
788                self.guest_send_claims.remove(&thread);
789            } else {
790                self.guest_send_claims.insert(thread, standing);
791            }
792            if refusal.is_some() {
793                return refusal;
794            }
795        }
796        None
797    }

799    /// What is left of `claim` for `thread`, a live thread of `process`, and
800    /// the refusal it now meets, if any (`audit_guest_send_claims`).
801    fn standing_claim(
802        &self,
803        thread: DetTid,
804        process: DetPid,
805        claim: GuestSendClaim,
806    ) -> (GuestSendClaim, Option<ClaimRefusal>) {
807        let (Ok(state), Some(mask)) = (
808            self.read_guest_signal_state(thread),
809            self.controlled_mask(thread),
810        ) else {
811            // Not readable now: judged at the next pass.
812            return (claim, None);
813        };
814        let shared = claim.shared & state.shared_pending;
815        let private = claim.private & state.thread_pending;
816        // Blocked now: a copy in its own queue waits for it, and a shared one
817        // for whichever thread unblocks it first.
818        if shared & mask != 0
819            && let Some(refusal) = self.retarget_refusal(thread, process, shared & mask)
820        {
821            return (GuestSendClaim::default(), Some(refusal));
822        }
823        let standing = GuestSendClaim {
824            shared: shared & !mask,
825            private: private & !mask,
826        };
827        if standing == GuestSendClaim::default() {
828            return (standing, None);
829        }
830        let refusal = match self.catch_reach(thread) {
831            Ok(_) | Err(SendRefusal::UnknownState(_)) => None,
832            Err(SendRefusal::Parked(_)) if standing.shared == 0 => None,
833            Err(SendRefusal::Parked(_)) => Some((standing.shared, SendRefusal::Parked(thread))),
834            Err(refusal) => Some((standing.shared | standing.private, refusal)),
835        };
836        (
837            standing,
838            refusal.map(|(bits, refusal)| ClaimRefusal {
839                receiver: thread,
840                signal: lowest_signal(bits),
841                reason: ClaimReason::Waits(refusal),
842            }),
843        )
844    }

846    /// The refusal for shared copies `bits` that `thread` was chosen for and
847    /// can no longer take, where another live thread of `process` leaves one
848    /// of them unblocked: Linux wakes that thread (`retarget_shared_pending`).
849    fn retarget_refusal(&self, thread: DetTid, process: DetPid, bits: u64) -> Option<ClaimRefusal> {
850        let unblocked = self
851            .process_signal_targets(process)
852            .into_iter()
853            .filter(|other| *other != thread)
854            .filter_map(|other| self.controlled_mask(other))
855            .fold(0, |unblocked, mask| unblocked | (bits & !mask));
856        (unblocked != 0).then(|| ClaimRefusal {
857            receiver: thread,
858            signal: lowest_signal(unblocked),
859            reason: ClaimReason::Retarget,
860        })
861    }

863    /// `process`'s shared queue, read through `thread` if it still has a
864    /// signal state and otherwise through the process's first live thread.
865    fn read_shared_pending_of(&self, process: DetPid, thread: DetTid) -> Option<u64> {
866        self.read_guest_signal_state(thread)
867            .ok()
868            .or_else(|| {
869                let first = self.process_signal_targets(process).into_iter().next()?;
870                self.read_guest_signal_state(first).ok()
871            })
872            .map(|state| state.shared_pending)
873    }

875    /// A shared copy claimed for a thread of `pid` other than `observed` that
876    /// an observation of `observed`, or a wake of it for a signal from the
877    /// shared queue, could take first, because `observed` leaves it unblocked
878    /// (module docs). Unknown masks count as unblocked.
879    pub(crate) fn contested_guest_send_claim(
880        &self,
881        pid: DetPid,
882        observed: DetTid,
883    ) -> Option<ClaimRefusal> {
884        if self.guest_send_claims.is_empty() {
885            return None;
886        }
887        let mask = self.controlled_mask(observed).unwrap_or(0);
888        self.guest_send_claims
889            .iter()
890            .filter(|(thread, claim)| {
891                **thread != observed && claim.shared != 0 && self.sigchld_process(**thread) == pid
892            })
893            .find_map(|(thread, claim)| {
894                let pending = self.read_shared_pending_of(pid, *thread)?;
895                let contested = claim.shared & pending & !mask;
896                (contested != 0).then(|| ClaimRefusal {
897                    receiver: *thread,
898                    signal: lowest_signal(contested),
899                    reason: ClaimReason::Contested { observed },
900                })
901            })
902    }
