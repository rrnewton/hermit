9//! The scheduler's SIGALRM ledger, for guest SIGALRM handlers on a backend
10//! that runs Detcore inside each guest process (in-guest LiteInst).
11//!
12//! Design: dev-hermit `ai_docs/transient/liteinst-inguest-signal-handlers-design-20261007.md`,
13//! phase 1, step I1a, under <https://github.com/rrnewton/hermit/issues/3520>.
14//!
15//! - A process's runtime publishes whether its SIGALRM disposition is a guest
16//!   handler. While it is, an emulated `alarm`/`setitimer` expiry adds a ledger
17//!   entry instead of sending a physical signal. A second expiry while one is
18//!   pending is absorbed: standard-signal coalescing in the process's one
19//!   shared queue.
20//! - The runtime also publishes each thread's "SIGALRM virtually blocked" bit,
21//!   inside the turn of the call that changes its mask. No expiry commits
22//!   while a thread holds its turn, so the bit is current at every expiry and
23//!   every admission. An entry is *due* when that bit is clear. (Publishing it
24//!   by control message rather than on every request leaves the request wire,
25//!   `Resources`, unchanged.)
26//! - A due entry ends an emulated `pause`: at the pause's own admission, when
27//!   the entry is already due as it is selected, or at the expiry, when the
28//!   pause is already parked. Either way the pause returns EINTR.
29//! - A due entry whose owner is blocked in any other wait records a
30//!   determinism loss: Linux would interrupt that wait, and phase 1 cannot.
31//!   A running thread, or one whose filed request has not blocked, takes the
32//!   entry at its syscall's completion; that delivery is the runtime's.
33//! - One polling wait is modelled instead (dev-hermit dh-ru056 slice 1,
34//!   signal phase-2 design revision 2, section 5.1): a restartable pipe read
35//!   retried after EAGAIN (`InternalIOPolling` with a `read_fd`) on a
36//!   descriptor only guest actions make ready, outside record and replay. The
37//!   entry is reserved to the owner (`ReservedPoll`) and the filed retry made
38//!   runnable. While that probe is unrun, step 3 selects its thread right
39//!   after a group-exit decider (`reserved_probe_to_resume`), so no other
40//!   thread's turn commits between the reservation and the probe. The probe's
41//!   successor request is classified at the next pass's step 2, before the
42//!   sweep (step 1 waits for every queued thread to file), or defensively at
43//!   that request's step-4 head:
44//!   - a retry that moved nothing is replaced by the `InboundSignal` wake, at
45//!     the front of its band (only: a better band or a chaos draw can still
46//!     run first, and the wake grant's own attempt then decides, R1);
47//!   - a retry that moved bytes is a protocol violation charged as a loss
48//!     (G1);
49//!   - a new read of the same descriptor is charged as a loss;
50//!   - any other successor that is not a retry is classified completed
51//!     without further checks: in production the delivery at the read's
52//!     completion, or the request of a scheduler wake that replaced the
53//!     unrun probe (requeued in its band, possibly at the back, not as a
54//!     placed taker). The entry stays pending for delivery at a completion.
55//!
56//!   An unrun probe whose thread is out of the run queue when step 3 begins
57//!   is released with a loss (`release_unqueued_sigalrm_reservation`; no
58//!   production path is known to reach it). Every other polling wait, a read
59//!   that does not pass these checks, an entry whose process already has a
60//!   loss recorded (kept per process: one the runtime reports after a take
61//!   also covers that process's later entries), and a second process's entry
62//!   while one probe is reserved, keep the loss.
63//! - Every change happens at a scheduler commit: an expiry, an admission, the
64//!   step-2 completion check and sweep, the step-3 selection, or the
65//!   successor's step-4 head. So what is pending, what is due, and what is
66//!   reserved is a function of the schedule. One exception, shared with the
67//!   ledger's existing retirement: a thread's retirement
68//!   (`retire_sigalrm_thread`) runs from `logically_kill_thread`, outside the
69//!   turns.
70//!
71//! Nothing publishes a handled SIGALRM until the runtime admits guest
72//! handlers. Phase 1 admits a pipe read in a handling process only on an end
73//! only guests hold, while no descriptor may have left the guest, with the
74//! reader's copy of the description's status the latest any process set,
75//! outside record and replay and schedule replay, and under a handler
76//! without `SA_RESTART`
77//! (`sigalrm_phase1::descriptor_class`, dh-ru056 slice 2); no other read
78//! reaches the reservation. An admitted read whose guest-held marks an export
79//! revokes while it waits stops the run by name when its entry falls due
80//! (`SigalrmLedger::stop`), and so does one whose probe's wake is still
81//! filed, ungranted, when the export commits (`SigalrmLedger::marked_wake`).
82//! An entry that finds another process's probe reserved waits, with no loss,
83//! for a later sweep.

103/// A due SIGALRM entry reserved for one deterministic probe of a
104/// polling pipe read (dh-ru056 slice 1, design revision 2 §5.1):
105/// the entry stays in `pending`; this binds the probe target until
106/// the probe's successor request is classified (at the next pass's
107/// step 2, before the sweep, or at that request's step-4 head), the
108/// target retires, or an unqueued unrun probe is released with a
109/// loss at step 3. Nothing else ends it: a take or a mask
110/// publication that would release it unclassified is deliberately
111/// unreachable, and the owned scheduler code asserts that (G1)
112/// rather than invent restore semantics for the pre-reservation
113/// request.
114#[derive(Debug, Clone, Copy, PartialEq, Eq)]
115pub(crate) struct ReservedPoll {
116    /// Process whose pending entry is reserved.
117    pub(crate) owner: DetPid,
118    /// Only thread that may consume the reservation, by running
119    /// the bound probe request.
120    pub(crate) target: DetTid,
121    /// Descriptor-table identity and fd of the bound read request.
122    pub(crate) read_fd: (detcore_model::fd::FilesId, i32),
123    /// Attempt lineage of the probe request as stored for its
124    /// grant: (`poll_attempt == 0`, this `upgraded_from_attempt`).
125    pub(crate) bound_upgraded_from_attempt: u32,
126}

128/// How the reserved probe's syscall pass ended, read from the
129/// profile fields of the successor request it filed.
130#[derive(Debug, Clone, Copy, PartialEq, Eq)]
131pub(crate) enum ReservedProbeOutcome {
132    /// The successor is the next retry of the same read and the
133    /// probe moved no bytes: substitute the wake (section 6 R2).
134    NoProgressRetry,
135    /// The successor is the next retry but the probe moved bytes: a
136    /// single blocking pipe read that moved bytes returns, so this is
137    /// a protocol violation slice 1 charges as a loss (G1).
138    ProgressRetry,
139    /// Any successor that is not a retry of the bound read, not checked
140    /// further: the probe's read ended without the reserved wake. In
141    /// production it is the due entry's delivery filed by the read's
142    /// completion (R1, post-result), or the request of a scheduler wake
143    /// that replaced the unrun probe, requeued in its band (a cross-task
144    /// drain wake goes to the back of it) rather than as a placed taker.
145    /// Records no loss; the entry stays pending for delivery at a
146    /// completion.
147    Completed,
148    /// The successor is a first attempt of another lineage on the same
149    /// descriptor: a new read began after a completion that delivered
150    /// no due entry, which the completion path never does with an entry
151    /// due (section 5.1 protocol violation). Records a loss.
152    NewRead,
153}

155/// The scheduler's record of guest-handled SIGALRMs.
156#[derive(Debug, Default)]
157pub(crate) struct SigalrmLedger {
158    /// Processes whose SIGALRM disposition is a guest handler.
159    handled: BTreeSet<DetPid>,
160    /// Processes with a pending SIGALRM: at most one each.
161    pending: BTreeSet<DetPid>,
162    /// Each thread's "SIGALRM virtually blocked" bit, as its runtime last
163    /// published it.
164    blocked: BTreeMap<DetTid, bool>,
165    /// Threads whose `InternalIOPolling` retry the run queue has deferred as a
166    /// poller. Kept here because the deferral resets the stored request's
167    /// attempt count (`upgrade_polled_to_runnable`); cleared when the request
168    /// is granted (`clear_nextturn`) or substituted (`force_unblock_thread`).
169    polling: BTreeSet<DetTid>,
170    /// The one reserved poll probe, if any (dh-ru056 slice 1).
171    reserved_poll: Option<ReservedPoll>,
172    /// Pending entries whose determinism loss is already recorded, so a
173    /// stranded entry is reported once.
174    lost: BTreeSet<DetPid>,
175    /// Whether any guest armed a kernel producer of SIGALRM
176    /// (`SigalrmControl::ArmProducer`). Never cleared: the producer may fire
177    /// at any later time.
178    producer_armed: bool,
179    /// The status flags last published for each pipe read description
180    /// (`SigalrmControl::PublishPipeStatus`): the description's status, which
181    /// a process's own copy may not show after a fork (dh-ru056 slice 2,
182    /// review P1-b), with the processes that may hold it. An entry lasts
183    /// while any of them does (`PipeStatus::holders`).
184    pipe_status: BTreeMap<OpenFileId, PipeStatus>,
185    /// The threads whose filed request is the signal wake a no-progress probe
186    /// substituted (`act_on_sigalrm_reserved_poll`) for a polled pipe read
187    /// that relied on guest-held marks, each until its wake is granted or
188    /// replaced (`end_sigalrm_polling_wait`) or it retires. The wake request
189    /// names neither the read nor its descriptor, so this is what tells the
190    /// sweep that the wake's final attempt still rests on those marks (review
191    /// of 29b3e6a8, finding 2). A set: another process's probe can settle,
192    /// and file its own wake, before an earlier wake is granted (finding S1
193    /// of coord7's review of 4d17d5ab).
194    marked_wake: BTreeSet<DetTid>,
195    /// The named refusal that ends the run before the next selection, set
196    /// when a due entry finds an admitted pipe read whose guest-held
197    /// authority was revoked while it waited (`act_on_pending_sigalrm`,
198    /// review P1-a). Taken by the turn loop (`take_sigalrm_stop`).
199    stop: Option<String>,
200}

202/// The latest status of one pipe read description (`SigalrmLedger::pipe_status`).
203#[derive(Debug, Default)]
204struct PipeStatus {
205    /// Its status flags, as the last process to set them published.
206    flags: i32,
207    /// Whether its status can no longer be followed: it may have left a
208    /// process over `SCM_RIGHTS` (`SigalrmControl::UntrackPipeStatus`), or a
209    /// change was published without the serial grant. Every copy then
210    /// differs (`SigalrmControl::PipeStatusDiffers`).
211    untracked: bool,
212    /// The processes that may hold the description: its creator, which
213    /// publishes it at the `pipe2` that made it, each process a holder's fork
214    /// creates (`Scheduler::sigalrm_process_created`), and any later
215    /// publisher. A holder leaves at the close of its last descriptor of it
216    /// (`Scheduler::release_pipe_status`, from the release Detcore sends for
217    /// every description's last local reference) or at its retirement
218    /// (`Scheduler::retire_sigalrm_thread`), and the entry goes with the last
219    /// one, so the ledger keeps only descriptions some process may still read
220    /// while a copy another process changed stays visible to every alias
221    /// (review of 29b3e6a8, finding 3). A process that receives the
222    /// description over `SCM_RIGHTS` is not counted: a send over a guest-held
223    /// channel revokes no mark, but it marks the description untracked
224    /// before every attempt (`Detcore::untrack_sent_pipe_status`,
225    /// `Detcore::pipe_reads_an_attempt_passes`), and the receiver, whose
226    /// Detcore records the descriptor as a description of its own, marks
227    /// that one untracked at the receipt
228    /// (`Detcore::untrack_received_pipe_status`). Phase 1 admits no read of
229    /// either (finding B1 of coord7's review of 4d17d5ab).
230    holders: BTreeSet<DetPid>,
231}

260    /// Records `process`'s SIGALRM disposition, published by its runtime inside
261    /// the turn of the call that changed it. A handler that becomes ignored or
262    /// default discards a pending entry, as Linux discards a pending signal that
263    /// becomes ignored. The runtime refuses the change to default while an
264    /// entry is pending, so a default-acted signal is never discarded here.
265    pub(crate) fn set_sigalrm_handled(&mut self, process: DetPid, handled: bool) {
266        if !handled {
267            self.assert_no_reserved_poll_release(
268                process.as_raw(),
269                "its disposition left the handler",
270            );
271        }
272        if handled {
273            self.sigalrm.handled.insert(process);
274        } else {
275            self.sigalrm.handled.remove(&process);
276            self.sigalrm.pending.remove(&process);
277            self.sigalrm.lost.remove(&process);
278        }
279    }

281    /// Decides a SIGALRM control message from `thread`'s Detcore, sent in its
282    /// turn before the call reaches the kernel; returns whether it is refused.
283    ///
284    /// While no process handles SIGALRM, nothing is refused, so runs without a
285    /// guest handler behave as before; an allowed producer arming is recorded.
286    /// Otherwise a sender that does not hold the serial grant is refused: its
287    /// question could race a commit. A send is refused when it reaches a
288    /// handling process (one the caller cannot name could be one), every
289    /// producer arming is refused, and a recurring `ITIMER_REAL` is refused in
290    /// a handling process.
291    pub(crate) fn sigalrm_control(&mut self, thread: DetTid, control: SigalrmControl) -> bool {
292        // The runtime's publications (phase 1 step I3) record what its
293        // runtime already changed inside the caller's turn; they hold whether
294        // or not any process handles SIGALRM yet.
295        let process = self.sigchld_process(thread);
296        match control {
297            SigalrmControl::Publish { handled, blocked } => {
298                self.set_sigalrm_handled(process, handled);
299                self.set_sigalrm_blocked(thread, blocked);
300                return false;
301            }
302            SigalrmControl::PublishBlocked(blocked) => {
303                self.set_sigalrm_blocked(thread, blocked);
304                return false;
305            }
306            SigalrmControl::PublishPipeStatus { id, flags } => {
307                // A change published without the serial grant, while a
308                // process handles SIGALRM, was recorded at a moment the host
309                // chose: fail closed rather than keep it as the latest.
310                let untimed = !self.sigalrm.handled.is_empty() && !self.holds_serial_grant(thread);
311                let status = self.sigalrm.pipe_status.entry(id).or_default();
312                status.flags = flags;
313                status.untracked |= untimed;
314                status.holders.insert(process);
315                return false;
316            }
317            SigalrmControl::UntrackPipeStatus { id } => {
318                let status = self.sigalrm.pipe_status.entry(id).or_default();
319                status.untracked = true;
320                status.holders.insert(process);
321                return false;
322            }
323            SigalrmControl::DeliveryLost => {
324                crate::detlog::write_loss_notice(&format!(
325                    "thread {thread} of process {process} took a pending guest-handled SIGALRM, but the runtime could not deliver it"
326                ));
327                self.sigalrm.lost.insert(process);
328                return false;
329            }
330            SigalrmControl::EntryDeliveryUnfaithful => {
331                crate::detlog::write_loss_notice(&format!(
332                    "thread {thread} of process {process} delivers a guest-handled SIGALRM before a syscall that has not run; its handler cannot see the registers Linux would show it (rcx and r11 as the syscall instruction left them)"
333                ));
334                self.sigalrm.lost.insert(process);
335                return false;
336            }
337            _ => {}
338        }
339        // Its questions, like every other control, are refused to a caller
340        // without the serial grant while any process handles SIGALRM: the
341        // answer could race a commit. (A handling process is sequentialized,
342        // so its own calls hold the grant.)
343        if !self.sigalrm.handled.is_empty() && !self.holds_serial_grant(thread) {
344            return true;
345        }
346        match control {
347            SigalrmControl::InstallHandler => {
348                // Also refused while the caller's process has a recurring
349                // ITIMER_REAL armed: phase 1 does not model one in a handling
350                // process (it is refused once a handler exists, too).
351                let recurring = self
352                    .blocked
353                    .timed_waiters
354                    .alarm_state(process)
355                    .is_some_and(|(_, interval)| interval != crate::types::LogicalTime::ZERO);
356                let refused = self.sigalrm_producer_armed() || recurring;
357                if refused {
358                    info!(
359                        "[dtid {}] SIGALRM handler refused: a guest armed a kernel producer of SIGALRM, or its process has a recurring ITIMER_REAL (signal phase 1).",
360                        thread
361                    );
362                }
363                return refused;
364            }
365            SigalrmControl::HandlerToDefault | SigalrmControl::PendingEntry => {
366                return self.sigalrm.pending.contains(&process);
367            }
368            SigalrmControl::DueEntry => return self.sigalrm_due(thread),
369            SigalrmControl::GuestHeldMarksRevoked => return self.guest_held_marks_revoked,
370            SigalrmControl::PipeStatusDiffers { id, flags } => {
371                return self
372                    .sigalrm
373                    .pipe_status
374                    .get(&id)
375                    .is_some_and(|published| published.untracked || published.flags != flags);
376            }
377            SigalrmControl::TakeEntry => {
378                let taken = self.take_sigalrm(process, thread);
379                if taken {
380                    info!(
381                        "[dtid {}] takes its process's pending SIGALRM for delivery to its handler.",
382                        thread
383                    );
384                }
385                return taken;
386            }
387            _ => {}
388        }
389        if self.sigalrm.handled.is_empty() {
390            if control == SigalrmControl::ArmProducer {
391                self.sigalrm.producer_armed = true;
392            }
393            return false;
394        }
395        if !self.holds_serial_grant(thread) {
396            return true;
397        }
398        if control == SigalrmControl::UnadmittedStdioIo {
399            if self.sigalrm_due(thread) {
400                self.record_sigalrm_loss(
401                    DetPid::from_raw(thread.as_raw()),
402                    thread,
403                    "a due SIGALRM found it entering I/O on inherited stdio that may sleep unadmitted",
404                );
405            }
406            return false;
407        }
408        let refused = match control {
409            SigalrmControl::SendTo(target) => {
410                self.sigalrm.handled.contains(&self.sigchld_process(target))
411            }
412            SigalrmControl::SendToUnnamed | SigalrmControl::ArmProducer => true,
413            SigalrmControl::UnadmittedStdioIo
414            | SigalrmControl::InstallHandler
415            | SigalrmControl::HandlerToDefault
416            | SigalrmControl::PendingEntry
417            | SigalrmControl::Publish { .. }
418            | SigalrmControl::PublishBlocked(_)
419            | SigalrmControl::DueEntry
420            | SigalrmControl::TakeEntry
421            | SigalrmControl::DeliveryLost
422            | SigalrmControl::EntryDeliveryUnfaithful
423            | SigalrmControl::GuestHeldMarksRevoked
424            | SigalrmControl::PublishPipeStatus { .. }
425            | SigalrmControl::UntrackPipeStatus { .. }
426            | SigalrmControl::PipeStatusDiffers { .. } => unreachable!("answered above"),
427            SigalrmControl::ArmRecurringTimer => {
428                self.sigalrm.handled.contains(&self.sigchld_process(thread))
429            }
430        };
431        if refused {
432            info!(
433                "[dtid {}] {:?} refused: a guest handles SIGALRM (signal phase 1).",
434                thread, control
435            );
436        }
437        refused
438    }

456    /// Review gate G1: in slice 1 a reservation is never released back to
457    /// `Pending`. The argument rests on this ordering, which the code
458    /// enforces where it says so. The target is single-threaded. From the
459    /// reservation (step 2) until its probe is granted, step 3 selects no
460    /// other thread except a group-exit decider (`reserved_probe_to_resume`),
461    /// and the target itself holds no turn; the probe is a retry inside the
462    /// same read, not a syscall entry, so no mask or disposition publication
463    /// of its own runs in it. If the target is out of the run queue when step
464    /// 3 begins, the reservation is released with a loss, not back to
465    /// `Pending` (`release_unqueued_sigalrm_reservation`). Any successor that
466    /// is not a retry, including the request of a scheduler wake that
467    /// replaced the unrun probe (requeued in its band, possibly at the back),
468    /// is classified completed, without further checks, before it is
469    /// granted, and the entry stays pending. The successor
470    /// request is filed before the next pass's step 2 (step 1 waits for every
471    /// queued thread to file) and classified there, before the sweep, or at
472    /// that request's step-4 head; either way before the request is granted.
473    /// A completed read's successor is its delivery's `InboundSignal` turn
474    /// (`Detcore::complete_syscall`, `deliver_due_sigalrm`), so the take in
475    /// that turn comes after the classification. A publication or take that
476    /// would release the reservation therefore cannot occur; one that does
477    /// is a defect of this argument, which stops the run rather than invent
478    /// restore semantics for the pre-reservation request (design rev.2
479    /// section 5, approval gate G1).
480    fn assert_no_reserved_poll_release(&self, raw: i32, what: &str) {
481        if let Some(reserved) = self.sigalrm.reserved_poll {
482            assert!(
483                reserved.target.as_raw() != raw && reserved.owner.as_raw() != raw,
484                "dh-ru056 slice 1 G1: the reserved pipe-read probe's thread {} would \
485                 release its reservation because {what}; slice 1 keeps release unreachable",
486                reserved.target
487            );
488        }
489    }

496    /// Record the reservation created by the step-2 reserved-probe
497    /// transition. Asserts the slice-1 single-flight discipline:
498    /// a reservation already being outstanding would mean a second
499    /// reserve raced the first probe, which placed precedence
500    /// forbids by construction.
501    pub(crate) fn record_sigalrm_reserved_poll(&mut self, reserved: ReservedPoll) {
502        assert!(
503            self.sigalrm.reserved_poll.is_none(),
504            "dh-ru056 slice 1: a second reserved poll while one is outstanding"
505        );
506        self.sigalrm.reserved_poll = Some(reserved);
507    }

517    /// Reserved-probe eligibility for the slice-1 pipe-read shape:
518    /// exactly the request `detcore`'s pipe read files for its
519    /// polling probes (`execute_nonblockable_fd_syscall`): an
520    /// `InternalIOPolling` resource plus `read_fd`, restartable
521    /// (`signal_interrupt_errno` is `ERESTARTSYS`, design rev.2
522    /// section 5.1), with no earlier progress, on a descriptor whose
523    /// readiness only guest actions change (`polls_only_guest_state`,
524    /// and not a named FIFO a process outside the container may hold):
525    /// otherwise whether the probe finds data or the wake substitutes
526    /// would depend on host timing. Any other errno (a deadline wait's
527    /// EINTR, or none) must never be replaced by the restart table's
528    /// outcome. Not under record or replay: there a polled read keeps the
529    /// guest-state authority taken at its entry, which descriptor exports do
530    /// not revoke (`execute_nonblockable_fd_syscall`), and the record/replay
531    /// test the design requires (D6) does not exist yet. Not under a schedule
532    /// replay either, whichever cursor replays it (`has_schedule_replay`: a
533    /// legacy record's `replayer` or a slice-boundary record's
534    /// `boundary_replayer`): a replay yield would read as the read's
535    /// completion and settle the probe (slice 2, review P2). Phase 1's gate
536    /// refuses such a read first (`ProcessFacts::schedule_trace`), so this
537    /// refusal is reached only if that gate is relaxed (dev-hermit
538    /// dh-xw2yzs). Returns the request identity to bind, or `None` to keep
539    /// phase 1's loss.
540    fn reservable_pipe_read(
541        &self,
542        request: &Resources,
543    ) -> Option<(detcore_model::fd::FilesId, i32)> {
544        if request.previous_attempt_made_progress
545            || request.signal_interrupt_errno()
546                != Some(reverie::syscalls::Errno::ERESTARTSYS.into_raw())
547            || !request
548                .resources
549                .contains_key(&ResourceID::InternalIOPolling)
550            || !self.polls_only_guest_state(request)
551            || request.polls_a_named_fifo
552            || self.recordreplay_modes
553            || self.has_schedule_replay()
554        {
555            return None;
556        }
557        request.read_fd
558    }

560    /// Reserve `process`'s due entry for one deterministic probe
561    /// of its polling pipe read (dh-ru056 slice 1 §5.1). The filed
562    /// substate is normalized by the same upgrade step 4 applies
563    /// (`upgraded_to_runnable`); the deferred-poller substate
564    /// keeps its stored request untouched and is only restored to
565    /// the run queue. Nothing is substituted here: the probe must
566    /// run first so a writer commit that preceded the expiry is
567    /// observed by the read (R1) instead of being masked by an
568    /// early wake. Returns whether a reservation was created.
569    fn reserve_sigalrm_poll(&mut self, process: DetPid, thread: DetTid) -> bool {
570        // Single flight: another process's probe is outstanding. The
571        // sweep waits for it before calling here (`act_on_pending_sigalrm`,
572        // no loss); this check keeps the single flight if a caller does
573        // not.
574        if self.sigalrm.reserved_poll.is_some() {
575            return false;
576        }
577        let deferred = self.sigalrm.polling.contains(&thread);
578        let filed = self
579            .next_turns
580            .get(&thread)
581            .and_then(|turn| turn.req.try_read())
582            .filter(|request| request.is_ok())
583            .map(|request| request.unwrap());
584        let Some(mut request) = filed else {
585            return false;
586        };
587        let Some(read_fd) = self.reservable_pipe_read(&request) else {
588            return false;
589        };
590        // The third slice-1 admission gate. Placed precedence is enforced
591        // where step 3 selects (`reserved_probe_to_resume`): the probe
592        // resumes right after a group-exit decider while it is unrun. So
593        // the reservation needs only what that selection and the poller
594        // restore below need: no open selection (the restore is a queue
595        // operation) and the thread queued to run. An entry whose loss is
596        // already recorded is not reserved again: the loss stands, and the
597        // entry is delivered at a completion as before. `lost` is kept per
598        // process, not per entry: a loss the runtime reports after its take
599        // (`DeliveryLost`, `EntryDeliveryUnfaithful`) stays recorded until
600        // the next take, so a later, distinct entry of that process is
601        // refused here too, with no second notice. Fail-closed and
602        // deterministic; phase 1's own rule, which this slice leaves as is.
603        if self.run_queue.tentative_pop_in_progress()
604            || !self.run_queue.contains_tid(thread)
605            || self.sigalrm.lost.contains(&process)
606        {
607            return false;
608        }
609        let bound_upgraded_from_attempt = request.upgraded_from_attempt.max(request.poll_attempt);
610        self.record_sigalrm_reserved_poll(ReservedPoll {
611            owner: process,
612            target: thread,
613            read_fd,
614            bound_upgraded_from_attempt,
615        });
616        if deferred {
617            // Deferred poller: step 4 already rewrote the stored request
618            // to its runnable copy and backed the thread off. Restore its
619            // normal priority and drop its poll deadline (section 5.1);
620            // the stored request is not rewritten.
621            self.run_queue.restore_poller_priority(thread);
622            self.forget_poll_deadline(thread);
623        } else {
624            // Filed substate: normalize with the same upgrade step 4
625            // applies, in place, so the stored request becomes the
626            // runnable probe (attempt 0). In place, not
627            // `substitute_request`: substituting would mint a second
628            // Ivar in between that retired/Cancelled the live
629            // request's response token.
630            request = request.upgraded_to_runnable();
631            let turn = self
632                .next_turns
633                .get_mut(&thread)
634                .expect("reservation target has a filed request");
635            turn.req = crate::ivar::Ivar::full(Ok(request));
636        }
637        debug_assert_eq!(
638            self.reserved_probe_to_resume(),
639            Some((process, thread)),
640            "a new reservation's probe is unrun and queued for step 3"
641        );
642        true
643    }

645    /// The reserved probe step 3 resumes next, with its process: the
646    /// outstanding reservation's target while its stored request is still
647    /// the unrun bound probe (`InternalIOPolling` on the bound `read_fd`,
648    /// attempt 0 at the bound lineage) and it is queued. Step 3 selects it
649    /// right after a group-exit decider (design rev.2 section 5, placed
650    /// precedence: the `sigchld_takers` class), ahead of signal takers,
651    /// alarm takers, `rt_sigreturn` continuations and a vfork child, so no
652    /// other thread's turn commits between the reservation and the probe.
653    /// Once the probe is granted, or a wake replaced it, this is `None`.
654    pub(super) fn reserved_probe_to_resume(&self) -> Option<(DetPid, DetTid)> {
655        let reserved = self.unrun_sigalrm_reserved_probe()?;
656        self.run_queue
657            .contains_tid(reserved.target)
658            .then_some((reserved.owner, reserved.target))
659    }

661    /// The outstanding reservation while its target's stored request is
662    /// still the unrun bound probe, queued or not.
663    fn unrun_sigalrm_reserved_probe(&self) -> Option<ReservedPoll> {
664        let reserved = self.sigalrm.reserved_poll?;
665        let request = self
666            .next_turns
667            .get(&reserved.target)
668            .and_then(|turn| turn.req.try_read())
669            .and_then(Result::ok)?;
670        let unrun = request
671            .resources
672            .contains_key(&ResourceID::InternalIOPolling)
673            && request.read_fd == Some(reserved.read_fd)
674            && request.poll_attempt == 0
675            && request.upgraded_from_attempt == reserved.bound_upgraded_from_attempt;
676        unrun.then_some(reserved)
677    }

679    /// Fails closed on an unrun reserved probe whose thread is out of the
680    /// run queue when step 3 begins: step 3 cannot select it, so its
681    /// precedence would be outlived by every turn committed meanwhile.
682    /// Releases the reservation through the loss path
683    /// (`record_sigalrm_reserved_poll_loss`), never back to `Pending`
684    /// (G1). No production path is known to reach this: the reservation
685    /// needs its thread queued, step 3 selects it next, and its only
686    /// happens-before hold is its own checkpoint, a successor request the
687    /// step-4 head classifies before the hold parks it.
688    pub(super) fn release_unqueued_sigalrm_reservation(&mut self) {
689        let Some(reserved) = self.unrun_sigalrm_reserved_probe() else {
690            return;
691        };
692        if self.run_queue.contains_tid(reserved.target) {
693            return;
694        }
695        self.record_sigalrm_reserved_poll_loss(
696            reserved.owner,
697            reserved.target,
698            "its reserved pipe-read probe left the run queue before it ran",
699        );
700    }

702    /// Successor classification of an outstanding reserved probe,
703    /// from the scheduler-owned profile fields of the request the
704    /// probe's syscall pass filed. `None` means no classifiable
705    /// successor has arrived yet: the stored request still reads
706    /// as the bound probe through every observable field (an
707    /// actual retry whose syscall pass already ran differs by
708    /// `poll_attempt`/`upgraded_from_attempt` lineage; a
709    /// completion differs by resource/read_fd shape).
710    fn peek_sigalrm_reserved_poll_result(&self) -> Option<(ReservedPoll, ReservedProbeOutcome)> {
711        let reserved = self.sigalrm.reserved_poll?;
712        let successor = self
713            .next_turns
714            .get(&reserved.target)
715            .and_then(|turn| turn.req.try_read())
716            .filter(|request| request.is_ok())
717            .map(|request| request.unwrap())?;
718        let is_retry = successor
719            .resources
720            .contains_key(&ResourceID::InternalIOPolling)
721            && successor.read_fd == Some(reserved.read_fd);
722        if !is_retry {
723            return Some((reserved, ReservedProbeOutcome::Completed));
724        }
725        if successor.poll_attempt == 0 {
726            if successor.upgraded_from_attempt == reserved.bound_upgraded_from_attempt {
727                // The stored request is still the bound probe itself:
728                // the probe has not granted, so no successor exists
729                // yet to classify.
730                return None;
731            }
732            // A first attempt of another lineage: a new read of the
733            // same descriptor began, so the bound read ended without
734            // its due entry's delivery. A retry of the bound read
735            // advances its lineage.
736            return Some((reserved, ReservedProbeOutcome::NewRead));
737        }
738        Some((
739            reserved,
740            if successor.previous_attempt_made_progress {
741                ReservedProbeOutcome::ProgressRetry
742            } else {
743                ReservedProbeOutcome::NoProgressRetry
744            },
745        ))
746    }

748    /// Act on a classified reserved probe at the step-2 completion
749    /// check: substitute the successor retry with the signal wake
750    /// (section 6 R2 wake/state), suffixed
751    /// `.sigalrm_wake_probe` in the durable run-marker trail so a
752    /// substitution before a data-ready probe remains visible.
753    fn act_on_sigalrm_reserved_poll(
754        &mut self,
755        (reserved, outcome): (ReservedPoll, ReservedProbeOutcome),
756    ) {
757        match outcome {
758            ReservedProbeOutcome::ProgressRetry => {
759                // G1: a single blocking pipe read that moved bytes
760                // returns; it cannot still be polling the same read.
761                // Seeing progress here is a protocol violation, not a
762                // state to carry across retries. (Defensive: slice 1
763                // reserves only a read with no earlier progress, and
764                // the probe is its one attempt.)
765                self.record_sigalrm_reserved_poll_loss(
766                    reserved.owner,
767                    reserved.target,
768                    "its reserved pipe-read probe reported progress but re-polled, \
769                     which slice 1 keeps unrepresentable (G1)",
770                );
771            }
772            ReservedProbeOutcome::NoProgressRetry => {
773                let taken = self.take_sigalrm_reserved_poll();
774                debug_assert_eq!(taken, Some(reserved));
775                // Whether the read's readiness rested on guest-held marks,
776                // read from the retry before the wake replaces it.
777                let relies_on_marks = self
778                    .next_turns
779                    .get(&reserved.target)
780                    .and_then(|turn| turn.req.try_read())
781                    .is_some_and(|request| {
782                        request.is_ok_and(|request| request.relies_on_guest_held_marks)
783                    });
784                // The successor retry is still queued (filed by
785                // the probe's syscall pass or the harness);
786                // dequeue it so force-unblock's requeue is its
787                // only queue entry.
788                self.run_queue.remove_tid(reserved.target);
789                // Front of its band only: a thread in a better band,
790                // or a targeted-chaos draw (`force_unblock_thread_at`),
791                // can still run before the wake, and the wake grant's
792                // own attempt then decides (R1: data that arrived in
793                // between is returned). Placed precedence for the wake
794                // itself would break the bound of
795                // https://github.com/rrnewton/hermit/issues/4929 (design
796                // section 5.1 amendment pending with its owner).
797                let requeued = self.force_unblock_thread_at(
798                    reserved.target,
799                    Self::sigalrm_wake_probe(reserved.target),
800                    true,
801                );
802                debug_assert!(
803                    requeued,
804                    "the no-progress wake requeues the reserved probe's thread"
805                );
806                // The wake's grant makes the read's final attempt, which
807                // still rests on those marks: an export committed before that
808                // grant stops the run (`act_on_pending_sigalrm`).
809                if requeued && relies_on_marks {
810                    self.sigalrm.marked_wake.insert(reserved.target);
811                }
812            }
813            ReservedProbeOutcome::Completed => {
814                let taken = self.take_sigalrm_reserved_poll();
815                debug_assert_eq!(taken, Some(reserved));
816                // The read ended without a wake: its result stands
817                // (R1) and the entry remains pending for the delivery
818                // at its completion (the successor itself, or the
819                // completion of the call a scheduler wake ended).
820            }
821            ReservedProbeOutcome::NewRead => {
822                self.record_sigalrm_reserved_poll_loss(
823                    reserved.owner,
824                    reserved.target,
825                    "its reserved pipe-read probe's read ended and a new read began \
826                     without the due entry's delivery (section 5.1)",
827                );
828            }
829        }
830    }

832    /// Record determinism loss for `process`'s pending entry (the
833    /// reserved-probe completion check's protocol-violation arm).
834    pub(crate) fn record_sigalrm_reserved_poll_loss(
835        &mut self,
836        process: DetPid,
837        thread: DetTid,
838        why: &str,
839    ) {
840        // A consumed reservation whose probe turn then cannot be
841        // accounted for: settle it before recording the loss.
842        if self.sigalrm.reserved_poll.map(|r| r.target) == Some(thread) {
843            let _ = self.take_sigalrm_reserved_poll();
844        }
845        self.record_sigalrm_loss(process, thread, why);
846    }

848    /// Settles an outstanding reservation of `thread` when its successor
849    /// request reaches step 4 as the selected head unclassified. In
850    /// production the step-2 check classifies the successor first (step 1
851    /// waits for every queued thread to file), so this is the defensive path
852    /// for a successor filed after that check (G2: still before step 4 can
853    /// defer it). Returns whether the wake was substituted: step 4 must then
854    /// end this turn rather than act on `thread`'s stale retry, so the
855    /// selection step 3 opened is committed first, and the substitution's
856    /// requeue is the thread's only queue entry. A completed or progressed
857    /// probe leaves the selection open and step 4 goes on with the head
858    /// request.
859    pub(super) fn act_on_sigalrm_reserved_head(&mut self, thread: DetTid) -> bool {
860        let Some(element) = self
861            .peek_sigalrm_reserved_poll_result()
862            .filter(|(reserved, _)| reserved.target == thread)
863        else {
864            return false;
865        };
866        let substitutes = element.1 == ReservedProbeOutcome::NoProgressRetry;
867        if substitutes {
868            let popped = self.run_queue.commit_tentative_pop();
869            assert_eq!(popped, thread, "step 4's head is the selected thread");
870        }
871        self.act_on_sigalrm_reserved_poll(element);
872        substitutes
873    }

911    /// Diverts an expiry of `signal` for `process` into the ledger when the
912    /// process handles SIGALRM. Returns whether it was diverted; otherwise the
913    /// caller sends the signal as before.
914    pub(crate) fn divert_sigalrm(&mut self, process: DetPid, signal: Signal) -> bool {
915        if signal != Signal::SIGALRM || !self.sigalrm.handled.contains(&process) {
916            return false;
917        }
918        if self.sigalrm.pending.insert(process) {
919            info!(
920                "[dpid {}] SIGALRM expired; a guest handler is installed, so it is pending in the ledger.",
921                process
922            );
923        } else {
924            info!(
925                "[dpid {}] SIGALRM expired while one was already pending; coalesced.",
926                process
927            );
928        }
929        self.act_on_pending_sigalrm(process);
930        true
931    }

933    /// The sweep at the start of step 2, after queued plain sleeps are
934    /// registered (`Scheduler::step2_register_queued_sleeps`): acts on every
935    /// pending entry, in process order. It records the loss of a thread that
936    /// blocked in a wait admitted with its entry already due, which, under
937    /// first-pass registration, includes a plain sleep filed in the last pass. It runs before the timed
938    /// events, so a sleep that blocked and is now expiring is seen blocked.
939    pub(crate) fn step2_sigalrm_ledger(&mut self) {
940        // Reserved-probe completion check (dh-ru056 slice 1 §5.1,
941        // review gate G2): classify the probe's successor request
942        // before the sweep acts on any other entry, and so before
943        // step 4 can defer the successor. A settled reservation is
944        // then free for another process the sweep finds due in a
945        // polling read (single flight). A reservation the sweep
946        // creates below has no successor yet, and a silent
947        // outstanding one means the probe has not granted: either
948        // stays outstanding until a later pass.
949        if let Some(reserved) = self.peek_sigalrm_reserved_poll_result() {
950            self.act_on_sigalrm_reserved_poll(reserved);
951        }
952        let pending: Vec<DetPid> = self.sigalrm.pending.iter().copied().collect();
953        for process in pending {
954            self.act_on_pending_sigalrm(process);
955        }
956    }

961    /// the same selected turn. Returns whether it was; the caller then grants
962    /// the turn.

975    /// Takes `process`'s entry for delivery, if it has one and it is due for
976    /// `thread`. The caller has checked that `thread` holds the serial grant.
977    pub(crate) fn take_sigalrm(&mut self, process: DetPid, thread: DetTid) -> bool {
978        self.assert_no_reserved_poll_release(process.as_raw(), "its entry was taken unclassified");
979        if !self.sigalrm.handled.contains(&process)
980            || self.sigalrm.blocked.get(&thread) != Some(&false)
981            || !self.sigalrm.pending.remove(&process)
982        {
983            return false;
984        }

989    /// Forgets `thread`, and its process's ledger state when the thread was
990    /// its process's leader: Linux drops pending signals at exit.
991    pub(crate) fn retire_sigalrm_thread(&mut self, thread: DetTid, process: DetPid) {
992        self.sigalrm.blocked.remove(&thread);
993        self.sigalrm.polling.remove(&thread);
994        // A reservation bound to the retiring thread dies with it:
995        // its probe will never grant, and a stale reservation
996        // would block every later reserve (failed wake, G2).
997        if self.sigalrm.reserved_poll.map(|r| r.target) == Some(thread) {
998            let _ = self.take_sigalrm_reserved_poll();
999        }
1000        self.sigalrm.marked_wake.remove(&thread);
1001        if thread.as_raw() == process.as_raw() {
1002            self.sigalrm.handled.remove(&process);
1003            self.sigalrm.pending.remove(&process);
1004            self.sigalrm.lost.remove(&process);
1005            // A retired process holds no descriptor.
1006            self.sigalrm.pipe_status.retain(|_, status| {
1007                status.holders.remove(&process);
1008                !status.holders.is_empty()
1009            });
1010        }
1011    }

1056    /// Wakes, reports or leaves `process`'s pending entry according to where its
1057    /// thread is.
1058    fn act_on_pending_sigalrm(&mut self, process: DetPid) {
1059        let thread = Self::sigalrm_owner(process);
1060        if !self.next_turns.contains_key(&thread) {
1061            // The process is gone; its pending signal goes with it.
1062            self.sigalrm.pending.remove(&process);
1063            self.sigalrm.lost.remove(&process);
1064            return;
1065        }
1066        match self.sigalrm.blocked.get(&thread) {
1067            // Blocked: the entry stays pending, as in Linux.
1068            Some(true) => return,
1069            Some(false) => {}
1070            // Every request of a process that handles SIGALRM carries the bit.
1071            // Without it, eligibility is unknown, so fail closed.
1072            None => {
1073                self.record_sigalrm_loss(process, thread, "its SIGALRM eligibility is unknown");
1074                return;
1075            }
1076        }
1077        if self.guest_held_marks_revoked && self.sigalrm.marked_wake.contains(&thread) {
1078            // A no-progress probe of a read admitted on guest-held marks was
1079            // replaced by the signal wake, whose grant makes the read's final
1080            // attempt; the wake is not placed, so a better band could run
1081            // first, and its export has revoked the marks that attempt rests
1082            // on. Whether it finds data or returns EINTR may now depend on a
1083            // process outside the guest: stop the run by name before the wake
1084            // is granted (review of 29b3e6a8, finding 2).
1085            self.stop_for_revoked_authority(thread);
1086            return;
1087        }
1088        if !matches!(self.thread_status(thread), ThreadStatus::NotRunning) {
1089            if self.sigalrm_reserved_poll_target() == Some(thread) {
1090                // Outstanding reservation: the probe has not yet
1091                // produced a successor; leave pending, no loss.
1092                return;
1093            }
1094            if self.in_polling_wait(thread) {
1095                if self.waits_on_revoked_guest_held_marks(thread) {
1096                    // Phase 1 admitted this pipe read on guest-held marks
1097                    // (its gate refuses one once they are revoked), and an
1098                    // export revoked them while it waited: whether its probe
1099                    // finds data may now depend on a process outside the
1100                    // guest, so no probe is reserved. Linux would interrupt
1101                    // the read here; leaving it to wait, with only a loss
1102                    // recorded, could hold it until data or forever. Stop the
1103                    // run by name instead (dh-ru056 slice 2, review P1-a).
1104                    self.stop_for_revoked_authority(thread);
1105                    return;
1106                }
1107                if self.sigalrm.reserved_poll.is_some() {
1108                    // Single flight: another process's probe is outstanding
1109                    // (this thread's own returned above). The entry stays
1110                    // pending with no loss, and every later sweep tries
1111                    // again (step 2 sweeps every pending entry each pass),
1112                    // so it is reserved once that probe settles, within that
1113                    // probe's own lifetime: its unrun probe resumes at the
1114                    // next selection with placed precedence, and the next
1115                    // pass's completion check settles it. Nothing is released
1116                    // back to pending, since nothing was reserved (G1); a
1117                    // read that ends meanwhile delivers the entry at its
1118                    // completion, as any call does (coord7 review of
1119                    // ec9b2177, S3).
1120                    return;
1121                }
1122                // dh-ru056 slice 1 (§5.1): reserve a deterministic
1123                // probe for eligible pipe reads instead of
1124                // recording the loss the phase-1 sweep recorded.
1125                if !self.reserve_sigalrm_poll(process, thread) {
1126                    self.record_sigalrm_loss(
1127                        process,
1128                        thread,
1129                        "a due SIGALRM found it in a polling wait that phase 1 cannot interrupt",
1130                    );
1131                }
1132            }
1133            // Otherwise running, or a filed request that has not blocked: a
1134            // pause is resolved at its admission, any other call takes the
1135            // entry at its completion.
1136            return;
1137        }
1138        if self.filed_pause(thread) {
1139            info!("[dtid {}] a pending SIGALRM wakes its pause.", thread);
1140            self.force_unblock_thread(thread, Self::sigalrm_wake(thread));
1141        } else {
1142            self.record_sigalrm_loss(
1143                process,
1144                thread,
1145                "a due SIGALRM found it blocked in a wait that phase 1 cannot interrupt",
1146            );
1147        }
1148    }

1150    /// Whether `thread`'s filed request is a polled read whose guest-state
1151    /// readiness rested on guest-held marks that a descriptor export has
1152    /// since revoked (`Scheduler::polls_only_guest_state`).
1153    fn waits_on_revoked_guest_held_marks(&self, thread: DetTid) -> bool {
1154        self.guest_held_marks_revoked
1155            && self
1156                .next_turns
1157                .get(&thread)
1158                .and_then(|turn| turn.req.try_read())
1159                .is_some_and(|request| {
1160                    request.is_ok_and(|request| {
1161                        request.read_fd.is_some()
1162                            && request.polls_guest_state_only
1163                            && request.relies_on_guest_held_marks
1164                            && request
1165                                .resources
1166                                .contains_key(&ResourceID::InternalIOPolling)
1167                    })
1168                })
1169    }

1172    /// authority was revoked, unless a stop is already set.
1173    fn stop_for_revoked_authority(&mut self, thread: DetTid) {
1174        if self.sigalrm.stop.is_none() {

1176                thread.as_raw(),
1177            );
1178            tracing::error!("[sched] {}", refusal);
1179            self.sigalrm.stop = Some(refusal);
1180        }

1201    /// Whether `thread`'s process holds an entry that is due for it.
1202    fn sigalrm_due(&self, thread: DetTid) -> bool {
1203        let process = DetPid::from_raw(thread.as_raw());
1204        self.sigalrm.handled.contains(&process)
1205            && self.sigalrm.pending.contains(&process)
1206            && self.sigalrm.blocked.get(&thread) == Some(&false)

1234    /// Whether `thread`'s filed request is an emulated `pause`: a wait with no
1235    /// deadline (`SleepUntil(INDEFINITE)`) tagged `PAUSE_FYI` by `handle_pause`.
1236    /// Under in-guest LiteInst it is an ordinary request, since the backend
1237    /// offers no parked signal sites. A `nanosleep` whose deadline saturates
1238    /// files the same resource without the tag; it is not a pause.
1239    fn filed_pause(&self, thread: DetTid) -> bool {
1240        self.next_turns
1241            .get(&thread)
1242            .and_then(|turn| turn.req.try_read())
1243            .is_some_and(|request| {
1244                request.is_ok_and(|resources| {
1245                    resources.fyi == PAUSE_FYI
1246                        && resources.resources.keys().any(|resource| {
1247                        matches!(resource, ResourceID::SleepUntil(deadline) if deadline.is_indefinite())
1248                    })
1249                })
1250            })
1251    }
