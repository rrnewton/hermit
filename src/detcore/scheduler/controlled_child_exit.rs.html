9//! The child-exit `SIGCHLD` of a controlled exit, decided by the scheduler
10//! (SIGSHARE S4, single-threaded parents; design
11//! `ai_docs/2026-10-29-kvm-sigshare-design.md`, sections 7.3, 8.4 and 10).
12//!
13//! On a backend that owns signal delivery (`provides_process_signal_control`,
14//! KVM) every exit is `Controlled`: the backend publishes the child's exit to
15//! its parent itself, inside the child-exit reservation the exit grant
16//! installs (`signal_control.rs`), and before this module Detcore took no
17//! decision of its own. ptrace's parent instead gets the scheduler's
18//! decision: a classification at the child's `Exit` grant
19//! (`classify_child_exit_notification`), a `ChildExit` timer one nanosecond
20//! after it, and at the timer's pop the same send path as any scheduler
21//! signal (`fire_child_exit_alarm` -> `fire_alarm_at` -> `send_guest_signal`),
22//! which logs the decision and wakes a parked parent.
23//!
24//! Here a controlled exit whose parent has one live thread takes that same
25//! path. Only the physical act differs, the design's "sink": the backend's
26//! publication is the physical send, and it has already happened when the
27//! timer pops, because the reservation is a control barrier and the timer
28//! pops only at a maintenance step, which the controlled turn loop runs only
29//! with the barrier down (`do_a_turn_blocking`). So `send_guest_signal` sends
30//! nothing on such a backend; it takes the publication's effect instead
31//! ([`Scheduler::child_exit_sink`]):
32//! - `Queued`: the copy is pending. The parent is woken as on ptrace when
33//!   the copy interrupts its wait (unblocked, and caught or default-fatal);
34//!   an unblocked ignored copy is logged as ptrace's discard, and a blocked
35//!   one wakes nothing ([`Scheduler::queued_sigchld_fate`]);
36//! - `Coalesced`: Linux does not queue a standard signal already pending
37//!   (`legacy_queue`), so no thread is woken, as `note_group_send` decides on
38//!   ptrace;
39//! - `SuppressedExplicitIgnore` or `DiscardedByDispositionChange`: Linux sent
40//!   nothing, logged as the discarded-at-send record does on ptrace, and no
41//!   thread is woken.
42//!
43//! The decision and the effect are checked against each other when the
44//! publication completes ([`Scheduler::check_child_exit_publication`]). A
45//! disagreement Linux cannot produce ends the run by name
46//! (`sigchld-decision-mismatch`), never a silent difference. One disagreement
47//! is expected and allowed: a default-ignored, unblocked `SIGCHLD`, which
48//! Linux discards at generation (`Discard`), is queued by the backend
49//! (design G8; S0 correction 2).
50//!
51//! A parent with more than one live thread takes the same path where the
52//! scheduler models signal targets (SIGSHARE S3b): the timer's send goes to
53//! the thread Linux's `complete_signal` chooses (`kernel_sigchld_target`),
54//! which is woken and resumed first (`sigchld_takers`). Elsewhere it keeps the
55//! backend's decision, as before.

70/// The scheduler's child-exit decisions for controlled exits, from the
71/// child's `Exit` grant to its `ChildExit` timer's pop.
72///
73/// Every entry is made and removed at a committed point under the scheduler
74/// mutex: the grant, the publication's completion (inside the reservation's
75/// control barrier, before any later turn), and the timer's pop.
76#[derive(Debug, Default)]
77pub(crate) struct ControlledChildExits {
78    /// The decision at each child's `Exit` grant, until its publication
79    /// completes.
80    decisions: BTreeMap<DetPid, ChildExitNotification>,
81    /// The publication effect of each child whose `ChildExit` timer has yet to
82    /// pop.
83    effects: BTreeMap<DetPid, ChildExitPublicationEffect>,
84    /// The child whose `ChildExit` timer is sending its `SIGCHLD` right now
85    /// (`send_guest_signal`).
86    sending: Option<DetPid>,
87    /// A decision and an effect that disagree: the run is refused.
88    refusal: Option<String>,
89}
90
91/// What a queued child-exit `SIGCHLD` does to its receiver's parked wait
92/// (`Scheduler::queued_sigchld_fate`).
93#[derive(Debug, Clone, Copy, PartialEq, Eq)]
94pub(crate) enum QueuedSigchld {
95    /// Unblocked and caught (or its state unreadable): it ends the wait.
96    Interrupts,
97    /// Unblocked and ignored, explicitly or by default: Linux discards it at
98    /// generation.
99    DiscardedAtGeneration,
100    /// Blocked: it stays pending, and the wait goes on.
101    StaysPending,
102}
103
104/// Whether a child-exit publication's effect (and its waitability) agrees
105/// with the scheduler's decision at the exit grant. `None` if it does,
106/// otherwise why not.
107pub(crate) fn child_exit_effect_mismatch(
108    decision: ChildExitNotification,
109    effect: ChildExitPublicationEffect,
110    waitable: bool,
111) -> Option<&'static str> {
112    use ChildExitNotification as N;
113    use ChildExitPublicationEffect as E;
114    match (decision, effect) {
115        // Linux sends nothing under an explicit SIG_IGN, and reaps the child
116        // itself (`do_notify_parent`): no status remains to wait for.
117        (N::None, E::SuppressedExplicitIgnore) if !waitable => None,
118        (N::None, E::SuppressedExplicitIgnore) => {
119            Some("the parent ignores SIGCHLD, but the child stayed waitable")
120        }
121        (N::None, _) => Some("the parent ignores SIGCHLD, but the backend did not suppress it"),
122        // Linux discards a default-ignored, unblocked SIGCHLD at generation;
123        // the backend queues it (design G8), which no wake follows.
124        (N::Discard, E::Queued | E::Coalesced) => None,
125        (N::Discard, _) => {
126            Some("SIGCHLD is default-ignored, but the backend reports an explicit ignore")
127        }
128        (N::Deliver, E::Queued | E::Coalesced) => None,
129        (N::Deliver, _) => Some("SIGCHLD is delivered, but the backend did not queue it"),
130        (N::Undecided, _) => None,
131    }
132}

142impl Scheduler {
143    /// The decision recorded at `child`'s controlled exit grant, until its
144    /// publication completes.
145    #[cfg(test)]
146    pub(super) fn controlled_child_exits_decision(
147        &self,
148        child: DetPid,
149    ) -> Option<ChildExitNotification> {
150        self.controlled_child_exits.decisions.get(&child).copied()
151    }

153    /// Whether the scheduler decides the child-exit `SIGCHLD` of a controlled
154    /// exit (`reserve_mode`) of `child` to `parent`: on a backend whose signal
155    /// state Detcore reads from the backend, outside the in-guest delivery
156    /// gate, for a child whose exit reserved its publication (the parent is
157    /// live), when the parent has exactly one live thread, or when the
158    /// scheduler models signal targets (`models_signal_targets`, SIGSHARE
159    /// S3b), so that it chooses which of the parent's threads takes the
160    /// signal as Linux's `complete_signal` does (`kernel_sigchld_target`).
161    pub(super) fn decides_controlled_child_exit(
162        &self,
163        reserve_mode: ExitReserveMode,
164        child: DetPid,
165        parent: DetPid,
166    ) -> bool {
167        reserve_mode == ExitReserveMode::Controlled
168            && reads_signal_state_from_backend(&self.backend)
169            && !self.in_guest_signal_delivery
170            && self.child_exit_reserved(child)
171            && (self.models_signal_targets || self.process_signal_targets(parent).len() == 1)
172    }

174    /// Record the scheduler's decision at the controlled `Exit` grant of
175    /// `child`.
176    pub(super) fn record_controlled_child_exit(
177        &mut self,
178        child: DetPid,
179        decision: ChildExitNotification,
180    ) {
181        self.controlled_child_exits
182            .decisions
183            .insert(child, decision);
184    }
185
186    /// Check a committed child-exit publication against the scheduler's
187    /// decision at the exit grant, if it took one, and keep its effect for the
188    /// `ChildExit` timer. Called when the publication completes, under the
189    /// scheduler mutex, while the reservation's control barrier still holds
190    /// every turn and every maintenance step.
191    pub(super) fn check_child_exit_publication(&mut self, receipt: &ChildExitPublication) {
192        let child = DetPid::from_raw(receipt.completion.child.tgid.as_raw());
193        let Some(decision) = self.controlled_child_exits.decisions.remove(&child) else {
194            return;
195        };
196        if let Some(why) =
197            child_exit_effect_mismatch(decision, receipt.effect, receipt.completion.waitable)
198        {
199            let reason = format!(
200                "HERMIT_REFUSAL sigchld-decision-mismatch: the exit of child {} decided {:?} \
201                 at its grant, and the backend published {:?} (waitable: {}): {}",
202                child, decision, receipt.effect, receipt.completion.waitable, why
203            );
204            tracing::error!("{}", reason);
205            self.controlled_child_exits.refusal.get_or_insert(reason);
206            return;
207        }
208        if matches!(
209            decision,
210            ChildExitNotification::Deliver | ChildExitNotification::Undecided
211        ) {
212            self.controlled_child_exits
213                .effects
214                .insert(child, receipt.effect);
215        }
216    }

218    /// Take the run's `sigchld-decision-mismatch` refusal, if one was made.
219    pub(crate) fn take_sigchld_decision_refusal(&mut self) -> Option<String> {
220        self.controlled_child_exits.refusal.take()
221    }

223    /// Run `fire` with `child` named as the child whose `ChildExit` timer is
224    /// sending (`child_exit_sink`), where a signal control is installed. The
225    /// timer's effect is consumed by its pop either way: a timer whose parent
226    /// is gone sends nothing, and its effect must not stand for a later child
227    /// that reuses the PID.
228    pub(super) fn sending_controlled_child_exit<R>(
229        &mut self,
230        child: DetPid,
231        fire: impl FnOnce(&mut Self) -> R,
232    ) -> R {
233        if !self.signal_control_installed() {
234            return fire(self);
235        }
236        let previous = self.controlled_child_exits.sending.replace(child);
237        let result = fire(self);
238        self.controlled_child_exits.sending = previous;
239        self.controlled_child_exits.effects.remove(&child);
240        result
241    }

243    /// What the `SIGCHLD` a child-exit publication queued for `dettid` does to
244    /// the wait `dettid` is parked in. `Queued` says only that the backend
245    /// queued a copy, not that it interrupts anything. Linux wakes a waiting
246    /// task for a signal only when the signal is unblocked and acted on
247    /// (caught, or default-fatal; `signal_wake_up` from `complete_signal`,
248    /// past `sig_ignored` and `wants_signal`). A blocked copy stays pending
249    /// and wakes nothing. An unblocked one that is ignored, explicitly or by
250    /// default, is discarded at generation (`sig_ignored`), which the backend
251    /// does not model (design G8, S0 correction 2): ptrace's send records that
252    /// discard, so this does too.
253    ///
254    /// The receiver's sets are the backend's (`backend_signal_state`, S2a),
255    /// under the mask the guest published while Detcore holds a private one
256    /// (`under_published_mask`), or under the temporary mask Linux holds
257    /// installed for a call the receiver waits in where there is one
258    /// (`controlled_temporary_mask`: a `ppoll`, a `pselect6`, a parked or
259    /// woken `rt_sigsuspend`; `set_user_sigmask` and `sigsuspend`,
260    /// kernel/signal.c:3272 and 4833 at v6.17), as the receiver was chosen
261    /// (`Scheduler::kernel_sent_signal_mask`), filtered as the drain filters
262    /// a restartable poll (`poll_wake_signals`). A temporary mask the request
263    /// says is unknown leaves the mask as before. Read under the thread's own
264    /// mask, a creator chosen for the `SIGCHLD` its `ppoll` lets in was left
265    /// waiting, the copy pending (the Codex review of
266    /// <https://github.com/rrnewton/hermit/pull/5259>, P1). They are read at the timer's pop, a
267    /// committed point where no guest thread holds the turn, so the answer is
268    /// a function of the schedule. An unreadable state wakes the thread, as
269    /// before this filter.
270    ///
271    /// Without this, a parked `nanosleep` (a wait the grant leaves Undecided)
272    /// was woken for a blocked or default-ignored `SIGCHLD` and answered EINTR
273    /// on KVM, where the sleep cannot judge the wake itself (`signal_sleep`;
274    /// the revastra2 review of https://github.com/rrnewton/hermit/pull/5192,
275    /// F1).
276    pub(super) fn queued_sigchld_fate(&self, dettid: DetTid) -> QueuedSigchld {
277        let bit = super::kernel_signal_bit(libc::SIGCHLD);
278        match self.backend_signal_state(dettid) {
279            Some(Ok(state)) => {
280                let state = match self.controlled_temporary_mask(dettid) {
281                    Ok(Some(temporary)) => crate::syscalls::KernelSignalState {
282                        blocked: temporary,
283                        ..state
284                    },
285                    Ok(None) | Err(_) => self.under_published_mask(dettid, state),
286                };
287                // The pop is the copy's generation, so its discard is decided
288                // here, from the dispositions read now, before the wake: where
289                // the scheduler models signal targets the drain's filter
290                // (`poll_wake_signals`) admits every unblocked standard signal,
291                // since an ordinary send's discard was already decided in its
292                // sender's turn, and this copy has had no such turn.
293                if state.discarded_at_generation() & bit != 0 {
294                    QueuedSigchld::DiscardedAtGeneration
295                } else if super::poll_wake_signals(&state, self.models_signal_targets) & bit != 0 {
296                    QueuedSigchld::Interrupts
297                } else {
298                    QueuedSigchld::StaysPending
299                }
300            }
301            Some(Err(_)) | None => QueuedSigchld::Interrupts,
302        }
303    }

305    /// Commit a child-exit `SIGCHLD` Linux discarded: ptrace's
306    /// discarded-at-send record, no delivery, and a wake that commits no
307    /// `InboundSignal` (`wake_signaled_guest_as`).
308    fn discard_child_exit_sigchld(
309        &mut self,
310        dettid: DetTid,
311        signal: nix::sys::signal::Signal,
312        named: DetTid,
313    ) {
314        info!(
315            target: "detcore::scheduler",
316            "[dtid {}] signal {} is one Linux discards as sent to {}; committing no wake.",
317            dettid, signal, named
318        );
319        // No delivery follows to consume the process's mark
320        // (`dispatch_timed_signal_at`).
321        let process = self.sigchld_process(dettid);
322        self.blocked.sigchld_ready.remove(&process);
323        if self.send_wakes(dettid) {
324            self.wake_signaled_guest_as(dettid, signal, true);
325        }
326    }

328    /// `send_guest_signal`'s physical step where a signal control is
329    /// installed: the backend's child-exit publication already made it, so
330    /// the scheduler acts on its effect. A send of anything else, or of a
331    /// `SIGCHLD` no publication made, would reach a host process that is not
332    /// the guest's: it is refused by name instead.
333    ///
334    /// `dettid` is the receiving thread and `named` the thread Linux names
335    /// (`fire_child_exit_alarm`).
336    pub(super) fn child_exit_sink(
337        &mut self,
338        dettid: DetTid,
339        signal: nix::sys::signal::Signal,
340        named: DetTid,
341    ) {
342        let effect = self
343            .controlled_child_exits
344            .sending
345            .filter(|_| signal == nix::sys::signal::Signal::SIGCHLD)
346            .and_then(|child| self.controlled_child_exits.effects.remove(&child));
347        let Some(effect) = effect else {
348            let reason = format!(
349                "HERMIT_REFUSAL sigchld-decision-mismatch: the scheduler would send signal {} \
350                 to dettid {} on a backend that owns signal delivery, with no publication \
351                 standing for it",
352                signal, dettid
353            );
354            tracing::error!("{}", reason);
355            self.controlled_child_exits.refusal.get_or_insert(reason);
356            self.guest_send_landed = Some(false);
357            return;
358        };
359        self.note_scheduler_signal_sent(dettid, signal as libc::c_int);
360        self.guest_send_landed = Some(true);
361        match effect {
362            ChildExitPublicationEffect::Queued => match self.queued_sigchld_fate(dettid) {
363                QueuedSigchld::Interrupts => {
364                    if self.send_wakes(dettid) {
365                        self.wake_signaled_guest_as(dettid, signal, false);
366                    }
367                }
368                // Decided from the receiver's sets, so it marks no walk: the
369                // walk is suppressed only when the thread the send names
370                // discards it at generation (`sig_ignored` at send), which
371                // `commit_kernel_signal_walk` checks (`discarded_when_sent_to`).
372                // A creator that blocks it has the copy queued, and
373                // `complete_signal` moves `curr_target` to the receiver,
374                // which then discards it as it dequeues it
375                // (`default-child-curr` in tests/c/process_signal_target.c).
376                QueuedSigchld::DiscardedAtGeneration => {
377                    self.discard_child_exit_sigchld(dettid, signal, named);
378                }
379                QueuedSigchld::StaysPending => {
380                    info!(
381                        target: "detcore::scheduler",
382                        "[dtid {}] SIGCHLD blocked by its receiver stays pending; waking no thread.",
383                        dettid
384                    );
385                }
386            },
387            ChildExitPublicationEffect::Coalesced => {
388                self.guest_send_reached_no_walk = true;
389                info!(
390                    target: "detcore::scheduler",
391                    "[dtid {}] SIGCHLD coalesced into the one pending in its process's shared queue; waking no thread.",
392                    dettid
393                );
394            }
395            // Linux sent nothing (`do_notify_parent` sets no signal for an
396            // explicit SIG_IGN), or discarded the copy: no `complete_signal`,
397            // so no receiver walk (`fire_child_exit_alarm`).
398            ChildExitPublicationEffect::SuppressedExplicitIgnore
399            | ChildExitPublicationEffect::DiscardedByDispositionChange => {
400                self.guest_send_reached_no_walk = true;
401                self.discard_child_exit_sigchld(dettid, signal, named);
402            }
403        }
404    }
