1//! `test-harness run` import mode: re-publish cell rows another runner wrote.
2//!
3//! With `E2E_IMPORT_RESULTS=<root>` the harness executes no cell. It reads the
4//! rows that a Buck run of the same plan left under
5//! `<root>/<lane>/manifest_<category>/results.jsonl` (the layout
6//! `ci/buck-e2e/ingest.py` writes) and emits them through the normal
7//! publication path, so `results.jsonl`, JUnit, `summary.json`, the retry
8//! history and the dagrun test counts are produced exactly as for an executed
9//! bucket. Every selected cell must be accounted for: a cell with no row and no
10//! host inapplicability this machine confirms becomes an ERROR row. That is the
11//! executed-equals-plan gate for an imported run, and nothing here may relax it.
12//!
13//! An imported cell may not end better than the same rows would have ended in
14//! an executed run:
15//!
16//! - Every row must describe this commit's clean source, this checkout's test
17//!   source, the current timeout policy, the `/proc` level the cell's test
18//!   declares, and (when the binary was stamped) a binary built from this
19//!   commit. Otherwise the cell is one `import-stale` ERROR.
20//! - The cell's rows, in file order, must be a history a producer writes:
21//!   attempts 1, 2, ... within the shared attempt cap, nothing after a PASS,
22//!   and no HOST-INAPPLICABLE row (a producer reports host inapplicability
23//!   only in `summary.json`). Otherwise the cell is one `import-history`
24//!   ERROR. This is checked on the whole history, before anything is dropped.
25//! - The producer retries every failure; this run's retry policy decides which
26//!   of those retries it would have made. History after a failed attempt (a
27//!   FAIL or an ERROR) that does not earn a retry here is dropped, so that
28//!   attempt is the cell's verdict.
29//! - The policy is the decision an executed run applies to its own attempt
30//!   (`attempt_retry_cause` in `test-harness`), applied to the imported row.
31//!   For an ERROR that is the skid-overshoot retry
32//!   (`skid_overshoot_only_reports`,
33//!   <https://github.com/rrnewton/hermit/issues/1845>) or the host-input
34//!   retry (`host_input_change_only`). Neither trusts the row's labels: each
35//!   re-decides the attempt from the report bytes the row retains, which must
36//!   match the row's `verification_report_sha256`, and the row must record
37//!   the exit, stdout and relaxation declarations of this checkout's cell. So
38//!   an imported skid-overshoot ERROR whose retained evidence decides it
39//!   continues to its producer's next attempt, as an executed one would, and
40//!   any other ERROR (an untyped one, a report that does not match its digest,
41//!   another declaration) ends the history.
42//! - A PASS counts only if the producer recorded complete evidence for the
43//!   execution that passed: that row's run id in `evidence_complete_executions`
44//!   in the bucket's `summary.json`. Evidence from another execution of the
45//!   same cell does not count.
46//! - A producer's host-inapplicable claim counts only if this machine lacks a
47//!   capability the cell requires, and the row carries this machine's reason.
48//! - The one HOST-INAPPLICABLE row a producer writes is a host-image
49//!   interpreter refusal it recorded under
50//!   `--record-host-image-interpreter-refusals`, as a cell's only row. It
51//!   counts only if this run was given that option too, and only with the
52//!   producer's `summary.json` claim for the cell, whose typed evidence must
53//!   be a refusal this run would record (`check_interpreter_refusal_claim`);
54//!   the cell is then this run's own such row, rebuilt from that evidence.
55//!   Without the option it is one `import-host-image-interpreter-refusal`
56//!   ERROR, never a HOST-INAPPLICABLE and never a pass. This run's own PASS
57//!   baseline check applies to it as to a refusal it recorded itself.
58//!
59//! An imported row is rebound to this run before publication: its `run_id`
60//! (and the run id its CPU observations are bound to) becomes this run's, and
61//! the observations' outer attempt follows the row's attempt, which the ingest
62//! assigned from Tpx's execution order. Its `source_tree_dirty` is set when this
63//! checkout is dirty, as an executed row's would be. The rows' original run ids
64//! are kept and reported.

97/// The decisions an executed run makes for itself, applied to imported rows.
98pub struct ImportPolicy<'a> {
99    /// Whether this run would retry after the last row of `history` (the
100    /// cell's attempts up to and including that row), by the rule an
101    /// executed run applies to its own history: its retry setting, the
102    /// cell's `no_retry_reason`, for an ERROR the skid-overshoot and
103    /// host-input rules, which re-decide the attempt from its retained
104    /// report bytes, and the history's attempt cap (the skid budget only
105    /// while every attempt is skid-only). It is consulted for every FAIL
106    /// and ERROR row; a PASS ends the history.
107    pub earns_retry: &'a dyn Fn(&SelectedCell, &[CellResult]) -> bool,
108    /// Why this machine cannot run the cell, if it cannot.
109    pub host_inapplicable: &'a dyn Fn(&SelectedCell) -> Option<String>,
110    /// Whether this run records a host-image interpreter refusal
111    /// (`--record-host-image-interpreter-refusals`), and so may accept one a
112    /// producer recorded.
113    pub record_refusals: bool,
114}

126/// The import of one `run`: one entry per selected cell, in selection order.
127pub struct ImportedRun {

133    /// Producer attempts dropped because the attempt before them would not

136}

221/// Why `row` cannot stand for `cell` in this run, if it cannot.
222fn stale_reason(context: &RunContext, cell: &SelectedCell, row: &CellResult) -> Option<String> {
223    if row.schema != CELL_RESULT_SCHEMA {
224        return Some(format!(
225            "imported row has schema {}, expected {CELL_RESULT_SCHEMA}",
226            row.schema
227        ));
228    }
229    if row.hermit_sha != context.source_sha {
230        return Some(format!(
231            "imported row was built from {}, this run is {}",
232            row.hermit_sha, context.source_sha
233        ));
234    }
235    if row.source_tree_dirty {
236        return Some("imported row was produced from a dirty source tree".into());
237    }
238    if let Some(binary) = row.binary_build_sha.as_deref() {
239        if binary != "unknown" && !(binary.len() >= 7 && context.source_sha.starts_with(binary)) {
240            return Some(format!(
241                "imported row ran a Hermit stamped {binary}, this run is {}",
242                context.source_sha
243            ));
244        }
245    }
246    match test_digest(&context.root, &cell.test) {
247        Ok(digest) if digest == row.test_sha256 => {}
248        Ok(digest) => {
249            return Some(format!(
250                "imported row ran test source {}, this checkout has {digest}",
251                row.test_sha256
252            ));
253        }
254        Err(error) => {
255            return Some(format!(
256                "cannot digest this checkout's test source: {error}"
257            ));
258        }
259    }
260    if let Some(mismatch) = proc_level_mismatch(row, cell) {
261        return Some(format!(
262            "imported row is not at this cell's /proc level: {mismatch}"
263        ));
264    }
265    match cell_timeouts(context, cell) {
266        Ok(policy)
267            if row.execution_cpu_timeout_seconds == Some(policy.cpu_seconds)
268                && row.execution_wall_timeout_seconds == Some(policy.wall_seconds) => {}
269        Ok(policy) => {
270            return Some(format!(
271                "imported row ran with cpu/wall timeouts {:?}/{:?}, this run's policy is {}/{}",
272                row.execution_cpu_timeout_seconds,
273                row.execution_wall_timeout_seconds,
274                policy.cpu_seconds,
275                policy.wall_seconds
276            ));
277        }
278        Err(error) => return Some(format!("cannot resolve this cell's timeouts: {error}")),
279    }
280    // Validate the row against the attempt its own CPU observations are
281    // bound to: a harness retry's second attempt is bound to attempt 2,
282    // while a row ingest renumbered from a separate producer execution is
283    // bound to that execution's attempt 1.
284    let Some(observations) = &row.cpu_observations else {
285        return Some("imported row has no CPU observations".into());
286    };
287    let bound = observations.binding.outer_attempt;
288    if bound != row.attempt && bound != 1 {
289        return Some(format!(
290            "imported row attempt {} carries CPU observations bound to attempt {bound}",
291            row.attempt
292        ));
293    }
294    let mut as_executed = row.clone();
295    as_executed.attempt = bound;
296    if let Err(error) = as_executed.require_cpu_observations() {
297        return Some(format!(
298            "imported row's CPU observations do not belong to its own execution: {error}"
299        ));
300    }
301    None
302}

304/// Why `rows`, in file order, are not a history a producer writes, if they
305/// are not. The executed path's own rule decides (`outcome_after_retries`),
306/// and a producer writes no HOST-INAPPLICABLE row except a recorded
307/// host-image interpreter refusal as a cell's only row, which `load` takes
308/// before this, so here any is refused. `no_rows` names, by
309/// attempt, the cause the producer recorded for each execution that wrote no
310/// row; it only words the refusal and never decides it.
311fn history_error(rows: &[CellResult], no_rows: Option<&BTreeMap<u64, String>>) -> Option<String> {
312    if let Some(row) = rows.iter().find(|row| row.outcome == "HOST-INAPPLICABLE") {
313        return Some(format!(
314            "imported attempt {} is a HOST-INAPPLICABLE row; a producer reports host inapplicability only in summary.json's host_inapplicable_cells",
315            row.attempt
316        ));
317    }
318    if !crate::runner::history_past_generic_bound_is_skid_qualified(rows) {
319        return Some(format!(
320            "imported rows are not one producer history: {} attempt(s) past the generic bound without skid-only evidence for every attempt before the final one",
321            rows.len()
322        ));
323    }
324    outcome_after_retries(rows.iter().map(|row| (row.attempt, row.outcome.as_str())))
325        .err()
326        .map(|error| {
327            let causes = no_rows
328                .into_iter()
329                .flatten()
330                .map(|(attempt, cause)| format!("; attempt {attempt} wrote no row: {cause}"))
331                .collect::<String>();
332            format!("imported rows are not one producer history: {error}{causes}")
333        })
334}

336/// Read the import root for `cells`. `results_path` is where this run
337/// publishes; an import file that is the same file is refused, because the
338/// harness appends to it.
339pub fn load(
340    root: &Path,
341    cells: &[SelectedCell],
342    context: &RunContext,
343    results_path: &Path,
344    policy: &ImportPolicy<'_>,
345) -> Result<ImportedRun, String> {
346    let wanted = cells.iter().map(cell_key).collect::<BTreeSet<_>>();
347    let buckets = cells
348        .iter()
349        .map(|cell| (cell.test.lane.clone(), cell.category.clone()))
350        .collect::<BTreeSet<_>>();
351    let publish = fs::canonicalize(results_path).ok();
352    let mut rows = BTreeMap::<Key, Vec<CellResult>>::new();
353    let mut inapplicable = BTreeMap::<Key, String>::new();
354    let mut evidence_complete = BTreeSet::<(Key, String)>::new();
355    let mut refusal_claims = BTreeMap::<Key, Vec<InterpreterRefusalEvidence>>::new();
356    let mut no_rows = BTreeMap::<Key, BTreeMap<u64, String>>::new();
357    for (lane, category) in &buckets {
358        let dir = bucket_dir(root, lane, category);
359        let results = dir.join("results.jsonl");
360        if publish.is_some() && fs::canonicalize(&results).ok() == publish {
361            return Err(format!(
362                "{IMPORT_RESULTS_ENV} file {} is this run's own results path",
363                results.display()
364            ));
365        }
366        match fs::read_to_string(&results) {
367            Ok(text) => {
368                for (number, line) in text.lines().enumerate() {
369                    if line.trim().is_empty() {
370                        continue;
371                    }
372                    let row: CellResult = serde_json::from_str(line).map_err(|error| {
373                        format!("{}:{}: {error}", results.display(), number + 1)
374                    })?;
375                    if row.lane != *lane || row.category != *category {
376                        return Err(format!(
377                            "{}:{}: row of {}/{} in the {lane}/{category} bucket",
378                            results.display(),
379                            number + 1,
380                            row.lane,
381                            row.category
382                        ));
383                    }
384                    let id = key(lane, category, &row.test, &row.mode, row.backend.as_deref());
385                    if wanted.contains(&id) {
386                        rows.entry(id).or_default().push(row);
387                    }
388                }
389            }
390            Err(error) if error.kind() == std::io::ErrorKind::NotFound => {}
391            Err(error) => return Err(format!("{}: {error}", results.display())),
392        }
393        let no_row_path = dir.join(NO_ROW_FILE);
394        match fs::read_to_string(&no_row_path) {
395            Ok(text) => {
396                for (number, line) in text.lines().enumerate() {
397                    if line.trim().is_empty() {
398                        continue;
399                    }
400                    let entry: NoRowExecution = serde_json::from_str(line).map_err(|error| {
401                        format!("{}:{}: {error}", no_row_path.display(), number + 1)
402                    })?;
403                    let id = key(
404                        lane,
405                        category,
406                        &entry.test,
407                        &entry.mode,
408                        entry.backend.as_deref(),
409                    );
410                    no_rows
411                        .entry(id)
412                        .or_default()
413                        .insert(entry.attempt, entry.cause);
414                }
415            }
416            Err(error) if error.kind() == std::io::ErrorKind::NotFound => {}
417            Err(error) => return Err(format!("{}: {error}", no_row_path.display())),
418        }
419        let summary = dir.join("summary.json");
420        match fs::read(&summary) {
421            Ok(bytes) => {
422                let summary: Summary = serde_json::from_slice(&bytes)
423                    .map_err(|error| format!("{}: {error}", summary.display()))?;
424                for cell in summary.host_inapplicable_cells {
425                    let id = key(
426                        lane,
427                        category,
428                        &cell.test,
429                        &cell.mode,
430                        cell.backend.as_deref(),
431                    );
432                    if wanted.contains(&id) {
433                        inapplicable.insert(id, cell.reason.unwrap_or_default());
434                    }
435                }
436                for claim in summary.host_image_interpreter_refusal_cells {
437                    if !claim.recorded {
438                        continue;
439                    }
440                    let id = key(
441                        lane,
442                        category,
443                        &claim.test,
444                        &claim.mode,
445                        claim.backend.as_deref(),
446                    );
447                    if wanted.contains(&id) {
448                        refusal_claims.entry(id).or_default().push(claim.evidence);
449                    }
450                }
451                evidence_complete.extend(summary.evidence_complete_executions.into_iter().map(
452                    |execution| {
453                        let id = key(
454                            lane,
455                            category,
456                            &execution.test,
457                            &execution.mode,
458                            execution.backend.as_deref(),
459                        );
460                        (id, execution.run_id)
461                    },
462                ));
463            }
464            Err(error) if error.kind() == std::io::ErrorKind::NotFound => {}
465            Err(error) => return Err(format!("{}: {error}", summary.display())),
466        }
467    }
468
469    let mut source_run_ids = BTreeSet::new();
470    let mut missing = 0;
471    let mut dropped_retries = 0;
472    let cells = cells
473        .iter()
474        .map(|cell| {
475            let id = cell_key(cell);
476            let found = rows.remove(&id);
477            let claimed = inapplicable.remove(&id);
478            let claims = refusal_claims.remove(&id).unwrap_or_default();
479            let mut refusal = None;
480            let rows = match (found, claimed) {
481                (Some(_), Some(_)) => vec![error_row(
482                    context,
483                    cell,
484                    "import-conflict",
485                    format!(
486                        "{IMPORT_RESULTS_ENV} has both result rows and a host-inapplicable entry for this cell"
487                    ),
488                )],
489                (None, Some(claimed)) => match (policy.host_inapplicable)(cell) {
490                    Some(reason) => vec![host_inapplicable_result(context, cell, reason)],
491                    None => vec![error_row(
492                        context,
493                        cell,
494                        "import-host-inapplicable-unconfirmed",
495                        format!(
496                            "{IMPORT_RESULTS_ENV} says this cell could not run ({claimed:?}), but this machine has every capability it requires"
497                        ),
498                    )],
499                },
500                (None, None) => {
501                    missing += 1;
502                    vec![error_row(
503                        context,
504                        cell,
505                        "import-missing",
506                        format!(
507                            "{IMPORT_RESULTS_ENV}={} has no result for this selected cell",
508                            root.display()
509                        ),
510                    )]
511                }
512                (Some(found), None)
513                    if found.len() == 1 && is_host_image_interpreter_refusal(&found[0]) =>
514                {
515                    // A producer's recorded host-image interpreter refusal.
516                    let row = &found[0];
517                    if let Some(reason) = stale_reason(context, cell, row) {
518                        vec![error_row(context, cell, "import-stale", reason)]
519                    } else if !policy.record_refusals {
520                        vec![error_row(
521                            context,
522                            cell,
523                            "import-host-image-interpreter-refusal",
524                            format!(
525                                "{IMPORT_RESULTS_ENV}'s producer recorded this cell as a host-image interpreter refusal, which this run records only under {}: {}",
526                                crate::runner::RECORD_INTERPRETER_REFUSALS_ARG,
527                                row.reason.as_deref().unwrap_or("no reason")
528                            ),
529                        )]
530                    } else {
531                        let checked = match claims.as_slice() {
532                            [claim] => check_interpreter_refusal_claim(cell, claim)
533                                .map(|()| claim.clone()),
534                            [] => Err("its summary.json has no recorded claim for it".into()),
535                            _ => Err(format!(
536                                "its summary.json has {} recorded claims for it",
537                                claims.len()
538                            )),
539                        };
540                        match checked {
541                            Ok(evidence) => {
542                                source_run_ids.insert(row.run_id.clone());
543                                let rebuilt =
544                                    host_image_interpreter_refusal_row(context, cell, &evidence);
545                                refusal = Some(evidence);
546                                vec![rebuilt]
547                            }
548                            Err(error) => vec![error_row(
549                                context,
550                                cell,
551                                "import-history",
552                                format!(
553                                    "{IMPORT_RESULTS_ENV}'s producer recorded this cell as a host-image interpreter refusal this run does not accept: {error}"
554                                ),
555                            )],
556                        }
557                    }
558                }
559                (Some(mut found), None) => {
560                    if let Some(reason) = found.iter().find_map(|row| stale_reason(context, cell, row)) {
561                        vec![error_row(context, cell, "import-stale", reason)]
562                    } else if let Some(reason) = history_error(&found, no_rows.get(&id)) {
563                        vec![error_row(context, cell, "import-history", reason)]
564                    } else {
565                        // Keep the history up to the first attempt this run
566                        // would not have retried. A PASS is already the last
567                        // row (`history_error`), so only a failed attempt can
568                        // drop later ones. A FAIL or an ERROR continues it
569                        // exactly when the policy retries it: a typed skid
570                        // overshoot does, as it would had this run executed
571                        // the attempt, because the policy re-decides it from
572                        // the report bytes the row retains.
573                        let kept = found
574                            .iter()
575                            .enumerate()
576                            .position(|(position, row)| {
577                                row.outcome == "PASS"
578                                    || !(policy.earns_retry)(cell, &found[..=position])
579                            })
580                            .map_or(found.len(), |terminal| terminal + 1);
581                        dropped_retries += found.len() - kept;
582                        found.truncate(kept);
583                        let last = found.last().expect("a found cell has at least one row");
584                        if last.outcome == "PASS"
585                            && !evidence_complete.contains(&(id.clone(), last.run_id.clone()))
586                        {
587                            vec![error_row(
588                                context,
589                                cell,
590                                "import-evidence-incomplete",
591                                format!(
592                                    "{IMPORT_RESULTS_ENV} has a PASS for this cell from producer run {}, which has no evidence_complete_executions record",
593                                    last.run_id
594                                ),
595                            )]
596                        } else {
597                            found
598                                .into_iter()
599                                .map(|mut row| {
600                                    source_run_ids.insert(std::mem::replace(
601                                        &mut row.run_id,
602                                        context.run_id.clone(),
603                                    ));
