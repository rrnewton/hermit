6//! Known-gap ledgers. A ledger lists the tests of a suite that a validation node does not yet
7//! require to pass on its backend, each with its tracking issue: the tests it runs and expects to
8//! fail, and the tests it skips. So a node can run a suite on a backend that does not pass all of
9//! it yet without counting a failure as a pass or hiding it.
10//!
11//! The format and its readers:
12//! - `ci/kvm-gap-ledger.rs`. It is the node's runner, the static check, and the history gate that
13//!   `make lint-checks` runs (`lint-check-known-gap-ledgers`).
14//! - The validation DAG generator. It writes each [`Declaration`] into its node's environment as
15//!   [`LEDGER_ENV`], so `ci/dag/validate.json` names the file the node judges.
16//! - `ci/compat-envelope/scorecard.rs`. It lists every row in SCORECARD.md and in
17//!   `ci/compat-envelope/known-gaps.json`, outside every E2E count.
18//! - The dev-hermit receipt qualifier, owned outside this repository. It reads a node's
19//!   [`LEDGER_ENV`] declaration from `validate.json` and the file as committed on main. A
20//!   `diagnostic_fail` row qualifies only if its structured-result `id` equals a row's [`Row::id`].
21//!   Do not change [`HEADER`] without telling that reader: the header is the schema's version.
22//!   Its parser predates [`Outcome::Skipped`] and refuses that outcome. It reads a ledger only for
23//!   a run that has diagnostic failures, which a ledger whose every row is skipped cannot produce;
24//!   a ledger that mixes skipped rows with rows the node runs needs that parser to accept them
25//!   first.
26//!
27//! # Format
28//!
29//! UTF-8 with LF line endings and a final newline. A line whose first character is `#` is a
30//! comment, wherever it is; a blank line is an error. The first other line is [`HEADER`]. Every
31//! later line is a row of six TAB-separated fields, none empty and none padded:
32//!
33//! | Column | Content |
34//! | --- | --- |
35//! | `id` | The test's structured-result id, `<cargo package>::<test binary>$<test function>`, exactly as the node's results name it. Rows are sorted by it, byte order, with no duplicate. |
36//! | `gap` | The reason: a short gap code, no whitespace. The ledger's comments define each code. |
37//! | `issue` | The tracking issue or pull request, as a full GitHub URL. |
38//! | `outcome` | How the failing attempt must end: `failed`, or `cpu_timeout` (stopped by its CPU budget). Or `skipped`: the node does not run the test at all, it leaves it out of the run by name, so there is no attempt. |
39//! | `signature` | For `failed`, text the test's output must show ([`signature_matches`]) when the node runs it with `RUST_BACKTRACE=0`, so a panic prints std's `note: run with` line rather than a backtrace; it may hold spaces, not TABs, and writes a newline as `\n`, a backslash as `\\` and any run of digits as `<N>`. For `cpu_timeout` and `skipped`, `-`. |
40//! | `approval` | `baseline` for a row present, unchanged, since the ledger's introduction; otherwise the full URL of a specific approving comment, review or commit. |
41//!
42//! Optional `# description<TAB>id<TAB>text` comments provide plain-text explanations for the
43//! scorecard. Each names a full row id in the same ledger, at most once; its text is nonempty,
44//! unpadded and contains no control characters. [`parse_descriptions`] reads these separately
45//! from the execution rows, so descriptions do not change their scope or approval history.
46//!
47//! # What may change, checked against history
48//!
49//! A row excuses one test failing one way: its id, outcome and signature ([`Row::scope`]). The
50//! history gate ([`judge_history`]) holds the ledger to the following rules along the first-parent
51//! history that starts at its introduction:
52//! - A row is a baseline row only if its scope has been in every committed version since that
53//!   introduction. A row added later, or whose outcome or signature changed, needs an approval URL
54//!   that a commit-message line binds to its id: `KVM-Gap-Approval: <URL> <id>`, in the commit
55//!   that added it or a later one. So the baseline can only shrink, and a swap is an addition.
56//!   Skipping a test is weaker than running it as a known gap (nothing then shows whether it still
57//!   fails), so turning a row skipped is such a change, and so is turning it back. Deleting a
58//!   skipped row needs nothing: its test becomes required, and the node runs it.
59//! - A test that leaves the required set needs approval too. Moving into the ledger is an
60//!   addition. Leaving the suite, or being `#[ignore]`d, needs `KVM-Required-Removal: <URL> <id>`.
61//!   A rename leaves under the old id.
62//! - One closed exception: [`SQUASHED_APPROVALS`] names, one by one, the rows whose approval line
63//!   an import dropped before the GitHub export received them. Such a row needs no line while it
64//!   has had exactly its listed text in every version from the listed commit, where it entered, to
65//!   the one judged. A row added later, one entering anywhere else, and one that differed in any
66//!   version since it entered, even if it returned to the listed text, need their line like any
67//!   other. hermit_import's prepare.rs prints the approval lines of an imported range for the
68//!   import commit's message, so later imports keep theirs.
69//!
70//! The required set comes from the suite's source ([`suite_tests`]), whose parser refuses every
71//! attribute form it does not understand on the lines it reads. The node also compares that set
72//! with Nextest's list of the built suite, test by test. Together, the parser and the node see
73//! every test added, removed or ignored. The history check alone, which is all the portable lanes
74//! run, does not: its parser skips an attribute that follows a block comment on the same line,
75//! takes a declaration faked inside a string or a block comment for a real one, and does not follow
76//! `include!`, a `#[path]` or `#[macro_use]` module, or a macro. Only the node, which runs on KVM
77//! hosts, catches a test added, removed or ignored through those.
78//!
79//! The walk follows first parents, so the verdict is the same on any linear (rebased) history: on
80//! main, which lands by rebase, and on a rebased branch. On a merge commit, a row or removal enters
81//! at the merge, and an approval line on the merged side branch is not read: such a change is
82//! refused until a commit on the first-parent chain carries the line. GitHub's checkout of an
83//! external pull request is such a merge (`refs/pull/N/merge`), so a pull request that adds an
84//! approved row goes red there until it is rebased.
85//!
86//! The walk reads every committed version since the introduction. A version it cannot read (a
87//! malformed ledger, a suite form the parser refuses, the suite file renamed) stops it at exit 2,
88//! and only a change to the checker can repair that, so a change to a ledger or its suite runs
89//! `make lint-check-known-gap-ledgers` before it lands. Validation runs that target in
90//! `check.lint_checks` (`make lint-checks`, profiles full, portable and hosted-portable). Renaming the
91//! suite file is moving the ledger: a new introduction, reviewed as one.
92//!
93//! What no offline check can see stays with review:
94//! - whether an approval URL really points at the coordinator's approval of those rows;
95//! - a test that returns early on one backend;
96//! - a change to the checker itself;
97//! - a new ledger, or a moved one, whose introduction starts a new baseline.

160/// Whether `row` of `ledger` is one of [`SQUASHED_APPROVALS`] exactly, in every version from the
161/// one where it entered to the one judged (`since_entered`, oldest first): the same ledger, the
162/// listed commit as the one where it entered, every field the same in each of those versions,
163/// and the named approval. A row that entered with other text, or had other text in any version
164/// since, is not exempt, even if it returned to the listed text.
165fn squashed_approval(ledger: &str, row: &Row, since_entered: &[Version]) -> bool {
166    let Some(entered) = since_entered.first() else {
167        return false;
168    };
169    let scope = row.scope();
170    SQUASHED_APPROVALS.iter().any(|exempt| {
171        exempt.ledger == ledger
172            && exempt.entered == entered.commit
173            && row.approval == Approval::Url(exempt.approval.to_string())
174            && parse(&format!("{HEADER}\n{}\n", exempt.row))
175                .is_ok_and(|rows| rows.as_slice() == std::slice::from_ref(row))
176            && since_entered.iter().all(|version| {
177                let same_scope = version
178                    .rows
179                    .iter()
180                    .filter(|other| other.scope() == scope)
181                    .collect::<Vec<_>>();
182                !same_scope.is_empty() && same_scope.iter().all(|other| *other == row)
183            })
184    })
185}

234/// A declaration's required tests are derived, never pinned: the suite's
235/// listed population less its run gap rows (see `required`). The ledger
236/// checks that listed population name-by-name against the suite source,
237/// and retains it beside the node's results for the landing census.
238/// How a gap row's failing attempt must end, or that the node does not run it.
239#[derive(Clone, Copy, Debug, Eq, Ord, PartialEq, PartialOrd)]
240pub enum Outcome {
241    /// An ordinary failure, whose output must contain the row's signature.
242    Failed,
243    /// Stopped by its per-test CPU budget.
244    CpuTimeout,
245    /// Not run: the node leaves the test out of its run by name, so there is no attempt to judge.
246    Skipped,
247}
248
249impl Outcome {
250    /// The ledger's spelling. For an outcome the node runs, it is also dagrun's attempt-outcome
251    /// spelling.
252    pub fn value(self) -> &'static str {
253        match self {
254            Self::Failed => "failed",
255            Self::CpuTimeout => "cpu_timeout",
256            Self::Skipped => "skipped",
257        }
258    }
259
260    /// Whether the node runs a row with this outcome.
261    pub fn is_run(self) -> bool {
262        self != Self::Skipped
263    }
264
265    fn parse(value: &str) -> Option<Self> {
266        match value {
267            "failed" => Some(Self::Failed),
268            "cpu_timeout" => Some(Self::CpuTimeout),
269            "skipped" => Some(Self::Skipped),
270            _ => None,
271        }
272    }
273}

308fn is_name(value: &str) -> bool {
309    !value.is_empty()
310        && value
311            .chars()
312            .all(|c| c.is_ascii_alphanumeric() || matches!(c, '-' | '_' | '.'))
313}
314
315fn is_number(value: &str) -> bool {
316    !value.is_empty() && !value.starts_with('0') && value.chars().all(|c| c.is_ascii_digit())
317}
318
319fn is_identifier(value: &str) -> bool {
320    !value.is_empty() && value.chars().all(|c| c.is_ascii_alphanumeric() || c == '_')
321}

323/// A structured-result test id: `<package>::<binary>$<test>`, whose test may be a `::` path.
324pub fn is_test_id(value: &str) -> bool {
325    let Some((binary, test)) = value.split_once('$') else {
326        return false;
327    };
328    let Some((package, binary)) = binary.split_once("::") else {
329        return false;
330    };
331    is_name(package)
332        && !package.contains('.')
333        && is_name(binary)
334        && !binary.contains('.')
335        && test.split("::").all(is_identifier)
336}

338/// A full GitHub issue or pull-request URL: `https://github.com/OWNER/REPO/issues/N` or
339/// `.../pull/N`.
340pub fn is_issue_url(value: &str) -> bool {
341    let Some(rest) = value.strip_prefix("https://github.com/") else {
342        return false;
343    };
344    matches!(
345        rest.split('/').collect::<Vec<_>>().as_slice(),
346        [owner, repo, "issues" | "pull", number]
347            if is_name(owner) && is_name(repo) && is_number(number)
348    )
349}

351/// The full URL of one specific approving artifact: a comment on an issue or pull request
352/// (`#issuecomment-N`), a review or review comment on a pull request (`#pullrequestreview-N`,
353/// `#discussion_rN`), or a commit by its full 40-hex SHA. A bare issue or pull-request URL is
354/// not specific: it names a thread, not the approval in it.
355pub fn is_approval_url(value: &str) -> bool {
356    let Some(rest) = value.strip_prefix("https://github.com/") else {
357        return false;
358    };
359    let (path, fragment) = match rest.split_once('#') {
360        Some((path, fragment)) => (path, Some(fragment)),
361        None => (rest, None),
362    };
363    let anchored = |prefixes: &[&str]| {
364        fragment.is_some_and(|fragment| {
365            prefixes
366                .iter()
367                .any(|prefix| fragment.strip_prefix(prefix).is_some_and(is_number))
368        })
369    };
370    match path.split('/').collect::<Vec<_>>().as_slice() {
371        [owner, repo, "issues", number] if is_name(owner) && is_name(repo) && is_number(number) => {
372            anchored(&["issuecomment-"])
373        }
374        [owner, repo, "pull", number] if is_name(owner) && is_name(repo) && is_number(number) => {
375            anchored(&["issuecomment-", "pullrequestreview-", "discussion_r"])
376        }
377        [owner, repo, "commit", sha] if is_name(owner) && is_name(repo) => {
378            fragment.is_none()
379                && sha.len() == 40
380                && sha
381                    .chars()
382                    .all(|c| c.is_ascii_digit() || ('a'..='f').contains(&c))
383        }
384        _ => false,
385    }
386}

388/// Parse a ledger ([module documentation](self)). Returns the rows, or the first violation of the
389/// format, with its line number.
390pub fn parse(text: &str) -> Result<Vec<Row>, String> {
391    if text.contains('\r') {
392        return Err("the ledger has a CR; its lines end with LF alone".into());
393    }
394    if !text.ends_with('\n') {
395        return Err("the ledger does not end with a newline".into());
396    }
397    let mut lines = text
398        .lines()
399        .enumerate()
400        .filter(|(_, line)| !line.starts_with('#'));
401    match lines.next() {
402        Some((_, line)) if line == HEADER => {}
403        Some((index, line)) => {
404            return Err(format!(
405                "line {}: expected the header {HEADER:?}, found {line:?}",
406                index + 1
407            ));
408        }
409        None => return Err(format!("no header {HEADER:?}")),
410    }
411    let mut rows: Vec<Row> = Vec::new();
412    for (index, line) in lines {
413        let number = index + 1;
414        let fields = line.split('\t').collect::<Vec<_>>();
415        let [id, gap, issue, outcome, signature, approval] = fields.as_slice() else {
416            return Err(format!(
417                "line {number}: a row has six TAB-separated fields (id, gap, issue, outcome, signature, approval), found {}: {line:?}",
418                fields.len()
419            ));
420        };
421        for (name, value) in [
422            ("id", id),
423            ("gap", gap),
424            ("issue", issue),
425            ("outcome", outcome),
426            ("approval", approval),
427        ] {
428            if value.is_empty() || value.chars().any(char::is_whitespace) {
429                return Err(format!(
430                    "line {number}: the {name} field must be one nonempty word, found {value:?}"
431                ));
432            }
433        }
434        if signature.is_empty()
435            || signature.trim() != *signature
436            || signature.chars().any(char::is_control)
437        {
438            return Err(format!(
439                "line {number}: the signature field must be nonempty text without padding or control characters, found {signature:?}"
440            ));
441        }
442        if *signature != NO_SIGNATURE {
443            signature_pieces(signature)
444                .map_err(|error| format!("line {number}: {id}: {error}, found {signature:?}"))?;
445        }
446        if !is_test_id(id) {
447            return Err(format!(
448                "line {number}: {id:?} is not a structured-result test id (<package>::<binary>$<test>)"
449            ));
450        }
451        if !is_issue_url(issue) {
452            return Err(format!(
453                "line {number}: {id}: the issue field must be the tracking issue's full URL (https://github.com/OWNER/REPO/issues/N), found {issue:?}"
454            ));
455        }
456        let outcome = Outcome::parse(outcome).ok_or_else(|| {
457            format!("line {number}: {id}: the outcome field must be failed, cpu_timeout or skipped, found {outcome:?}")
458        })?;
459        let signature = match (outcome, *signature) {
460            (Outcome::CpuTimeout | Outcome::Skipped, NO_SIGNATURE) => None,
461            (Outcome::CpuTimeout | Outcome::Skipped, other) => {
462                return Err(format!(
463                    "line {number}: {id}: a {} row has no output to match, so its signature is {NO_SIGNATURE:?}, found {other:?}",
464                    outcome.value()
465                ));
466            }
467            (Outcome::Failed, NO_SIGNATURE) => {
468                return Err(format!(
469                    "line {number}: {id}: a failed row names the text its failure must show, so its signature cannot be {NO_SIGNATURE:?}"
470                ));
471            }
472            (Outcome::Failed, text) => Some(text.to_string()),
473        };
474        let approval = if *approval == BASELINE_APPROVAL {
475            Approval::Baseline
476        } else if is_approval_url(approval) {
477            Approval::Url(approval.to_string())
478        } else {
479            return Err(format!(
480                "line {number}: {id}: the approval field must be {BASELINE_APPROVAL:?} or the full URL of a specific approving comment, review or commit (#issuecomment-N, #pullrequestreview-N, #discussion_rN, or commit/<40-hex SHA>), found {approval:?}"
481            ));
482        };
483        if let Some(previous) = rows.last() {
484            if previous.id == *id {
485                return Err(format!("line {number}: {id} is listed twice"));
486            }
487            if previous.id.as_str() > *id {
488                return Err(format!(
489                    "line {number}: rows must stay sorted by id: {id} comes after {}",
490                    previous.id
491                ));
492            }
493        }
494        rows.push(Row {
495            id: id.to_string(),
496            gap: gap.to_string(),
497            issue: issue.to_string(),
498            outcome,
499            signature,
500            approval,
501        });
502    }
503    Ok(rows)

506/// Read scorecard descriptions for the rows returned by [`parse`] for this ledger.
507pub fn parse_descriptions(
508    text: &str,
509    rows: &[Row],
510) -> Result<BTreeMap<String, String>, Box<dyn std::error::Error + Send + Sync>> {
511    let ids = rows
512        .iter()
513        .map(|row| row.id.as_str())
514        .collect::<BTreeSet<_>>();
515    let mut descriptions = BTreeMap::new();
516    for (index, line) in text.lines().enumerate() {
517        let fields = line.split('\t').collect::<Vec<_>>();
518        if fields.first() != Some(&"# description") {
519            continue;
520        }
521        let number = index + 1;
522        let [_, id, description] = fields.as_slice() else {
523            return Err(format!("line {number}: expected # description<TAB>id<TAB>text").into());
524        };
525        if !ids.contains(id) {
526            return Err(format!(
527                "line {number}: description id {id:?} is not a row in this ledger"
528            )
529            .into());
530        }
531        if description.is_empty()
532            || description.trim() != *description
533            || description.chars().any(char::is_control)
534        {
535            return Err(format!(
536                "line {number}: description must be nonempty text without padding or control characters"
537            ).into());
538        }
539        if descriptions
540            .insert(id.to_string(), description.to_string())
541            .is_some()
542        {
543            return Err(format!("line {number}: description for {id} is listed twice").into());
544        }
545    }
546    Ok(descriptions)
547}

549/// The placeholder in a signature that matches one or more ASCII digits.
550pub const NUMBER_PLACEHOLDER: &str = "<N>";
551
552/// A signature's literal pieces, split at each [`NUMBER_PLACEHOLDER`], with its escapes decoded:
553/// `\n` is a newline and `\\` a backslash; any other backslash is refused. The first piece must
554/// not be empty, and two placeholders cannot be adjacent.
555pub fn signature_pieces(signature: &str) -> Result<Vec<String>, String> {
556    let mut pieces = vec![String::new()];
557    let mut chars = signature.chars().peekable();
558    while let Some(c) = chars.next() {
559        match c {
560            '\\' => match chars.next() {
561                Some('n') => pieces.last_mut().expect("one piece").push('\n'),
562                Some('\\') => pieces.last_mut().expect("one piece").push('\\'),
563                other => {
564                    return Err(format!(
565                        "a signature's backslash is followed by {other:?}; its only escapes are \\n (a newline) and \\\\ (a backslash)"
566                    ));
567                }
568            },
569            '<' if chars.clone().take(2).collect::<String>() == "N>" => {
570                chars.next();
571                chars.next();
572                if pieces.last().is_some_and(String::is_empty) {
573                    return Err(format!(
574                        "a signature must start with literal text, and two {NUMBER_PLACEHOLDER} cannot be adjacent"
575                    ));
576                }
577                pieces.push(String::new());
578            }
579            c => pieces.last_mut().expect("one piece").push(c),
580        }
581    }
582    Ok(pieces)
583}

585/// Whether `output` shows `signature` ([`signature_pieces`]): its first piece somewhere, and each
586/// later piece right after a run of ASCII digits that follows the piece before it.
587pub fn signature_matches(signature: &str, output: &str) -> bool {
588    fn follows(pieces: &[String], text: &str) -> bool {
589        let Some((piece, rest)) = pieces.split_first() else {
590            return true;
591        };
592        let digits = text.bytes().take_while(u8::is_ascii_digit).count();
593        (1..=digits).rev().any(|take| {
594            text[take..].starts_with(piece.as_str()) && follows(rest, &text[take + piece.len()..])
595        })
596    }
597    let Ok(pieces) = signature_pieces(signature) else {
598        return false;
599    };
600    let (first, rest) = pieces.split_first().expect("one piece");
601    output
602        .match_indices(first.as_str())
603        .any(|(at, _)| follows(rest, &output[at + first.len()..]))
604}

606/// `text` with the whitespace outside string literals removed: the form attributes are compared in.
607fn compact(text: &str) -> String {
608    let mut out = String::with_capacity(text.len());
609    let mut in_string = false;
610    let mut escaped = false;
611    for c in text.chars() {
612        if in_string {
613            out.push(c);
614            match c {
615                _ if escaped => escaped = false,
616                '\\' => escaped = true,
617                '"' => in_string = false,
618                _ => {}
619            }
620        } else if c == '"' {
621            in_string = true;
622            out.push(c);
623        } else if !c.is_whitespace() {
624            out.push(c);
625        }
626    }
627    out
628}

630/// The identifiers of an attribute, outside its string literals.
631fn attribute_words(attribute: &str) -> Vec<String> {
632    let mut words = Vec::new();
633    let mut word = String::new();
634    let mut in_string = false;
635    let mut escaped = false;
636    for c in attribute.chars() {
637        if in_string {
638            match c {
639                _ if escaped => escaped = false,
640                '\\' => escaped = true,
641                '"' => in_string = false,
642                _ => {}
643            }
644            continue;
645        }
646        if c.is_ascii_alphanumeric() || c == '_' {
647            word.push(c);
648            continue;
649        }
650        if !word.is_empty() {
651            words.push(std::mem::take(&mut word));
652        }
653        in_string = c == '"';
654    }
655    if !word.is_empty() {
656        words.push(word);
657    }
658    words
659}

669/// Whether `attribute` (compact) is a string-valued form `#[name = "..."]`: one string literal,
670/// then the closing `]`.
671fn is_string_valued(attribute: &str, name: &str) -> bool {
672    let Some(rest) = attribute.strip_prefix(&format!("#[{name}=\"")) else {
673        return false;
674    };
675    let mut escaped = false;
676    for (offset, c) in rest.char_indices() {
677        match c {
678            _ if escaped => escaped = false,
679            '\\' => escaped = true,
680            '"' => return &rest[offset + 1..] == "]",
681            _ => {}
682        }
683    }
684    false

687/// An attribute the parser accepts on an item, test functions included: lint and documentation
688/// attributes, the common item attributes, and `#[path = "..."]` on a module.
689fn is_neutral_attribute(attribute: &str) -> bool {
690    [
691        "#[allow(",
692        "#[expect(",
693        "#[warn(",

697        "#[derive(",
698        "#[repr(",
699        "#[inline(",
700    ]
701    .iter()
702    .any(|prefix| attribute.starts_with(prefix) && attribute.ends_with(")]"))

704            "#[inline]",
705            "#[must_use]",
706            "#[track_caller]",
707            "#[cold]",

715/// One attribute, from the line that starts it to the `]` that closes it, and the index of the
716/// line after it. Refuses an attribute that shares its last line with code.
717fn attribute_at(lines: &[&str], start: usize) -> Result<(String, usize), String> {
718    let mut text = String::new();
719    let mut depth = 0usize;
720    let mut in_string = false;
721    let mut escaped = false;
722    for (index, line) in lines.iter().enumerate().skip(start) {
723        for (offset, c) in line.char_indices() {
724            if in_string {
725                match c {
726                    _ if escaped => escaped = false,
727                    '\\' => escaped = true,
728                    '"' => in_string = false,
729                    _ => {}
730                }
731                continue;
732            }
733            match c {
734                '"' => in_string = true,
735                '[' => depth += 1,
736                ']' => {
737                    depth = depth.checked_sub(1).ok_or_else(|| {
738                        format!("line {}: an unbalanced ] in an attribute", index + 1)
739                    })?;
740                    if depth == 0 {
741                        if !line[offset + 1..].trim().is_empty() {
742                            return Err(format!(
743                                "line {}: code shares a line with an attribute; the ledger's parser reads one attribute per line: {:?}",
744                                index + 1,
745                                line.trim()
746                            ));
747                        }
748                        text.push_str(line);
749                        return Ok((compact(&text), index + 1));
750                    }
751                }
752                _ => {}
753            }
754        }
755        text.push_str(line);
756        text.push('\n');
757    }
758    Err(format!("line {}: an attribute is never closed", start + 1))
759}

761/// The name of the function a top-level line declares: `fn name(` or `fn name<`, optionally
762/// `pub`, `pub(crate)` or `pub(super)`.
763fn declared_fn(line: &str) -> Option<&str> {
764    let rest = ["pub(crate) ", "pub(super) ", "pub "]
765        .iter()
766        .find_map(|prefix| line.strip_prefix(prefix))
767        .unwrap_or(line);
768    let rest = rest.strip_prefix("fn ")?;
769    let end = rest.find(['(', '<'])?;
770    let name = &rest[..end];
771    (!name.is_empty() && name.chars().all(|c| c.is_ascii_alphanumeric() || c == '_'))
772        .then_some(name)
773}

775/// The test functions a suite's source declares, each with whether it is ignored.
776///
777/// A test is a top-level `fn` whose attributes include `#[test]`; it is ignored when they also
778/// include `#[ignore]` or `#[ignore = "..."]`, before or after `#[test]`. Every other attribute on a
779/// test must be neutral: `#[should_panic]` in any form, lint and documentation attributes. Among
780/// the lines it reads, it REFUSES what it does not understand:
781/// - any attribute that names `test`, `ignore`, `cfg` or `cfg_attr` other than the forms above,
782///   anywhere in the file: `#[cfg_attr(all(), test)]`, `#[tokio::test]`, `#[cfg(test)]`, a
783///   conditional `#[cfg_attr(.., ignore)]`;
784/// - such an attribute on an indented line (a nested module's test, or a macro's);
785/// - any attribute it does not know on a function, which could be a test-generating macro;
786/// - `#[ignore]` without `#[test]`, `#[test]` on anything but a top-level `fn`, a test declared
787///   twice, and an inner attribute other than a lint.
788///
789/// It is not a Rust parser: it skips an attribute that follows a block comment on the same line,
790/// takes a declaration inside a string or a block comment for a real one, and does not follow
791/// `include!`, `#[path]` and `#[macro_use]` modules, or macros. The node checks the result against
792/// Nextest's own list of the built suite, which is authoritative, so the two together see every
793/// test added, removed or ignored; this is the check that needs no build, and the one history can
794/// make.
795pub fn suite_tests(source: &str) -> Result<BTreeMap<String, bool>, String> {
796    let lines = source.lines().collect::<Vec<_>>();
797    let mut tests = BTreeMap::new();
798    let mut group: Vec<(usize, String)> = Vec::new();
799    let mut index = 0;
800    while index < lines.len() {
801        let line = lines[index];
802        let trimmed = line.trim();
803        let number = index + 1;
804        if trimmed.starts_with("/*") {
805            // A block comment, to the line that closes it.
806            while !lines[index].contains("*/") {
807                index += 1;
808                if index == lines.len() {
809                    return Err(format!("line {number}: a block comment is never closed"));
810                }
811            }
812            index += 1;
813            continue;
814        }
815        if trimmed.is_empty() || trimmed.starts_with("//") {
816            index += 1;
817            continue;
818        }
819        if trimmed.starts_with('#') && trimmed[1..].trim_start().starts_with('!') {
820            let (attribute, next) = attribute_at(&lines, index)?;
821            let lint = [
822                "#![allow(",
823                "#![expect(",
824                "#![warn(",
825                "#![deny(",
826                "#![forbid(",
827            ]
828            .iter()
829            .any(|prefix| attribute.starts_with(prefix));
830            if !lint || names_test_machinery(&attribute) {
831                return Err(format!(
832                    "line {number}: the inner attribute {attribute} could change which tests run; the ledger's parser accepts only lint attributes there"
833                ));
834            }
835            index = next;
836            continue;
837        }
838        if trimmed.starts_with('#') && trimmed[1..].trim_start().starts_with('[') {
839            let (attribute, next) = attribute_at(&lines, index)?;
840            let indented = line.starts_with(char::is_whitespace);
841            if indented {
842                if names_test_machinery(&attribute) {
843                    return Err(format!(
844                        "line {number}: the indented attribute {attribute} names test, ignore or cfg; the ledger's parser reads only top-level tests, so a nested module's or a macro's test is refused"
845                    ));
846                }
847            } else {
848                group.push((number, attribute));
849            }
850            index = next;
851            continue;
852        }
853        // Code: the item the pending attributes belong to, if any.
854        if !group.is_empty() {
855            let item = if line.starts_with(char::is_whitespace) {
856                None
857            } else {
858                declared_fn(line)
859            };
860            let mut is_test = false;
861            let mut ignored = false;
862            for (at, attribute) in &group {
863                match attribute.as_str() {
864                    "#[test]" if is_test => {
865                        return Err(format!("line {at}: a second #[test] on one item"));
866                    }
867                    "#[test]" => is_test = true,
868                    "#[ignore]" => ignored = true,
869                    "#[should_panic]" => {}
870                    _ if is_string_valued(attribute, "ignore") => ignored = true,
871                    _ if is_string_valued(attribute, "should_panic")
872                        || (attribute.starts_with("#[should_panic(")
873                            && attribute.ends_with(")]")
874                            && !names_test_machinery(&attribute["#[should_panic".len()..])) => {}
875                    _ if names_test_machinery(attribute) => {
876                        return Err(format!(
877                            "line {at}: the attribute {attribute} could change which tests run or whether one is ignored; the ledger's parser accepts #[test], #[ignore], #[ignore = \"...\"], #[should_panic] in any form, and lint and documentation attributes"
878                        ));
879                    }
880                    _ if is_neutral_attribute(attribute) => {}
881                    _ if item.is_some() => {
882                        return Err(format!(
883                            "line {at}: the attribute {attribute} on fn {} is one the ledger's parser does not know; it could make the function a test",
884                            item.unwrap_or_default()
885                        ));
886                    }
887                    _ => {}
888                }
889            }
890            match (is_test, item) {
891                (true, Some(name)) => {
892                    if tests.insert(name.to_string(), ignored).is_some() {
893                        return Err(format!("line {number}: the suite declares {name} twice"));
894                    }
895                }
896                (true, None) => {
897                    return Err(format!(
898                        "line {number}: #[test] is not on a top-level fn: {trimmed:?}"
899                    ));
900                }
901                (false, _) if ignored => {
902                    return Err(format!(
903                        "line {number}: #[ignore] without #[test]: {trimmed:?}"
904                    ));
905                }
906                (false, _) => {}
907            }
908            group.clear();
909        }
910        index += 1;
911    }
912    if let Some((at, attribute)) = group.first() {
913        return Err(format!(
914            "line {at}: the attribute {attribute} ends the file"
915        ));
916    }
917    if tests.is_empty() {
918        return Err("the suite declares no #[test] function".into());
919    }
920    Ok(tests)
921}

923/// The static rules of one version: every row names a test of the suite that is not ignored, and
924/// the backend-proof test is a test of the suite, not ignored and not a row. Returns every
925/// violation.
926pub fn check(
927    declaration: &Declaration,
928    rows: &[Row],
929    tests: &BTreeMap<String, bool>,
930) -> Vec<String> {
931    let mut errors = Vec::new();
932    for row in rows {
933        let Some(test) = row.test(declaration.id_prefix) else {
934            errors.push(format!(
935                "{}: not a test of {}: every id of this ledger starts with {:?}",
936                row.id, declaration.suite_source, declaration.id_prefix
937            ));
938            continue;
939        };
940        match tests.get(test) {
941            None => errors.push(format!(
942                "{}: {} declares no test {test}; delete the row, or correct its id",
943                row.id, declaration.suite_source
944            )),
945            Some(true) => errors.push(format!(
946                "{}: the test is #[ignore]d, so no run can show whether it still fails",
947                row.id
948            )),
949            Some(false) => {}
950        }
951    }
952    let proof = format!(
953        "{}{}",
954        declaration.id_prefix, declaration.backend_proof_test
955    );
956    match tests.get(declaration.backend_proof_test) {
957        None => errors.push(format!(
958            "{}: the backend-proof test is not in {}",
959            declaration.backend_proof_test, declaration.suite_source
960        )),
961        Some(true) => errors.push(format!(
962            "{}: the backend-proof test is #[ignore]d",
963            declaration.backend_proof_test
964        )),
965        Some(false) => {}
966    }
967    if rows.iter().any(|row| row.id == proof) {
968        errors.push(format!(
969            "{proof}: the backend-proof test cannot be a gap row: it is what shows that the node ran on {}",
970            declaration.backend
971        ));
972    }
973    errors
974}

1081/// Hold a ledger to its history ([module documentation](self)). `versions` are the committed
1082/// versions at every commit that changed the ledger or the suite, from the introduction (position
1083/// 0) to the commit judged; `trailers` are the approval lines of every commit of that history.
1084pub fn judge_history(
1085    declaration: &Declaration,
1086    versions: &[Version],
1087    trailers: &[CommitTrailers],
1088) -> HistoryVerdict {
1089    let mut verdict = HistoryVerdict::default();
1090    let (Some(introduction), Some(head)) = (versions.first(), versions.last()) else {
1091        verdict.violations.push(format!(
1092            "{}: no committed version to judge",
1093            declaration.ledger
1094        ));
1095        return verdict;
1096    };
1097    if introduction.position != 0
1098        || versions
1099            .windows(2)
1100            .any(|pair| pair[0].position >= pair[1].position)
1101    {
1102        verdict.violations.push(format!(
1103            "{}: the versions do not start at the introduction and advance; the history walk is inconsistent",
1104            declaration.ledger
1105        ));
1106        return verdict;
1107    }
1108    let bound = |kind: TrailerKind, url: Option<&str>, id: &str, from: usize| {
1109        trailers
1110            .iter()
1111            .filter(|commit| commit.position >= from)
1112            .flat_map(|commit| &commit.trailers)
1113            .any(|trailer| {
1114                trailer.kind == kind
1115                    && url.is_none_or(|url| trailer.url == url)
1116                    && trailer.ids.iter().any(|named| named == id)
1117            })
1118    };
1119    for row in &head.rows {
1120        let scope = row.scope();
1121        let mut start = versions.len() - 1;
1122        while start > 0
1123            && versions[start - 1]
1124                .rows
1125                .iter()
1126                .any(|earlier| earlier.scope() == scope)
1127        {
1128            start -= 1;

1190        }
