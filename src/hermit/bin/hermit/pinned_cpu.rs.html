9//! The CPU a sequentialized run is pinned to.
10//!
11//! A run with a `max_timeslice` pins its tracer, its notifier threads and
12//! every guest thread to one CPU for the whole run, because its retired-branch
13//! counts must not see a migration (`RunOpts::pin_threads`). Every ptrace stop
14//! then costs several wakeups on that one CPU: the guest stops, its notifier
15//! thread wakes, the tracer wakes, and the tracer resumes the guest.
16//!
17//! So the CPU matters, and a CPU-bound task already on it is the worst case.
18//! Linux shares a CPU between cgroups by weight, and it scales a cgroup's
19//! weight on one CPU by about the share of the cgroup's load that is on that
20//! CPU (`calc_group_shares`, kernel/sched/fair.c). A run inside a cgroup that
21//! is busy on many other CPUs, as a test runner's is, therefore has almost no
22//! weight on its own CPU. Beside a CPU-bound task from a cgroup whose load is
23//! concentrated there, each of the run's wakeups waits for that task, and the
24//! run does the same work hundreds of times slower
25//! (<https://github.com/rrnewton/hermit/issues/4824>). Measured on a 316-CPU
26//! host: one strict verify of an epoll guest took 1.5 s on an idle CPU and
27//! 15.5 s on a CPU running a busy loop from another cgroup, while the run's
28//! own cgroup kept 24 busy loops on other CPUs. Under a loaded test runner,
29//! runs were 170 to 1,400 times slower and hit test deadlines.
30//!
31//! A uniformly random CPU lands on such a task as often as there are busy
32//! CPUs. Instead, a run samples the allowed CPUs' busy time from `/proc/stat`
33//! over [`SAMPLE_WINDOW`] and draws uniformly from the ones that were idle, or,
34//! when none was, from the least busy.
35//!
36//! A sample alone cannot keep concurrent runs apart. Runs that sample at the
37//! same moment draw from the same candidates: every idle CPU while there are
38//! some (three runs among eight idle CPUs share one 34% of the time), but
39//! often a single CPU when there are none, since at 10 ms ticks the least busy
40//! fraction is rarely tied. And a run whose guest mostly waits leaves its CPU
41//! looking idle to a later run's sample. Two runs on one CPU take turns at
42//! every ptrace stop: two copies of a 40,000-syscall guest pinned to one core
43//! took 260 s each, against 27 s on two cores. So a run also reserves its CPU
44//! for its lifetime (`reserve`): an abstract Unix socket named after the CPU,
45//! which the kernel lets one socket in a network namespace hold
46//! (`unix_bind_abstract`, net/unix/af_unix.c) and releases when the last
47//! descriptor for it closes: when Hermit and its container init, which holds
48//! a copy and dies with Hermit, have exited, however they exit. A CPU another
49//! run holds is passed over for the next draw from the same sample, and only
50//! when every allowed CPU is held does a run share one: the CPU it drew
51//! first. Sharing costs speed, never determinism. Runs in different network
52//! namespaces do not see each other's socket names, so a run also takes an
53//! exclusive `flock` on its CPU's file in a lock directory (`lock`,
54//! [`LOCK_DIR_DEFAULT`]), which every run sharing that directory sees, and
55//! which the kernel likewise releases with the last descriptor. A CPU either
56//! channel holds is held. A directory Hermit creates is private to its user
57//! (0700) unless it runs as root; root's shared form is mode 1777 with the
58//! sticky bit (`open_lock_dir`). A container with a private `/dev/shm` has a
59//! private copy of the default directory, so it coordinates only within
60//! itself unless one directory is bind-mounted into every container (the
61//! validation wrapper bind-mounts a host shared-form directory at the
62//! default path); nothing can detect that case from inside.
63//!
64//! A run that cannot keep other runs off its CPU (it shares one, cannot
65//! reserve one, or can reserve one only within its network namespace) says
66//! so by name on Hermit's own stderr, once per process, or, under `hermit run
67//! --pinned-cpu=refuse` or `wait`, refuses before the guest starts (`admit`).
68//!
69//! A process holds one reservation at a time (`HELD`). Its later runs (the
70//! second run of a `--verify` pair, `analyze` trials) sample again, count the
71//! CPU the process holds as free rather than as another run's, and move the
72//! reservation when they draw a different CPU.
73//!
74//! Among the candidates, a run passes over the CPUs a PMU is bound to while
75//! any other candidate remains. Some PMUs open their events on a few CPUs,
76//! named by `/sys/bus/event_source/devices/<pmu>/cpumask` (on AMD, `amd_l3`
77//! on one CPU per L3 and `amd_df` and `amd_umc` on CPU 0), and ptrace stops
78//! cost several times as much CPU there
79//! (<https://github.com/rrnewton/hermit/issues/3265>: 7.6-7.9x for a
80//! ptrace-stop-heavy cell; 2.5x for the epoll verify above on CPU 0). Because
81//! validation and `bin/safehermit` keep runs off those CPUs, they are often
82//! idle, and an idle draw would otherwise favour them. The set is derived as
83//! the validation launcher derives the CPUs it excludes: the union of every
84//! PMU `cpumask` that names at most a quarter of the online CPUs, since a
85//! wider one belongs to a per-core PMU. Where the launcher would skip a PMU
86//! entry or cpumask that is not what sysfs presents, this passes nothing over.
87//!
88//! Not handled: a CPU-bound task that reaches the CPU after the sample (load
89//! balancing moves one there, or a job starts or pins itself there) still
90//! slows the run for the rest of its life, and nothing reports it. Moving the
91//! run then would migrate its guest threads, which is what pinning exists to
92//! prevent. Nor can a sample tell a CPU-bound task from the run's own
93//! launcher: with few allowed CPUs, the launcher can keep the only other CPU
94//! busy for the whole window too, and the draw then takes either.
95//!
96//! The choice is host placement only, and it was already a random draw per
97//! run. The guest sees its own virtual CPU through getcpu, sched_getaffinity,
98//! `/proc/self/status` and RDTSCP's TSC_AUX. As before, only a guest that
99//! executes RDPID although CPUID hides it, or that uses rseq under the
100//! compatibility opt-out, can read the host CPU number.

115/// How long the allowed CPUs' busy time is sampled before a run takes one.
116/// `/proc/stat` counts in 1/USER_HZ ticks, 10 ms on Linux, so this is about
117/// five ticks per CPU. A CPU that was busy for 10 ms or more of the window
118/// shows at least one busy tick, so a CPU-bound task is always seen; the
119/// window is long enough that one which runs half of every 100 ms is too.
120pub(crate) const SAMPLE_WINDOW: Duration = Duration::from_millis(50);
121
122/// A CPU is idle when at most this fraction of the sample was busy, expressed
123/// as a denominator: one tick in five. Each read rounds to whole ticks, so an
124/// idle CPU can show one busy tick, while a CPU-bound task shows four or five.
125const IDLE_DENOMINATOR: u64 = 5;

173/// Why a run got the CPU it got, for the log line that names it.

236/// Choose a CPU from `allowed`, the tracer's affinity mask, with the
237/// observation made by `observe`, which tests replace, and say why. `None`
238/// only when `allowed` is empty. Reserves nothing: runs choose through
239/// [`choose_for_run`], which draws the same way.
240#[cfg(test)]
241pub(crate) fn choose_with(
242    allowed: &[usize],
243    observe: impl FnOnce(&[usize]) -> Option<Observation>,
244) -> Option<(usize, Basis)> {
245    match allowed {
246        [] => None,
247        [only] => Some((*only, Basis::OnlyAllowed)),
248        _ => Some(draw(allowed, observe(allowed).as_ref())),
249    }
250}

252/// One draw from `pool`, two or more CPUs: from its candidates under
253/// `observation`, or from all of it without one.
254fn draw(pool: &[usize], observation: Option<&Observation>) -> (usize, Basis) {
255    let (candidates, basis) = observation
256        .and_then(|observation| candidates(pool, observation))
257        .unwrap_or_else(|| (pool.to_vec(), Basis::Unsampled));
258    (candidates[rand::random_range(0..candidates.len())], basis)
259}

270/// The reservation this process holds: its CPU and the descriptor that holds
271/// its name. A later run of the same process (a `--verify` pair runs twice)

273/// descriptor, so a process never holds a CPU it moved away from. Runs one

286/// How a run holds its CPU against other Hermit runs.
287#[derive(Clone, Debug, PartialEq, Eq)]
288pub(crate) enum Hold {
289    /// This process holds the CPU: no other Hermit run in this network
290    /// namespace is pinned to it. `passed_over` CPUs other runs hold were
291    /// passed over first.
292    Reserved { passed_over: usize },
293    /// This process already held the CPU, for an earlier run, and keeps it.
294    Kept,
295    /// Every allowed CPU is held by another Hermit run, so this run shares
296    /// the CPU it drew first with one of them.
297    Shared,
298    /// A reservation could not be made (the error), so the CPU is used
299    /// unreserved, and another run may share it.
300    Unreserved(String),
301}

339/// Choose and reserve the CPU this run is pinned to from `allowed`, the
340/// tracer's affinity mask, over a fresh sample, counting the CPU this process
341/// already holds as free. `None` only when `allowed` is empty.
342pub(crate) fn choose_for_run(allowed: &[usize], dir: &Path) -> Option<(Choice, Coordination)> {
343    let mut held = HELD.lock().unwrap_or_else(|poison| poison.into_inner());
344    let (dir, coordination) = match open_lock_dir(dir) {
345        Ok(fd) => (Some(fd), Coordination::Host(dir.to_path_buf())),
346        Err(reason) => (None, Coordination::NetworkNamespaceOnly(reason)),
347    };
348    let choice = choose_for_run_with(allowed, observe, &mut held, |cpu| {
349        reserve_both(RESERVATION_PREFIX, dir.as_ref(), cpu)
350    })?;
351    Some((choice, coordination))
352}

354/// [`choose_for_run`] with the observation, the process's reservation and
355/// the reservation call supplied, which tests replace. `reserve` answers the
356/// descriptor that now holds a CPU, or `None` when another run holds it.
357/// A run that reserves a different CPU replaces `held`, closing the old
358/// descriptor; a run that shares or goes unreserved leaves `held` empty, since
359/// the process no longer runs on the CPU it held.
360fn choose_for_run_with<R>(
361    allowed: &[usize],
362    observe: impl FnOnce(&[usize]) -> Option<Observation>,
363    held: &mut Option<(usize, R)>,
364    mut reserve: impl FnMut(usize) -> io::Result<Option<R>>,
365) -> Option<Choice> {
366    let own = held.as_ref().map(|(cpu, _)| *cpu);
367    let mut taken = None;
368    let mut choice = choose_reserving(allowed, observe, |cpu| {
369        if Some(cpu) == own {
370            return Ok(true);
371        }
372        Ok(reserve(cpu)?.map(|fd| taken = Some((cpu, fd))).is_some())
373    })?;
374    match (&choice.hold, taken) {
375        (Hold::Reserved { .. }, Some(new)) => *held = Some(new),
376        (Hold::Reserved { .. }, None) => choice.hold = Hold::Kept,
377        _ => *held = None,
378    }
379    Some(choice)
380}

382/// [`choose_with`], passing over the CPUs other Hermit runs hold. `reserve`
383/// takes a CPU for this run: `Ok(true)` when the run now holds it, `Ok(false)`
384/// when another run does, and an error when reservations cannot be made at
385/// all. Every draw uses the one observation: it is [`choose_with`]'s draw over
386/// the allowed CPUs not yet found held, so a run passes a held idle CPU over
387/// for another idle one, and then for the least busy free one. With every CPU
388/// held, the run shares the CPU it drew first.
389pub(crate) fn choose_reserving(
390    allowed: &[usize],
391    observe: impl FnOnce(&[usize]) -> Option<Observation>,
392    mut reserve: impl FnMut(usize) -> io::Result<bool>,
393) -> Option<Choice> {
394    let observation = match allowed {
395        [] => return None,
396        [_] => None,
397        _ => observe(allowed),
398    };
399    let mut free = allowed.to_vec();
400    let mut first = None;
401    loop {
402        let (cpu, basis) = match allowed {
403            [only] => (*only, Basis::OnlyAllowed),
404            _ => draw(&free, observation.as_ref()),
405        };
406        let first = *first.get_or_insert((cpu, basis));
407        let hold = match reserve(cpu) {
408            Ok(true) => Hold::Reserved {
409                passed_over: allowed.len() - free.len(),
410            },
411            Ok(false) => {
412                free.retain(|other| *other != cpu);
413                if !free.is_empty() {
414                    continue;
415                }
416                return Some(Choice {
417                    cpu: first.0,
418                    basis: first.1,
419                    hold: Hold::Shared,
420                });
421            }
422            Err(error) => Hold::Unreserved(error.to_string()),
423        };
424        return Some(Choice { cpu, basis, hold });
425    }
426}

428/// Hold `cpu` while the returned descriptor is open: an abstract Unix socket
429/// named `<prefix>:<cpu>`, bound close-on-exec, which the kernel releases when
430/// its last descriptor closes, at the latest when Hermit exits. Another run
431/// that binds the same name gets `EADDRINUSE`, answered as `Ok(None)`. The
432/// names belong to a network namespace: runs in different ones do not see
433/// each other's CPUs.
434fn reserve(prefix: &str, cpu: usize) -> io::Result<Option<OwnedFd>> {
435    use std::os::linux::net::SocketAddrExt;
436    let name = format!("{prefix}:{cpu}");
437    let address = std::os::unix::net::SocketAddr::from_abstract_name(name.as_bytes())?;
438    let socket = match std::os::unix::net::UnixDatagram::bind_addr(&address) {
439        Ok(socket) => socket,
440        Err(error) if error.raw_os_error() == Some(libc::EADDRINUSE) => return Ok(None),
441        Err(error) => return Err(error),
442    };
443    Ok(Some(move_high(OwnedFd::from(socket))?))
444}

446/// `fd` moved to a high close-on-exec descriptor, and its low number closed:
447/// at least [`RESERVATION_FD_FLOOR`] where the descriptor limit allows, and
448/// otherwise a free number just below the limit, so that a run under a
449/// low `RLIMIT_NOFILE` (1000 or less, where `F_DUPFD_CLOEXEC` from the floor
450/// fails with `EINVAL`) still reserves its CPU. Keeps `fd` where it is only
451/// when no number above it is free.
452fn move_high(fd: OwnedFd) -> io::Result<OwnedFd> {
453    // SAFETY: `fd` is an open descriptor this function owns.
454    let moved = unsafe { libc::fcntl(fd.as_raw_fd(), libc::F_DUPFD_CLOEXEC, RESERVATION_FD_FLOOR) };
455    if moved >= 0 {
456        // SAFETY: `moved` is a new descriptor nothing else owns; `fd` closes
457        // its own number when it drops.
458        return Ok(unsafe { OwnedFd::from_raw_fd(moved) });
459    }
460    let error = io::Error::last_os_error();
461    // EINVAL: the floor is at or above the limit. EMFILE: every number from
462    // the floor to the limit is taken (a limit just above the floor).
463    if !matches!(error.raw_os_error(), Some(libc::EINVAL | libc::EMFILE)) {
464        return Err(error);
465    }
466    let limit = nix::sys::resource::getrlimit(nix::sys::resource::Resource::RLIMIT_NOFILE)
467        .map_err(io::Error::from)?
468        .0;
469    // `F_DUPFD_CLOEXEC` takes the lowest free number at or above its floor,
470    // atomically, so no other thread's descriptor is ever replaced. Lower the
471    // floor from just below the limit until a number is free (`EMFILE` means
472    // none is at or above that floor).
473    let limit = libc::c_int::try_from(limit.min(RESERVATION_FD_FLOOR as u64)).unwrap_or(0);
474    let mut step = 1;
475    while limit - step > fd.as_raw_fd() {
476        // SAFETY: `fd` is an open descriptor this function owns.
477        let moved = unsafe { libc::fcntl(fd.as_raw_fd(), libc::F_DUPFD_CLOEXEC, limit - step) };
478        if moved >= 0 {
479            // SAFETY: `moved` is a new descriptor nothing else owns.
480            return Ok(unsafe { OwnedFd::from_raw_fd(moved) });
481        }
482        let error = io::Error::last_os_error();
483        if error.raw_os_error() != Some(libc::EMFILE) {
484            return Err(error);
485        }
486        step *= 2;
487    }
488    Ok(fd)
489}

531/// The mode a lock directory is created with: root's shared form (1777 with
532/// the sticky bit), which every user's runs can lock in, and otherwise 0700,
533/// private to the user, since no other user's run would use another user's
534/// directory (`acceptable_owner`) and a writable one would only let others
535/// squat its CPUs' files.
536fn created_lock_dir_mode(euid: u32) -> libc::mode_t {
537    if euid == 0 { 0o1777 } else { 0o700 }
538}

540/// Opens, or creates, the lock directory `base`, and checks the directory it
541/// opened: a real directory (`O_NOFOLLOW`, so not a symlink), owned by this
542/// user, or else root's shared form (mode 1777 with the sticky bit), so no
543/// other user can remove or replace this user's lock files. The checks apply
544/// to the open descriptor, which `lock` then opens files in (`openat`), so a
545/// component swapped after the check cannot redirect them. Components above
546/// `base` (`/dev/shm` itself) are the administrator's configuration and are
547/// trusted as given.
548fn open_lock_dir(base: &Path) -> Result<OwnedFd, String> {
549    use std::os::unix::ffi::OsStrExt;
550    let shown = base.display();
551    let euid = nix::unistd::geteuid().as_raw();
552    let path = std::ffi::CString::new(base.as_os_str().as_bytes())
553        .map_err(|_| format!("{shown} contains a NUL byte"))?;
554    let mode = created_lock_dir_mode(euid);
555    // SAFETY: `path` is a NUL-terminated string.
556    let created = unsafe { libc::mkdir(path.as_ptr(), mode) } == 0;
557    if !created {
558        let error = io::Error::last_os_error();
559        if error.raw_os_error() != Some(libc::EEXIST) {
560            return Err(format!("cannot create {shown}: {error}"));
561        }
562    }
563    // SAFETY: `path` is a NUL-terminated string; the result is checked.
564    let fd = unsafe {
565        libc::open(
566            path.as_ptr(),
567            libc::O_RDONLY | libc::O_DIRECTORY | libc::O_NOFOLLOW | libc::O_CLOEXEC,
568        )
569    };
570    if fd < 0 {
571        let error = io::Error::last_os_error();
572        // With both O_DIRECTORY and O_NOFOLLOW, a symlink can fail with
573        // ENOTDIR as well as ELOOP, so ask which it was.
574        let symlink = fs::symlink_metadata(base).is_ok_and(|meta| meta.file_type().is_symlink());
575        return Err(match error.raw_os_error() {
576            Some(libc::ELOOP | libc::ENOTDIR) if symlink => format!("{shown} is a symbolic link"),
577            Some(libc::ENOTDIR) => format!("{shown} is not a directory"),
578            _ => format!("cannot open {shown}: {error}"),
579        });
580    }
581    // SAFETY: `fd` is a new descriptor nothing else owns.
582    let dir = unsafe { OwnedFd::from_raw_fd(fd) };
583    let stat =
584        nix::sys::stat::fstat(&dir).map_err(|error| format!("cannot stat {shown}: {error}"))?;
585    if !acceptable_owner(stat.st_uid, stat.st_mode, euid) {
586        return Err(format!(
587            "{shown} belongs to user {} and is not root's shared form (mode 1777, sticky); \
588             as root, `install -d -m 1777 -o root -g root {shown}` creates the shared form",
589            stat.st_uid
590        ));
591    }
592    if created {
593        // The umask may have cleared bits `mkdir` asked for.
594        // SAFETY: fchmod on a directory this function owns.
595        if unsafe { libc::fchmod(dir.as_raw_fd(), mode) } != 0 {
596            return Err(format!(
597                "cannot set the mode of {shown}: {}",
598                io::Error::last_os_error()
599            ));
600        }
601    }
602    Ok(dir)
603}

605/// Whether a lock directory owned by `owner` with `mode` may be used by user
606/// `euid`: its own, or root's shared mode-1777 sticky directory.
607fn acceptable_owner(owner: u32, mode: u32, euid: u32) -> bool {
608    owner == euid || (owner == 0 && mode & 0o7777 == 0o1777)
609}

611/// Hold `cpu`'s lock file in the lock directory `dir` (`open_lock_dir`) while
612/// the returned descriptor is open: an exclusive `flock`, which the kernel
613/// releases when the last descriptor for it closes, however its holders exit.
614/// `Ok(None)` when the CPU counts as held: another run holds the lock, or the
615/// file is not one this run can lock (another user's that it cannot open, a
616/// symlink, or not a regular file), which a squatter could arrange but which
617/// only ever makes this run pass the CPU over or share it. The file is opened
618/// without following a symlink and without blocking (a FIFO in its place
619/// cannot stall the run). A file this user owns is made mode 0644 whatever the
620/// umask, so other users' runs in root's shared directory can lock it too.
621fn lock(dir: &OwnedFd, cpu: usize) -> io::Result<Option<OwnedFd>> {
622    let name = std::ffi::CString::new(cpu.to_string()).expect("a number has no NUL");
623    let flags = libc::O_NOFOLLOW | libc::O_CLOEXEC | libc::O_NONBLOCK;
624    let open = |extra: libc::c_int| {
625        // SAFETY: `dir` is an open directory and `name` is NUL-terminated.
626        let fd = unsafe { libc::openat(dir.as_raw_fd(), name.as_ptr(), flags | extra, 0o644) };
627        if fd < 0 {
628            Err(io::Error::last_os_error())
629        } else {
630            // SAFETY: `fd` is a new descriptor nothing else owns.
631            Ok(unsafe { OwnedFd::from_raw_fd(fd) })
632        }
633    };
634    let file = match open(libc::O_RDWR | libc::O_CREAT).or_else(|error| {
635        // Another user's file, readable: a shared lock file.
636        if error.raw_os_error() == Some(libc::EACCES) {
637            open(libc::O_RDONLY)
638        } else {
639            Err(error)
640        }
641    }) {
642        Ok(file) => file,
643        // Unopenable (another user's, unreadable), a symlink (`ELOOP`), a
644        // directory (`EISDIR`) or a device or socket with nothing behind it
645        // (`ENXIO`).
646        Err(error)
647            if matches!(
648                error.raw_os_error(),
649                Some(libc::EACCES | libc::ELOOP | libc::EISDIR | libc::ENXIO)
650            ) =>
651        {
652            return Ok(None);
653        }
654        Err(error) => return Err(error),
655    };
656    let stat = nix::sys::stat::fstat(&file)?;
657    if stat.st_mode & libc::S_IFMT != libc::S_IFREG {
658        return Ok(None);
659    }
660    if stat.st_uid == nix::unistd::geteuid().as_raw() && stat.st_mode & 0o7777 != 0o644 {
661        // SAFETY: fchmod on a file this function owns.
662        if unsafe { libc::fchmod(file.as_raw_fd(), 0o644) } != 0 {
663            return Err(io::Error::last_os_error());
664        }
665    }
666    // SAFETY: flock on a descriptor this function owns.
667    if unsafe { libc::flock(file.as_raw_fd(), libc::LOCK_EX | libc::LOCK_NB) } == 0 {
668        return Ok(Some(move_high(file)?));
669    }
670    let error = io::Error::last_os_error();
671    if error.raw_os_error() == Some(libc::EWOULDBLOCK) {
672        return Ok(None);
673    }
674    Err(error)
675}

677/// Reserve `cpu` through both channels: its lock file in `dir`, when there is
678/// one, and then its abstract socket name. `Ok(None)` when either is held.
679fn reserve_both(
680    prefix: &str,
681    dir: Option<&OwnedFd>,
682    cpu: usize,
683) -> io::Result<Option<Reservation>> {
684    let lock = match dir {
685        Some(dir) => match lock(dir, cpu)? {
686            Some(lock) => Some(lock),
687            None => return Ok(None),
688        },
689        None => None,
690    };
691    Ok(reserve(prefix, cpu)?.map(|socket| Reservation {

693        _lock: lock,

695}

697/// What a pinned run does when it cannot hold a CPU of its own
698/// (`hermit run --pinned-cpu`).
699#[derive(Clone, Copy, Debug, PartialEq, Eq)]
700pub(crate) enum PinnedCpuPolicy {
701    /// Run anyway, on a CPU another run may share, with a notice saying so.
702    Share,
703    /// Refuse the run before the guest starts.
704    Refuse,
705    /// Wait up to this long for a CPU to come free, then refuse.
706    Wait(Duration),
707}
708
709/// The default `--pinned-cpu=wait` bound.
710pub(crate) const DEFAULT_WAIT: Duration = Duration::from_secs(600);
711
712/// How often `--pinned-cpu=wait` tries again. Each try sleeps; nothing spins.
713pub(crate) const WAIT_INTERVAL: Duration = Duration::from_millis(500);
714
715impl std::str::FromStr for PinnedCpuPolicy {
716    type Err = String;
717    fn from_str(text: &str) -> Result<Self, String> {
718        match text {
719            "share" => Ok(Self::Share),
720            "refuse" => Ok(Self::Refuse),
721            "wait" => Ok(Self::Wait(DEFAULT_WAIT)),
722            _ => match text.strip_prefix("wait:").map(str::parse::<u64>) {
723                Some(Ok(seconds)) if seconds > 0 => Ok(Self::Wait(Duration::from_secs(seconds))),
724                _ => Err(format!(
725                    "expected share, refuse, wait or wait:SECONDS (SECONDS above 0), got {text:?}"
726                )),
727            },
728        }
729    }
730}

732impl fmt::Display for PinnedCpuPolicy {
733    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
734        match self {
735            Self::Share => f.write_str("share"),
736            Self::Refuse => f.write_str("refuse"),
737            Self::Wait(wait) if *wait == DEFAULT_WAIT => f.write_str("wait"),
738            Self::Wait(wait) => write!(f, "wait:{}", wait.as_secs()),
739        }
740    }
741}

895/// What kept a run from holding a CPU of its own, or `None` when nothing did.
896fn shortfall<'a>(choice: &'a Choice, coordination: &'a Coordination) -> Option<Shortfall<'a>> {
897    match (&choice.hold, coordination) {
898        (Hold::Shared, _) => Some(Shortfall::Shared),
899        (Hold::Unreserved(error), _) => Some(Shortfall::Unreserved(error)),
900        (_, Coordination::NetworkNamespaceOnly(reason)) => Some(Shortfall::NetnsOnly(reason)),
901        _ => None,
902    }
903}
904
905enum Shortfall<'a> {
906    Shared,
907    Unreserved(&'a str),
908    NetnsOnly(&'a str),
909}
910
911impl Shortfall<'_> {
912    /// The named notice a `share` run prints.
913    fn notice(&self, allowed: &[usize], cpu: usize) -> String {
914        let set = cpu_set(allowed);
915        match self {
916            Shortfall::Shared => format!(
917                "hermit: warning: cpu-shared: every allowed CPU ({set}) is held by another Hermit \
918                 run; this run shares CPU {cpu} and runs slower (placement only: guest output is \
919                 unaffected). --pinned-cpu=wait or =refuse avoids sharing."
920            ),
921            Shortfall::Unreserved(error) => format!(
922                "hermit: warning: cpu-unreserved: could not reserve CPU {cpu} ({error}); another \
923                 Hermit run may be pinned to it."
924            ),
925            Shortfall::NetnsOnly(reason) => format!(
926                "hermit: warning: cpu-netns-only: CPU {cpu} is reserved only against Hermit runs in \
927                 this network namespace ({}): {reason}. Runs in other network namespaces may pick \
928                 the same CPU; name a lock directory they share with --pinned-cpu-dir.",
929                network_namespace()
930            ),
931        }
932    }
933
934    /// The refusal under `refuse`, or `wait` when waiting cannot help.
935    fn refusal(&self, policy: PinnedCpuPolicy, allowed: &[usize], cpu: usize) -> String {
936        let set = cpu_set(allowed);
937        match self {
938            Shortfall::Shared => format!(
939                "--pinned-cpu={policy}: every allowed CPU ({set}) is held by another Hermit run, \
940                 so the run was not started. Retry when one is free, wait for one with \
941                 --pinned-cpu=wait[:SECONDS], allow more CPUs, or run on a shared CPU with \
942                 --pinned-cpu=share."
943            ),
944            Shortfall::Unreserved(error) => format!(
945                "--pinned-cpu={policy}: CPU {cpu} of the allowed CPUs ({set}) could not be \
946                 reserved ({error}), so the run was not started. Fix that cause, or run \
947                 unreserved with --pinned-cpu=share."
948            ),
949            Shortfall::NetnsOnly(reason) => format!(
950                "--pinned-cpu={policy}: a reservation on the allowed CPUs ({set}) would reach only \
951                 Hermit runs in this network namespace ({}): {reason}. The run was not started. \
952                 Name a usable lock directory with --pinned-cpu-dir=PATH, or run with \
953                 --pinned-cpu=share.",
954                network_namespace()
955            ),
956        }
957    }
958
959    /// The notice kind, which a process prints once (`place`).
960    fn kind(&self) -> &'static str {
961        match self {
962            Shortfall::Shared => "cpu-shared",
963            Shortfall::Unreserved(_) => "cpu-unreserved",
964            Shortfall::NetnsOnly(_) => "cpu-netns-only",
965        }
966    }
967}

969/// `0-3,8` for the CPUs in `cpus`.
970fn cpu_set(cpus: &[usize]) -> String {
971    let mut ranges: Vec<(usize, usize)> = Vec::new();
972    for &cpu in cpus {
973        match ranges.last_mut() {
974            Some((_, end)) if *end + 1 == cpu => *end = cpu,
975            _ => ranges.push((cpu, cpu)),
976        }
977    }
978    ranges
979        .iter()
980        .map(|&(start, end)| {
981            if start == end {
982                start.to_string()
983            } else {
984                format!("{start}-{end}")
985            }
986        })
987        .collect::<Vec<_>>()
988        .join(",")
989}

998/// Place a pinned run on a CPU from `allowed` under `policy`, writing each
999/// notice (its kind and text) to `notices`. `choose` makes one attempt
1000/// (`choose_for_run`). Under `wait`, a run whose every CPU is held prints one
1001/// "waiting" line, then sleeps (`pause`) and tries again until `elapsed`
1002/// reaches the wait's bound, the smaller of the policy's and `wait_cap`, and
1003/// is refused then. A refusal names the CPU set, why, and what to do.
1004fn admit(
1005    allowed: &[usize],
1006    policy: PinnedCpuPolicy,
1007    wait_cap: Option<Duration>,
1008    mut choose: impl FnMut(&[usize]) -> Option<(Choice, Coordination)>,
1009    mut pause: impl FnMut(Duration),
1010    mut elapsed: impl FnMut() -> Duration,
1011    notices: &mut dyn FnMut(&'static str, &str),
1012) -> Result<Option<Choice>, PlacementRefusal> {
1013    let mut announced = false;
1014    loop {
1015        let Some((choice, coordination)) = choose(allowed) else {
1016            return Ok(None);
1017        };
1018        let Some(shortfall) = shortfall(&choice, &coordination) else {
1019            return Ok(Some(choice));
1020        };
1021        match (policy, &shortfall) {
1022            (PinnedCpuPolicy::Share, _) => {
1023                notices(shortfall.kind(), &shortfall.notice(allowed, choice.cpu));
1024                return Ok(Some(choice));
1025            }
1026            (PinnedCpuPolicy::Wait(wait), Shortfall::Shared) => {
1027                let bound = wait_cap.map_or(wait, |cap| cap.min(wait));
1028                let waited = elapsed();
1029                if waited >= bound {
1030                    let capped = if bound < wait {
1031                        " (bounded by --timeout)"
1032                    } else {
1033                        ""
1034                    };
1035                    return Err(PlacementRefusal(format!(
1036                        "--pinned-cpu={policy}: every allowed CPU ({}) stayed held by another \
1037                         Hermit run for the whole {} s wait{capped}, so the run was not started. \
1038                         Retry later, wait longer with --pinned-cpu=wait:SECONDS, allow more CPUs, \
1039                         or run on a shared CPU with --pinned-cpu=share.",
1040                        cpu_set(allowed),
1041                        bound.as_secs()
1042                    )));
1043                }
1044                if !announced {
1045                    announced = true;
1046                    notices(
1047                        "cpu-waiting",
1048                        &format!(
1049                            "hermit: waiting up to {} s for a CPU: every allowed CPU ({}) is held \
1050                             by another Hermit run (--pinned-cpu={policy}).",
1051                            bound.as_secs(),
1052                            cpu_set(allowed)
1053                        ),
1054                    );
1055                }
1056                pause(WAIT_INTERVAL.min(bound - waited));
1057            }
1058            (PinnedCpuPolicy::Refuse | PinnedCpuPolicy::Wait(_), _) => {
1059                return Err(PlacementRefusal(
1060                    shortfall.refusal(policy, allowed, choice.cpu),
1061                ));
1062            }
1063        }
1064    }
1065}

1071/// [`admit`] for this process: the settings `set_settings` gave, real

1073/// Hermit's own stderr unless the notices are off.
1074pub(crate) fn place(allowed: &[usize]) -> Result<Option<Choice>, PlacementRefusal> {
1075    let settings = SETTINGS
1076        .lock()
1077        .unwrap_or_else(|poison| poison.into_inner())
1078        .clone()
1079        .unwrap_or_else(PinnedCpuSettings::from_env);
1080    let start = std::time::Instant::now();
1081    let coordination = std::cell::RefCell::new(None);
1082    let placed = admit(
1083        allowed,
1084        settings.policy,
1085        settings.wait_cap,
1086        |allowed| {
1087            let chosen = choose_for_run(allowed, &settings.dir);
1088            if let Some((_, scope)) = &chosen {
1089                *coordination.borrow_mut() = Some(scope.clone());
1090            }
1091            chosen
1092        },
1093        thread::sleep,
1094        || start.elapsed(),
1095        &mut |kind, text| {
1096            let first = NOTICED
1097                .lock()
1098                .unwrap_or_else(|poison| poison.into_inner())
1099                .insert(kind);
1100            if settings.notice && first {
1101                use std::io::Write;
1102                let _ = writeln!(io::stderr().lock(), "{text}");
1103            }
1104        },
1105    );
1106    if let Ok(Some(choice)) = &placed {
1107        let coordination = coordination.borrow();
1108        tracing::info!(
1109            cpu = choice.cpu,
1110            hold = ?choice.hold,
1111            coordination = coordination.as_ref().map(ToString::to_string),
1112            "pinned CPU placement"
1113        );
1114    }
1115    placed
1116}

1118/// Two readings of `/proc/stat`, [`SAMPLE_WINDOW`] apart, and the PMU-bound
1119/// CPUs.
1120fn observe(allowed: &[usize]) -> Option<Observation> {
1121    let read = || {
1122        fs::read_to_string("/proc/stat")
1123            .map_err(|error| tracing::debug!("cannot sample CPU load from /proc/stat: {error}"))
1124            .ok()
1125            .map(|text| parse_proc_stat(&text, allowed))
1126    };
1127    let before = read()?;
1128    thread::sleep(SAMPLE_WINDOW);
1129    let after = read()?;
1130    Some(Observation {
1131        before,
1132        after,
1133        pmu_bound: pmu_bound_cpus(Path::new("/sys")),
1134    })
1135}

1137/// The per-CPU lines of `/proc/stat` for the CPUs in `allowed`:
1138/// `cpuN user nice system idle iowait irq softirq steal guest guest_nice`,
1139/// where kernels before 2.6.11 stop earlier. The first line, `cpu`, sums
1140/// every CPU and has no number, so it is skipped.
1141fn parse_proc_stat(text: &str, allowed: &[usize]) -> Reading {
1142    let mut times = BTreeMap::new();
1143    for line in text.lines() {
1144        let Some(rest) = line.strip_prefix("cpu") else {
1145            continue;
1146        };
1147        if !rest.starts_with(|c: char| c.is_ascii_digit()) {
1148            continue;
1149        }
1150        let mut fields = rest.split_ascii_whitespace();
1151        let Some(Ok(cpu)) = fields.next().map(str::parse::<usize>) else {
1152            continue;
1153        };
1154        if !allowed.contains(&cpu) {
1155            continue;
1156        }
1157        let ticks: Vec<u64> = fields
1158            .take(8)
1159            .map_while(|field| field.parse().ok())
1160            .collect();
1161        // user, nice, system and idle are the four columns every kernel has.
1162        if ticks.len() < 4 {
1163            continue;
1164        }
1165        let iowait = ticks.get(4).copied().unwrap_or(0);
1166        times.insert(
1167            cpu,
1168            CpuTime {
1169                idle: ticks[3] + iowait,
1170                total: ticks.iter().sum(),
1171            },
1172        );
1173    }
1174    times
1175}

1177/// The CPUs a PMU is bound to, read under `sys` (normally `/sys`): the union
1178/// of every `bus/event_source/devices/<pmu>/cpumask` that names at most a
1179/// quarter of the online CPUs (`devices/system/cpu/online`). A PMU with no
1180/// cpumask names no CPUs. Anything else that is not what sysfs presents (an
1181/// unreadable directory, a PMU entry that does not resolve to a directory, a
1182/// cpumask that does not resolve to a regular file, a malformed list) makes
1183/// the result empty, so nothing is passed over: a partial set from a sysfs
1184/// that cannot be read is not trusted.
1185fn pmu_bound_cpus(sys: &Path) -> BTreeSet<usize> {
1186    let read_list = |path: &Path| {
1187        fs::read_to_string(path)
1188            .ok()
1189            .and_then(|text| parse_cpu_list(&text))
1190    };
1191    let Some(online) = read_list(&sys.join("devices/system/cpu/online")) else {
1192        return BTreeSet::new();
1193    };
1194    let Ok(entries) = fs::read_dir(sys.join("bus/event_source/devices")) else {
1195        return BTreeSet::new();
1196    };
1197    let mut masks = Vec::new();
1198    for entry in entries {
1199        let Ok(entry) = entry else {
1200            return BTreeSet::new();
1201        };
1202        if !fs::metadata(entry.path()).is_ok_and(|metadata| metadata.is_dir()) {
1203            return BTreeSet::new();
1204        }
1205        // Absent means no CPUs. Present, even as a symlink that resolves to
1206        // nothing, it must resolve to a regular file.
1207        let path = entry.path().join("cpumask");
1208        match fs::symlink_metadata(&path) {
1209            Ok(_) => {}
1210            Err(error) if error.kind() == std::io::ErrorKind::NotFound => continue,
1211            Err(_) => return BTreeSet::new(),
1212        }
1213        if !fs::metadata(&path).is_ok_and(|metadata| metadata.is_file()) {
1214            return BTreeSet::new();
1215        }
1216        let Some(mask) = read_list(&path) else {
1217            return BTreeSet::new();
1218        };
1219        masks.push(mask);
1220    }
1221    bound_cpus(&online, masks)
1222}

1224/// The union of the `masks` that name at most a quarter of `online`, each
1225/// limited to `online`.
1226fn bound_cpus(
1227    online: &BTreeSet<usize>,
1228    masks: impl IntoIterator<Item = BTreeSet<usize>>,
1229) -> BTreeSet<usize> {
1230    let mut bound = BTreeSet::new();
1231    for mask in masks {
1232        let mask: BTreeSet<usize> = mask.intersection(online).copied().collect();
1233        if mask.len() * PMU_BOUND_SHARE_DENOMINATOR <= online.len() {
1234            bound.extend(mask);
1235        }
1236    }
1237    bound
1238}

1240/// Parse a kernel CPU list such as `0,16-19\n`. `None` if it is malformed or
1241/// names a CPU above [`MAX_CPU_NUMBER`].
1242fn parse_cpu_list(text: &str) -> Option<BTreeSet<usize>> {
1243    let text = text.trim();
1244    let mut cpus = BTreeSet::new();
1245    if text.is_empty() {
1246        return Some(cpus);
1247    }
1248    for part in text.split(',') {
1249        let (low, high) = part.split_once('-').unwrap_or((part, part));
1250        let number = |value: &str| {
1251            (!value.is_empty() && value.bytes().all(|byte| byte.is_ascii_digit()))
1252                .then(|| value.parse::<usize>().ok())
1253                .flatten()
1254        };
1255        let (low, high) = (number(low)?, number(high)?);
1256        if high < low || high > MAX_CPU_NUMBER {
1257            return None;
1258        }
1259        cpus.extend(low..=high);
1260    }
1261    Some(cpus)
1262}

1264/// The allowed CPUs to draw from: the idle ones, or the least busy when none
1265/// was idle, passing over PMU-bound CPUs while any other remains. `None` when
1266/// the readings cover none of `allowed`.
1267fn candidates(allowed: &[usize], observation: &Observation) -> Option<(Vec<usize>, Basis)> {
1268    // (cpu, busy ticks, total ticks) over the sample.
1269    let busy: Vec<(usize, u64, u64)> = allowed
1270        .iter()
1271        .filter_map(|cpu| {
1272            let before = observation.before.get(cpu)?;
1273            let after = observation.after.get(cpu)?;
1274            let total = after.total.checked_sub(before.total)?;
1275            let idle = after.idle.checked_sub(before.idle)?;
1276            (total > 0).then(|| (*cpu, total.saturating_sub(idle), total))
1277        })
1278        .collect();
1279    if busy.is_empty() {
1280        return None;
1281    }
1282    let sampled = busy.len();
1283    let idle: Vec<usize> = busy
1284        .iter()
1285        .filter(|(_, busy, total)| busy * IDLE_DENOMINATOR <= *total)
1286        .map(|(cpu, ..)| *cpu)
1287        .collect();
1288    let (pool, found_idle) = if idle.is_empty() {
1289        // The least busy fraction, every CPU at it kept; busy_a/total_a and
1290        // busy_b/total_b compare by cross-multiplying. Not widened by a tick:
1291        // with few allowed CPUs, the run's own launcher can make the only
1292        // other CPU look four ticks in five busy, and a widened set would then
1293        // admit a CPU a CPU-bound task held for the whole window.
1294        let (_, least_busy, least_total) =
1295            *busy
1296                .iter()
1297                .min_by(|(_, busy_a, total_a), (_, busy_b, total_b)| {
1298                    (busy_a * total_b).cmp(&(busy_b * total_a))
1299                })?;
1300        let tied: Vec<usize> = busy
1301            .iter()
1302            .filter(|(_, busy, total)| busy * least_total == least_busy * total)
1303            .map(|(cpu, ..)| *cpu)
1304            .collect();
1305        (tied, false)
1306    } else {
1307        (idle, true)
1308    };
1309    let (unbound, bound): (Vec<usize>, Vec<usize>) = pool
1310        .into_iter()
1311        .partition(|cpu| !observation.pmu_bound.contains(cpu));
1312    let (candidates, pmu) = match (unbound.is_empty(), bound.len()) {
1313        (false, 0) => (unbound, Pmu::NoneBound),
1314        (false, passed_over) => (unbound, Pmu::PassedOver(passed_over)),
1315        (true, _) => (bound, Pmu::AllBound),
1316    };
1317    let basis = if found_idle {
1318        Basis::Idle {
1319            candidates: candidates.len(),
1320            sampled,
1321            pmu,
1322        }
1323    } else {
1324        Basis::LeastBusy {
1325            candidates: candidates.len(),
1326            sampled,
1327            pmu,
1328        }
1329    };
1330    Some((candidates, basis))
1331}

1719    /// A sysfs root with 16 online CPUs and these PMU entries.
1720    fn sysfs(entries: &[(&str, Entry)]) -> tempfile::TempDir {
1721        use std::os::unix::fs::symlink;
1722        let root = tempfile::tempdir().expect("temporary sysfs root");
1723        let cpu = root.path().join("devices/system/cpu");
1724        let devices = root.path().join("bus/event_source/devices");
1725        let targets = root.path().join("devices/pmus");
1726        for directory in [&cpu, &devices, &targets] {
1727            fs::create_dir_all(directory).expect("sysfs directory");
1728        }
1729        fs::write(cpu.join("online"), "0-15\n").expect("online file");
1730        for (name, entry) in entries {
1731            let path = devices.join(name);
1732            let gone = targets.join("gone");
1733            match entry {
1734                Entry::Mask(mask) => {
1735                    fs::create_dir(&path).expect("PMU directory");
1736                    fs::write(path.join("cpumask"), mask).expect("cpumask");
1737                }
1738                Entry::LinkedMask(mask) => {
1739                    let target = targets.join(name);
1740                    fs::create_dir(&target).expect("PMU directory");
1741                    fs::write(target.join("cpumask"), mask).expect("cpumask");
1742                    symlink(&target, &path).expect("PMU entry symlink");
1743                }
1744                Entry::NoMask => fs::create_dir(&path).expect("PMU directory"),
1745                Entry::MaskIsDir => {
1746                    fs::create_dir(&path).expect("PMU directory");
1747                    fs::create_dir(path.join("cpumask")).expect("cpumask directory");
1748                }
1749                Entry::DanglingMask => {
1750                    fs::create_dir(&path).expect("PMU directory");
1751                    symlink(&gone, path.join("cpumask")).expect("dangling cpumask");
1752                }
1753                Entry::Dangling => symlink(&gone, &path).expect("dangling entry"),
1754                Entry::PlainFile => fs::write(&path, "").expect("plain file"),
1755            }
1756        }
1757        root
1758    }

2057    /// What `admit` did with the attempts `answers` gives in turn: its
2058    /// result, the notices (kind and text) and the pauses, on a clock that
2059    /// advances only by the pauses.
2060    struct Admitted {
2061        result: Result<Option<Choice>, PlacementRefusal>,
2062        notices: Vec<(&'static str, String)>,
2063        pauses: Vec<Duration>,
2064    }
2065
2066    fn admitted(
2067        policy: PinnedCpuPolicy,
2068        wait_cap: Option<Duration>,
2069        answers: Vec<(Choice, Coordination)>,
2070    ) -> Admitted {
2071        let mut answers = answers.into_iter();
2072        let mut last = None;
2073        let mut notices = Vec::new();
2074        let pauses = std::cell::RefCell::new(Vec::new());
2075        let result = admit(
2076            &[2, 3],
2077            policy,
2078            wait_cap,
2079            |_| {
2080                if let Some(answer) = answers.next() {
2081                    last = Some(answer);
2082                }
2083                last.clone()
2084            },
2085            |pause| pauses.borrow_mut().push(pause),
2086            || pauses.borrow().iter().sum(),
2087            &mut |kind, text| notices.push((kind, text.to_owned())),
2088        );
2089        Admitted {
2090            result,
2091            notices,
2092            pauses: pauses.into_inner(),
2093        }
2094    }

2439    /// Runs `check` (the name of an `#[ignore]`d test of this module) in a
2440    /// child process of this test binary, with the descriptor limit
2441    /// `nofile` and the umask `umask` set before it starts: both are
2442    /// process-wide, so they must not reach other tests. Returns whether the
2443    /// check passed.
2444    fn in_a_child(check: &str, nofile: Option<u64>, umask: Option<libc::mode_t>) -> bool {
2445        use std::os::unix::process::CommandExt;
2446        let module = module_path!()
2447            .split_once("::")
2448            .map_or(module_path!(), |(_, rest)| rest);
2449        let mut command = std::process::Command::new(std::env::current_exe().unwrap());
2450        command
2451            .args(["--exact", &format!("{module}::{check}"), "--ignored"])
2452            .env(CHILD_CHECK_ENV, check);
2453        // SAFETY: setrlimit and umask only, between fork and exec.
2454        unsafe {
2455            command.pre_exec(move || {
2456                if let Some(nofile) = nofile {
2457                    let limit = libc::rlimit {
2458                        rlim_cur: nofile,
2459                        rlim_max: nofile,
2460                    };
2461                    if libc::setrlimit(libc::RLIMIT_NOFILE, &limit) != 0 {
2462                        return Err(io::Error::last_os_error());
2463                    }
2464                }
2465                if let Some(mask) = umask {
2466                    libc::umask(mask);
2467                }
2468                Ok(())
2469            });
2470        }
2471        let output = command.output().expect("start the child check");
2472        output.status.success() && String::from_utf8_lossy(&output.stdout).contains("1 passed")
2473    }
