9//! The CPU a sequentialized run is pinned to.
10//!
11//! A run with a `max_timeslice` pins its tracer, its notifier threads and
12//! every guest thread to one CPU for the whole run, because its retired-branch
13//! counts must not see a migration (`RunOpts::pin_threads`). Every ptrace stop
14//! then costs several wakeups on that one CPU: the guest stops, its notifier
15//! thread wakes, the tracer wakes, and the tracer resumes the guest.
16//!
17//! So the CPU matters, and a CPU-bound task already on it is the worst case.
18//! Linux shares a CPU between cgroups by weight, and it scales a cgroup's
19//! weight on one CPU by about the share of the cgroup's load that is on that
20//! CPU (`calc_group_shares`, kernel/sched/fair.c). A run inside a cgroup that
21//! is busy on many other CPUs, as a test runner's is, therefore has almost no
22//! weight on its own CPU. Beside a CPU-bound task from a cgroup whose load is
23//! concentrated there, each of the run's wakeups waits for that task, and the
24//! run does the same work hundreds of times slower
25//! (<https://github.com/rrnewton/hermit/issues/4824>). Measured on a 316-CPU
26//! host: one strict verify of an epoll guest took 1.5 s on an idle CPU and
27//! 15.5 s on a CPU running a busy loop from another cgroup, while the run's
28//! own cgroup kept 24 busy loops on other CPUs. Under a loaded test runner,
29//! runs were 170 to 1,400 times slower and hit test deadlines.
30//!
31//! A uniformly random CPU lands on such a task as often as there are busy
32//! CPUs. Instead, a run samples the allowed CPUs' busy time from `/proc/stat`
33//! over [`SAMPLE_WINDOW`] and draws uniformly from the ones that were idle, or,
34//! when none was, from the least busy.
35//!
36//! A sample alone cannot keep concurrent runs apart. Runs that sample at the
37//! same moment draw from the same candidates: every idle CPU while there are
38//! some (three runs among eight idle CPUs share one 34% of the time), but
39//! often a single CPU when there are none, since at 10 ms ticks the least busy
40//! fraction is rarely tied. And a run whose guest mostly waits leaves its CPU
41//! looking idle to a later run's sample. Two runs on one CPU take turns at
42//! every ptrace stop: two copies of a 40,000-syscall guest pinned to one core
43//! took 260 s each, against 27 s on two cores. So a run also reserves its CPU
44//! for its lifetime (`reserve`): an abstract Unix socket named after the CPU,
45//! which the kernel lets one socket in a network namespace hold
46//! (`unix_bind_abstract`, net/unix/af_unix.c) and releases when the last
47//! descriptor for it closes: when Hermit and its container init, which holds
48//! a copy and dies with Hermit, have exited, however they exit. A CPU another
49//! run holds is passed over for the next draw from the same sample, and only
50//! when every allowed CPU is held does a run share one: the CPU it drew
51//! first. Sharing costs speed, never determinism. Runs in different network
52//! namespaces do not see each other's reservations.
53//!
54//! A process holds one reservation at a time (`HELD`). Its later runs (the
55//! second run of a `--verify` pair, `analyze` trials) sample again, count the
56//! CPU the process holds as free rather than as another run's, and move the
57//! reservation when they draw a different CPU.
58//!
59//! Among the candidates, a run passes over the CPUs a PMU is bound to while
60//! any other candidate remains. Some PMUs open their events on a few CPUs,
61//! named by `/sys/bus/event_source/devices/<pmu>/cpumask` (on AMD, `amd_l3`
62//! on one CPU per L3 and `amd_df` and `amd_umc` on CPU 0), and ptrace stops
63//! cost several times as much CPU there
64//! (<https://github.com/rrnewton/hermit/issues/3265>: 7.6-7.9x for a
65//! ptrace-stop-heavy cell; 2.5x for the epoll verify above on CPU 0). Because
66//! validation and `bin/safehermit` keep runs off those CPUs, they are often
67//! idle, and an idle draw would otherwise favour them. The set is derived as
68//! the validation launcher derives the CPUs it excludes: the union of every
69//! PMU `cpumask` that names at most a quarter of the online CPUs, since a
70//! wider one belongs to a per-core PMU. Where the launcher would skip a PMU
71//! entry or cpumask that is not what sysfs presents, this passes nothing over.
72//!
73//! Not handled: a CPU-bound task that reaches the CPU after the sample (load
74//! balancing moves one there, or a job starts or pins itself there) still
75//! slows the run for the rest of its life, and nothing reports it. Moving the
76//! run then would migrate its guest threads, which is what pinning exists to
77//! prevent. Nor can a sample tell a CPU-bound task from the run's own
78//! launcher: with few allowed CPUs, the launcher can keep the only other CPU
79//! busy for the whole window too, and the draw then takes either.
80//!
81//! The choice is host placement only, and it was already a random draw per
82//! run. The guest sees its own virtual CPU through getcpu, sched_getaffinity,
83//! `/proc/self/status` and RDTSCP's TSC_AUX. As before, only a guest that
84//! executes RDPID although CPUID hides it, or that uses rseq under the
85//! compatibility opt-out, can read the host CPU number.

100/// How long the allowed CPUs' busy time is sampled before a run takes one.
101/// `/proc/stat` counts in 1/USER_HZ ticks, 10 ms on Linux, so this is about
102/// five ticks per CPU. A CPU that was busy for 10 ms or more of the window
103/// shows at least one busy tick, so a CPU-bound task is always seen; the
104/// window is long enough that one which runs half of every 100 ms is too.
105pub(crate) const SAMPLE_WINDOW: Duration = Duration::from_millis(50);
106
107/// A CPU is idle when at most this fraction of the sample was busy, expressed
108/// as a denominator: one tick in five. Each read rounds to whole ticks, so an
109/// idle CPU can show one busy tick, while a CPU-bound task shows four or five.
110const IDLE_DENOMINATOR: u64 = 5;
111
112/// The widest PMU `cpumask` that still counts as bound to a few CPUs, as a
113/// share of the online CPUs: one quarter, the validation launcher's rule
114/// (ci-hub/validate/cpu_placement.py in dev-hermit). A wider mask, such as
115/// `power_core=0-157` on a 316-CPU host, belongs to a per-core PMU.
116const PMU_BOUND_SHARE_DENOMINATOR: usize = 4;
117
118/// The highest CPU number Linux allows (CONFIG_NR_CPUS is at most 8192). A
119/// CPU list naming a higher one is malformed, and is refused before its range
120/// is expanded.
121const MAX_CPU_NUMBER: usize = 8191;

123/// One CPU's cumulative time from `/proc/stat`, in USER_HZ ticks.
124#[derive(Clone, Copy, Debug, PartialEq, Eq)]
125pub(crate) struct CpuTime {
126    /// idle plus iowait.
127    idle: u64,
128    /// user, nice, system, idle, iowait, irq, softirq and steal. The guest
129    /// columns are already counted in user and nice, so they are not added.
130    total: u64,
131}

133/// Per-CPU times from one reading of `/proc/stat`.
134pub(crate) type Reading = BTreeMap<usize, CpuTime>;

136/// What a run's choice is made from.
137#[derive(Clone, Debug)]
138pub(crate) struct Observation {
139    /// `/proc/stat` before [`SAMPLE_WINDOW`].
140    pub(crate) before: Reading,
141    /// `/proc/stat` after it.
142    pub(crate) after: Reading,
143    /// The CPUs a PMU is bound to (see the module documentation).
144    pub(crate) pmu_bound: BTreeSet<usize>,
145}

147/// How the CPUs a PMU is bound to figured in a draw.
148#[derive(Clone, Copy, Debug, PartialEq, Eq)]
149pub(crate) enum Pmu {
150    /// No candidate was PMU-bound.
151    NoneBound,
152    /// This many PMU-bound candidates were passed over for the others.
153    PassedOver(usize),
154    /// Every candidate was PMU-bound, so the run takes one of them.
155    AllBound,
156}

158/// Why a run got the CPU it got, for the log line that names it.
159#[derive(Clone, Copy, Debug, PartialEq, Eq)]
160pub(crate) enum Basis {
161    /// The allowed set has one CPU.
162    OnlyAllowed,
163    /// Drawn from `candidates` of the `sampled` allowed CPUs, all idle across
164    /// the sample.
165    Idle {
166        candidates: usize,
167        sampled: usize,
168        pmu: Pmu,
169    },
170    /// No sampled CPU was idle: drawn from the `candidates` least busy (ties
171    /// all kept).
172    LeastBusy {
173        candidates: usize,
174        sampled: usize,
175        pmu: Pmu,
176    },
177    /// `/proc/stat` was unreadable or covered none of the allowed CPUs: drawn
178    /// from every allowed CPU.
179    Unsampled,
180}
181
182impl fmt::Display for Pmu {
183    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
184        match self {
185            Pmu::NoneBound => write!(f, "none PMU-bound"),
186            Pmu::PassedOver(count) => write!(f, "passing over {count} PMU-bound"),
187            Pmu::AllBound => write!(f, "all of them PMU-bound"),
188        }
189    }
190}
191
192impl fmt::Display for Basis {
193    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
194        let window = SAMPLE_WINDOW.as_millis();
195        match self {
196            Basis::OnlyAllowed => write!(f, "the only allowed CPU"),
197            Basis::Idle {
198                candidates,
199                sampled,
200                pmu,
201            } => write!(
202                f,
203                "one of {candidates} of {sampled} allowed CPUs idle over {window} ms, {pmu}"
204            ),
205            Basis::LeastBusy {
206                candidates,
207                sampled,
208                pmu,
209            } => write!(
210                f,
211                "none of {sampled} allowed CPUs idle over {window} ms; one of the {candidates} \
212                 least busy, {pmu}"
213            ),
214            Basis::Unsampled => {
215                write!(f, "drawn from every allowed CPU; /proc/stat gave no sample")
216            }
217        }
218    }
219}

221/// Choose a CPU from `allowed`, the tracer's affinity mask, with the
222/// observation made by `observe`, which tests replace, and say why. `None`
223/// only when `allowed` is empty. Reserves nothing: runs choose through
224/// [`choose_for_run`], which draws the same way.
225#[cfg(test)]
226pub(crate) fn choose_with(
227    allowed: &[usize],
228    observe: impl FnOnce(&[usize]) -> Option<Observation>,
229) -> Option<(usize, Basis)> {
230    match allowed {
231        [] => None,
232        [only] => Some((*only, Basis::OnlyAllowed)),
233        _ => Some(draw(allowed, observe(allowed).as_ref())),
234    }
235}

237/// One draw from `pool`, two or more CPUs: from its candidates under
238/// `observation`, or from all of it without one.
239fn draw(pool: &[usize], observation: Option<&Observation>) -> (usize, Basis) {
240    let (candidates, basis) = observation
241        .and_then(|observation| candidates(pool, observation))
242        .unwrap_or_else(|| (pool.to_vec(), Basis::Unsampled));
243    (candidates[rand::random_range(0..candidates.len())], basis)
244}

246/// The prefix of the abstract socket names that reserve a CPU
247/// (`hermit-pinned-core:<cpu>`, [`reserve`]).
248const RESERVATION_PREFIX: &str = "hermit-pinned-core";
249
250/// The lowest descriptor number a reservation is moved to, so that taking one
251/// does not shift the numbers of the descriptors Hermit opens after it, some
252/// of which reach the guest's setup.
253const RESERVATION_FD_FLOOR: libc::c_int = 1000;
254
255/// The reservation this process holds: its CPU and the descriptor that holds
256/// its name. A later run of the same process (a `--verify` pair runs twice)
257/// counts that CPU as free, and replacing the reservation closes the old
258/// descriptor, so a process never holds a CPU it moved away from. Runs one
259/// process makes at the same time (test threads, say) may draw its CPU too.
260static HELD: Mutex<Option<(usize, OwnedFd)>> = Mutex::new(None);
261
262/// How a run holds its CPU against other Hermit runs.
263#[derive(Clone, Debug, PartialEq, Eq)]
264pub(crate) enum Hold {
265    /// This process holds the CPU: no other Hermit run in this network
266    /// namespace is pinned to it. `passed_over` CPUs other runs hold were
267    /// passed over first.
268    Reserved { passed_over: usize },
269    /// This process already held the CPU, for an earlier run, and keeps it.
270    Kept,
271    /// Every allowed CPU is held by another Hermit run, so this run shares
272    /// the CPU it drew first with one of them.
273    Shared,
274    /// A reservation could not be made (the error), so the CPU is used
275    /// unreserved, and another run may share it.
276    Unreserved(String),
277}

279/// The CPU a run is pinned to, why, and how it holds it.
280#[derive(Clone, Debug, PartialEq, Eq)]
281pub(crate) struct Choice {
282    pub(crate) cpu: usize,
283    /// How the CPU was drawn, over the allowed CPUs no other run was found to
284    /// hold.
285    pub(crate) basis: Basis,
286    pub(crate) hold: Hold,
287}
288
289impl fmt::Display for Choice {
290    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
291        if let Hold::Reserved { passed_over } = self.hold
292            && passed_over > 0
293        {
294            write!(
295                f,
296                "among the allowed CPUs no other Hermit run holds ({passed_over} held): "
297            )?;
298        }
299        write!(f, "{}; ", self.basis)?;
300        match &self.hold {
301            Hold::Reserved { .. } => write!(f, "reserved"),
302            Hold::Kept => write!(f, "already reserved by this process"),
303            Hold::Shared => write!(
304                f,
305                "every allowed CPU is held by another Hermit run, so this run shares it and \
306                 both run slower"
307            ),
308            Hold::Unreserved(error) => {
309                write!(f, "unreserved, so another Hermit run may share it: {error}")
310            }
311        }
312    }
313}

315/// Choose and reserve the CPU this run is pinned to from `allowed`, the
316/// tracer's affinity mask, over a fresh sample, counting the CPU this process
317/// already holds as free. `None` only when `allowed` is empty.
318pub(crate) fn choose_for_run(allowed: &[usize]) -> Option<Choice> {
319    let mut held = HELD.lock().unwrap_or_else(|poison| poison.into_inner());
320    choose_for_run_with(allowed, observe, &mut held, |cpu| {
321        reserve(RESERVATION_PREFIX, cpu)
322    })
323}

325/// [`choose_for_run`] with the observation, the process's reservation and
326/// the reservation call supplied, which tests replace. `reserve` answers the
327/// descriptor that now holds a CPU, or `None` when another run holds it.
328/// A run that reserves a different CPU replaces `held`, closing the old
329/// descriptor; a run that shares or goes unreserved leaves `held` empty, since
330/// the process no longer runs on the CPU it held.
331fn choose_for_run_with(
332    allowed: &[usize],
333    observe: impl FnOnce(&[usize]) -> Option<Observation>,
334    held: &mut Option<(usize, OwnedFd)>,
335    mut reserve: impl FnMut(usize) -> io::Result<Option<OwnedFd>>,
336) -> Option<Choice> {
337    let own = held.as_ref().map(|(cpu, _)| *cpu);
338    let mut taken = None;
339    let mut choice = choose_reserving(allowed, observe, |cpu| {
340        if Some(cpu) == own {
341            return Ok(true);
342        }
343        Ok(reserve(cpu)?.map(|fd| taken = Some((cpu, fd))).is_some())
344    })?;
345    match (&choice.hold, taken) {
346        (Hold::Reserved { .. }, Some(new)) => *held = Some(new),
347        (Hold::Reserved { .. }, None) => choice.hold = Hold::Kept,
348        _ => *held = None,
349    }
350    Some(choice)
351}

353/// [`choose_with`], passing over the CPUs other Hermit runs hold. `reserve`
354/// takes a CPU for this run: `Ok(true)` when the run now holds it, `Ok(false)`
355/// when another run does, and an error when reservations cannot be made at
356/// all. Every draw uses the one observation: it is [`choose_with`]'s draw over
357/// the allowed CPUs not yet found held, so a run passes a held idle CPU over
358/// for another idle one, and then for the least busy free one. With every CPU
359/// held, the run shares the CPU it drew first.
360pub(crate) fn choose_reserving(
361    allowed: &[usize],
362    observe: impl FnOnce(&[usize]) -> Option<Observation>,
363    mut reserve: impl FnMut(usize) -> io::Result<bool>,
364) -> Option<Choice> {
365    let observation = match allowed {
366        [] => return None,
367        [_] => None,
368        _ => observe(allowed),
369    };
370    let mut free = allowed.to_vec();
371    let mut first = None;
372    loop {
373        let (cpu, basis) = match allowed {
374            [only] => (*only, Basis::OnlyAllowed),
375            _ => draw(&free, observation.as_ref()),
376        };
377        let first = *first.get_or_insert((cpu, basis));
378        let hold = match reserve(cpu) {
379            Ok(true) => Hold::Reserved {
380                passed_over: allowed.len() - free.len(),
381            },
382            Ok(false) => {
383                free.retain(|other| *other != cpu);
384                if !free.is_empty() {
385                    continue;
386                }
387                return Some(Choice {
388                    cpu: first.0,
389                    basis: first.1,
390                    hold: Hold::Shared,
391                });
392            }
393            Err(error) => Hold::Unreserved(error.to_string()),
394        };
395        return Some(Choice { cpu, basis, hold });
396    }
397}

399/// Hold `cpu` while the returned descriptor is open: an abstract Unix socket
400/// named `<prefix>:<cpu>`, bound close-on-exec, which the kernel releases when
401/// its last descriptor closes, at the latest when Hermit exits. Another run
402/// that binds the same name gets `EADDRINUSE`, answered as `Ok(None)`. The
403/// names belong to a network namespace: runs in different ones do not see
404/// each other's CPUs.
405fn reserve(prefix: &str, cpu: usize) -> io::Result<Option<OwnedFd>> {
406    use std::os::linux::net::SocketAddrExt;
407    let name = format!("{prefix}:{cpu}");
408    let address = std::os::unix::net::SocketAddr::from_abstract_name(name.as_bytes())?;
409    let socket = match std::os::unix::net::UnixDatagram::bind_addr(&address) {
410        Ok(socket) => socket,
411        Err(error) if error.raw_os_error() == Some(libc::EADDRINUSE) => return Ok(None),
412        Err(error) => return Err(error),
413    };
414    // Keep the reservation on a high descriptor and close the low one it was
415    // bound on (`RESERVATION_FD_FLOOR`).
416    // SAFETY: `socket` is an open descriptor this function owns.
417    let moved = unsafe {
418        libc::fcntl(
419            socket.as_raw_fd(),
420            libc::F_DUPFD_CLOEXEC,
421            RESERVATION_FD_FLOOR,
422        )
423    };
424    if moved < 0 {
425        return Err(io::Error::last_os_error());
426    }
427    // SAFETY: `moved` is a new descriptor nothing else owns; `socket` closes
428    // its own number when it drops.
429    Ok(Some(unsafe { OwnedFd::from_raw_fd(moved) }))
430}

432/// Two readings of `/proc/stat`, [`SAMPLE_WINDOW`] apart, and the PMU-bound
433/// CPUs.
434fn observe(allowed: &[usize]) -> Option<Observation> {
435    let read = || {
436        fs::read_to_string("/proc/stat")
437            .map_err(|error| tracing::debug!("cannot sample CPU load from /proc/stat: {error}"))
438            .ok()
439            .map(|text| parse_proc_stat(&text, allowed))
440    };
441    let before = read()?;
442    thread::sleep(SAMPLE_WINDOW);
443    let after = read()?;
444    Some(Observation {
445        before,
446        after,
447        pmu_bound: pmu_bound_cpus(Path::new("/sys")),
448    })
449}

451/// The per-CPU lines of `/proc/stat` for the CPUs in `allowed`:
452/// `cpuN user nice system idle iowait irq softirq steal guest guest_nice`,
453/// where kernels before 2.6.11 stop earlier. The first line, `cpu`, sums
454/// every CPU and has no number, so it is skipped.
455fn parse_proc_stat(text: &str, allowed: &[usize]) -> Reading {
456    let mut times = BTreeMap::new();
457    for line in text.lines() {
458        let Some(rest) = line.strip_prefix("cpu") else {
459            continue;
460        };
461        if !rest.starts_with(|c: char| c.is_ascii_digit()) {
462            continue;
463        }
464        let mut fields = rest.split_ascii_whitespace();
465        let Some(Ok(cpu)) = fields.next().map(str::parse::<usize>) else {
466            continue;
467        };
468        if !allowed.contains(&cpu) {
469            continue;
470        }
471        let ticks: Vec<u64> = fields
472            .take(8)
473            .map_while(|field| field.parse().ok())
474            .collect();
475        // user, nice, system and idle are the four columns every kernel has.
476        if ticks.len() < 4 {
477            continue;
478        }
479        let iowait = ticks.get(4).copied().unwrap_or(0);
480        times.insert(
481            cpu,
482            CpuTime {
483                idle: ticks[3] + iowait,
484                total: ticks.iter().sum(),
485            },
486        );
487    }
488    times
489}

491/// The CPUs a PMU is bound to, read under `sys` (normally `/sys`): the union
492/// of every `bus/event_source/devices/<pmu>/cpumask` that names at most a
493/// quarter of the online CPUs (`devices/system/cpu/online`). A PMU with no
494/// cpumask names no CPUs. Anything else that is not what sysfs presents (an
495/// unreadable directory, a PMU entry that does not resolve to a directory, a
496/// cpumask that does not resolve to a regular file, a malformed list) makes
497/// the result empty, so nothing is passed over: a partial set from a sysfs
498/// that cannot be read is not trusted.
499fn pmu_bound_cpus(sys: &Path) -> BTreeSet<usize> {
500    let read_list = |path: &Path| {
501        fs::read_to_string(path)
502            .ok()
503            .and_then(|text| parse_cpu_list(&text))
504    };
505    let Some(online) = read_list(&sys.join("devices/system/cpu/online")) else {
506        return BTreeSet::new();
507    };
508    let Ok(entries) = fs::read_dir(sys.join("bus/event_source/devices")) else {
509        return BTreeSet::new();
510    };
511    let mut masks = Vec::new();
512    for entry in entries {
513        let Ok(entry) = entry else {
514            return BTreeSet::new();
515        };
516        if !fs::metadata(entry.path()).is_ok_and(|metadata| metadata.is_dir()) {
517            return BTreeSet::new();
518        }
519        // Absent means no CPUs. Present, even as a symlink that resolves to
520        // nothing, it must resolve to a regular file.
521        let path = entry.path().join("cpumask");
522        match fs::symlink_metadata(&path) {
523            Ok(_) => {}
524            Err(error) if error.kind() == std::io::ErrorKind::NotFound => continue,
525            Err(_) => return BTreeSet::new(),
526        }
527        if !fs::metadata(&path).is_ok_and(|metadata| metadata.is_file()) {
528            return BTreeSet::new();
529        }
530        let Some(mask) = read_list(&path) else {
531            return BTreeSet::new();
532        };
533        masks.push(mask);
534    }
535    bound_cpus(&online, masks)
536}

538/// The union of the `masks` that name at most a quarter of `online`, each
539/// limited to `online`.
540fn bound_cpus(
541    online: &BTreeSet<usize>,
542    masks: impl IntoIterator<Item = BTreeSet<usize>>,
543) -> BTreeSet<usize> {
544    let mut bound = BTreeSet::new();
545    for mask in masks {
546        let mask: BTreeSet<usize> = mask.intersection(online).copied().collect();
547        if mask.len() * PMU_BOUND_SHARE_DENOMINATOR <= online.len() {
548            bound.extend(mask);
549        }
550    }
551    bound
552}

554/// Parse a kernel CPU list such as `0,16-19\n`. `None` if it is malformed or
555/// names a CPU above [`MAX_CPU_NUMBER`].
556fn parse_cpu_list(text: &str) -> Option<BTreeSet<usize>> {
557    let text = text.trim();
558    let mut cpus = BTreeSet::new();
559    if text.is_empty() {
560        return Some(cpus);
561    }
562    for part in text.split(',') {
563        let (low, high) = part.split_once('-').unwrap_or((part, part));
564        let number = |value: &str| {
565            (!value.is_empty() && value.bytes().all(|byte| byte.is_ascii_digit()))
566                .then(|| value.parse::<usize>().ok())
567                .flatten()
568        };
569        let (low, high) = (number(low)?, number(high)?);
570        if high < low || high > MAX_CPU_NUMBER {
571            return None;
572        }
573        cpus.extend(low..=high);
574    }
575    Some(cpus)
576}

578/// The allowed CPUs to draw from: the idle ones, or the least busy when none
579/// was idle, passing over PMU-bound CPUs while any other remains. `None` when
580/// the readings cover none of `allowed`.
581fn candidates(allowed: &[usize], observation: &Observation) -> Option<(Vec<usize>, Basis)> {
582    // (cpu, busy ticks, total ticks) over the sample.
583    let busy: Vec<(usize, u64, u64)> = allowed
584        .iter()
585        .filter_map(|cpu| {
586            let before = observation.before.get(cpu)?;
587            let after = observation.after.get(cpu)?;
588            let total = after.total.checked_sub(before.total)?;
589            let idle = after.idle.checked_sub(before.idle)?;
590            (total > 0).then(|| (*cpu, total.saturating_sub(idle), total))
591        })
592        .collect();
593    if busy.is_empty() {
594        return None;
595    }
596    let sampled = busy.len();
597    let idle: Vec<usize> = busy
598        .iter()
599        .filter(|(_, busy, total)| busy * IDLE_DENOMINATOR <= *total)
600        .map(|(cpu, ..)| *cpu)
601        .collect();
602    let (pool, found_idle) = if idle.is_empty() {
603        // The least busy fraction, every CPU at it kept; busy_a/total_a and
604        // busy_b/total_b compare by cross-multiplying. Not widened by a tick:
605        // with few allowed CPUs, the run's own launcher can make the only
606        // other CPU look four ticks in five busy, and a widened set would then
607        // admit a CPU a CPU-bound task held for the whole window.
608        let (_, least_busy, least_total) =
609            *busy
610                .iter()
611                .min_by(|(_, busy_a, total_a), (_, busy_b, total_b)| {
612                    (busy_a * total_b).cmp(&(busy_b * total_a))
613                })?;
614        let tied: Vec<usize> = busy
615            .iter()
616            .filter(|(_, busy, total)| busy * least_total == least_busy * total)
617            .map(|(cpu, ..)| *cpu)
618            .collect();
619        (tied, false)
620    } else {
621        (idle, true)
622    };
623    let (unbound, bound): (Vec<usize>, Vec<usize>) = pool
624        .into_iter()
625        .partition(|cpu| !observation.pmu_bound.contains(cpu));
626    let (candidates, pmu) = match (unbound.is_empty(), bound.len()) {
627        (false, 0) => (unbound, Pmu::NoneBound),
628        (false, passed_over) => (unbound, Pmu::PassedOver(passed_over)),
629        (true, _) => (bound, Pmu::AllBound),
630    };
631    let basis = if found_idle {
632        Basis::Idle {
633            candidates: candidates.len(),
634            sampled,
635            pmu,
636        }
637    } else {
638        Basis::LeastBusy {
639            candidates: candidates.len(),
640            sampled,
641            pmu,
642        }
643    };
644    Some((candidates, basis))
645}

883    /// One PMU directory entry in a test sysfs.
884    #[derive(Clone, Copy)]
885    enum Entry {
886        /// A directory with this cpumask.
887        Mask(&'static str),
888        /// A symlink to a directory with this cpumask, as sysfs presents one.
889        LinkedMask(&'static str),
890        /// A directory with no cpumask.
891        NoMask,
892        /// A directory whose cpumask is a directory.
893        MaskIsDir,
894        /// A directory whose cpumask is a symlink that resolves to nothing.
895        DanglingMask,
896        /// A symlink that resolves to nothing.
897        Dangling,
898        /// A plain file.
899        PlainFile,
900    }
901
902    /// A sysfs root with 16 online CPUs and these PMU entries.
903    fn sysfs(entries: &[(&str, Entry)]) -> tempfile::TempDir {
904        use std::os::unix::fs::symlink;
905        let root = tempfile::tempdir().expect("temporary sysfs root");
906        let cpu = root.path().join("devices/system/cpu");
907        let devices = root.path().join("bus/event_source/devices");
908        let targets = root.path().join("devices/pmus");
909        for directory in [&cpu, &devices, &targets] {
910            fs::create_dir_all(directory).expect("sysfs directory");
911        }
912        fs::write(cpu.join("online"), "0-15\n").expect("online file");
913        for (name, entry) in entries {
914            let path = devices.join(name);
915            let gone = targets.join("gone");
916            match entry {
917                Entry::Mask(mask) => {
918                    fs::create_dir(&path).expect("PMU directory");
919                    fs::write(path.join("cpumask"), mask).expect("cpumask");
920                }
921                Entry::LinkedMask(mask) => {
922                    let target = targets.join(name);
923                    fs::create_dir(&target).expect("PMU directory");
924                    fs::write(target.join("cpumask"), mask).expect("cpumask");
925                    symlink(&target, &path).expect("PMU entry symlink");
926                }
927                Entry::NoMask => fs::create_dir(&path).expect("PMU directory"),
928                Entry::MaskIsDir => {
929                    fs::create_dir(&path).expect("PMU directory");
930                    fs::create_dir(path.join("cpumask")).expect("cpumask directory");
931                }
932                Entry::DanglingMask => {
933                    fs::create_dir(&path).expect("PMU directory");
934                    symlink(&gone, path.join("cpumask")).expect("dangling cpumask");
935                }
936                Entry::Dangling => symlink(&gone, &path).expect("dangling entry"),
937                Entry::PlainFile => fs::write(&path, "").expect("plain file"),
938            }
939        }
940        root
941    }

1193    #[test]
1194    fn a_run_that_moves_releases_the_cpu_the_process_held() {
1195        let prefix = private_prefix();
1196        let mut held = reserve(&prefix, 1).expect("bind").map(|fd| (1, fd));
1197        // The allowed set no longer has CPU 1: the run reserves CPU 2.
1198        let choice = choose_for_run_with(
1199            &[2, 3],
1200            |_| Some(busy(&[(2, 0), (3, 5)], &[])),
1201            &mut held,
1202            |cpu| reserve(&prefix, cpu),
1203        )
1204        .expect("two CPUs");
1205        assert_eq!(
1206            (choice.cpu, &choice.hold),
1207            (2, &Hold::Reserved { passed_over: 0 })
1208        );
1209        assert_eq!(held.as_ref().map(|(cpu, _)| *cpu), Some(2));
1210        assert!(
1211            reserve(&prefix, 1).expect("bind").is_some(),
1212            "the CPU the process moved away from is free again"
1213        );
1214        // Then a run restricted to CPU 4, which another run holds, shares it
1215        // and leaves this process holding nothing.
1216        let _other = reserve(&prefix, 4).expect("bind").expect("free");
1217        let choice = choose_for_run_with(&[4], |_| None, &mut held, |cpu| reserve(&prefix, cpu))
1218            .expect("one CPU");
1219        assert_eq!((choice.cpu, &choice.hold), (4, &Hold::Shared));
1220        assert!(held.is_none(), "a shared run holds no reservation");
1221        assert!(
1222            reserve(&prefix, 2).expect("bind").is_some(),
1223            "and the CPU the process held before is free again"
1224        );
1225    }
