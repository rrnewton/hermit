Generate ci/test-footprints.json from Cargo metadata and the hosted-portable DAG.

Cargo owns package paths and dependency edges. The hosted-portable DAG owns test nodes and commands. ci/test-footprints-policy.json contains only the fail-safe path policy and semantic edges for non-Cargo harnesses.
