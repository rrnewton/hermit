Materializes one recorded regular file beneath a pinned replay root. Every parent component is opened with O_NOFOLLOW; only symlinks explicitly captured during recording are created/followed, and their targets must match byte-for-byte. Final replacement uses renameat relative to a pinned parent, so even a racing symlink cannot redirect writes outside the replay root.
