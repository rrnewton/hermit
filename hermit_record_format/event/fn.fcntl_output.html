Expand description

Returns the output buffer and its size for an fcntl command that writes a result through its argument instead of returning it: F_GETOWN_EX, the record-lock queries F_GETLK, F_GETLK64 and F_OFD_GETLK, and the write-hint queries. Recording keeps those bytes, and replay writes them back; returning only the recorded status would leave the guest’s struct as it was (https://github.com/rrnewton/hermit/issues/2289). glibc implements fcntl(F_GETOWN) with F_GETOWN_EX, so this also covers F_GETOWN.
