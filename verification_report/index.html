Read a current --verify-json file through Hermit’s producer-owned type.

Shell and Python tests call this instead of maintaining their own accepted verdict strings. A new Verdict variant therefore makes this exhaustive match fail to compile; an unavailable, incomplete, or malformed report is a named refusal and never falls back to a human-readable banner.
