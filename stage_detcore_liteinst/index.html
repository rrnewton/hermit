reverie_gitlink_pin 🔒
The Reverie revision recorded by the reverie submodule gitlink of the checkout rooted at root, or None when it cannot be read: the index entry when an advance is staged, else HEAD’s tree entry — the same pair scripts/check-reverie-pin.rs reads. Fallback only (see reverie_pin_at): provenance for trees with no submodule checkout and no marker (tarballs, uninitialized submodules), where the value degrades to "unknown" at callers exactly as an unparseable manifest did.
reverie_marker_pin 🔒
The pin recorded by the Eden/Sapling marker, reverie.submodule.txt holding exactly Subproject commit <40-hex> on one line — the only spelling CodeSync produces or consumes. Anything else yields None (fall through), never a partial read.
reverie_pin_at 🔒
The Reverie pin of the checkout rooted at root, in the order the build actually sees the sources: submodule checkout HEAD, Eden marker, recorded gitlink, pre-migration manifest. None renders as "unknown" at callers.
