pub(crate) fn pinned_workspace_files(
    workspace_root: &Path,
    declared: &[String],
) -> Result<Vec<(String, String)>>
Expand description

Pinned expectation digests for resolve_buck: the CLI --workspace-file list, with BUCK and fb-only/liteinst-runtime-profile.bzl appended if absent (dedup, preserving order), each hashed from the pinned workspace tree. The profile entry is hashed from workspace_root, never from the --profile-bzl argument, so resolve_buck can tie that argument’s identity to this inventory entry and refuse a mismatch there.
