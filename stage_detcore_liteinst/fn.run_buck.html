Buck mode: run the pinned buck2 build and qualify its ELF directly against Buck-declared sources — no Cargo build and no byte-identity gate. The buck2 invocation runs through the retained-command runner with --show-full-output; with_buck_build(&runner, elf) binds the runner’s own last retained record of that run and computes the ELF digest from the stdout-derived file itself. No caller-filled command, artifact path or hash reaches qualification. Then qualify_detcore_constructor_with_sources, and stage + publish buck_receipt exactly as the Cargo arm publishes its receipt. The sibling fbcode reverie-liteinst-artifact this binary compiles against carries that authority; the D1c-2/D1c-6 machine-code recipes still refuse the real Buck-built ELF by name inside qualification, before anything is staged.
