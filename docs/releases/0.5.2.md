# Hermit 0.5.2

Hermit 0.5.2 is a build fix for the 0.5.0 crates on crates.io. It changes no
run-time behaviour. Only `hermit-detcore` and `hermit-replay` are republished.
Every other 0.5.0 crate, including `hermit-run`, stays at 0.5.0 and picks the
fixed versions up through its `^0.5.0` requirement.

## Build fix

- `cargo install hermit-run` without `--locked` failed to compile. Cargo
  resolved libc 0.2.190 or later, and libc 0.2.190
  ([rust-lang/libc#5345](https://github.com/rust-lang/libc/pull/5345)) made
  the glibc Linux `siginfo_t` a structure whose union holds raw pointers.
  `siginfo_t` stopped being `Send` and `Sync`, and so did Reverie's
  `AddrMut<siginfo_t>`. Detcore's and replay's syscall handlers kept one across
  an `.await`, which made their futures non-`Send`. They now hold a guest
  `siginfo_t` as `GuestSiginfo`, a same-layout wrapper that is `Send` and
  `Sync`; the bytes that reach the guest are unchanged. See
  [the fix on main](https://github.com/rrnewton/hermit/pull/4549).
- `cargo install hermit-run --version 0.5.0 --locked` keeps working, because
  the 0.5.0 lockfile pins libc 0.2.189.
