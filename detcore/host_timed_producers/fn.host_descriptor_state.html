pub fn host_descriptor_state(fd: RawFd) -> Result<(ProducerState, bool), Errno>
Expand description

The state of descriptor fd of the calling process, read from the host, with whether it holds a lease (F_GETLEASE): what Hermit checks before an in-guest launch in each descriptor the guest would inherit (D25). An O_PATH descriptor arms nothing (check_fcntl_cmd refuses every arming command on one), so it reads as arming nothing. A directory notification cannot be read back (there is no F_GETNOTIFY, and fdinfo does not show dnotify), so it is not reported.
