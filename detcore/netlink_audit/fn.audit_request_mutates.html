Whether an outgoing netlink message of this type only reads the audit subsystem and so may be sent on to the host kernel. Every other audit-domain type (1000 and above) either mutates host audit configuration (AUDIT_SET and family: rules, TTY/module/logging controls) or emits a record into the host audit log – the kernel’s user-message ranges 1100-1199 (AUDIT_FIRST_USER_MSG..=LAST) and 2100-2999 (..MSG2) are record emission gated only by CAP_AUDIT_WRITE in audit_netlink_ok, and AUDIT_USER_TTY (1124) also drives tty_audit_push(). Unknown and kernel-record types are refused too: new write verbs must not acquire a pass-through by default. Types below 1000 are generic netlink control (NLMSG_*), never audit requests.
