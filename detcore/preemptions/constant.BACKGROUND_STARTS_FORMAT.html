pub const BACKGROUND_STARTS_FORMAT: u32 = 4;
Expand description

The first format whose records note every background start (BackgroundStart), so that a call such a record does not start at a point did not start there: the next number above SWITCH_IN_CHARGE_FORMAT on the record-format counter (PREEMPTION_RECORD_FORMAT_MAX).

Only a writer that notes every start it takes may state this format or a newer one (PreemptionWriter::noting_background_starts). Any other writer, and any record that drops its starts, states at most the format below it (format_without_background_starts).
