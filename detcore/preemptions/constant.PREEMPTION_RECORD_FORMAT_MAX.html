The newest preemption-record format this Hermit writes and reads (PreemptionRecord::format_version), one counter for every format change: a record of format N has every property of the formats before it.

  • Format 1 has no version field: every record written before the field existed.
  • Format 2 (TIME_SKIPS_FORMAT) lists every jump of global time its run made (time_skips, absent when there was none).
  • Format 3 (SWITCH_IN_CHARGE_FORMAT) was written by a run that charged every stretch of guest code a turn, so its replay charges a replayed switch-in under which guest code runs.
  • Format 4 (BACKGROUND_STARTS_FORMAT) notes every background start its run took (background_starts), so its schedule replay begins each kernel-run call where the recording did.
  • Format 5 (STOPLESS_SLICE_ENDS_FORMAT) may mark a Branch event stopless: a lone thread’s timeslice end its run took without a stop, so the event has no end_rip, and a replay takes that end without a stop where its thread runs alone.
  • Format 6 (INSTRUCTION_OFFSET_ROWS_FORMAT) may hold --chaos-instruction-offset decisions in its rows. Rows alone (PreemptionRecord::rows_alone) follow format 1’s timing rules (PreemptionRecord::timing_format).

A record that drops one feature’s data while it keeps a later feature’s follows one rule. A feature that can be lowered without breaking replay is lowered, its data cleared with it: a record that notes no background starts holds no stopless marks (PreemptionRecord::forget_stopless_marks_below_their_format). One that cannot be lowered keeps its number and marks the earlier feature’s data absent with an explicit flag instead of clearing it: rows with instruction offsets keep format 6 and say that they note no background starts (PreemptionRecord::background_starts_unnoted), as rows alone say they hold no schedule trace (PreemptionRecord::rows_alone). So a reader decides what a record holds by its format and those flags together (PreemptionRecord::notes_background_starts, PreemptionRecord::timing_format), never by the number alone, and a Hermit that reads only older formats still refuses the record by its number.

A record of a newer format is refused (PreemptionRecord::validate_format), so a Hermit that reads only formats 1 to 4 refuses a record with such marks rather than replay it with a stop it would not find at those ends, and one that reads only formats 1 to 5 refuses a record with offset rows.
