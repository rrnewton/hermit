pub fn requests_first_pass_sleep_registration(config: &Config) -> bool
Expand description

Whether config asks for queued sleeps to be registered at the first pass, before the backend’s limit: a replay that leaves --sleep-registration unset takes its record’s rule (a record that cannot be read counts as when-chosen; the replay’s own loader fails on it), and any other run Config::queued_sleeps_registered_at_first_pass. Scheduler::new registers at the first pass only when this holds and the scheduler reads a sleeper’s signal state (Config::reads_sleeper_signal_state), and hermit refuses a launch where this holds and that does not, before the guest starts.
