Module native_exec 

Source
Expand description

Inactive, backend-neutral validation of a prepared single-thread exec cut.

These APIs inspect actual Detcore data. They do not authorize kernel exec, observe a physical task, install a backend, or run a lifecycle callback. The caller must own the quiescent dispatch and separately prove the admitted one-main-thread/childless domain, physical identity and registrations. In particular, probing an Arc’s lock does not establish that no other task owns it. No ordinary exec path calls this module.

The transport consumer must bound the payload before allocation/decode, authenticate its exact bytes and Config, and reject trailing bytes. It must retain the same live cut through its final physical exec edge. Deserializing serde-skipped capabilities cannot reconstruct them; the live producer must validate them before preparing the replacement table.
