Module exec_record 

Source
Expand description

The image a process executes, which its /proc/<pid>/exe link names.

Detcore records it at each exec, on every backend, and checks it against the kernel’s own link when the exec completes (tool_global). The kernel’s answer is the file it exec’d, and a backend whose launcher loads the guest itself (SaBRe’s loader) has the kernel exec the launcher, so the kernel names the launcher; only there does Detcore answer the link from the record (Detcore::launched_exe). Everywhere else the kernel’s answer stands.

Only the path is recorded. Where the image ends, which a program-break model would need, is known only once the image is loaded, and nothing reads it yet.
