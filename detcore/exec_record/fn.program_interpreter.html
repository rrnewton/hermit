pub fn program_interpreter(path: &Path) -> Option<PathBuf>
Expand description

The program interpreter (PT_INTERP) the ELF64 image at path names, which the kernel opens and maps at the exec (load_elf_binary, fs/binfmt_elf.c), or None for any other file, an image without one, and one the caller cannot read. Like the kernel, this refuses a name shorter than 2 or longer than PATH_MAX bytes or one whose last byte is not NUL, and the name is the string up to its first NUL, which open_exec opens.
