Print canonical INFO messages after applying a caller-supplied record filter.

Every record is parsed and its level tag validated before keep_record is consulted. Existing callers should use write_canonical_info; backend adapters use this form to exclude transport-only records at their boundary. This low-level hook does not name the predicate, so any product verdict or JSON report using it must bind the function to a typed, serialized policy.
