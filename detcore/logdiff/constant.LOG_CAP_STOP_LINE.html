Expand description

The last line hermit’s --max-log-bytes cap writes before it ends the run with exit 123 (the class line of its stop message, without the newline).

A log that ends with this line stopped at the cap: whatever the run would have logged after it was never written, exactly as after TRUNCATION_MARKER. The cap’s writer in hermit-cli composes the line itself; its unit test runs the real stop message through log_was_truncated, which binds the two texts.
