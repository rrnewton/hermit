Compare only the records both logs have finished writing.

The tail of a log being written may be half-flushed, and a half-flushed record is not a difference – it is an absence. Truncating both inputs to their common complete prefix is what makes this safe to run against a live run: bytes that have not been written yet can never be mistaken for bytes that disagree.
