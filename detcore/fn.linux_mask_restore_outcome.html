pub fn linux_mask_restore_outcome(
    facts: &PendingMaskRestore,
) -> Result<MaskRestoreOutcome, UndecidableRestart>
Expand description

The outcome Linux’s do_signal takes for the restart code the facts name (arch/arm64/kernel/signal.c:1395-1464 at v6.12.9): with a handler, -EINTR for ERESTARTNOHAND and ERESTART_RESTARTBLOCK and a restart for ERESTARTNOINTR; with none, a restart for every code. Refuses the two cases it cannot decide (UndecidableRestart).
