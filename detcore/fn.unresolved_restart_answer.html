Detcore’s answer to a restart code its backend could not hand to the kernel (Tool::handle_unresolved_restart): an UnresolvedRestartRefusal that ends the run, unless Config::allow_unresolved_restart_codes admits it; then EINTR, Linux’s result for an interrupted call that does not restart, never the code itself, after the same refusal is logged as a warning.
