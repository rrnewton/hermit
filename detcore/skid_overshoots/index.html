Module skid_overshoots

Skid overshoots counted as events, not as reports.

Two sites report a precise PMU timer event that took effect past its target. Reverie reports it where its timer finds the thread past the target, usually with a [reverie::SkidOvershootDetail] naming the thread and the target. Detcore’s prehook reports it when the thread ran more branches since its last handler than its timer was armed for (record_rcb_overshoot_report, called by report_rcb_overshoot). Both increment Reverie’s process-global count ([reverie::record_skid_overshoot]), so one late event usually counts twice. That count stays a count of reports: a refusal, and --verify’s attribution of a divergence to skid, need only that it is nonzero, and Detcore’s report is what keeps it nonzero for an overshoot no Reverie site saw.

Detcore keys each report by thread and target, the pair a detail names, and SkidOvershootCounts::count counts a Detcore report whose pair matches a detail once.

The pair is matched rather than the order of detection, because the two sites detect in either order. Reverie records a late delivery before the Tool’s timer callback, whose prehook reports it again; it records an event that another stop overtook only when that stop is settled, after the Tool’s callback for the stop, and so after the prehook’s report and after any other thread the prehook yielded to has run.

skid_overshoot_counts
take_skid_overshoots’s counts, read without taking them, as a report written before the run’s final take does. Reverie returns its details only by taking them, so they are put back in order: unchanged, since this runs once the run’s threads have stopped and no site records in between, and all of them, since no more than Reverie keeps were taken. A Reverie accessor that reads the details without taking them, as reverie::skid_overshoot_count reads the count, would replace the take and re-record; that is the clean follow-up, left out of this change to keep Reverie’s pin.
take_skid_overshoots
Take every site’s skid overshoots since the last take: Reverie’s count and details and Detcore’s reports, counted with SkidOvershootCounts::count. Returns the details as well, in detection order.
