Coordinator-owned native exec transactions. No Tool is decoded or run here.

This inactive interface requires a trusted watched native launcher. A PID, ticket or socket credential alone is not proof that a kernel exec occurred. The launcher owns that unsafe contract, including the covered interpreter, protected bootstrap descriptors and successor-before-loader initialization.
