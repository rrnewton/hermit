Expand description

Existing full request wire type; native controls preserve its exact tags. This is public only so it can be used in the GlobalTool trait. It should NOT be used by any client outside of this file.

Variants§

§

WithForwardedCount(u64, Box<GlobalRequest>)

request, sent with the number of records this guest thread produced for forwarding since its previous counted request, so the coordinator can check they all arrived (detlog::check_forwarded_count). Sent only by a thread that has produced some (counted_request).

§

RequestResources(Resources, DetPid)

Lock the resources Also contains the DetPid of the process containing the thread requesting resources.

§

ParkedRequest(Resources, DetPid, ControlCapability)

Request resources with the actual backend parked-callback capability.

§

ResumeParkedRequest

Resume a previously parked request at its actual current callback site.

Fields

§ticket: ResumeTicket

Scheduler-issued one-use continuation ticket.

§current_site: CallbackSignalSite

Actual callback site supplied by the backend on resumption.

Finish the observation belonging to one scheduler-owned parked wait.

Actual pending wait identity.

§lease: ParkedObservationLease

Backend observation lease belonging to that wait.

§site: CallbackSignalSite

Actual callback site at the observation boundary.

§finish: ObservationFinish

Result of the observation, including an explicit failure.

Report a terminal violation of the parked continuation protocol.

Fields

Deterministic process whose signal was dequeued.

§identity: SignalTaskIdentity

Backend identity of the actual signal task.

§dequeue: SignalDequeue

Exact signal dequeue observation.

Release the locks

For convenience, release all the resources held by the current TID.

ReportUnsupportedSyscall(String)

Add a syscall to the run-wide unsupported-use summary.

§

AnnounceSignalHandlerNotInstalled(i32)

A guest asked for a disposition of this signal that Detcore answered with success but did not install. The coordinator announces it once per signal per run.

§

PolicyRefusal(String)

The fail-closed policy is ending the run, for this reason. Sent just before the Tool image exits with HERMIT_POLICY_REFUSAL_EXIT, which on an in-guest backend ends only the guest process: the launcher reads the reason here to report the refusal (GlobalState::policy_refusal).

§

PrepareExec(DetPid, MmId, Box<ExecFdState>)

Save the caller, address-space identity, and logically blocking descriptors before exec. A successful backend may reload the Tool or preserve and transfer its thread state. Boxed, as is GlobalResponse::MarkPastFirstExecve’s: inline, the largest payload sizes every RPC future, and each of the hundreds of handler futures handle_syscall_event awaits holds some, which in a debug build overflowed the 2 MiB test thread that runs ptrace record through the library (record_replay’s public_record_* tests).

§

CancelExec(DetPid)

Clear the saved transition after an exec attempt returns with an error.

§

ReconnectExec

Authenticate the preserved exec caller taking over its process leader’s TID.

Fields

§former: DetTid

Preserved caller before the kernel leader-identity transition.

§process: DetPid

Continuing process leader identity.

§

ResumeExec(DetPid)

Acquire the replacement’s first turn without newborn state initialization.

§

RetireExec

Consume a transferred owner if genuine cancellation interrupts local rebinding. The Tool copies signaled from the backend’s exit status; ordinary exit requires a separately recorded backend failure.

Fields

§thread: ThreadDeregistration

Final transferred thread state and accounting.

§signaled: bool

Whether the backend observed signal termination.

§

MarkPastFirstExecve(DetPid, Option<SignalTaskIdentity>, Option<ExecRecord>, Option<(u64, u64)>)

Complete a successful image transition, including the initial image, and delete the process’s POSIX timer deadlines before the new image runs. The last field is the device and inode of the file the kernel’s /proc/<pid>/exe link names for the new image, where the tool can read it, which the image’s record is checked against (crate::exec_record). Before it, in a run that declares a launcher, the record the new image resolved from the path its exec was given, for an exec Detcore did not prepare.

§

CreateChildThread(DetTid, DetPid, usize, Option<CloneFlags>, c_int, Option<(i32, i32)>, Option<Priority>)

The parent is adding a child-thread to the round-robin pool. Contains the dettid of the new child and it’s starting scheduler priority IF it is available to the caller. The only scenario where the Priority will be missing is when we’re replaying preemptions. In that case it is the global state that holds the information regarding the new thread’s initial priority.

§

CreateVforkChildThread(DetTid, DetPid, DetTid, usize, CloneFlags, c_int, Option<Priority>)

A vfork child registering itself while its parent is blocked inside the kernel. Contains the (real) parent dettid and detpid, the child dettid, the child TID address, the clone flags, and the starting priority (absent only when replaying preemptions).

§

StartNewThread(DetTid, DetPid, Option<(i32, i32)>, Option<SignalTaskIdentity>)

New thread is alive and waiting to run its first instruction. Contains the dettid and detpid of the new child.

Remove a thread from scheduler data structures, guaranteeing that it will consume no further turns. Carries its final timeslice distribution and any chaos-epoch transitions not yet flushed by a priority-change commit.
