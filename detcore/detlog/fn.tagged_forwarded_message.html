pub fn tagged_forwarded_message(tid: i32, index: u64, line: &[u8]) -> Vec<u8> ⓘ
Expand description

Prefixes a forwarded record with the id of the guest thread that sent it and the record’s index in that thread’s counted interval, T<tid>.<index> , so the coordinator can write each thread’s records at that thread’s own scheduler turn (write_forwarded_for) and check that it holds exactly the records the thread produced, in order (check_forwarded_count). The coordinator strips the tag before the record reaches the log.
