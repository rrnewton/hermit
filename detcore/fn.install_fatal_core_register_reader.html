pub fn install_fatal_core_register_reader(read: RegisterReader) -> bool
Expand description

Installs read, which gives a core the general registers of each of its threads but the offered one as the backend’s tracer holds them. Returns false if one was installed already. Without one, a core holds the kernel’s copy of those registers.

The two can differ. Reverie’s ptrace backend keeps a register write it makes at a stop in its own cache, and hands it to the kernel only when the thread runs again or a request reads the kernel’s copy. A thread that Detcore parks after Reverie ran a syscall for it on Reverie’s private page keeps that syscall’s registers in the kernel, with its instruction pointer in that page, while its own registers wait in the cache; a fatal signal takes it to its exit stop without the write. The offered thread’s registers ([FatalSignalExit::regs]) already come from that cache. Read from the kernel, every other parked thread’s would not, and which thread is offered first is decided by host timing, so two runs of one guest could keep different cores.

The crate that hosts Detcore on the ptrace backend calls this before the tracer starts.
