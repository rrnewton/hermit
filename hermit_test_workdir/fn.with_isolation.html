Expand description

Run on a new host thread in a new mount namespace with the requested mounts and, for local networking, a new network namespace with only loopback.

The same contract as with_isolated_workdir: CAP_SYS_ADMIN is required, every setup error returns before the callback can launch a guest, and the mounts disappear with the namespace. Local networking also needs CAP_NET_ADMIN to bring loopback up; failure never falls back to host networking. A bind target must be a normal absolute path strictly below /tmp; a bind source and a preserved path are resolved before /tmp is replaced, so they may lie below the original /tmp.
