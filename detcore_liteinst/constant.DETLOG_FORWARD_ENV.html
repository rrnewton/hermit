Private opt-in, set by Hermit, for forwarding the in-guest Tool’s deterministic INFO records: the number and identity of an inherited socket (the sending end of a Unix SOCK_SEQPACKET pair) to send them on (detcore::detlog::tool_output_env_value). The constructor removes it from the guest’s environment (scrubbing its bytes), refuses to start when the number no longer names that socket (guest .preinit_array code, which runs before this constructor, closed it or put a socket of its own there), moves the socket to a number Reverie reserves and protects from the guest (reverie_liteinst::reserve_tool_output_fd), and sends each record there as one message, where Hermit’s --verify reads them into the run’s log. The guest cannot write to, close or shut down that socket, so its own output never mixes with the records.
