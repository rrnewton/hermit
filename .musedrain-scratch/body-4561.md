## Why

A full `--log=info` log of a real build step is large: 817 MB for one 116-package dnf transaction. So nobody keeps it on in every build, and when a build that ran without it does not reproduce, the evidence is gone. That is the TTS CVM INSTALLTIME drift today. Hermit had no bounded in-memory log; CI's `--log-tail-bytes` covers guest logs only.

## What

`hermit --log-ring=SIZE --log-ring-file=FILE run ...` keeps the newest SIZE bytes of hermit's log in FILE, at the `--log` level or INFO if that is quieter.

- FILE is a 64-byte header plus a SIZE-byte circular data area, mapped shared into hermit. Each tracing record is copied in as `[u32 length][bytes]`.
  - The header's end position moves only after a copy, and the oldest position moves before anything is overwritten.
  - So the file holds the newest whole records however hermit ends: normal exit, error, panic, the container processes' `_exit`, or SIGKILL. Nothing has to run at exit.
- Other logging (`--log-file` or stderr) is unchanged; the ring is a second tracing layer with its own filter.
- Like `--log-file`, FILE is opened on the host before the container exists.
- `hermit log-diff FILE` decodes a ring file into a log, starting with a DEBUG record naming how many older records were dropped. `hermit log-diff A B` compares ring files with each other or with ordinary logs.

## Tests

- `log_ring::tests::the_file_keeps_the_newest_whole_records_in_order`: 2000 records into a 4 KiB ring; the decoded file is exactly the newest whole records, and the header reports the dropped count.
- `log_ring::tests::oversized_records_keep_their_tail_and_other_files_are_not_rings`: a record longer than the ring keeps its tail; a non-ring file is passed through; a ring under 4 KiB is refused.
- `log_ring_keeps_the_end_of_the_info_log_and_log_diff_reads_it` (cli): two runs of `/bin/true` with `--log=info --log-file` and a 16 KiB ring. The ring's records, printed by `log-diff FILE`, are exactly the end of the full log's; the file is 16 KiB + 64 bytes; the two runs' rings compare equal.
- By hand, through `bin/safehermit`:
  - With a 64 KiB ring, `ls /etc` kept its last 342 lines, including the run summary.
  - After SIGKILL of a running hermit (exit 137), a 16 KiB ring held whole records up to syscall #15208.
- clippy and rustfmt are clean. Full validation has not been run.

## Cost

One memory copy of each formatted record at the ring's level. The formatting is the cost `--log=info` already has: it is skipped today when nothing logs at INFO, and the ring turns it on. Measuring that cost on a real build is part of the always-on trace design (item 4); this PR does not claim it.
