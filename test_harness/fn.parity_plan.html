The verify cells whose comparisons decide which ptrace verify runs name the parity golden’s CPU profile (runner::PARITY_GOLDEN_PROFILE_ARG): planned_verify, this run’s own verify cells, or with --parity-plan-of-test the verify cells of a run of the same filters without --mode and --backend, which is the plan of the whole test.

A category run plans a test’s ptrace verify cell beside its candidates, so that cell names x86-64-v2. ci/buck-e2e/cell.sh runs every Buck cell alone (--test --mode --backend), so its own plan holds one cell, no comparison, and the same cell ran auto (x86-64-v3 on a qualifying host), another CPU than Cargo validation presents. With the flag a cell run alone names the profile a run of its test names.
