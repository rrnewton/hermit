Expand description

How the warning Hermit prints on a host whose retired-branch counter failed Reverie’s validation begins. The rest of the line names the command’s consequence and Reverie’s reason, whose measured counts differ from one process to the next, so a comparison of two runs’ output drops the line by this prefix; sharing it keeps such filters in step with the warning.
