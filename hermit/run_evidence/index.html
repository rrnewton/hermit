Module run_evidence 

Source
Expand description

Typed evidence for one ordinary hermit run invocation.

This is deliberately distinct from crate::canonical_verdict: verification compares two runs, while this report binds one run’s disposition to one complete canonical-INFO input. A consumer must still compare two validated reports before making a determinism claim.
