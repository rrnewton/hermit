Typed machine-readable reports produced by hermit log-diff --json.

This lives in the library rather than the CLI module because the manifest runner and scorecard consume the report. Keeping one producer-owned type is what prevents a textual log-diff success banner from becoming a parity verdict after the producer changes shape.
