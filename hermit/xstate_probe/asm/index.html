hermit::xstate_probe

Module asm 

Source
Expand description

The probe’s measured windows, written in assembly (https://github.com/rrnewton/hermit/issues/4243).

Each arm runs from “every register of every enabled component holds a known value” through “the case’s initializing step” to “XSAVE of every enabled component” inside one assembly function. No compiler-generated code runs in that window, so nothing Rust emits (a memcpy using SSE, say) can change the state being measured. The Rust driver prepares the buffers before a call and reads the certificates (interrupt counter, getrusage, schedstat) outside it.
