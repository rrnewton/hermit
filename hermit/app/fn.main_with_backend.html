pub fn main_with_backend<A: BackendAdapter>(adapter: A)
Expand description

Run the shared application with this executable’s one linked backend.

The executable must retain the same preinit stdin reservation as hermit. Its identity selects the adapter directly; no built-in backend enum value or injected argument is needed. An explicit shared –backend selector must match that identity. Ordinary main is unchanged.
