The one statically selected application’s physical-backend boundary.

An executable supplies one concrete adapter to super::main_with_backend. The common application still owns entry, argument parsing, input snapshots, run disposition, comparison and publication. In particular neither a physical capture nor backend facts are a verification verdict.
