Expand description

One statically linked physical adapter, never a registry or a verdict owner.

The selected executable supplies its own concrete options and state. None of these public types depends on a third-party backend enum or feature.

fn prepare_record_program( &self, _target: &Path, ) -> Result<Option<PathBuf>, Error>

Prepare only the supplied core-resolved original program. Return the rewritten file, or None when no overlay is required; this callback cannot select mounts or run a second recorder. Called at each actual recording-container preparation, after common admission.

Source

fn strace(&self, _program: &Path, _args: &[String]) -> Result<ExitStatus, Error>

Run only this executable’s admitted physical tracer. Common logging admission has already completed; this hook cannot select a verdict.

Source

fn validate_mode(&self, mode: Mode) -> Result<(), Error>

Static operation support, checked before input/resource/writer work. This must not probe a runtime or create resources. Saved execution is opt-in only after the adapter uses the real core capture and, for native evidence, implements the raw save/restore owner callbacks below.

Source

fn save_native_evidence( &self, _facts: &Self::Facts, ) -> Result<SavedNativeEvidence, Error>

Preserve the backend’s validated raw native records for the core-owned saved-run writer. This is not a serialization of comparison summaries.

Source

fn restore_native_evidence( &self, _evidence: SavedNativeEvidenceRef<'_>, ) -> Result<Self::Facts, Error>

Restore through the same native decoder and refusal policy as a live run. The core still compares the complete pair_evidence dimensions.
