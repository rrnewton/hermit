pub fn rcb_history_refusal(
    config: &DetConfig,
    inputs: &[(&str, &Path)],
) -> Result<Option<String>>
Expand description

The RCB clock identity refusal Detcore’s replay admission would give a run prepared with config ([prepare_backend_config]) for the histories in inputs, each an option and a path, or None when its effective RCB clock admits their identities. An early diagnostic of identity only: it does not check a history’s strict or legacy mode, which Detcore checks when the run starts, as it checks identity again. It reads CPUID and the process’s PMU state, installs and pins nothing, so a --skid-margin recorded later still applies. A history in a format this build refuses is a refusal; an otherwise unreadable history is an error, not a refusal.
