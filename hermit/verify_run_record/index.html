Module verify_run_record 

Source
Expand description

Producer-owned record and raw streams for one retained verification run. Producer-owned wire record and raw streams for one retained execution.

The CLI writes the final record after the output files. Both the CLI comparator and the manifest runner read this schema; policy stays with those consumers.
