pub fn cached_rewrite(

Expand description

The cache entry holding rewritten, the rewrite of source, which the overlay bind-mounts over the path the guest loads source from; written if need be.

The entry is named by everything that decides the bytes the guest maps: the rewriter’s format, a digest of the rewritten bytes themselves, and the source’s permissions, which the copy carries (elf::write_rewritten); name, the source’s file name, is there for a reader. So two runs that would map different bytes – two builds of the rewriter, say – never share an entry, and what one run checked cannot be replaced by another run’s bytes before it mounts it. Nor is an entry ever written in place: a missing one, or one that does not hold the bytes and the mode its name promises, is written whole under a temporary name and renamed over the name, so a run that already mounted the file it replaces keeps that file.
