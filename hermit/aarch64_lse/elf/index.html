hermit::aarch64_lse

Module elf 

Source
Expand description

Writing rewritten aarch64 ELF files. The rewrite itself, a pure function of a file’s bytes, is Detcore’s (detcore::aarch64_lse::elf), because Detcore also applies it to a guest’s mapped pages; this module adds the files the overlay and hermit rewrite-exclusives write.

Functions§

plan_bytes
Decide the rewrite of bytes without applying it: the report rewrite_bytes gives, and each replacement as a FilePatch. A caller that applies the replacements somewhere other than the file (a process’s mapped pages) gets exactly the bytes a rewritten file would hold. Like rewrite_bytes, it rewrites only what mapping symbols prove is code.
rewrite_bytes
Rewrite the executable segments of bytes in place.
rewrite_file
Read input, rewrite it, and write the result to output with input’s permissions.
write_rewritten
Write already-rewritten bytes to output, with source’s permissions.
