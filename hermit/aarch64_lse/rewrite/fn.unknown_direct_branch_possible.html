pub fn unknown_direct_branch_possible(word: u32) -> bool

Whether word might be a direct branch whose target is unknown.

The entry protection fails closed BY CONSTRUCTION: it is a positive allow-list of the top-level encoding classes (bits 28:25) that are positively known to contain no PC-relative direct branch, each matched by its documented fixed bits:

  • 01xx: data processing (register) and scalar FP/SIMD — no branch encodings at all;
  • 100x: data processing (immediate), including ADR/ADRP, which compute an address but never transfer control;
  • 11xx: loads/stores and data processing (register) — literal loads read memory, nothing here jumps;
  • 0010: the SVE encodings. The Arm Architecture Reference Manual for A-profile (DDI 0487), section C4.1, “A64 instruction set encoding”, assigns this top-level class (op1, bits 28:25) to SVE alone, and none of its instructions writes the PC: SVE has no branch. Its predicate-generating and compare-and-terminate instructions set the condition flags, and control flow on them is a base A64 conditional branch, which decode recognises.

Every other word the decoder does not recognise is a possible direct branch with an unknown target: the reserved (0000, SME) and UNALLOCATED (0001, 0011) top-level classes, any future extension, and everything in the branch/exception/system group (101x) beyond its positively known non-direct members — exception generation (11010100: SVC/HVC/SMC/BRK and kin, which trap), the system/hint space (11010101: MSR/MRS, barriers, hints, CLREX), and the indirect branch/return forms (1101011 with BR/BLR/RET/ERET/DRPS opcodes), which have no computable image target here. Known direct branches are decoded by decode and never reach this predicate as Other.

One encoding in the reserved class is positively known too: UDF #imm16, bits 31:16 all zero, is permanently undefined (Arm Architecture Reference Manual for A-profile, DDI 0487, A64 base instruction UDF, “Permanently Undefined”: encoding 0000 0000 0000 0000 imm16). It raises an Undefined Instruction exception and never transfers control to a target, so it cannot enter a sequence. Zero words are the padding that bytes no mapping symbol marks are full of.
