pub fn name_libc_need(auto: AutoChoice, libc_v3: bool) -> AutoChoice
Expand description

Names the C library in an x86-64-v3 the host admitted (admitted) for a program whose C library declares that it needs x86-64-v3 (libc_v3, libc_needs_v3), with LIBC_V3_DETAIL: that declaration is why the program runs at x86-64-v2 on no host. hermit run and hermit record start both name it, so the two record the same choice for one program and host. Every other choice is left as it is.
