Exact compatibility for a separately linked CLI backend executable.

This is separate from the closed presentation/recording BuildInfo schema. Equal ELF build IDs are neither expected nor used: the executables differ, but must contain the same measured core source/API and build cohort. Matching this record is not runtime qualification or publisher attestation.
