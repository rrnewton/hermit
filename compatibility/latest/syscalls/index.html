Syscall coverage

Linux syscalls the passing tests exercise, by backend, and how Hermit handled each.

Which Linux syscalls the tests exercise on each backend, and what Hermit did with them. Each passing cell contributes one execution: the first run of the validation result the site shows as the cell's latest, never a verification's second run, a retry or a pressure repetition. A count is the sum over those cells.

On backends whose runtime starts inside the program (LiteInst, in-guest-trap, SaBRe) the dynamic loader runs before the runtime, so its syscalls are not counted; those histograms are marked partial. A passing cell without a histogram (recorded before histograms existed) is shown as missing, not as zero use.
