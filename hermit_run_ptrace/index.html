Hermit’s plain (neither recording nor replaying) ptrace run, and the one place its Detcore instantiation is rooted.

detcore::Detcore under reverie_ptrace‘s TracedTask is a large instantiation. In its own crate it builds in a separate rustc process, beside the other backends’ instantiations. The entry point, spawn_tracer, is not generic and returns a boxed future, so its callers instantiate nothing of it (see hermit-record for why it is boxed).

spawn_tracer
Spawns COMMAND under Detcore with CONFIG on the ptrace backend, collecting backend statistics as STATS requests. When GDBSERVER names a port, a gdb remote is served there; SEQUENTIALIZED_GUEST then tells gdbserver that Detcore already sequentializes the guest’s threads.
