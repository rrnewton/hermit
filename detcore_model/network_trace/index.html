Module network_trace 

Source
Expand description

Versioned data model for schedule-independent external network input.

This module deliberately contains no recorder, replayer, or scheduler hook. It defines the fail-closed v1 envelope and its framing so a future runtime integration cannot accidentally reuse the schedule-coupled syscall event stream. Merely constructing a NetworkTraceConfig does not enable any behavior today.
