Module canonical_test_epoch 

Source
Expand description

The one virtual-time epoch tests and E2E cells pass when they need a fixed one, as --epoch or HERMIT_EPOCH: hermit run --strict refuses a run whose epoch would come from the host clock. Bump it here and nowhere else.

This file has no dependencies, so a rust-script that renders Hermit commands includes it with #[path] rather than depending on this crate.
