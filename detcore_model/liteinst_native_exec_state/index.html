Exact versioned neutral cut envelope outside opaque Tool state. Exact neutral identity envelope around opaque Tool and backend state.

These are authenticated transport data, never native-exec authority. The registry must independently join the cut to its real scheduler/watch owner. Old descriptor-table identity originates in the trusted live guest receipt; the host does not reconstruct it from kernel descriptors or decode a Tool.
