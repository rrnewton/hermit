pub fn parse_fdinfo_mount_id(contents: &[u8]) -> Option<u64>

Parse the one decimal mnt_id field required by Linux fdinfo.

Missing, duplicate, malformed, signed, or out-of-range values are rejected. Keeping this byte parser below both hermit-cli and detcore prevents the container capture path from accepting input the guest-visible sanitizer would later refuse.
