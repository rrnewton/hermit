Bounded InitialImage launch packet shared by the host and private runtime.

Packet bytes, nonce and file seals are not authorization. The coordinator separately redeems a one-use launch instance against its actual process watch. Decoding validates the complete byte shape without allocating. Only the host encodes packets; the private initializer consumes borrowed fields.
