Module liteinst_native_exec_input 

Source
Expand description

Separate, inactive native Initial/Successor bootstrap input data.

No decoder fallback to HLIINIT1 exists. Packet bytes, socket identities, nonces, tickets and digests are not admission or kernel-exec authority. A future trusted native consumer must compare independently held expectations, verify distinct protected actual sockets, and redeem its one-use instance. The runtime/Tool composite is delivered separately on the bounded state path.
