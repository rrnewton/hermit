# Batch 101 Handoff

## What I Was Working On

Task `impl-debug-batch-101`: diagnose and fix three distinct ptrace failures under
`hermit --log=debug run --strict --verify`:

- GNU `timeout 1 sleep 5` did not expire.
- A one-shot POSIX timer was not consumable through `sigtimedwait`.
- A blocked one-shot POSIX timer signal was not consumable through `signalfd`.

The implementation adds independent process-local POSIX timer events to the
deterministic scheduler, cancellation/rearm/exit cleanup, and Linux `SI_TIMER`
metadata delivery. It also adds C and Rust integration coverage.

## Blockers And Issues

Reverie's ptrace signal event API uses `nix::Signal`, which excludes realtime
signals. Blocked realtime signals can remain kernel-pending for synchronous
consumption, but unblocked realtime delivery must be explicitly rejected or
requires a coordinated Reverie API change. Review also found exec lifecycle and
multithread process-directed delivery gaps described above.
